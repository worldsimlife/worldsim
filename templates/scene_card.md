# scene_card.md 模板

创建新场景时复制此模板，用实际内容替换 `<!-- -->` 中的占位文本。

| 字段 | 内容 |
|------|------|
| 场景ID | `<!-- SXX，递增 -->` |
| 场景名 | `<!-- 中文名，如"档案室" -->` |
| 类型(INT/EXT) | `<!-- INT = 室内, EXT = 室外 -->` |
| 基准时间 | `<!-- 第N日 HH:MM -->` |
| 出场角色 | `<!-- 角色名(PC/状态), 逗号分隔 -->` |
| 场景目标 | `<!-- 一句话目标 -->` |
| 前情钩子 | `<!-- 为什么角色来到这里 -->` |

存入 `{世界名}/scenes/{场景ID}-{场景名}/scene_card.md`。
