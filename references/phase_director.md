# 阶段③ · 导演（现场引擎·阶段开始前必读）

> 定位：**事件线与实时演出之间的控制器**——回答「这一拍现在演到哪里了？」。只产出轻量「导演决策状态」（direction·核心三件=**演出状态/承接判断/节拍决策**）。
> 全局铁律=SKILL.md「通用约束」。Single Writer：direction

## 数据就绪（本阶段开头）

storylines ＋ conflicts ＋ 上轮事实（scene_state 场景时间线＋焦内 CHAR_state 连续行动轨迹本轮条目）＋ scene_state 出场摘要（焦内）＋ pending_actions（焦外事实）＋ direction 旧值 ＋ in-track 只读查询（`worldctl.py <世界> in-track`·循环角色预设此刻应在哪/做什么）。

## 职责

1. **回判（每轮第一动作·判定后置不变量）**——上轮实际演出结果 vs 当前拍戏剧问题，十问：
   当前拍是否仍有戏？当前戏剧问题有没有继续发展？张力是在上升、下降还是停滞？角色行动是否产生有效变化？是否需要继续当前拍？是否已经回答当前拍问题？是否应该推进下一拍？是否应该切换空间？是否应该进入转折？**是否出现意外事件导致原计划需要调整？**
   判定输出：已兑现 → `###BEAT: advance SL-XX 下一拍名`（顶点拍=advance 余波·出线核验——出线后线已演完·由②编剧 `close` 收束并建后继线）；未兑现且当前拍问题正被逼近（张力上升或有明确逼近路径）→ `###BEAT: stay SL-XX`——**承接判断必须写出「怎么逼近的」·写不出=按停滞处理；上轮节拍决策已是「继续当前拍」而本轮仍不推进 → 本批写 `escalation_flags.停滞`（gate 核验）→ ①戏剧家次轮必须加压——余波拍除外：线已演完·出口=②编剧 close 收束·不加压**；线间失焦（新事件夺焦·本线前提与戏剧问题仍成立·已有活跃线可接焦）→ 节拍决策=切换事件线 → `###BEAT: set <目标线> <该线拍>`——原线保留（非焦点=自然挂起）；不承接（空间/时间/事件漂移·意外事件致原计划失效）→ escalation flag → ②编剧次轮三问定原线去向（保留+建新线接焦/rewrite/clear·判据见 phase_storyliner 职责2）；无实质进展（仅寒暄/走位/状态滚动不算进展）→ 演出状态=停滞 → escalation flag → ①戏剧家次轮兜底。停滞旗标已消化（上轮戏剧家已加压·推进池 CT 施压方向≠维持）→ 本批写 `escalation_flags: {}` 清除。
2. **自然完成判进（导演不是剧情警察）**：不强迫角色把事件线演完——观察实际发生的戏，判断当前拍问题是否已被**自然地实质性回答**；回答来自任何涌现路径（不限于编剧预设的兑现形态）即推进。模式锚定：
   - 编剧规划「拍2：Gunslinger 能否阻止 Angela 接近玩家？」→ 实际演出：Angela 主动拉拢玩家 → Gunslinger 没有阻止 → 玩家反而怀疑 Angela → Angela 暴露出异常 → Gunslinger 抓住机会 → 导演发现「阻止接近」已获实质性回答 → 推进拍3「Angela 是否会暴露真实意图？」——**而不是强行让 Gunslinger 执行编剧安排**。
   - 三方分工：**编剧有结构、角色有自由、导演有现场判断力。**
3. **演出状态评定**：上升/持续/转折/收束/停滞；同批写**承接判断**（当前拍继续的理由 或 进入下一拍的理由）——与节拍决策合为核心三件留痕。
4. **本轮指导 guidance**（≤5 行·硬性）：当前戏剧问题＋张力方向＋焦点提示——张力方向取材推进池 CT 的施压方向（瞄准转译·非复制）。当前拍=顶点 → 焦点提示必含两项：**核心张力**（顶点约束声明的、本场关系必须被推至的**转变临界**——它是顶点的**目的**，演出与叙事的一切手段围绕它收拢）＋**非玩家爆破指向**（外部加压源·防主体静止死锁——它是逼出临界的**手段**，时机与形式自由；**手段服从目的**：爆破落地的唯一验收＝核心张力是否被推至临界——禁止替代摊牌、取消摊牌、或只为打断而打断）。爆破源为具名外部角色 → 调度单按「即将触发事件」纳入登场考量。**禁预写角色行动**（「导演控制现在这一拍，而不是预写角色的行为」）。涉及用户角色定性抉择 → 标记抉择悬崖（NPC 照常行动·照常兑现自己的冲突线）。
5. **场景切换判定**（每轮两问·任一为是→写 `转场.目标场景/理由` → ⑤场记执行 init_scene）：① 焦点角色的 REGION.md 节点 ≠ 焦点场景 scene_card「区域」节点？（有 regions/ 目录树时以此为准·round-check 机械复核）② 时间区间跨越（跨天必切）？无目录树的迷雾制世界按 scene_management §移动场景协议 既有规则判断。
6. **时间窗口设定**：本轮时间预算（如 10-20 分钟）写入 direction——④调度节流依据（窗口耗尽或无新受影响者→行动链收敛）。
7. **调度单（画面调度·决定谁入画）**： 读 推进池CT.关联角色 + scene_state（焦内）+ pending_actions（焦外）+ in-track（循环角色预设此刻应在哪/做什么）→ 判定本轮焦内活跃/背景/焦外·登场退场·是否触发焦外→焦内（§主动接近协议）→ 写 direction.调度单。判定标准（通用）：在场景＋冲突/戏剧焦点＋用户指令涉及＋即将触发事件。 **调度单角色一律写 CHAR_{名} 具名条目；仅无 CHAR_.md 的背景可标群像**
8. **顶点出线核验**：advance 余波时 `gate director --check` 自动比对——顶点约束齐备（关系主体≥2/核心张力/变化维度/非玩家爆破）＋基准快照存在＋**关系主体的实质状态发生真实变化**＋承接判断含两行表态：`爆破兑现：<事实>` 或 `爆破豁免：<理由>`（对设计承诺表态·防爆破要素被静默丢弃）＋`张力结算：<核心张力是否被推至临界·以何为凭>`（对设计目的表态——判定未达临界须附 `张力去向：<登记进余波/后继线的承接方式>`·张力未落地的顶点不允许静默出线）；缺项 exit 1=批次拦截·撤回本阶段。脚本验收、演出交给现场——验收对比面不预先声明（信念演化/防御重构/自主性等最高级改变不公开为验收靶子）。

## 写入（direction 唯一写者·###BEAT 自动执行）

**字段写语义（键/格式/约束）以 keys.md「direction.yaml」节为权威·批次与写入通道以 references/write_protocol.md 为权威——本节只列动作与触发。**

```
###STAGE: 导演
###META: 回判 兑现✗/进展✓/承接✓ 演出状态=上升 窗口=15分钟
###BEAT: stay SL-02
###FILE: direction
###KEY: 承接判断
铺垫问题未兑现·但访客试探推进了信息揭露——stay
###KEY: 当前张力
访客步步逼近·T 防守收紧
###KEY: 演出状态
上升
###KEY: 节拍决策
继续当前拍
###KEY: 调度单
焦内活跃=A,B · 背景=C · 焦外=D（可揭示）· 焦外→焦内=无
```

**防镜像（validate 拦截）**：只引用不复制——焦点场景=world_state 权威·CT 紧迫度=conflicts 权威·拍序=storylines 权威；「当前张力」是拍级趋势评估（一行定性），不是 CT 紧迫度的数值复制。
