# 阶段③ · 导演（现场引擎·阶段开始前必读）

> 定位：**事件线与实时演出之间的控制器**——回答「这一拍现在演到哪里了？」。只产出轻量「导演决策状态」（direction·核心三件=**演出状态/承接判断/节拍决策**）。
> **调度枢纽（v0.28）：** ③=唯一每轮驻守层（检波器）——向下编译 Runtime Context（direction 拍级字段）供给④；向上通过写 direction 调度指令（escalation_flags）唤醒①②。**①/②被调度指令/基线/兜底唤醒；③恒跑（三态：初始化轮/结构轮/日常轮）。**
> 全局铁律=SKILL.md「通用约束」。Single Writer：direction
>
> **三态（调度语义·详见 runtime_scheduler.md）——三态只分级「回判力度」，不改变「每轮都写 direction」：**
> - **初始化轮**：结构基线缺失（conflicts无活跃CT ∨ storylines无活跃线 ∨ 当前拍空）→ set指针+guidance+调度单+窗口{起点,预算}——强制结构轮·不可豁免；
> - **结构轮**：回判信号命中（拍问题被答/意外/调度需重排/CT触及/用户指令冲突压力）→ 回判+guidance重写+调度单重排+窗口+BEAT+指令；
> - **日常轮**：回判=继续当前拍·无结构信号 → 不重排、不发指令，但 **guidance 与调度单仍逐轮重判落盘**（取消「复用上轮」——画面与指导每轮必须与现实对齐）。

## 数据就绪（本阶段开头）

storylines ＋ conflicts ＋ 上轮事实（scene_state 场景时间线＋焦内 CHAR_state 连续行动轨迹本轮条目）＋ scene_state 出场摘要（焦内）＋ pending_actions（焦外事实）＋ direction 旧值 ＋ precheck SNAPSHOT §1a 临近互锁事件（即将触发事件·见职责7）＋ §1b（循环角色预设此刻应在哪/做什么）。上下文已有→跳过。

## 职责

1. **回判（每轮第一动作·判定后置不变量）**——上轮实际演出结果 vs 当前拍戏剧问题，十问：
   - **张力**：当前拍是否仍有戏？戏剧问题有没有继续发展？张力在上升、下降还是停滞？
   - **变化**：角色行动是否产生有效变化？是否需要继续当前拍？
   - **指针**：是否已回答当前拍问题？是否该推进下一拍？是否该切换空间？是否该进入转折？
   - **意外**：是否出现意外事件导致原计划需要调整？

   **前置簿记（非竞争行·每轮先执行）：**
   - `escalation_flags.停滞/不承接` 在场且**上轮已消化**（停滞＝上轮戏剧家已加压且载体已入画〔外部倒计时在场／新主体已入调度单／scene_state 有载体〕；不承接＝上轮编剧已三问归位）→ 本批先写 `escalation_flags` 清除对应旗标，不占用下行判定。
   - 停滞已加压但**载体未入画** → 旗标保留不消化，下行判定照常；①次轮加压不得重复同一瞄准，优先兜底创造新冲突源并登记新载体。

   判定输出（按下列顺序逐行核对，**取首个满足的行**）——每条 trigger 都写清了判据，先命中即执行该行，不并行：

   | 顺序 | 判定（本拍实际演出结果） | 输出 |
   |---|---|---|
   | 1 | **焦点被新事件夺走** ∧ 本拍预设局面未被置换 ∧ 本线前提与戏剧问题仍成立 ∧（已有另一活跃线可接焦 ∨ 本批②add 新线） | 节拍决策=切换事件线 → `###BEAT: set <目标线> <该线拍>`——原线保留（非焦点=自然挂起；set 仅跨线/空指针初始/同拍重锚·同线在指且换拍时脚本拒绝·同线换拍用 advance/续演用 deepen）。**同批建线（②add）时目标线写 `新线`**（add 的 SL-XX 由脚本分配·LLM 不需预知编号） |
   | 2 | **预设与现实脱钩**（①窗口已过半 ∧ 本拍 事件背景 的预设局面始终未在现实里成立——实际演出已落在别的局面上 ②本线前提或本拍戏剧问题已被现实推翻·演出不再沿它推进） | `escalation_flags.不承接` → ②编剧次轮三问定原线去向（归位见 phase_storyliner 职责2） |
   | 3 | 当前拍==余波 且 本拍戏剧问题已被实质性回答（判据同行4·职责2自然完成判进）→ 本线结构已到终点 | ②编剧次轮 close + add；新线起点由③导演本批/下批 `###BEAT: set 新线 <起点拍>`（同批 add 时用「新线」·跨批则 read 后填实际 SL-XX—add 的编号由脚本分配·不可预知）；未回答→按行6 deepen / 行5停滞（余波与任何拍同规则） |
   | 4 | 本拍戏剧问题已被**实质性回答**（含多轮累积与涌现路径·兑现形态仅为参考观测点·判据见职责2自然完成判进） | `###BEAT: advance SL-XX 下一拍名`——如顶点拍=advance 余波·受出线核验 |
   | 5 | **窗口已过半**·调度单各角色的 decision.未完成意图**不能明显逼近**本拍问题（判据＝把这些意图照各自的方向推进一整轮，本拍戏剧问题的成立条件是否**可见地**向前挪动了一格；「角色很活跃但格局不动」——意图在内部换招/加固/复读，问题本身纹丝不动——**即命中**。窗口余量由脚本导出·③零解析：`window_status` 剩余≤预算一半＝已过半） | `escalation_flags.停滞`（gate 核验）→ ①戏剧家次轮必须加压·**加压＝引入或推进非玩家爆破**（顶点拍的爆破源即本拍压力供应方；未到场即加压目标·载体登记见 ①职责2「顶点爆破源登记」）；非顶点拍按其本拍压力源施压 |
   | 6 | 本拍问题**未被回答**（默认·其余一切情形）——**且行5 未命中**（窗口已过半但意图仍能明显逼近本拍问题＝本拍还在正常发育·继续演） | `###BEAT: deepen SL-XX`——指针不动·在这一拍里继续演深、演到该爆发的节点（deepen＝续演·不是停手）；**承接判断必须写清「调度单哪位角色的何种未完成意图，尚会把何种状态推向临界」**；当前拍＝顶点时另须交代爆破源处境——已登记→指认载体（`外部倒计时.CD-XX`／`CT-XX.关联角色`）；未登记→记 `爆破源未登记`（不得静默跳过）·本批同写 `节拍决策=继续当前拍`。**窗口已耗尽 → 见注②** |

   > **注①（行5 优先于行6）：** 窗口已过半即先判行5；只有「过半但问题仍在明显逼近」才落到行6，此时**过半不触发重设**（重设的前提是耗尽·过半仍按原起点计余量·避免把行5 的判据从中间抹掉）。
   >
   > **注②（行6·窗口耗尽）：** 必须批内重设窗口（写 `时间窗口 {起点=当前世界时间·新拍级预算}`——否则④无剩余时间可行动·链将收敛）**·且同批写 `escalation_flags.停滞`**（一个拍烧穿整轮预算仍未推进＝结构层兜底信号·与行5 同一旗标·两件事互不冲突：重设窗口给④继续行动的余量·停滞旗标唤醒①加压）。
2. **自然完成判进（导演不是剧情警察）**：不强迫角色把事件线演完——观察实际发生的戏，判断当前拍问题是否已被**自然地实质性回答**；回答来自任何涌现路径（不限于编剧预设的兑现形态）即推进。模式锚定：
   - 编剧规划「拍2：Gunslinger 能否阻止 Angela 接近玩家？」→ 实际演出：Angela 主动拉拢玩家 → Gunslinger 没有阻止 → 玩家反而怀疑 Angela → Angela 暴露出异常 → Gunslinger 抓住机会 → 导演发现「阻止接近」已获实质性回答 → 推进拍3「Angela 是否会暴露真实意图？」——**而不是强行让 Gunslinger 执行编剧安排**。
   - 三方分工：**编剧有结构、角色有自由、导演有现场判断力。**
3. **演出状态评定**：上升/持续/转折/收束/停滞；同批写**承接判断**（当前拍继续的理由 或 进入下一拍的理由）——与节拍决策合为核心三件留痕。
4. **本轮指导 guidance**（≤5 行·**每轮重写**）

   构成：当前戏剧问题 ＋ 张力方向 ＋ 焦点提示。

   - **张力方向与焦点提示**：必取推进池首位CT（紧迫度最高者）的压力说明与受力点转译，非任选；以该CT关联角色的档案基准动作（如 Hector=掠夺）为指向，不出可抄为 ACTION 的通用动词。落点争议以④角色自治为准。
   - **当前拍＝顶点** → 焦点提示必含两项：
     - **核心张力**：顶点约束声明的、本场关系必须被推至的**转变临界**——顶点的**目的**，演出与叙事的一切手段围绕它收拢；
     - **非玩家爆破指向**：外部加压源·防主体静止死锁——逼出临界的**手段**，时机与形式自由。**手段服从目的**：爆破落地的唯一验收＝核心张力是否被推至临界——禁止替代摊牌、取消摊牌、或只为打断而打断。
   - **当前拍＝余波**：已兑现 → 收束/沉淀/转向新线；未兑现 → 按回判行5/行6 写张力方向与焦点提示（同其他拍）。
   - 涉及用户角色定性抉择 → 标记抉择悬崖（NPC 照常行动·照常兑现自己的冲突线）。
   - **禁预写角色行动**——「导演控制现在这一拍，而不是预写角色的行为」。
   - **每轮重写**：逐轮按推进池首位CT 的压力说明与受力点重新判定并落盘（内容可不变，但不得沿用旧值）。
5. **场景切换判定**（每轮两问·任一为是→写 `转场.目标场景/理由` → ⑤场记执行 init_scene）：① POV 角色的 REGION.md 节点 ≠ 焦点场景 scene_card「区域」节点？（有 regions/ 目录树时以此为准·round-check 机械复核）② 时间区间跨越（跨天必切）？无目录树的迷雾制世界按 scene_management §移动场景协议 既有规则判断。
6. **时间窗口设定（拍级·非轮级）**——写 `direction.时间窗口 = {拍, 起点, 预算}`，供行动链耗尽判定。

   | 字段 | 值 | 谁定 |
   |---|---|---|
   | `拍` | 本窗口对应的拍名 | 脚本随 `###BEAT: set/advance` 落（防跨拍沿用旧预算） |
   | `起点` | 当前世界时间 | 结构轮设定（缺失时脚本以当前世界时间兜底） |
   | `预算` | 默认＝当前拍拍序的 `预估时长` | 脚本随 BEAT 机械导出·③无需手填 |

   **现场重估（③职责·拍内可覆盖）：** 按本轮戏剧问题、张力方向、冲突紧迫度与故事节奏（＝本拍在事件线中的位置/拍型）重估——角色咬合激烈·链持续延伸 → 上调；问题快速兑现·张力提前收束 → 下调。**重估须在承接判断中写一行理由**，不写理由即采用编剧基准。

   **已耗／剩余／已过半／已耗尽 ＝ 脚本机械导出**（precheck 与 `worldctl context` 同口径·跨日修正·③零解析）：已过半＝剩余≤预算一半；实质耗尽＝剩余≤0（剩余≈≤2分钟可视为提前验收·LLM 裁量）。

   **两个验收点：**
   - **过半** → 先判行5（意图能否明显逼近本拍问题）：仍能明显逼近 → 行6 续演（**过半不重设窗口**·按原起点继续计余量）；不能 → 行5 停滞（①加压）。
   - **耗尽** → 已答＝行4 advance；未答且意图仍在推进 → 行6 续演**且批内重设窗口**（`{起点=当前世界时间, 新拍级预算}`·否则④无剩余时间可行动·链将收敛）。

   **窗口＝拍的发育期：** 未过半且本拍问题未被实质性回答 → 默认行6 deepen；**问题已被实质性回答 → 行4 advance·不受过半约束**（窗口是发育期**上限**·非下限）。**日常轮不重设**（拍内不变）。**`预估时长` 缺失（存量线）** → 脚本不导默认值，本职责现场重估直接定值（自愈·不阻塞运行）。

7. **调度单（主次分档·场景级·每轮重判落盘）**

   **输入：** 推进池CT.关联角色 ＋ scene_state（焦内）＋ pending_actions（焦外）＋ world_state.外部倒计时（顶点拍：爆破源的到场时钟）＋ precheck SNAPSHOT §1a（临近互锁）/§1b（循环角色预设此刻应在哪/做什么）。参照承接判断与本轮指导判定后，写 `direction.调度单`。

   **四层定义**（本表只收角色具名条目——事件描述写进来会让解析器把相邻档一并吞掉）：

   | 档 | 是什么 | 本轮产出 |
   |---|---|---|
   | `焦内活跃` | 本拍能以自身选择改变争夺资源/控制权/关系状态/退路的行动主体 | 完整行动链·触发成链 |
   | `背景角色` | 受波及余光 | 仅一句可观察显影·不逐人产 ACTION·不承担行动主体 |
   | `焦外` | 场外待入 | — |
   | `焦外→焦内` | 跨场景迁移、过渡中升入画面 | 须落到最终桶并完成状态更新（见 phase_actor/phase_keeper） |

   **定档规则：**
   - 定档依据＝本拍戏剧问题 ＋ 推进池首位CT；判定标准＝在场景＋戏剧焦点＋用户角色可观察行动的感知后果＋即将触发事件四者上定档。**禁以用户点名替代戏剧问题/推进池首位CT定焦**，禁机械按场景/编剧预设 copy 全员。
   - `焦内活跃` 常态 1-2 个，超出须在承接判断附主次理由。
   - 优先入选：资源持有者 / 即时决定资源归属者 / 能施加不可逆后果的对抗方；双方都能即时改写局面时共同入选。
   - **本拍事件/CT 的行动主体不得留 `背景角色`**——持械者、被指向者、事件中被卷入的具名在场者归 `焦内活跃`；一名角色可同时是多条 CT 的关联者，据此入档。

   **硬性约束：**
   - **顶点拍对齐**：当前拍＝顶点时，`顶点约束.关系主体` 本轮要么入画（焦内活跃/背景角色），要么在承接判断写明未入画理由。
   - **空舞台**：`焦内活跃` 不得只剩 POV 一人；若只剩 POV 一人，必须有 `背景角色` 或 `焦外→焦内` 的**具名角色**及可观察事件。

   **具名条目：** 一律写 `CHAR_{名}`；仅无 CHAR_.md 的纯背景可标群像。

   **常驻NPC 归属**（NPC 会动·非静态全员硬入）：
   - 按**当前时刻**「默认循环时间线」命中位置判定是否本场；
   - 命中本场者须分档（背景角色/焦外·或有资格升级焦内活跃）·不得全档缺席；
   - 时间线命中别处者＝他处仍在世界·不视为本场缺席（不强制入本场调度单·由④/⑤焦外管道跟踪）；
   - 无「默认循环时间线」可解析 / 骨架未物化（precheck SNAPSHOT §3 名单）→ 按 REGION 静态归属与场景出场摘要保守纳入本场分档，再交④物化。

   **边界（角色层优先）：** 调度单＝画面分档·不封禁行动——角色自身条件触发（失败后续 / 意图被新事实破坏 / 档案级行动要求·见 phase_actor 角色路由前置判定）时按焦内活跃执行，本档仅为画面参考。

   **每轮重排：** 逐轮重新判定并落盘（取消「复用」——内容未变也照写）；**切场景 / 角色入场或退场 / 位置变化 / 事件主体升降档** 命中任一 = 必须重排（不得以机械「日常轮」标签豁免）。

   **三个附加动作：**
   - 推进池关联CT的焦外角色，按场景与互锁窗口置为焦外自推演或适时升为焦内活跃/背景角色。
   - **回归判定（循环世界·本轮有偏离角色时·loop_machinery §1 步骤 4）**：对照①轨道扫描结论，每个偏离者三选一——主动回归／持续偏离／强制回收，去向并入本轮调度单（回归=回 CHAR_.md「默认循环时间线」位置·持续偏离=保留当前位置·强制回收=退出本轮画面）。无偏离角色 → 跳过。**判出持续偏离时同批写 `escalation_flags.偏离提示`**（三选一中仅此项写旗标）
   - **顶点爆破取材（顶点拍）**：顶点约束 `非玩家爆破` 是**事件**、不进本表四层角色档（本表只收角色具名条目——事件描述写进来会让解析器把相邻档一并吞掉）。③从两根**已登记**的载体取材：`world_state.外部倒计时`（它何时到·④经 context 感知）+ `CT.关联角色`（到了之后是谁在动·③取入本表按常规分档）。爆破源为无档案的临时外部力量 → 本表按 `背景角色` 档写具名群像条目（如 `Mesa 回收队`），**不预建档**——⑤场记在该群像首次发生**交互**（被搭话/被指认/被拦阻）时按 keys.md「自动创建规则」自然建档。两根载体皆缺 → 本拍无爆破源可调度，须在承接判断显式记 `爆破源未登记`（不静默跳过）。
8. **顶点出线核验**——advance 余波时 `gate director --check` 自动比对，缺项 exit 1＝批次拦截·撤回本阶段。

   **核验项：**
   - **顶点事件已完成**：对照该拍 戏剧问题/顶点约束 ＋ 实际演出判定——该拍最高潮已真实发生并落地（落入 scene_state 场景时间线与叙事）。**变化发生但高潮尚未完整落地 → 保持顶点拍（deepen·继续把这场戏精彩展开到底）·不得出线**。
   - **顶点约束齐备**：关系主体≥2 / 核心张力 / 变化维度 / 非玩家爆破。
   - **基准快照存在**。
   - **关系主体的实质状态发生真实变化**。

   **承接判断须含两行表态：**
   - `爆破兑现：<事实>` 或 `爆破豁免：<理由>`——对设计承诺表态·防爆破要素被静默丢弃；
   - `张力结算：<核心张力是否被推至临界·以何为凭>`——对设计目的表态；判定未达临界须附 `张力去向：<登记进余波/新线的承接方式>`·张力未落地的顶点不允许静默出线。

   > 脚本验收、演出交给现场——验收对比面不预先声明（信念演化/防御重构/自主性等最高级改变不公开为验收靶子）。
