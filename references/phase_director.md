## 回判评估（回判层与 D4 节拍决策的公共输入·每轮第一动作）

**问题**：上轮实际演出结果 vs 当前拍戏剧问题，现在处于什么关系？四个判断维度：
- **张力**：当前拍是否仍有戏？戏剧问题有没有继续发展？张力在上升、下降还是停滞？
- **变化**：角色行动是否产生有效变化？是否需要继续当前拍？
- **指针**：是否已回答当前拍问题？是否该推进下一拍？是否该切换空间？是否该进入转折？
- **意外**：是否出现意外事件导致原计划需要调整？

**事实观察**（本节产出·供本层决策与 D4 取用）：
- **CT触及观察**——上轮已落盘角色行动是否改变或触及某条活跃 CT 的被争夺资源、控制权、关系状态或退路（对照 conflicts 活跃 CT）
- **转场检测观察**（机械·每轮执行·round-check 机械复核同一判据）——① 空间脱锚：POV 角色的 REGION.md 节点 ≠ 焦点场景 scene_card「区域」节点（有 regions/ 目录树时以此为准）；② 跨时：时间区间跨越（跨天必切）；无目录树的迷雾制世界按 scene_management §移动场景协议 既有规则判断

**主评估顺序（多标准同命中·取先·适用于 D2 承接/D4 节拍）**：切换事件线 ＞ 不承接 ＞ 推进下一拍 ＞ 停滞 ＞ 继续当前拍。

**前置簿记（非竞争行·每轮先执行）**：旗标消化=D2 承接决策的「消化规则」——先于一切评估执行。

## D1 CT结算触发（判定型·回判层）

**决策问题**：回判评估的 CT触及观察是否为是？
**缺省选项**：否

**决策选项与选中标准**:
- `是` — CT触及观察为是（行动改变或触及活跃 CT 的资源/控制权/关系/退路）
- `否` — 未触及

**结果语义**：是 → 登记 `escalation_flags.CT待结算` → ①戏剧家次轮结算+重估（precheck 提示 + gate 硬拦：①批无 CT op=拦）

## D2 承接决策（判定型·回判层·停滞的真正判定处）

**决策问题**：当前线的预设局面与拍内格局是否仍成立——需要唤醒①②介入处置吗？
**缺省选项**：正常承接（以下标准均未命中时）

**决策选项与选中标准**（评估顺序 不承接＞停滞）:
- `不承接` — **预设与现实脱钩**：①窗口已过半 ∧ 本拍 事件背景 的预设局面始终未在现实里成立（实际演出已落在别的局面上），或 ②本线前提或本拍戏剧问题已被现实推翻·演出不再沿它推进
- `停滞` — **格局停滞**：窗口已过半·**上轮调度单**各角色的 decision.未完成意图**不能明显逼近**本拍问题（判据＝把这些意图照各自的方向推进一整轮，本拍戏剧问题的成立条件是否**可见地**向前挪动了一格；「角色很活跃但格局不动」·窗口余量脚本导出·③零解析）；「格局不动」前提含回判评估的 CT触及观察——行动已触及 CT 资源＝格局载体变动→停滞不成立
- `正常承接` — 上述标准皆未命中

**消化规则（先于评估·每轮先执行）**：`停滞/不承接` 在场且**上轮已消化**（停滞＝上轮戏剧家已加压且载体已入画〔外部倒计时在场／新主体已入调度单／scene_state 有载体〕；不承接＝上轮编剧已三问归位）→ 本批先清除对应旗标，不占用本轮评估；停滞已加压但**载体未入画** → 旗标保留不消化·本轮评估照常·①次轮加压不得重复同一瞄准

## D3 演出状态（评级型·回判层末综合）

**决策问题**：本拍演出此刻处于哪种状态？（恒选最贴合一项·无缺省——与 D2 判定同向一致：机械停滞命中→评级停滞；反向不成立）

**决策选项与选中标准**:
- `上升` — 张力增强·调度单角色意图正在兑现
- `持续` — 意图仍在推进但张力未增强（僵持未失速）
- `转折` — 相位翻转/意外事件入场
- `收束` — 本拍问题正被实质性回答·趋向换拍
- `停滞` — 意图换招复读·格局不动（描述性评级·定性判据）——**不自动写旗标**；`escalation_flags.停滞` 唯一来源=D2 承接决策（窗口机械线：过半＋意图不能明显逼近）

**用途注记**：①下轮回判的状态基线（direction 旧值连续性对比）；②窗口耗尽替代表态（见 D4 继续当前拍·gate 同口径）；③描述性评级·本层末综合输出。

## 第一层过程留痕

**P1 承接判断**（prose·多行·回判层——D2 承接决策的过程留痕·兼作 D4 节拍决策的输入之一·落笔随批次完成）
- 内容: 当前拍继续的理由 或 进入下一拍的理由——与节拍决策/演出状态合为核心三件留痕
- 硬线: ≥120 字（gate 硬拦）；deepen 批须逐角色点名「调度单哪位角色的何种未完成意图，尚会把何种状态推向临界」；deepen 且当前拍==顶点 → 交代爆破源处境（已登记→指认载体 `外部倒计时.CD-XX`／`CT-XX.关联角色`；未登记→记 `爆破源未登记`·不得静默跳过）；顶点出线两行表态（推进下一拍且当前拍==顶点时）：`爆破兑现：<事实>` 或 `爆破豁免：<理由>`（对设计承诺表态·防爆破要素被静默丢弃）＋ `张力结算：<核心张力是否被推至临界·以何为凭>`（判定未达临界须附 `张力去向：<登记进余波/新线的承接方式>`·张力未落地的顶点不允许静默出线）——gate 出线核验对照面：顶点事件已完成（**变化发生但高潮尚未完整落地 → 保持顶点拍 deepen·不得出线**）·顶点约束齐备（关系主体≥2/核心张力/变化维度/非玩家爆破）·基准快照存在·关系主体实质状态真实变化；脚本验收、演出交给现场——验收对比面不预先声明（信念演化/防御重构/自主性等最高级改变不公开为验收靶子）

## D4 节拍决策（判定型·本拍层）

**决策问题**：依据回判层产出·当前拍何去何从？
**缺省选项**：继续当前拍（以下标准均未命中时）

**前置分支（先于选项评估）**：`当前事件线`或`当前拍`为空（首次启动/结构基线缺失）→ 直接产出 `###BEAT: set <活跃线> <其起点拍>`＋D6 参数 `{起点, 预算}`（目标线=当前唯一活跃线或②本批 add 的线·由脚本/本批 add 定）——初始化不占下方选项（选项评估以指针存在为前提）

**决策选项与选中标准**:
- `继续当前拍` — 本拍戏剧问题未被实质性回答·且 D2 未命中停滞（窗口过半但**上轮调度单**各角色 decision.未完成意图仍能明显逼近本拍问题＝正常发育；窗口未过半为默认）。窗口耗尽且问题未回答 → 本值仍成立·批内重设窗口（**表态=重设·不写停滞——耗尽≠停滞**）；**D3 演出状态=上升/转折时视为推进中同拍·可替代表态（gate 同口径）**
- `推进下一拍` — 本拍戏剧问题已被实质性回答（判据=自然完成判进·见下）。当前拍==余波时＝本线结构已到终点·收束承接=②编剧次轮 close + add·新线起点由③下批 set；当前拍==顶点时→P1 须含顶点出线两行表态（受 gate 出线核验）
- `切换事件线` — **焦点被新事件夺走** ∧ 本拍预设局面未被置换 ∧ 本线前提与戏剧问题仍成立 ∧（已有另一活跃线可接焦 ∨ 本批②add 新线）。原线保留（非焦点=自然挂起）
- `切换场景` — 回判评估的转场检测观察命中（空间脱锚/跨时·机械）
- D2 命中停滞/不承接时 → 本值保持继续当前拍·无指针动作·处置走旗标

**参数**（选中该选项即随结果一并返回）: 推进下一拍 → `下一拍名`；切换事件线 → `目标线`＋`该线拍名`（同批②add 的新线目标写「新线」·add 的 SL-XX 由脚本分配·不可预知）；切换场景 → `目标场景`＋`理由`

**结果语义**: 继续当前拍＝拍内续演·演到该爆发的节点（不是停手）；推进下一拍＝指针前移；切换事件线＝换焦点·原线挂起；切换场景＝⑤场记执行 init_scene（③不直接改场景文件·拍随场景延续）。同批若同时有指针动作与切场：节拍决策记指针动作值·转场参数照常返回（两者不互斥）

**自然完成判进（「实质性回答」判据·导演不是剧情警察）**：不强迫角色把事件线演完——观察实际发生的戏，判断当前拍问题是否已被**自然地实质性回答**；回答来自任何涌现路径（不限于编剧预设的兑现形态）即推进。模式锚定：
- 编剧规划「拍2：Gunslinger 能否阻止 Angela 接近玩家？」→ 实际演出：Angela 主动拉拢玩家 → Gunslinger 没有阻止 → 玩家反而怀疑 Angela → Angela 暴露出异常 → Gunslinger 抓住机会 → 导演发现「阻止接近」已获实质性回答 → 推进拍3「Angela 是否会暴露真实意图？」——**而不是强行让 Gunslinger 执行编剧安排**。
- 三方分工：**编剧有结构、角色有自由、导演有现场判断力。**

## D5 调度单（评级型·本拍层·逐角色一次）

**输入：** 推进池CT.关联角色 ＋ scene_state（焦内）＋ pending_actions（焦外）＋ world_state.外部倒计时（顶点拍：爆破源的到场时钟）＋ precheck SNAPSHOT §1a（临近互锁）/§1b（循环角色预设此刻应在哪/做什么）。参照承接判断·按 **D4 确定后的本拍戏剧问题**逐角色判定。

**决策问题**：该角色本拍在画面中的档位？（评级型·逐角色各选一档·恒选最贴合·无缺省）

**决策选项与选中标准**:
- `焦内活跃` — 本拍能以自身选择改变争夺资源/控制权/关系状态/退路的行动主体（完整行动链·触发成链）
- `背景角色` — 受波及余光·在场的非行动主体（仅一句可观察显影·不逐人产 ACTION·不承担行动主体）
- `焦外` — 场外待入（收录判据见下方定档规则；由④/⑤焦外管道跟踪）
- `焦外→焦内` — 跨场景迁移、过渡中升入画面（本轮须落到最终桶并完成状态更新·见 phase_actor/phase_keeper）
- 只收角色具名条目——事件/机制/环境变化不入（事件类经 `world_state.外部倒计时` 承载、新主体类经 `CT.关联角色` 承载·见 phase_dramatist D9/D11 载体登记）

**定档规则：**
- 定档依据＝本拍戏剧问题 ＋ 推进池首位CT；判定标准＝在场景＋戏剧焦点＋用户角色可观察行动的感知后果＋即将触发事件四者上定档。**禁以用户点名替代戏剧问题/推进池首位CT定焦**，禁机械按场景/编剧预设 copy 全员。
- `焦内活跃` 常态 1-2 个，超出须在承接判断附主次理由。
- 优先入选：资源持有者 / 即时决定资源归属者 / 能施加不可逆后果的对抗方；双方都能即时改写局面时共同入选。
- `焦外` 收录判据（满足任一）：①临近互锁事件涉及（precheck SNAPSHOT §1a）；②推进池 CT 对抗方在途或临近揭示；③用户关注或 pending_actions 活跃中有待揭示事实；④本拍爆破源载体。其余角色不进表·由④/⑤焦外管道跟踪。
- **本拍事件/CT 的行动主体不得留 `背景角色`**——持械者、被指向者、事件中被卷入的具名在场者归 `焦内活跃`；一名角色可同时是多条 CT 的关联者，据此入档。

**硬性约束：**
- **顶点拍对齐**：当前拍＝顶点时，`顶点约束.关系主体` 本轮要么入画（焦内活跃/背景角色），要么在承接判断写明未入画理由。
- **空舞台**：`焦内活跃` 不得只剩 POV 一人；若只剩 POV 一人，必须有 `背景角色` 或 `焦外→焦内` 的**具名角色**及可观察事件。

**具名条目：** 一律写 `CHAR_{名}`；仅无 CHAR_.md 的纯背景可标群像。

**常驻NPC 归属**（NPC 会动·非静态全员硬入）：
- 按**当前时刻**「默认循环时间线」命中位置判定是否本场；
- 命中本场者须分档（背景角色/焦外·或有资格升级焦内活跃）·不得全档缺席；
- 时间线命中别处者＝他处仍在世界·不视为本场缺席（不强制入本场调度单·由④/⑤焦外管道跟踪）；
- 无「默认循环时间线」可解析 / 骨架未物化（precheck SNAPSHOT §3 名单）→ 按 REGION 静态归属与场景出场摘要保守纳入本场分档，再交④物化。

**边界（角色层优先）：** 调度单＝画面分档·不封禁行动——角色自身条件触发（失败后续 / 意图被新事实破坏 / 档案级行动要求·见 phase_actor 角色路由前置判定）时按焦内活跃执行，本档仅为画面参考。

**每轮重排：** 逐轮重新判定并落盘（取消「复用」——内容未变也照写）；**切场景 / 角色入场或退场 / 位置变化 / 事件主体升降档** 命中任一 = 必须重排（任何标签不豁免）。

**三个附加动作：**
- 推进池关联CT的焦外角色，按场景与互锁窗口置为焦外自推演或适时升为焦内活跃/背景角色。
- **回归判定（循环世界·本轮有偏离角色时·loop_machinery §1 步骤 4）**：对照①轨道扫描结论，每个偏离者三选一——主动回归／持续偏离／强制回收，去向并入本轮调度单（回归=回 CHAR_.md「默认循环时间线」位置·持续偏离=保留当前位置·强制回收=退出本轮画面）。无偏离角色 → 跳过。判出持续偏离 → 登记 `escalation_flags.偏离提示`（三选一中仅此项触发登记·precheck 提示 → ①戏剧家次轮按偏离者四件套处理）
- **顶点爆破取材（顶点拍）**：顶点约束 `非玩家爆破` 是**事件**、不进调度单四档（调度单只收角色具名条目）。③从两根**已登记**的载体取材：`world_state.外部倒计时`（它何时到·④经 context 感知）+ `CT.关联角色`（到了之后是谁在动·③取入本表按常规分档）。爆破源为无档案的临时外部力量 → 本表按 `背景角色` 档写具名群像条目（如 `Mesa 回收队`），**不预建档**——⑤场记在该群像首次发生**交互**（被搭话/被指认/被拦阻）时按 keys.md「自动创建规则」自然建档。两根载体皆缺 → 本拍无爆破源可调度，须在承接判断显式记 `爆破源未登记`（不静默跳过）。

## D6 时间窗口（参数型·本拍层）

**决策问题**：本拍发育期窗口如何锚定？（参数型·直接返回参数值——LLM 只设起点/现场重估预算；`已耗/剩余/已过半/已耗尽` 由脚本机械导出·precheck 与 context 同口径·LLM 零解析）

**参数**:

| 参数 | 值 | 谁定 |
|---|---|---|
| `起点` | 当前世界时间 | 本批设定（缺失时脚本以当前世界时间兜底） |
| `预算` | 默认＝当前拍拍序的 `预估时长` | 脚本随 BEAT 机械导出·③无需手填·现场重估可覆盖（须在承接判断写一行理由·不写理由即采用编剧基准） |

**现场重估（③职责·拍内可覆盖）：** 按本轮戏剧问题、张力方向、冲突紧迫度与故事节奏（＝本拍在事件线中的位置/拍型）重估——角色咬合激烈·链持续延伸 → 上调；问题快速兑现·张力提前收束 → 下调。

**已耗／剩余／已过半／已耗尽 ＝ 脚本机械导出**（precheck 与 `worldctl context` 同口径·跨日修正·③零解析）：已过半＝剩余≤预算一半；实质耗尽＝剩余≤0（剩余≈≤2分钟可视为提前验收·LLM 裁量）。

**窗口＝拍的发育期（上限·非下限）：** 验收点判定标准归属 D2（停滞）与 D4（继续/推进）——窗口事实（已过半/耗尽）由脚本机械导出供其取用。**耗尽＝验收点而非停滞**：表态三选一（推进下一拍/停滞旗标/重设续演·gate 同口径）。**拍内不重设**。**`预估时长` 缺失（存量线）** → 脚本不导默认值，D6 现场重估直接定值（自愈·不阻塞运行）。

## 第二层过程留痕与第三层指导

**P2 guidance**（prose·≤5 行·**每轮重写**·指导层——D4 后的本拍戏剧问题＋推进池首位CT＋D3 评级 供给④的演出指导）
- 构成: 当前戏剧问题 ＋ 张力方向 ＋ 焦点提示
- **张力方向与焦点提示**：必取推进池首位CT（紧迫度最高者）的压力说明与受力点转译，非任选；以该CT关联角色的档案基准动作（如 Hector=掠夺）为指向，不出可抄为 ACTION 的通用动词。落点争议以④角色自治为准。
- **当前拍＝顶点** → 焦点提示必含两项：
  - **核心张力**：顶点约束声明的、本场关系必须被推至的**转变临界**——顶点的**目的**，演出与叙事的一切手段围绕它收拢；
  - **非玩家爆破指向**：外部加压源·防主体静止死锁——逼出临界的**手段**，时机与形式自由。**手段服从目的**：爆破落地的唯一验收＝核心张力是否被推至临界——禁止替代摊牌、取消摊牌、或只为打断而打断。
- **当前拍＝余波**：已兑现 → 收束/沉淀/转向新线；未兑现 → 按回判评估结果写张力方向与焦点提示（同其他拍）。
- 涉及用户角色定性抉择 → 标记抉择悬崖（NPC 照常行动·照常兑现自己的冲突线）。
- **禁预写角色行动**——「导演控制现在这一拍，而不是预写角色的行为」。
- **每轮重写**：逐轮按推进池首位CT 的压力说明与受力点重新判定并落盘（内容可不变，但不得沿用旧值）。
