# 六阶段人工审计协议（标准模式·gate 明细）

> 沉浸模式（全局默认）跳过人工审计，保留代码化核验——**随 `write-raw --batch` 逐段自动执行**（批次类五阶段·必含项缺失/硬性违规=该段整体拦截 exit 1 不落盘；作家段豁免，叙事核验由 `gate writer --check` 承担 W1/W4/W5 机械拦截＋长度统计（token 估算））。`worldctl.py <世界> gate <阶段> --check` 用于 writer 叙事核验与单段手动复检。标准模式（/loud）在代码化核验之上追加本协议人工审计。
>
> **v0.28 调度口径（结构层·详见 runtime_scheduler.md）：** ①/② 为条件段——**被调度指令/基线/兜底唤醒才批**；其检查项（D1-D5/S0-S4）在「①/② 批出现时」核验（结构轮口径），未唤醒轮（无该层批）无此检查。③ 恒跑——**每轮必写**（guidance+调度单逐轮落盘·无「复用放行」），回判力度按三态分级。角色层/场记层/作家层（A/K/W）每轮检查一口不漏（快路径恒在层）。新增 `CT待结算` 硬拦：escalation_flags.CT待结算 在场但①批无 conflicts CT op → exit 1。

## 共用协议（所有阶段）

1. **角色转变声明（先于一切检查）**：「以下检查由独立审计{阶段名}执行——非本轮该阶段决策者」。
2. **默认不通过**：起点是全部项「不通过」，逐项主动找茬，只有引用证据（文件路径+字段/叙事原文）证明该项确实干净才翻转为「通过」——通过的形式是**找茬失败记录**，不是「未发现问题」。
3. **修复纪律**：审计者只读，修复由决策者执行；不通过 → 按修复指令重检（≤2 轮）；超 2 轮 → 终止该轮并报告用户（防审计与决策互相辩护死循环）。
4. 若审计反复发现同类违规（补丁无效）→ 主动建议用户更换 LLM model——诚实承认模型能力/注意力上限。
5. **执行绑定（标准模式进入审计时判定一次）**——仅标准模式 /loud 触发本条；默认沉浸式无人工审计·不触发子 agent。

   - **宿主具备子 agent/任务委派类工具** → 每阶段人工审计由独立只读子 agent 执行。
     - **输入**：该阶段清单 ＋ 被审阶段已落盘产物的文件路径 ＋ 批次回执（write-raw/gate stdout·FILE 清单与 round-check 报告）＋ **本轮账本**（`worldctl.py <世界> ledger <轮次>`——④段行动卡/心流/META 原文与行序；审④与审⑥时必读）。
     - **产出**：审计者自主取证（只读·文件检索 / `worldctl.py` 只读子命令），返回逐项 {通过|不通过|跳过} ＋ 证据原文；返回清单原样留痕，不经改写。
     - **节奏**：重检＝重新调用审计子 agent（≤2 轮）；审计随段串行——该段审计通过前不进入下一阶段，不通过 → 修复 → 重检 → 通过才推进。
     - **边界**：代码化拦截不迁移——write-raw 内嵌闸门与 `gate <阶段> --check` 仍在主 agent 落盘管道执行，子 agent 仅承担人工判读清单。
   - **本会话派发报错（工具不存在）** → 决策上下文内按第 1 条角色转变声明执行（现状兜底）。

## 各阶段清单（逐项 {通过|不通过|跳过}+证据）

### ①戏剧家 D（gate dramatist）
- D1 冲突推进：≥1 条 CT 推进/注册（推进池非空）
- D2b 施压方向：本轮推进的每条 CT 已带 `CT-{XX}.施压方向`（枚举/写法/禁写清单=phase_dramatist 职责3·单一规格源）。**余波已兑现批豁免**（余波只结算·不施压）；四爆破缺压力说明=软警；停滞旗标在场 → 禁全维持＋加压批须含新变量载体（`CT-{XX}.关联角色`＝①唯一写通道·威胁/事件类同由 CT 承载；需 `world_state.外部倒计时` 时①只指定·落盘=⑤场记）——缺=拦截
- D2 代价：CT 对抗双方可核验变化（资源易主/载体状态/新增伤害/控制权易手/被迫选择/被迫承认/关系档位——内部认知描述不算）
- D3 实质推进：对抗加码或重大转折（仅出场无变化=未推进·该 CT 计冷却；焦外演化不因冷却写弱）
- D4 抽象方：显现机制可指认＋本轮出手形态＋主角抵抗留下的痕迹（纯在场=影子拳击）
- D5 循环轨道：偏离检测（**逐角色**·决策/行动 vs CHAR_.md「默认循环时间线」基线）＋冲突化（1 次即注册）＋超限埋后果＋兜底（执行表与阶段分派见 loop_machinery §1：①只判定·状态结算归④角色）

### ②编剧 S（gate storyliner）
- S0 重路径触发（机械硬拦·应重路径却只写轻量声明=本层未扫描）：① 存在与焦点场景空间关联的未引用活跃线 CT 且当前无活跃线可接（无活跃线，或当前拍==余波且该线余波已兑现且无其他非余波活跃线可接）→ 必含 add；含 add 时 META 须回显 `取材=CT-XX`（缺=拦），且该 CT 引用命中任一活跃线=拦；未引用 CT 全与焦点场景无关联 → 不构成强制 add 源（以当前场景为锚兜底建线，META 标注兜底来源）；② `escalation_flags.不承接` 在场 → 必含 add/rewrite/clear 三问归位。已收束 CT 不参与扫描（在表 CT 即未收束·收束的已从 conflicts 移除）。
- S1 戏剧问题：每拍有边界可回答（禁无界持续描述）；拍序字段齐备（空间/时间/预估时长/戏剧问题——`预估时长` 缺失仅软警·③现场重估自愈·不拦截）
- S2 顶点约束：关系主体 ≥2（顶点单位=关系·不区分玩家/NPC）＋核心张力点名赌注所在＋变化维度合法＋非玩家爆破 ≥1（外部加压·防死锁）
- S3 弧线对照：storylines.故事弧线 vs SETTING 弧线声明＋张力基调（防微观有张力·宏观整体投降）＋活跃线/遗留线对账（轻量批仍查）
- S4 LOOPS 融入：在轨节拍并入结构（无来源标记·角色层不知晓）

### ③导演 R（gate director）
- R1 回判：上轮结果 vs 当前拍戏剧问题（十问·含意外事件→原计划调整）
- R2 承接判断：当前拍继续的理由或进入下一拍的理由（已写入 direction·核心留痕）
- R2b 深演主体：`deepen` 的承接判断点名调度单各角色的未完成意图及待改变状态；未完成意图相对本拍戏剧问题已不再推进（意图已兑现而无新意图·或已转向与本拍问题无关的方向）者不构成承接（姿态/情绪/走位/同一喝令微变不算）
- R3 演出状态：上升/持续/转折/收束/停滞（停滞→escalation flag→①兜底）
- R4 guidance：问题+张力方向·**禁预写角色行动**（预写=诱导下轮照抄）；顶点拍必含核心张力（目的）＋非玩家爆破指向（手段·手段服从目的——禁止替代/取消摊牌）
- R5 场景切换：物理变化/跨天必切（机械规则·转场决策→⑤执行）
- R6 顶点出线双表态：承接判断含 `张力结算`（目的验收·未达临界须附 `张力去向`）＋`爆破兑现/豁免`（承诺验收）——张力未落地的顶点不允许静默出线；**出线仅当「顶点事件已完成」**（对照该拍 戏剧问题/顶点约束+演出判定·高潮已落地）；变化发生但高潮尚未完整落地 → 保持顶点拍（deepen·继续把这场戏精彩展开到底），不设为出线
- R7 调度单具名（机械核验）：调度单**凡写出的桶**（焦内活跃/背景角色/焦外/焦外→焦内）须为具名条目；`焦内活跃`≥1 个可解析已建档角色（常态 1-3·超出=软警告·承接判断须附主次理由）；背景角色/焦外/焦外→焦内 段虚词（群像/外部者/游客）不得替代已建档角色（仅无 CHAR_.md 纯背景可标群像）；`焦外→焦内` 角色**若写出**须落到焦内活跃/背景角色最终桶（gate director 硬拦）

### ④角色 A（gate actor）
- A1 行动卡三件套+有条件代价：###ACTION 驱动/情绪/强度必含（audit 硬检）+ 代价有条件必填（条件见 actor_decision.md「行动代价」·audit 软警）；**每个 ACTION 角色须有同名 ###MUSE 行（机械硬拦·只验有无·内容倒补归审计）**＋同角色 MUSE 与 ACTION 成对、计数相等（机械硬拦·多环按发生顺序成对排列 MUSE₁ ACTION₁ MUSE₂ …）＋MUSE 字数下限（机械硬拦·三段结构＋权重判定最底线·仅第二人称 POV 豁免·疑似失忆整改：重读 phase_actor＋actor_decision 再重做④）****；原文与心流行序取证=本轮账本（行序可核验「心流先于动作」）
- A0 决策就绪：行动角色的 decision 八子字段已实体化；首次物化同批写全八项，后续行动同批更新运行层六项（当前行动/驱动/对象/窗口/失败后续/未完成意图）；**有 ACTION 的角色本批须含连续行动轨迹 APPEND（机械硬拦·意图循环门依赖轨迹文本）**
- A2 反顺从四则：档案强度（≥基准·顺从默认=重写）/抽象方显现/认知闸门/价值底线升级路径；取舍与代价引自 1.4 账本（取舍判据·见 actor_decision.md）
- A3 认知上限：循环档位速查（脚本=流程+极细微裂缝（生成见 §2.3）·禁元视角；漂移=碎片直觉 1-2 次/日；觉醒/变质=清醒）
- A4 用户角色行动来源（单一规格源=SKILL.md「视角语义」）：角色始终保有自主行动权——第二人称＝仅用户输入（未给输入→本轮无 ACTION·不代写）；第一人称＝用户输入优先·无输入自主行动；第三人称＝用户输入经自主决策吸收后执行。第二人称下 ACTION 与角色覆盖可选（行动卡 vs 用户本轮输入逐条核授权）。
- A5 记忆：入锚写前五步（扫旧/融合/管道B/管道A/追加≤100字）＋角色覆盖/记忆✓ 留痕＋行动连续性（目标→计划→行动→结果·非每轮孤立）
- A6 计划-动作一致性：`计划变化` 值域三档（无/推进/调整——概括）；覆盖源＝1.4「长期计划巡检」判定（见 actor_decision.md）。gate --check 双向核对——记 `调整` 却未覆盖、或本轮有轨迹却覆盖而未记 `调整` = 拦
- A7 意图循环（僵持再评估）：`未完成意图` 连续 3 轮相同（含仅幅度/称谓变化）→ 拦（gate actor 机械强制·计数按轮次去重——同轮多环＝同一轮·取该轮末环的 `未完成意图`）。审计复核：是否误拦（放行=本轮意图与近 3 轮任一不同·豁免=循环角色在轨轻量）；拦下后角色是否按「先读 decision.失败后续 / 换路径 / 目标重估 / 抓新机会」换招——僵持轮须见意图变化或计划推进（Hector 式），不见=角色层仍原地踏步
- A8 自治复推（软核查·找茬制起步）：`ACTION` 能否从本角色 `CHAR_.md` 八变量＋`CHAR_state` 复推（原文取证=本轮账本）；ACTION 动词仍须能从角色变量复推；出现照抄 `guidance`/施压说明动词即不通过
- A9 执行绑定（gate actor 机械核验＋审计复核）：每个 ###ACTION 行动角色须在 META `绑定:` 声明路径（`子agent(组装✓)` / `单窗口(豁免原因)`）——缺声明或裸 `单窗口`=机械拦；**非 POV 单窗口须命中豁免白名单字面（`子agent不可用`／`工具不存在`·须有本会话派发报错为据；`宿主不可续话`·据＝绑定声明）否则机械硬拦**（“在轨轻量/背景位/主agent直演”等自编理由=硬拦）。审计复核：白名单字面通过者仍须查依据（前二者查派发报错·`宿主不可续话` 查绑定声明与实际工具面是否相符）；走子 agent 路径的角色，主 agent 收口的行动卡与 decision 是否与子 agent 返回的决策批次一致（未改写、未代为重新决策）；**同窗口多环＝同一具名会话逐环追加「感知增量 ＋ 本人上一环终止态」**
- A10 行动链留痕：角色批须含 ≥1 条 ###SCHEDULE（机械硬拦·只验存在·调度权威仍归③调度单）；同角色多环须按发生顺序成对并入批次（MUSE₁ ACTION₁ MUSE₂ …·核验项见 phase_actor 闸门「多环留痕」）

### ⑤场记 K（gate keeper）
- K1 场景事实：场景时间线/出场摘要（集合索引·位置权威在 CHAR_state）/道具锚点线索
- K2 世界事实：时间/轮次/前情/倒计时走表/时间线压缩（场景 COMPLETE 时）
- K3 落点：scene_state 落在焦点场景目录（world_state.焦点场景 唯一权威）
- K4 轮完整：round-check 通过
- K5 Single Writer：场记批不含 CHAR_state/conflicts/storylines/direction 写入
- K6 场景基线 cast 覆盖（转场/新场景入画·机械硬拦）：scene_card cast（出场角色焦内＋焦外/在场焦外）须覆盖 `_scene_cast_baseline`——常驻NPC 仅取当前时刻时间线命中本场者（NPC 会动·命中别处不硬套·由④/⑤焦外管道跟踪）；缺任一命中本场角色=拦。触发（任一）：direction.转场.目标场景 非空 / 本批写 scene_card / 入场帧批（本批写 scene_state 且盘上场景时间线为空——场景创建后/重置后首次落盘·覆盖场记自行检测切换·导演未写转场的路径）。**跨场景轮豁免：转场目标 ≠ 当前焦点场景 = 旧场景收尾批，跳过 cast 硬拦（对账基线属新场景·切场景后的入场帧批照常核）**

### ⑥作家 W（gate writer）
- W1 POV 过滤：每句 POV 能看见/听见/推理出？焦外切镜两通道验证（POV 感知/焦点切换）；情绪经 POV 感知与身体显影（他人内心与意图不入文）
- W2 代价在纸上：###ACTION 含 `代价:` 时，失去/转折须落地为 POV 可见动作（抽象失去宣言句=机械拦截·细则=phase_writer「写作硬约束2」）
- W3 一致性：卡里记的事不得增减（谁做了什么／结果与代价·卡里没有的不出现）·**怎么讲全归作家**——照抄卡上叙述措辞与条目顺序=不通过·行为可写且优先·**台词照卡上那句的意思说成这个人会说的话·字句由作家定**；行为偏移落地不解释来源
- W4 锚点约束：元素/人物存在性＋形态与注册原文一致（`worldctl grep <元素名>` 核对）——代码化部分由 gate writer --check 强制；**角色自述/内心须符合该角色自主性档位认知上限**（脚本档禁觉醒式自我定性·禁「脚本/程序」自指——见 loop_machinery §2.3）
- W5 特异性（机械部分=`gate writer --check` 复读拦截）：新变量优先·旧变量不重描·余光整轮限一句且换感官通道；跨轮整句/长分句复用=拦截（细则=phase_writer「写作硬约束5」）
- W6 **文学自查**（人工·对照 references/narrative_style_sepia.md）：**删什么**——无三并列连发/连词堆叠/抽象大词簇/分词复述尾/反思尾总结腔；无连续 3+ 等长句；朗读 test 通过；先查白名单（单点不判·累积才改）。**补什么**（sepia §4／zh §3·按语域定档·sprinkled 不 poured）——语气词（啊／吧／呢／嘛／啦）、单音节动词、主语省略与口语紧缩、平实的说话标签（「他说」重复属人味·轮换「他低声道／他扬声说」是机器优雅）。**变质地**（discourse §2）——相邻段落勿同一质：一段密接一段快、一段对白接一段概述
