# 六阶段人工审计协议（标准模式·gate 明细）

> 静默模式（全局默认）跳过人工审计，保留代码化核验（`worldctl.py <世界> gate <阶段> --check`·批次必含项缺失 exit 1=不进下一阶段）。标准模式（/loud）执行本协议。

## 共用协议（所有阶段）

1. **角色转变声明（先于一切检查）**：「以下检查由独立审计{阶段名}执行——非本轮该阶段决策者」。
2. **默认不通过**：起点是全部项「不通过」，逐项主动找茬，只有引用证据（文件路径+字段/叙事原文）证明该项确实干净才翻转为「通过」——通过的形式是**找茬失败记录**，不是「未发现问题」。
3. **修复纪律**：审计者只读，修复由决策者执行；不通过 → 按修复指令重检（≤2 轮）；超 2 轮 → 终止该轮并报告用户（防审计与决策互相辩护死循环）。
4. 若审计反复发现同类违规（补丁无效）→ 主动建议用户更换 LLM model——诚实承认模型能力/注意力上限。

## 各阶段清单（逐项 {通过|不通过|跳过}+证据）

### ①戏剧家 D（gate dramatist）
- D1 冲突推进：≥1 条 CT 推进/注册（推进池非空）
- D2b 施压方向：conflicts.施压方向 已写（死局两难/防御踩爆/关系撕裂/不可逆代价/维持——施压瞄准·不参与验收；停滞旗标在场时禁维持）
- D2 代价：CT 对抗双方可核验变化（资源易主/载体状态/新增伤害/控制权易手/被迫选择/被迫承认/关系档位——内部认知描述不算）
- D3 实质推进：对抗加码或重大转折（仅出场无变化=未推进·该 CT 计冷却；焦外演化不因冷却写弱）
- D4 抽象方：显现机制可指认＋本轮出手形态＋主角抵抗留下的痕迹（纯在场=影子拳击）
- D5 循环轨道：偏离检测（决策/行动 vs LOOPS 基线）＋冲突化（1 次即注册）＋超限埋后果＋兜底

### ②编剧 S（gate storyliner）
- S1 戏剧问题：每拍有边界可回答（禁无界持续描述）
- S2 顶点约束：关系主体 ≥2（顶点单位=关系·不区分玩家/NPC）＋核心张力点名赌注所在＋变化维度合法＋非玩家爆破 ≥1（外部加压·防死锁）
- S3 弧线对照：SETTING 故事弧线/张力基调（防微观有张力·宏观整体投降）
- S4 LOOPS 融入：在轨节拍并入结构（无来源标记·角色层不知晓）

### ③导演 R（gate director）
- R1 回判：上轮结果 vs 当前拍戏剧问题（十问·含意外事件→原计划调整）
- R2 承接判断：当前拍继续的理由或进入下一拍的理由（已写入 direction·核心留痕）
- R3 演出状态：上升/持续/转折/收束/停滞（停滞→escalation flag→①兜底）
- R4 guidance：问题+张力方向·**禁预写角色行动**（预写=诱导下轮照抄）
- R5 场景切换：物理变化/跨天必切（机械规则·转场决策→⑤执行）

### ④角色 A（gate actor）
- A1 行动卡四件套：###ACTION 驱动/情绪/强度/代价（audit ①①b 机械检查）
- A2 反顺从五则：代价前置/档案强度（≥基准·顺从默认=重写）/抽象方显现/认知闸门/VB 升级路径
- A3 认知上限：循环档位速查（脚本=流程+一瞬裂缝·禁元视角；漂移=碎片直觉 1-2 次/日；觉醒/变质=清醒）
- A4 用户角色：行动资格=仅用户输入·禁引擎代笔定性抉择（行动卡 vs 用户本轮输入逐条核授权）
- A5 记忆：入锚写前五步（扫旧/融合/管道B/管道A/追加≤100字）＋角色覆盖/记忆✓ 留痕＋行动连续性（目标→计划→行动→结果·非每轮孤立）

### ⑤场记 K（gate keeper）
- K1 场景事实：场景时间线/出场摘要（集合索引·位置权威在 CHAR_state）/道具锚点线索
- K2 世界事实：时间/轮次/前情/倒计时走表/时间线压缩（场景 COMPLETE 时）
- K3 落点：scene_state 落在焦点场景目录（world_state.焦点场景 唯一权威）
- K4 轮完整：round-check 通过
- K5 Single Writer：场记批不含 CHAR_state/conflicts/storylines/direction 写入

### ⑥作家 W（gate writer）
- W1 POV 过滤：每句 POV 能看见/听见/推理出？焦外切镜两通道验证（POV 感知/焦点切换）；情绪经显影
- W2 代价在纸上＋特异性（换人测试）
- W3 一致性：行动卡骨架如实呈现·行为偏移落地不解释来源
- W4 锚点约束：元素/人物存在性＋形态与注册原文一致（`worldctl grep <元素名>` 核对）——代码化部分由 gate writer --check 强制
