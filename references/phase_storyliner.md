## 公共评估（本阶段第一动作·供 D1–D4 取用）

**问题**：上轮落盘的结构与冲突池，对本轮的结构动作提出什么要求？四项事实观察：

- **冲突池扫描观察**——conflicts 全表（①本批刚落盘的结算结果）中**未被任何活跃线承载**的 CT（判据＝该 CT 的 `事件线引用` 不命中任何 `状态=活跃` 的事件线·含 NPC-NPC 冲突·与玩家 CT 同权）。CT 引用指向已收束线（SL 状态≠活跃）视同未引用；已收束 CT（生命周期到期已从 conflicts 移除）不参与扫描——在表 CT 即未收束。消费方：D5。
- **空间关联观察**——扫描出的候选 CT 中，对抗双方或资源载体落在 POV 感知窗口内（可目击/耳闻/见事后残局）者。NPC-NPC 线的拍序空间以 POV 角色感知窗口为锚（与 SKILL.md 通用约束「认知边界」一致）；玩家参与的线以玩家在场为锚。**扫描产出的是「与焦点场景空间关联的候选 CT」**——不与焦点场景关联的 CT 不入选（其张力在焦外自然演化·非焦点=自然挂起）；一个都不合格时以当前场景为锚兜底建线。消费方：D5。
- **活跃线对账观察**——`storylines.事件线` 中 `状态=活跃` 的清单（SL-XX＋指针是否在它上面＋该线当前拍）。消费方：D1（节拍落位规划需知现有线）／D3（哪条线待收束）／D4（有无活跃线可接）。
- **三问观察**（`direction.escalation_flags.不承接` 在场时执行）——`前提存续`＝对抗双方＋被争夺资源在新现实下仍成立·`问题存续`＝本线戏剧问题仍值得关注·`承诺存续`＝已投入的不可逆事实仍需本线兑现。消费方：D2。

## D1 弧线定位（参数型·框架层）

**决策问题**：本幕的宏观位置与节拍落位如何锚定？

**参数**:

| 参数 | 值 | 判据 |
|---|---|---|
| `当前幕` | 三幕骨架阶段名 | 对照 SETTING 故事弧线声明＋beat_structure 宏观骨架（三幕十五拍） |
| `张力基调` | `松` / `紧` / `极紧`（Score） | 本幕整体张力**实测**——两档判据：① SETTING「故事弧线」声明了张力预算 → 对照实测，**偏离则记实测值**（防微观有张力·宏观整体投降）；② **未声明**（该字段可选）→ 按 beat_structure 该幕骨架默认（第一幕 `松` / 第二幕 `紧` / 第三幕 `极紧`） |
| `节拍落位` | 当前幕全部节拍 → `SL-XX` / `待定` | **预先规划本幕全部节拍**——键域=当前幕节拍清单（权威=beat_structure.md §一）：**第一幕** 开场画面/主题陈述/铺垫/催化剂/挣扎犹豫（5）·**第二幕** 进入第二幕/B故事/游戏时间/中点/反派逼近/失去一切/灵魂暗夜（7）·**第三幕** 进入第三幕/高潮/终场画面（3）。**本决策写全表**（尚无承载线的写 `待定`）；**本批建线/收束承载的节拍由脚本批末回填覆盖**——D4/D3 把 `承载节拍` 写进 `###STORYLINE:` 行内参数，脚本分配出 SL-XX 后落盘，② 不需预知编号。**多线并存时由本决策判断哪个节拍该由哪条线承载**——`待定` 是设计判断，不是机械填空 |

**每批必写**（幂等·内容可不变）；**幕切换时整体重写**节拍清单为新幕的节拍。`待定` 堆积＝宏观结构跟不上的信号。**本幕主题/收敛边界不在本决策输出面**——弧线声明权威=SETTING，写入即镜像。

**本决策是本批其余决策的框架输入**：D4/D6 须对照 `当前幕`/`张力基调`/`节拍落位`（beat_structure.md「先读指引再规划」）。

## D2 不承接归位（判定型·处置层）

**决策问题**：原线（`direction.escalation_flags.不承接` 所指）何去何从？
**缺省选项**：无（三问组合穷尽三分支·恒命中一格）

**决策选项与选中标准**（依据三问观察·取最先命中的一行）:

| 顺序 | 选中标准 | 选项 | 结果语义 |
|---|---|---|---|
| 1 | 三问**全过**·原线只是被搁置（焦点被新事件夺走·无活跃线可接焦） | `保留挂起` | 原线不动（非焦点=自然挂起）→ 当轮建线接焦由 D4 承担 |
| 2 | 三问**全过但本拍预设局面已脱钩**，或 三问**不全过但线仍可续**（`前提` 或 `承诺` 存续） | `rewrite` | `###STORYLINE: rewrite N`（重规划走向·顶点约束同步重填·缺则拒绝·内容＝D6 拍序） |
| 3 | 三问**全灭**（前提崩塌＋问题无意义＋无承诺待兑现） | `clear` | `###STORYLINE: clear N`（废弃·整条抹为空锚点·direction 指针自动复位） |

**结果语义**：`保留挂起` 不产生 storylines 写入；`rewrite`/`clear` 由 write-raw 自动执行对应子命令。旗标由③导演下轮回判清除（direction 唯一写者·②不碰）。

## D3 收束决策（判定型·处置层）

**决策问题**：当前线是否收束？
**缺省选项**：不 close（以下标准均未命中时）

**决策选项与选中标准**:
- `close` — `direction.当前拍==余波` ∧ 该线余波拍已演出/待收束（视演出是否完整落地·close 非机械强制）
- `不 close` — 上述未命中

**参数**：`收束摘要`（选中 `close` 时必带·一行结局定性·缺则脚本拒绝——不想留档说明该走 clear 废弃）；`落定节拍`（本线实际落定的节拍·建线时 D4 的指派若与实际不符则在此更正·无更正则省略）——**写在 `###STORYLINE: close` 的行内参数上**（`###STORYLINE: close SL-01 落定节拍=高潮`），由脚本批末回填 `故事弧线.节点落位.{节拍}`。

**结果语义**：`###STORYLINE: close N` → 保留 名称/类型＋状态=已收束＋收束摘要·清拍序；当前线收束时 direction 指针复位 → 当轮须由 D4 建线接续（否则 round-check FAIL）。**余波拍戏剧问题限沉淀类**（确认/回响/伏笔入口），兑现形态=伏笔/下一动线入口，禁「加剧/深化」类措辞。

**与 D4 的关系**：close 与 add 两个**落盘动作**可同批（write-raw 无执行顺序要求）；**决策上 D4 消费 D3 的结果**——D3 判 `close` 是 D4「余波已兑现」标准的一种命中情况。

## D4 建线决策（判定型·结构层）

**决策问题**：本轮是否需要新建事件线？
**缺省选项**：不建线（以下标准均未命中时）

**决策选项与选中标准**:
- `建线` — 以下任一成立（命中即建线·取材与拍序由 D5/D6 给出）：
  - **无活跃线** — 活跃线对账观察为空表，或 D3 收束后指针复位无活跃线可接（空表由 gate/round-check 机械兜底）
  - **合并触发（机械·独立于语义评估）** — 同时满足：① 存在**与焦点场景空间关联**的未引用活跃线 CT；② 当前**无活跃线可接**（无活跃线；或 `direction.当前拍==余波` 且该线余波已兑现，且无其他非余波活跃线〔接触/升级/顶点〕可接）——每轮至多取一条
  - **原线搁置接焦** — D2 判 `保留挂起`（焦点被新事件夺走·原线非焦点=自然挂起）→ 当轮建线接焦
  - **余波已兑现** — `direction.当前拍==余波` ∧（**D3 判定结果＝`close`** ∨ 该线余波拍戏剧问题已被实质性回答）→ 余波拍=离开该线·须承接下一段叙事
- `不建线` — 上述标准皆未命中

**参数**（选中 `建线` 时随结果返回）：`承载节拍`——本条线承载的当前幕节拍（≥1·可多个）——**写在 `###STORYLINE: add` 的行内参数上**（`###STORYLINE: add 承载节拍=催化剂,主题陈述`），由脚本在分配 SL-XX 后回填 `故事弧线.节点落位.{节拍}`（`rewrite` 同：`###STORYLINE: rewrite N 承载节拍=…`）。

**结果语义**：`建线` → 产出 `###STORYLINE: add`（内容＝D6 拍序）＋ META 回显取材来源（D5）；起点指针由③导演 `###BEAT: set 新线 <起点拍>` 落 direction（②不碰 direction）。`add` 只增线·不构成对既有活跃线的处置义务。**「新线」＝本次批次 add 刚建的那条线**（SL-XX 由脚本自动分配·LLM 不需预知编号·同批/合批均可引用）。

## D5 取材（参数型·结构层）

**决策问题**：新线取材于哪条 CT？
**参数**:

| 参数 | 值 | 判据 |
|---|---|---|
| `取材` | `CT-XX` | 空间关联观察的候选中**紧迫度最高者**（每轮至多取一条·缺省视同🟢） |
| | `场景兜底` | 扫描零合格者 → 以当前场景为锚新建 |

**取材资格（硬性·gate 拦）**：该 CT 当前未被任何活跃线承载（已承载=已进入·取即违规）；已收束 CT 不参与扫描。

**新线主体**＝该 CT 的对抗双方＋被争夺资源。

**回显义务**：取材为 `CT-XX` 时 META 须回显 `取材=CT-XX`（gate 硬拦）；`场景兜底` 时 META 标注兜底来源。

## D6 拍序设计（参数型·结构层）

**决策问题**：这条线由哪些拍构成——**如何落进本幕骨架**？

**框架对照（硬性·先对照再设计）**：

| 对照项 | 取自 | 决定什么 |
|---|---|---|
| 本线承载的节拍 | D1 节拍落位 / 本批 D4 的 `承载节拍` | 拍序的**起拍与峰值位置**——承载 `催化剂` 的线从铺垫起、峰值在升级之后；承载 `高潮` 的线峰值在顶点且**必带 `顶点约束`** |
| `张力基调` | D1 | 拍的**量级与修正方向**——基调 `紧`/`极紧` 时升级与顶点取量级上界并偏上调；`松` 时取基准 |
| `当前幕` | D1 | 本线在骨架中的**功能定位**——对照 beat_structure.md 该幕节拍的功能定义（这幕该发生什么） |
| **起拍衔接** | 被收束线的余波拍（D4 由 D3 收束触发时）／当前焦点场景 | 新线起点拍的**空间与时间**——**承接原线余波拍的残余**：空间＝原线余波拍空间（＝当前焦点场景）·时间接续；**不得把起点拍放到尚未发生的场景** |

**参数**：拍序列表，每拍六字段：

| 字段 | 内容 |
|---|---|
| 空间 | 本拍发生地 |
| 时间 | 叙事时间落点（第几日/时刻·供事件线在时间轴上连贯·**不是时长**） |
| 预估时长 | 本拍发育期基准（`N分钟`·按下方拍型量级表） |
| 事件背景 | 本拍依托的预设局面或上拍已落定事实（一句话） |
| 戏剧问题 | 该背景下本拍必须回答的、有边界的戏剧问题（禁无界持续描述「加剧/深化」类措辞） |
| 兑现形态 | 问题被回答时的可观察形态：证据易手/被迫承认/控制权转移/关系定性/退路封死（代表性判据·非唯一路径·回答可经涌现路径达成·见 phase_director D4「自然完成判进」） |

**顶点拍另需 `顶点约束`**（五字段·参数内嵌）：`关系主体`（≥2 去重·不区分玩家/NPC——顶点的单位是关系不是单人·与 CT 对抗双方同构）/ `核心张力`（一句话·必须被推至临界的未决问题·点名赌注所在）/ `变化维度`（枚举 关系/认知/决策/资源·创作意图声明）/ `非玩家爆破`（≥1 外部角色或事件·主体静止时的加压力量·防死锁）/ `基准快照`（脚本进入顶点拍时自动记录·私有落档·LLM 不填不读）。定义级说明：**顶点约束＝目的声明**——这一场关系必须被推至的转变临界；**非玩家爆破＝手段**——手段可千变万化，验收只认目的。

**预估时长定档（Score·建线预估·③导演现场按实况重估·基准×修正关系）**——按拍型取量级（来源=影视行业场景/序列时长惯例：多数场景 1-3 分钟·序列 10-15 分钟·多场景叠加的拍更长）：

| 拍型 | 结构功能 | 基准量级 |
|---|---|---|
| 铺垫 / 接触 | 建立基线·引入变量 | **10-20 分钟** |
| 升级 | 对抗翻倍·推向临界 | **30-60 分钟** |
| 顶点 | 情绪极值·逼至临界 | **30-60 分钟** |
| 余波 | 能量沉淀 | **10-15 分钟** |

**修正规则（叠加在基准上）：** 多方角色互相咬合、对话密集的拍 → 量级**下调**（对白耗时长、单位时间推进快）；动作/环境驱动、单主体推进的拍 → 量级**上调**（视觉段落一页撑更久）。预估时长是**建线规划值**，不是硬约束——现场任何时刻以④角色自主演出为准，③导演按实况重估。

**结构硬约束（脚本机械校验·当场反馈）**：拍名 ∈ 五段式枚举（铺垫/接触/升级/顶点/余波）且不重复；拍序 ≥2 拍（新线从铺垫/接触起拍·余波由 advance 推进到达）；每拍必含戏剧问题。

**对照示例（模式锚定）**：本批 `当前幕=第二幕·对抗`、`张力基调=紧`，新线承载 `中点`——
- **起拍**＝铺垫（建立基线·不抢中点该在的位置）；**峰值**＝顶点（中点＝「长线中段转折·力量逆转」→ `顶点约束.核心张力` 须围绕"力量逆转"落笔，而非泛泛的对抗升级）
- **量级**：升级/顶点取量级上界（紧基调）·若拍内多方咬合则再下调
- **功能定位**：第二幕＝对抗 → 本线不承担"解决"功能（出线后由余波拍或新线承接）

## 过程留痕

**META 回显**（决策完成后落盘备查·**非决策**）：
- **取材回显**（D5 结果·gate 硬拦）：`取材=CT-XX` / `取材=场景兜底`；
- **结构动作回显**（D2/D3/D4 结果）：`建线SL-XX` / `归位SL-XX` / `收束SL-XX`。

**LOOPS 融入（循环世界·D6 的附加约束）**：在轨节拍并入事件线规划——**不标记来源**（角色层永不知晓事件线哪些部分来自预设循环）。

**storylines 是结构蓝图**——不含当前拍（指针权威=direction·③导演）；提供**结构问题，而不是角色行动脚本**。落点争议以④角色自治为准。
