# 阶段② · 编剧（结构引擎·阶段开始前必读）

> 职责：规划跨轮故事结构——回答「**这场戏整体要经历什么？**」。层级链：故事弧线→事件线→多轮拍序→每拍戏剧问题→顶点结构；只关注故事结构。
> 全局铁律=SKILL.md「通用约束」。Single Writer：storylines。
>
> **唤醒条件（v0.28 调度·详见 runtime_scheduler.md）——被唤醒才执行·未唤醒=无批·复用上轮 storylines：**
> - **结构基线缺失**（storylines 无活跃线 或 当前拍空）→ 强制结构轮·必跑（建线）；
> - **调度指令在场**：`escalation_flags.不承接`（②必须三问定原线去向 add/rewrite/clear）；
> - **语义信号**：拍问题已被回答（③ advance 后收束）/ 未引用 CT 且无活跃线可接（建线取材表）。
> - **未唤醒轮**：不产批次——storylines 维持上轮落盘值（结构蓝图=中长期·稳定期零成本）。

## 数据就绪（本阶段开头）

conflicts（①刚写——若①未跑则读上轮落盘值·②读最新落盘）＋ storylines ＋ direction（**escalation_flags.不承接 消化**）＋ world_state（焦点场景）＋ scene_state（出场摘要——建线取材场景侧）＋ SETTING 故事弧线 ＋ beat_structure 宏观骨架 ＋（循环世界）LOOPS 结构素材（跨角色互锁时刻） + 伏笔 foreshadow。

## 职责

1. **弧线校准（被唤醒时·结构事件级·非每轮）**：
   - 结构参考：references/beat_structure.md（宏观骨架三幕十五拍·规划前读）
   - 本幕主题/整体张力（紧/松）/宏观位置/收敛边界——一行张力基调确认写入 META；**同批加一行活跃线对账**（当前活跃线/遗留线是否演完待 close·无遗留= `无遗留`，有遗留= `SL-XX已演完待close`）；
   - 建线/重大推进时对照 SETTING 弧线（幕数/中点/高潮目标/张力预算）逐项校准；
   - 校准结论的持久落点=storylines.故事弧线（当前幕＋四节点落位·随重路径同批回写·见写入节）。**张力基调/对账=幕级概念·只在结构事件时（建线/收束/重规划/幕切换）执行——蓝图稳定期零成本（未唤醒轮不校准）。**
 
2. **建线/重规划/收束（触发式·结构性动作）**：
   - 结构参考：references/beat_structure.md（五段式节拍表/分形咬合·规划前读）
   - **建线取材表**（任一行命中 → `###STORYLINE: add`·META 回显取材来源（如 `建线SL-XX·取材=CT-YY`）；add 只增线·不构成对既有活跃线的处置义务；同批更新 故事弧线——首次建线=初始化·其后按宏观位置回写）：

      | 顺序 | 触发 | 取材 |
      |---|---|---|
      | 1 | 无活跃线（storylines 空表·或 close 后指针复位无活跃线可接） | 冲突池扫描（下方取材规则）——空表由 gate/round-check 机械兜底 |
      | 2 | conflicts 有未被任何活跃线引用的 CT（含 NPC-NPC 冲突·与玩家 CT 同权） | 紧迫度最高者（每轮至多取一条·缺省视同🟢）——资格与空间关联判据见下方取材规则 |

      **第 2 行取材规则：**
      - **取材资格**：该 CT 当前未被任何活跃线拍序承载（已承载=已进入·取即违规）。
      - **空间关联**：对抗双方或资源载体落在 POV 感知窗口内（可目击/耳闻/见事后残局）——无一合格则不取材，转冲突池兜底（以当前场景为锚新建）。
      - **新线主体**＝该 CT 的对抗双方＋被争夺资源。

      **合并触发（机械硬性·gate 拦）：** 同时满足以下两条 → 本轮必含 `###STORYLINE: add` 新线（取材按本表第2行·每轮至多取一条）：

      - 存在**与焦点场景空间关联**的未引用活跃线 CT；
      - 当前**无活跃线可接**（storylines 无活跃线；或 `direction.当前拍==余波` 且该线余波已兑现，且无其他非余波活跃线〔接触/升级/顶点〕可接——余波兑现后收束，停留由停滞/close 承接）。

      边界：已收束 CT（生命周期到期已从 conflicts 移除）不参与扫描——在表 CT 即未收束；CT 引用指向已收束线（如 SL 状态≠活跃）视同未引用。**未引用 CT 全与焦点场景无关联 → 不构成强制 add 源**——改以当前场景为锚兜底建线（扫描零合格者的兜底路径·见下行）。

      冲突池扫描＝conflicts 全表（①戏剧家批刚落盘的结算结果）＋当前焦点场景（world_state.焦点场景＋scene_state 出场摘要）。**扫描产出的是「与焦点场景空间关联的候选 CT」**——不与焦点场景关联的 CT 不入选（其张力在焦外自然演化·非焦点=自然挂起）。一个都不合格时以当前场景为锚新建线。NPC-NPC 线的拍序空间以 POV 角色感知窗口为锚（目击/耳闻/事后残局·与 SKILL.md 通用约束「认知边界」一致）；玩家参与的线以玩家在场为锚。
   - `direction.escalation_flags.不承接` → 依次答三问，**取最先命中的一行**归位原线。三问判据：`前提存续`=对抗双方+被争夺资源在新现实下仍成立·`问题存续`=本线戏剧问题仍值得关注·`承诺存续`=已投入的不可逆事实仍需本线兑现：

      | 顺序 | 三问答案 | 原线归位 |
      |---|---|---|
      | 1 | 三问**全过**，原线只是被搁置（焦点被新事件夺走·无活跃线可接焦） | 原线不动（非焦点=自然挂起）→ 当轮 `###STORYLINE: add` 新线接焦（取材按建线取材表）·由③导演 `###BEAT: set` 切指针 |
      | 2 | 三问**全过但本拍预设局面已脱钩**，或 三问**不全过但线仍可续**（`前提` 或 `承诺` 存续） | `###STORYLINE: rewrite N`（重规划走向·顶点约束同步重填·缺则拒绝） |
      | 3 | 三问**全灭**（前提崩塌+问题无意义+无承诺待兑现） | `###STORYLINE: clear N`（废弃·整条抹为空锚点·direction 指针自动复位） |
   - 进入余波拍且已兑现（`direction.当前拍==余波` 且戏剧问题已被实质性回答）→ 分别触发（互不依赖）：
     - `###STORYLINE: add` 新线——**优先**（余波拍=离开该线·须承接下一段叙事）：无其他非余波活跃线可接指针时必 add·取材按建线取材表（未兑现张力的去向登记可并入取材候选）；**有未引用活跃线 CT 时机械强制 add（见上方合并触发）**；
     - `###STORYLINE: close N`（收束·必带一行 收束摘要——结局定性；同批更新 故事弧线——节点落定·宏观进位）——当该线余波拍已演出/待收束时（close 非机械强制·视演出是否完整落地）；
     两者可同批、可分两轮先后落地，**不设先后依赖**。余波拍戏剧问题限沉淀类（确认/回响/伏笔入口），兑现形态=伏笔/下一动线入口，禁“加剧/深化”类措辞。
3. **拍序设计**——每拍填以下字段：

   | 字段 | 内容 |
   |---|---|
   | 空间 | 本拍发生地 |
   | 时间 | 叙事时间落点（第几日/时刻·供事件线在时间轴上连贯·**不是时长**） |
   | 预估时长 | 本拍发育期基准（`N分钟`·按下方拍型量级表） |
   | 事件背景 | 本拍依托的预设局面或上拍已落定事实（一句话） |
   | 戏剧问题 | 该背景下本拍必须回答的、有边界的戏剧问题（禁无界持续描述「加剧/深化」类措辞） |
   | 兑现形态 | 问题被回答时的可观察形态：证据易手/被迫承认/控制权转移/关系定性/退路封死（代表性判据·非唯一路径·回答可经涌现路径达成·见 phase_director 职责2） |

   **顶点拍另需预填 `顶点约束`**（五字段：关系主体/核心张力/变化维度/非玩家爆破/基准快照）。定义级说明：**顶点约束＝目的声明**——这一场关系必须被推至的转变临界；**非玩家爆破＝手段**（防死锁的外部加压·形式不限）——手段可千变万化，验收只认目的。

   **预估时长定档准则**（建线预估·③导演现场按实况重估·**基准×修正**关系）——按拍型取量级（来源=影视行业场景/序列时长惯例：多数场景 1-3 分钟·序列 10-15 分钟·多场景叠加的拍更长）：

   | 拍型 | 结构功能 | 基准量级 |
   |---|---|---|
   | 铺垫 / 接触 | 建立基线·引入变量 | **10-20 分钟** |
   | 升级 | 对抗翻倍·推向临界 | **30-60 分钟** |
   | 顶点 | 情绪极值·逼至临界 | **30-60 分钟** |
   | 余波 | 能量沉淀 | **10-15 分钟** |

   **修正规则（叠加在基准上）：** 多方角色互相咬合、对话密集的拍 → 量级**下调**（对白耗时长、单位时间推进快）；动作/环境驱动、单主体推进的拍 → 量级**上调**（视觉段落一页撑更久）。预估时长是**建线规划值**，不是硬约束——现场任何时刻以④角色自主演出为准，③导演按实况重估。

   - `关系主体` ≥2 去重（不区分玩家/NPC——顶点的单位是关系不是单人·与 CT 对抗双方同构）
   - `核心张力`：必须被推至临界的未决问题——一句话点名赌注所在（爆破点库挑最痛）
   - `变化维度`：枚举 关系/认知/决策/资源（立场/承诺/信息由认知·关系承载）——**创作意图声明**：宣告想推动什么类型的转变·指导张力走向与演出侧重（选维度时对照四类施压方向的可达性——保证戏剧家无论以哪种压力推进·峰值的转变都有落点）
   - `非玩家爆破` ≥1：外部角色或事件——主体静止时的加压力量（防死锁）
   - `基准快照`：脚本进入顶点拍时自动记录（私有落档·LLM 不填不读）
4. **LOOPS 融入（循环世界）**：在轨节拍并入事件线规划——**不标记来源**（角色层永不知晓事件线哪些部分来自预设循环）。

**storylines 是结构蓝图**——不含当前拍（指针权威=direction·③导演）；提供**结构问题，而不是角色行动脚本**。落点争议以④角色自治为准。

## 闸门

闸门随落盘逐段自动执行（硬性：###STAGE 匹配＋**被唤醒批必含**：STORYLINE 动作（add/rewrite/close/clear 按触发形态）+ 张力基调+活跃线对账（META 双声明·S3）+ 顶点约束（建线含顶点拍时）·不合格=本段整体拦截不落盘）；未唤醒轮（无②批）无此检查·storylines 上轮值保留。单段复检=`gate storyliner --check`。标准模式人工审计（S 清单）见 references/gates.md。
