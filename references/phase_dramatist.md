# 阶段① · 戏剧家（冲突引擎·阶段开始前必读）

> 职责：**持续制造和推进戏剧压力**——回答「哪里有戏？」。
> 全局铁律=SKILL.md「通用约束」。Single Writer：conflicts。
>

## 数据就绪（本阶段开头·只加载这些）

conflicts ＋ world_state（时间/倒计时/焦点场景/全局标记）＋ direction（**escalation_flags 消化**·停滞旗标当轮必须加压）＋ **scene_state（上轮场记事实·当前场景事件列表/道具状态）** ＋ 焦内外 CHAR_state（各角色 decision/连续行动轨迹/位置）＋ **pending_actions（焦外角色清单·识别相关焦外·登记 CT）** ＋ SETTING（核心高压法则/循环声明）＋（循环世界）相关角色 LOOPS（按需 `worldctl grep` 补读）。上下文已有→跳过。

## 职责（顺序执行）

1. **上轮 CT 结算**（每轮第一动作）：依据场记事实＋角色行动结果，逐条结算活跃 CT——资源易手了吗？控制权转移了吗？对峙态势变了吗？→ 更新 关系状态/内部状态/相位/被争夺资源。
2. **压力扫描**（每轮必做·META 留痕）：
   - 人际张力：在场角色两两 Desire/Fear 直接对抗/历史伤痕/关系档位变化 → 注册人际 CT（即使🟢也注册）
   - **自主目标冲突**：各角色 decision.当前目标 之间互相阻碍——**NPC 自主性是戏剧动力的一部分**（角色目标/计划/恐惧与外部压力的矛盾本身就是冲突）
   - 资源争夺 / 计划受阻 / 关系变化 / 欲望与恐惧
   - 循环轨道：偏离检测（decision.当前计划/实际行动 vs LOOPS 基线·差异即偏离）→ 偏离者四件套分发（见下）
   - 跨叙事压力（有 CROSS_NARRATIVES 时）/ 时间压力（外部倒计时/互锁窗口**逼近·定性感知**·只感知者注册·**不精确推进时间**——世界时间数字推进=⑤场记）/ 环境压力 / SETTING 核心高压法则落点（每轮必查）
3. **施压方向标注**（每轮·跟随推进池·写 `conflicts.施压方向`＋META 回显）：本轮推进的 CT 从哪个方向加压。三步顺序执行：
   - **Step 1 选方向**：本轮有明确新增/增压（新🔴CT / 触发 Value Boundary / 偏离增压 / 用户指令加压）→ 四爆破工程四选一：**死局两难**（保住A就要毁灭B·欲望与价值底线硬碰硬）/ **防御踩爆**（当众剥夺保护壳·逼最脆弱的本态面对）/ **关系撕裂**（因各自信念走向对立·双向善意的悲剧）/ **不可逆代价**（高压下的抉择·失去成为永恒）。本轮无新增压（观察/过渡/按部就班推进·轻量轮）→ 施压方向=`维持`（沿既有 CT 推进方向·不新选——轻量轮不必硬造方向）
   - **Step 2 维持连续核验**：上轮 conflicts.施压方向 已是 `维持` → 本轮改标四选一，并从推进池 CT 的未决时机取材构造具体压力情境
   - **Step 3 停滞旗标核验**：direction.escalation_flags.停滞 在场 → 本轮标四选一兑现加压（gate 核验）

   定位：施压方向是对压力的瞄准，不是演出计划的预测——怎么兑现交给③导演与④角色现场。
4. **推进池**（每轮至少推进或注册一条 CT·硬性）：用户显式指定 > 🔴 > 🟡 > 🟢 > 新注册优先；全部无 → **兜底创造新冲突源**（新角色/新信息/环境攻击/内部引爆）——「什么都没发生」不是可选输出。
5. **CT 生命周期**：发现→注册→发展→升级→转折→收束/**转化**（收束的 CT 转化为新冲突源）；未推进冷却降一级；「Host vs 法则」型豁免冷却（紧迫度绑定偏离状态）；未推进冲突在焦外演化（①据焦外角色实际动作+冲突推进更新 conflicts.紧迫度/内部状态——**非节拍字段**·休眠≠消解·回归时🔴）。
6. **偏离冲突化**：行动级偏离 1 次即注册「Host vs 法则」CT（冲突化窗口归零）；轻微偏差走状态结算（④角色自记偏离登记）。偏离者四件套：a 状态结算=④角色；b 冲突化=本阶段；c 超限埋后果（登记外部倒计时·必带期限）=本阶段；d 回归判定=③导演。

## 写入（conflicts 唯一写者）

CT 八字段：描述/对抗双方（抽象方必附显现机制：代理人/机制载体/心理显影）/被争夺资源（`{资源}·当前载体/持有者={谁/在哪}·双方动机`·**挂钩内部变量——是 Desire 的载体、恐惧的化身，不是地图上的一个点**）/关系状态（空间占位+攻守态势+未决时机）/内部状态（各角色生理+认知+未抉择分叉）/相位 ⏩🔄/紧迫度/关联角色＋**事件线引用**（storyline_refs·关联结构由②编剧维护）。
