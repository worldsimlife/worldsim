## 一、上轮 CT 结算

**逐条结算活跃 CT**——依据场记事实＋角色行动结果，回答 D1–D6 六个问题。**只有实质变化才写**（无变化即不写该字段·缺省=未变）。

### D1 资源归属（判定型·逐 CT）

**决策问题**：该 CT 的被争夺资源易手／控制权转移了吗？
**缺省选项**：未变（以下标准均未命中时）

**决策选项与选中标准**:
- `易手` — 被争夺资源的持有者/载体发生转移（资源易主·载体状态改变·被摧毁/被夺取）
- `转移` — 资源归属未变，但**控制权**易手（谁在主导这个局面变了·攻守易位）
- `未变` — 上述未命中

**参数**（选中 `易手`/`转移` 时随结果返回）：`新归属`——一句话写新的持有者/载体状态（写进 `被争夺资源` 的 `当前载体/持有者=` 位）。

### D2 对峙态势（判定型·逐 CT）

**决策问题**：该 CT 的对峙态势变了吗？
**缺省选项**：未变（以下标准均未命中时）

**决策选项与选中标准**:
- `有变` — 空间占位／攻守态势／未决时机三者任一发生实质变化
- `未变` — 上述未命中

**参数**（选中 `有变` 时随结果返回）：`态势快照`——多行 prose，写 空间占位＋攻守态势＋未决时机（对峙动力学）。

### D3 内部状态（判定型·逐 CT）

**决策问题**：该 CT 各角色的内部状态有实质变化吗？
**缺省选项**：未变（以下标准均未命中时）

**决策选项与选中标准**:
- `有变` — 任一关联角色的生理反应／认知判断／未抉择分叉出现新内容
- `未变` — 上述未命中

**参数**（选中 `有变` 时随结果返回）：`内部快照`——多行 prose，逐角色独立写 生理反应＋认知判断＋未抉择分叉。

> D2/D3 的产出是**快照**（仅记录上轮实况）——**本轮角色不读作当前真态**（会错误影响角色行动）。

### D4 相位（判定型·逐 CT）

**决策问题**：该 CT 此刻处于生命周期哪个阶段？
**缺省选项**：推进中⏩（以下标准均未命中时）

**决策选项与选中标准**:
- `转折点🔄` — 该 CT 发生结构性翻转（力量逆转／关系定性／退路封死／控制权易位）
- `休眠` — 本轮未推进**且**紧迫度已降至 🟢 后仍无新压力（**休眠≠消解**·冲突在焦外继续演化）
- `推进中⏩` — 上述未命中

**结果语义**：`休眠` → 该 CT 退出紧迫度面（D5 不再评级）；**回归时**（被重新触及）→ 相位回 `推进中⏩` ＋ 紧迫度 `🔴`。`Host vs 法则` 型 CT 的相位/紧迫度**绑定偏离状态**，不参与冷却。

### D5 紧迫度（评级型·逐 CT）

**决策问题**：该 CT 此刻多紧迫？（恒选最贴合一项·无缺省）
**适用对象**：相位 ≠ `休眠` 的活跃 CT。

**决策选项与选中标准**:
- `🔴` — 客观紧急（外部倒计时逼近／资源控制权突变／§1a 互斥窗口临近／被重新触及的休眠回归）
- `🟡` — 有压力但未到临界
- `🟢` — 低压力·焦外自然演化

**基线（不是规则·可被覆盖）**：每轮未推进 → 降一级（🔴→🟡→🟢）；再一步即 **D4 转 `休眠`**。
**覆盖条件**：客观紧急**直接升级**；**激活重置**（休眠中被触及 → 回 🟡 或 🔴）。
**输入**：外部倒计时逼近／被争夺资源控制变化／对抗态势／人际张力／场记新事实；precheck §1a 临近互锁事件作为时间压力一并输入。**重估结果直接落在 `CT-XX.紧迫度` 上**（逐条 CT 一个值·数据层即留痕·META 不复述）。
**边界**：`Host vs 法则` 型豁免冷却（紧迫度绑定偏离状态）。

### D6 CT 存续判定（判定型·逐 CT）

**决策问题**：该 CT 是否已收束？
**缺省选项**：存续（以下标准均未命中时）

**决策选项与选中标准**:
- `已收束` — **同时满足**：① `相位 = 休眠`；② 被争夺资源**已有定论**（易手定局／控制权已定／退路封死／对抗双方关系已定性）；③ **无未决时机**（没有还在等兑现的下一步）
- `存续` — 上述未命中

**结果语义**：`已收束` → 本批产出 `###DELETE: CT-XX`（整条从 conflicts 移除）。**转化**＝若其张力仍需承接，同批由 **D8** 注册新 CT（「收束的 CT 转化为新冲突源」）。**并集条目**（事件扩散产出）随该 CT 收束/休眠一同清除。

## 二、压力扫描

### D7 轨道判定（判定型·逐角色·每轮必查·并行成员）

**决策问题**：各相关循环角色此刻处于轨道哪个状态？（**每轮必查·不依赖本批是否已有 CT 推进**）
**缺省选项**：在轨（无差异即无偏离）

**决策选项与选中标准**（依据循环轨道观察）:
- `偏离·离岗` — 决策/行动 vs `CHAR_.md`「默认循环时间线」基线存在**行动级偏离**（离岗／跨节点／结构性行动变更）
- `已回归` — 上轮偏离者本轮回基线
- `在轨` — 上述未命中（轻微偏差＝记忆碎片渗透/短暂出神，不算·走状态结算）

**结果语义**：META `轨道✓(全名=状态·限定词; …)`——**逐角色结论·格式与分隔符见 `loop_machinery.md §1`**；裸勾、或只写「无偏离」而无逐角色基线对照 = 本层未扫描（gate 硬拦）。偏离者 → 本批 **D8·源④轨道** 执行冲突化；**状态结算归 ④**（① 只判定·不代写 CHAR_state）。

### D8 逐源快判（判定型·十源·每源必表态）

**决策问题**：本源本轮有没有压力？（**逐源各判一次·十源全表态**）

**决策选项与选中标准**（每源 `有` / `无`；`有` → 按本源的产出落地）:

| 源 | `有` 的判据 | 产出 |
|---|---|---|
| ① 人际 | 在场角色两两 Desire/Fear 直接对抗／历史伤痕／关系档位变化 | 注册人际 CT（**即使🟢也注册**） |
| ② 目标 | 各角色 `decision.核心诉求` 之间互相阻碍 | 注册 CT |
| ③ 资源 | 资源争夺／计划受阻／关系变化／欲望与恐惧 | 注册 CT |
| ④ 轨道 | D7 判出偏离者（行动级偏离 1 次即注册·冲突化窗口归零） | 注册「Host vs 法则」CT |
| ⑤ 跨叙事 | 有 `CROSS_NARRATIVES.md` 且其触发链被本批事实命中 | 注册/更新 CT |
| ⑥ 时间 | 外部倒计时／互锁窗口**逼近**（定性感知·**只感知者注册**·不精确推进时间） | 更新紧迫度 / 注册 CT |
| ⑦ 环境 | 环境变化构成压力 | 注册 CT |
| ⑧ 法则 | SETTING 核心高压法则落点（**必查**） | 注册/更新 CT |
| ⑨ 扩散 | 重大突发事件（物理强制／性／死亡／背叛／暴力升级／显著认知冲击） | 见下三步 |
| ⑩ 兜底 | 用户指令无压力 ∧ 无🔴/🟡 ∧ 本轮无新注册 | 兜底创造新冲突源 |

**源⑨ 扩散·三步按序**：① **关联角色并集（硬性）**——事件的**在场具名**受影响者与目击者全部并入该事件 CT 的 `关联角色`（群像不入表·用事件描述/全局标记承载）；并入＝事实登记（谁被这件事波及），**不动对抗双方与被争夺资源**；该并集同时是 ③调度单 与 ⑤cast 的取人源。② **爆破点核对（逐被并入者）**——该事件是否踩中此角色爆破点库（Desire/Fear/Defense/价值底线/关系锚点）？踩中→冲突落地（推进其关联 CT·或按爆破点注册·紧迫度可🔴）；未踩中→**不建 CT**，只作关联角色＋常规反应。③ **并发负载**——单轮新注册 CT ≤2–4 条，超限分轮，优先度 `🔴＞用户指令关联＞事件关联者＞目击者`。

**源⑩ 兜底·硬约束**：「什么都没发生」不是可选输出——**新角色建档义务（硬性）**：创造的具名角色若要有台词/自主行动 → 同批或次批内补建 `CHAR_.md`（精简档即可）＋`CHAR_state`；不建档则降级为无名群像/纯外压（叙事不得给其具名台词）。

**参数**（任一源命中时随结果返回）：新 CT 的 `描述`/`对抗双方`（抽象方必附显现机制）／`被争夺资源`（须含 `当前载体=`/`当前持有者=`）；或既有 CT 的更新字段。

### D9 顶点爆破源登记（判定型·独立扫描·不依赖停滞旗标）

**决策问题**：本拍顶点约束声明的爆破源，在事实层有载体吗？
**触发**：`direction.当前拍==顶点`（非顶点拍 → 本决策不适用）。
**缺省选项**：已登记（以下标准均未命中时）

**决策选项与选中标准**:
- `未登记` — 顶点观察显示爆破源**两根载体皆缺**（`CT.关联角色` 与 `world_state.外部倒计时` 都无承载者）
- `已登记` — 至少一根载体在场

**结果语义**：`未登记` → **本批指定**（爆破源已在设计层声明、只在等载体落地，指定是①的本职·不是等旗标）：新主体类写 `CT-{新ID}.关联角色`（含被卷入的既有角色）；事件/机制类**只指定** `world_state.外部倒计时.{新CD-ID}`（名称/类型/到期时刻/剩余时间/说明/感知者），**落盘=⑤场记**。`已登记` → 核对 `剩余时间`／相位是否需按当前世界时间推进。

**此条为独立触发：不依赖 `escalation_flags.停滞`**（停滞旗标的登记义务见 D11·两条判据不同、目的地相同）。

## 三、推进池及施压方向

### D10 推进池（参数型）

**决策问题**：本轮推进哪条 CT？
**硬约束**：**至少推进或注册一条 CT（本批必含）**；推进该 CT 时**批次必含资源状态变化——不更新=该 CT 本轮没推进**。

**前置分支（先于排序）**：**用户指令分流**（仅 SKILL.md 第四类常规轮角色输入参与本分流·引擎命令/查询不参与）——用户指令命中**冲突压力四类判据之一**（判据唯一权威位＝`runtime_scheduler §1`）→ 该 CT 进入推进池首位；未命中 → 视为日常行为（仅作压力扫描的输入·不参与排序）。META 记录用户指定是否命中。

**参数**：`CT-XX`（排序规则·取先）:
1. 用户指令制造了明确的冲突压力
2. `🔴`
3. `🟡`
4. `🟢`
5. 新注册优先

**全部无符合条件** → **D8·源⑩兜底**创造新冲突源（新角色／新信息／环境攻击／内部引爆）。

### D11 施压方向（判定型·Choice5）

**决策问题**：该 CT 本轮从哪个方向加压？
**适用对象**：D10 选中的推进池 CT。
**缺省选项**：`维持`（以下标准均未命中时）

**前置分支（先于选项评估）**:

- **余波拍且已兑现**（`direction.当前拍==余波` ∧ 该线戏剧问题已被实质性回答）→ **本批不评估本决策**（**余波只结算·不施压**·不写施压方向）。
- **顶点拍收停滞**（`当前拍==顶点` ∧ 停滞旗标在场）→ 施压方向即「**让爆破源到场**」（压力源＝本拍 `顶点约束.非玩家爆破`·见 D9），**不得另寻方向绕开它**。
- **停滞旗标在场**（`escalation_flags.停滞`·非顶点拍）→ 本轮**至少一条**推进 CT 的施压方向为四爆破之一，**且同批含新变量载体**（见下「载体登记」）；优先选择重估后 `🔴`／`🟡`／与 SETTING 核心高压法则关联的 CT；均无符合条件时按**兜底创造新冲突源**兑现，**禁止**使用 `🟢` 且非核心高压法则关联的 CT 兑现。

**决策选项与选中标准**（四爆破须含具体压力源、受力点与转变方向；须以该 CT 关联角色的**档案基准动作**（如 Hector=掠夺）为指向，**不出可抄为 ACTION 的通用动词**）:

- **`死局两难`** — 制造无法两全的选择：保住A必然牺牲B，满足欲望必然触碰底线，履行责任必然放弃私愿。不给角色安全的第三条路，迫使其用实际选择暴露真正的欲望、价值排序或底线
- **`防御踩爆`** — 直接击穿角色赖以维持现状的保护壳：秘密被揭开、伪装被拆穿、软肋被触碰、身份被暴露，使角色无法继续躲藏或维持体面，必须以最真实、最脆弱或最危险的本态回应
- **`关系爆破`** — 人物关系发生不可忽略的结构性改变：相遇、吸引、告白、承诺、绑定、背叛、对立、决裂或和解均可。重点是让两个人再也不能停留在原来的关系状态；新的关系本身必须制造新的欲望、阻力或风险
- **`不可逆代价`** — 把角色的选择变成无法撤销的现实后果：失去、牺牲、暴露、承诺、债务、身份改变、机会关闭、权力转移等。重点是永久改变其之后还能走哪些路，使故事无法无损地退回原点
- **`维持`** — 本轮不对该 CT 额外加压（**可省略说明**）

**参数**（选中四爆破之一时随结果返回）：`说明`——**一句压力说明**，写清**压力从哪来、作用于何处、局面被推向什么转变**。
- **写**：外部/内部受力源（谁的行动、什么倒计时、哪条法则、哪段历史伤痕）·受力点（哪条保护壳、哪份隐瞒、哪个承诺、哪条退路）·转变方向（无法两全、保护壳失效、关系不可复原、路径永久关闭）。
- **不写**：角色怎么选（坦白/原谅/决裂/牺牲）·下一场演什么（当众揭穿/安排对峙）·结算结果（已易手/已决裂——归 CT 八字段）。说明写**角色被放进什么处境**，不写**角色在这个处境里做什么**。
- 示例：`关系爆破——Logan 的尽职调查逼近 Angela 的保护性隐瞒，两人信任结构的受力点从「是否知情」转向「知情后是否仍被保护」`。
- 示例：`防御踩爆——Angela 赖以维持专业的迎宾脚本在身体相贴的距离上失去可执行的体面，受力点是「完美」这条保护壳`。
- 反例：`关系爆破——Angela 向 Guest 坦白，Guest 选择原谅`（预写角色选择与行动）。

**结果语义**：**施压方向是对压力的瞄准，不是演出计划的预测**——说明压力从哪来、压在哪；怎么兑现交给③导演与④角色现场。**落点争议以④角色自治为准**。

**载体登记（同批·D9/D11 共用）**：新变量须登记认知层载体——`CT.关联角色`（③调度单入场承载；威胁/事件类同样以 CT 承载——对抗双方/被争夺资源即该威胁的显现）。需落 `world_state.外部倒计时` 时，本阶段只**指定**（写明 CD-ID/名称/类型/到期/感知者），落盘＝⑤场记同轮登记；**④角色只感知已登记**的处境，施压方向说明仅是瞄准。载体登记不止服务于停滞加压——顶点拍的爆破源同样经由载体落地；**载体是「④能感知到什么」的唯一事实源，登记时机由戏剧需要决定，不由旗标决定**。
