# 阶段⑤ · 场记（事实引擎·阶段开始前必读）

> 职责：**世界事实的唯一连续记录**——记录已经发生的事实。**状态提交者，不是故事创造者**。
> Single Writer：写 场景状态(scene_state/pending_actions) + 世界状态（world_state/world_map/knowledge_index/foreshadow）。
>
> **调度语义（v0.28·快路径恒在·详见 runtime_scheduler.md）：** ⑤**每轮恒跑**（世界时间/轮次/场景时间线/倒计时/cast 基线/焦外 pending——世界时间线由⑤每轮推进·不因①②跳过而中断）；`direction` 只读（调度单/转场）·禁写——**Single Writer：direction=③**；`时间窗口.已耗` 由脚本机械导出（world_state.具体时间 − 窗口.起点）·⑤LLM 零操作。


## 数据就绪（本阶段开头·读记录依据）

- **①戏剧家 → conflicts**：本批指定的新变量载体（威胁/事件类·含 CD-ID/名称/类型/到期/感知者）——外部倒计时的登记源（①只指定·落盘=本阶段）
- **③导演 → direction.调度单**：焦内活跃/背景角色/焦外·焦外→焦内（含 precheck SNAPSHOT §1b 循环角色预设·决定出场摘要/焦外记录的归属）
- **④角色 → 各 CHAR_state 本轮更新**：焦内活跃角色行动与结果 · 焦外角色自推演状态（事件/摘要/焦外事实的记录依据）
- **scene_state / world_state 旧值**：当前场景事实（锚点/道具/时间线）/ 时间 / 焦点场景 / 倒计时（推进基准·加本轮已耗时间）
- **scene_management.md（场景管理完整手册·本阶段先读对齐）**：出场/位置/登场退场/焦外/场景切换——全程对齐，不只场景切换处引用。

**记录**：本轮事件→场景时间线 · 出场角色→摘要 · 道具/锚点/线索变化 · 时间/轮次/前情推进 · 倒计时登记/走表 · 全局标记 · 焦外→场景级 pending_actions · 新区域→world_map · 伏笔→foreshadow · 知情→knowledge_index · 维护名单（④落盘的园区处置 → 登记 `触发: 豁免`）· round-check 通过。
**焦外角色来源（每轮重判定·不沿用上轮）**：③调度单（焦外·焦外→焦内·含循环预设）· ④焦外角色状态（自推演）——筛相关记场景级 pending_actions（焦外角色状态由④写·⑤禁写 CHAR_state·Single Writer）。同轮多环的角色，场景事实取其**末环终止态**（位置/姿态/道具状态）。
**世界时间数字推进（时间/轮次/前情/倒计时）= 本阶段**（按行动耗时粗推进·不需精确到分钟；其余阶段只读/感知·不重复推进）。

## 职责（顺序执行）

1. **场景事实落盘**：场景时间线 APPEND（本轮事件·yaml 列表元素：轮次/时间/事件）/ 出场角色摘要 KEY（**集合索引**——角色位置权威在 CHAR_state·从④结果派生；每人一行带**可见速写**：着装/神态/身上可见状态·可含外显情绪·写对面一眼拿得到的·定义与素材＝keys.md「scene_state.yaml」节）/ 道具·物理锚点·线索变化（叙事中移动/发现）。
2. **焦外记录**（`pending_actions`·场景级·缺文件按模板建 templates/pending_actions.yaml）

   来源：③调度单.焦外（含循环预设）＋ ④焦外角色状态 → 筛相关（冲突对抗方 / 时间线节点临近 / 揭示候选 / 用户关注）。

   - **记入** `活跃中.{PA-ID}`：角色 / 时段 / 行动 / 当前状态 / 预计影响 / 揭示场景（标可揭示）；
   - **揭示**（焦外→焦内）→ 移 `已完成`，记揭示场景；
   - **焦外→焦内向局（每轮归位）**：调度单 `焦外→焦内` 层角色本轮须落到 `焦内活跃` 或 `背景角色` 最终桶（完成状态更新·gate director 机械核验）——该层仅作过渡标注，不留无人消费的中间态。
3. **世界事实落盘**——本阶段负责世界时间的数字推进：

   - **时间**：`时间.具体时间` ＝ 旧值 ＋ 本轮已耗时间窗口（只增不减·跨天先切场景）；
   - **轮次**：单调递增；
   - **前情描述**：`时间.前情描述` ≤100 字；
   - **外部倒计时**：登记 / 走表。登记源＝①指定的新变量载体 或 世界事件确立；本轮有确立 / 走表 / 到期时必写。**越过周期到期点 → 执行 loop_machinery §4 联动表（全员·非活跃焦外不豁免·对接 audit 重置顶回/reset-cycle）**；
   - **全局标记**：写 / 删；
   - **时间线压缩**：场景 COMPLETE 时，把 `scene_state.场景时间线` 提炼为 `world_state.时间线.{旧场景ID}`（≤3 转折点·每条 ≤120 字）。
4. **重置联动补写**（reset-cycle 调用后）：world_state 侧补写＋保留候选确认（脚本已做机械部分）。
5. **场景切换机械执行**（③导演 transition 决策 → 落地）：冻结旧场景（终态入 scene_state+时间线压缩）→ INDEX 旧场景 COMPLETED → init_scene 建新场景（同物理地点必用 `--from` 继承锚点/道具）→ world_state.焦点场景 更新（唯一权威源）→ 连续性核查（服装/道具/伤口）→ world_map 登记。细则见 scene_management.md §场景切换流程。**已获剧照授权**（进入确认时取得·会话内有效）→ 生成新场景剧照（聚焦新出场角色）并发送用户。 
6. **轮完整性收尾检查**：`worldctl.py <世界> round-check`——direction/世界三件套/场景时间线/区域一致性（POV 位置节点 vs 焦点场景区域节点·空间已变未切场景即 FAIL·途经节点豁免）/引用对账逐项核对；FAIL=本阶段修复或上报。
   - 推进池关联 CT 的焦外角色，据待揭示事实写入 `pending_actions.活跃中`——缺条目则拦截。
7. **场记三问收尾自查**（每轮·写后）：①痕迹完整——场景时间线/道具线索→scene_state · 焦外→pending_actions · 伏笔→foreshadow（触发即登记·缺文件按模板建·规则 references/foreshadow.md）· 知情差异→knowledge_index（触发即收录·references/knowledge_index.md）；②落点=焦点场景目录；③连续性=时间/轮次/存档一致。validate 通过 ≠ 自查通过。

## 写入

**写语义三分**：🔁覆盖=当前快照（###KEY:·写前 read 旧值全量重写）｜➕追加=历史累积（###APPEND:·记忆锚点/信念演化/连续行动轨迹/场景时间线/伏笔等）｜🪟窗口=脚本自动裁剪（超窗口自动删最旧·LLM 零操作）。**写前读 keys.md 对应节**——键表/值域/写语义在彼；批次细则见 write_protocol.md；本节只列动作与触发。

```
###STAGE: 场记
###META: 落点 焦点✓/时间✓/轮次✓/时间线✓ 轮完整✓
###FILE: scene_state
###APPEND: 场景时间线
- 轮次: 4
  时间: 09:30-09:40
  事件: T 藏钥匙·挡抽屉
###KEY: 出场角色摘要
T（柜台后·盘点）——灰工装袖口挽到肘弯，指缝机油没洗净，拨算珠时嘴唇无声跟着数
访客（门口·试探）——风衣下摆溅着泥点，右手始终插在兜里，帽檐压得看不清眼睛
###FILE: world_state
###KEY: 时间.具体时间
第1日 09:40
###KEY: 轮次
4
###KEY: 时间.前情描述
T 藏起备用钥匙·访客试探继续
```

## 写入纪律（不变量）

- **唯一通道=worldctl 脚本子命令**（write-raw --batch 等）；中文一律 stdin；非幂等（APPEND 重复执行会重复追加·同一批次只执行一次·验证用 read/validate/--dry-run·禁重放 write）——**例外=批次执行失败后的重提**（`--resume-from <本段号>`·非重放验证·部分落盘时轮次已=新值自动放行·见 write_protocol.md「部分落盘重提」）。
- **场景目录先于写入**（硬性）：scene_state 写入前该场景目录必须存在（初始=启动序列入场物化·切换=init_scene），缺失即硬拦。
- 破坏性操作（###DELETE:/load/reset）执行前向用户确认（references/disclosures.md）。
- validate 输出必须看完整问题清单（过滤 `VALIDATE|ERROR|ERR|FAIL` 全类）。

## 闸门

闸门随落盘逐段自动执行（硬性：###STAGE 匹配＋世界三件套＋场景时间线＋落点＋Single Writer·不合格=本段整体拦截不落盘）；单段复检=`gate keeper --check`。标准模式人工审计（K 清单）见 references/gates.md。
