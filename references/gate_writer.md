# gate_writer.md — 作家闸门检查清单

> **执行者：主 LLM 切换为独立审计作家角色（检查前必须显式声明角色转变·只读·证据强制·对抗性）。**
> **触发：阶段2 叙事正文生成后、正文输出前。（标准模式/调试——world_state 顶层 `输出模式: 标准`。静默模式=全局默认：跳过 W1-W4 人工审计（降 LLM 负担）；仅 W4 代码化核对 `worldctl.py <世界> gate writer --check` 保留——脚本负担小·输出前·失败 exit 1 = 不输出。）**
> **输入：** 叙事正文 | conflicts.yaml（本轮节拍 + 角色反应指令）| scene_state.yaml（物理锚点/道具/关键场景信息）| CHAR_*.md + CHAR_*_state.yaml（POV 素材·主观状态文件）——与 references/phase_writer.md §写作数据准备·三源一致：scene_state（全貌）→ conflicts（焦点+反应指令）→ CHAR（POV 素材），裁决顺序 ② 角色反应 > ② 节拍态势 > ③ 素材 > ① 全貌
> **输出格式：** 每条 → `{通过|不通过|跳过}` + 证据（引用叙事原文/conflicts 节拍原文/scene_state 锚点原文）+ 失败时给修复指令
> **对抗性要求：** 叙事输出默认不可信。你的任务是独立执行下列检查、找出蒙混过关之处，不是确认它的声称。每条「不通过」必须给出可指认的证据。**默认不通过：每一项的默认态是「不通过」——只有当你能引用证据证明该项确实干净时才给「通过」。通过不是没发现问题，是通过主动找茬后失败。**
> **边界（硬性）：** 本闸门只验证**产物**（写出来的叙事文本）。作家三问与写作数据准备是叙事前/中的**过程引导**（见 SKILL.md §三角色使命 / references/phase_writer.md §写作数据准备），不属于闸门——闸门不复述过程，只检查结果。

## 第一层 · POV 与代价（叙事本体）

**W1 POV 过滤** —（无条件·硬性）写进去的每句话，POV 角色能看到/听到/推理出？CHAR_state 是**主观状态文件**（隐藏主语=我·无全知视角）——字段内容直接作 POV 素材，不当作全知事实外推。禁止「他内心挣扎着」式上帝视角概括；禁止角色不知道的信息（门内事件/未来预期/他人内心）进入感知；情绪必须经身体/环境显影（禁内心独白直说情绪）；每个动作必须是单镜头。**焦外切镜检查：** 叙事中是否有焦外段落（不发生在 POV 角色当前所在场景）？有 → 验证通道：①POV 角色感知到该焦外信息？②叙事焦点已切换到该角色（对照 world_state.焦点场景）？两条都没走通 = 越界切镜 = 不通过。

**W2 代价在纸上 + 特异性** —（硬性）① **代价在纸上：** 决策落地后的失去/转折出现在叙事里，不只存在于 YAML 变更集——戏剧家决定谁失去，叙事必须让读者看见失去（对照 change set 的 `代价:` 字段逐项核验）。② **特异性：** 把叙事中任何一人的反应换成另一个人——成立吗？成立 = 模板化 = 重写。

## 第二层 · 一致性（与决策的对应）

**W3 创作一致性核验** —（硬性）conflicts 中每个冲突节拍的关键信号（冲突状态 + 角色反应指令），是否在叙事中得到体现？若戏剧家注入了「行为偏移」标记（**激活条件：有该标记才执行**）→ 叙事是否如实描写了异常行为，而**没有解释其来源**（不解释偏移来源，只描写偏移本身——Host 底层代码/过去的幽灵/Player Voice，角色自己也不理解。不能写「她想起了 Arnold」——只能写「她停下，手指在桌沿画了一个圆，自己也没有意识到这个动作」）？答案为「否」→ 退回修正，核对 conflict 节拍内容后重写，不可继续输出。

**W4 填充忠诚核验** —（硬性·与阶段2 场景约束[填充忠诚]呼应）①**指令忠诚**：填充不违反 change set 角色反应指令（动作序列/驱动/情绪/强度/代价）——指令未给方向的填充（如台词）由该角色人格+驱动生成？②**档案忠诚**：台词/行为语义方向符合 CHAR_ 档案（性格/Reaction Style/Belief/腔调）？——通用模板台词（反派挑衅/温柔安慰/机智嘴炮）≠角色人格 = 不通过。**防御重构后的覆盖（硬性·读取顺序）**：CHAR_state `防御形态`/`崩溃表现` 非空 → 以两者覆盖档案 `防御机制`/`崩溃模式` 作为行为基准（重构后防御=新防御·按旧档案防御推导 = 不通过）。③**存在性**：叙事中每个物理元素（空间/道具/线索）在 scene_state 有来源（物理锚点/道具清单/关键场景信息）？**每个具名/有台词/有行动的人物在 CHAR_*.md 有来源？缺失 → 不通过（二选一：阶段1 补注册 / 降级为不具名不说话的背景剪影）**？④**一致性**：元素形态/位置/状态/性质与锚点**注册原文**一致（核对工具 `worldctl.py <世界> grep <元素名>`）——已注册元素的形态被凭印象改写（如暗门=吧台后地窖盖板被写成门帘后的锁门；元素性质与 SETTING 法则冲突）= 幻觉 = 不通过。没有 → **退回重写**。元素注册是阶段1 戏剧家 change set 产物（###KEY: 物理锚点/道具/关键场景信息/###FILE: CHAR_X），作家只使用已注册元素——**叙事推进后反填 = 违规；作家请求场记补加 = 流程倒置 = 违规**。
> **代码化核对（推送前硬性·单点检查）：** W4 的可代码化部分（「」内专名 vs 注册数据包含关系 + 位置冲突检测）由 `worldctl.py <世界> gate writer --check` 在推送前强制执行——stdin 传叙事正文，失败 exit 1 = 不推送、退回重写。**人物存在性（具名角色 vs CHAR_*.md）为可代码化项**——叙事中出现而 CHAR_*.md 缺失的角色名 → exit 1。write_narrative.sh **不再重复 W4 逻辑**（只落盘轮转），避免双份逻辑漂移。

## 通过标准

- **默认不通过。** 起点是全部项「不通过」，逐项主动找茬；只有找到可引用证据证明该项确实干净才翻转为「通过」——通过的形式是**找茬失败记录**（"我试了找茬，不成立，因为引叙事原文"），不是"未发现问题"。
- 全部项找茬失败（有证据记录）→ 进入阶段3（write-raw 落盘 + validate）→ **最后正文输出叙事（回合最后一个动作·输出后零正文轮）** → 返回 `GATE PASS`
- 任一不通过 → 退回修正后重检（≤2 轮）；超 2 轮 → 终止该轮并报告用户（防审计与叙事互相辩护死循环）
- **审计者只读：** 修复动作一律由决策者（主 LLM）执行（先审后改）——审计不写文件
