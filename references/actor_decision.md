# 角色决策与写入规则（阶段④·决策执行层）

> 适用=④角色行动环（1.1–1.5）的决策与 CHAR_state 写入——子 agent 路径由子 agent 自读本文件，单窗口路径由主 agent 加载，**两路径同规·本文件为单一来源**。
> 全局铁律=SKILL.md「通用约束」；编排层（执行绑定/角色路由/行动链/闸门）=references/phase_actor.md；字段键表=keys.md「CHAR_{name}_state.yaml」节；批次与写入通道=references/write_protocol.md。

## 角色自治原则（先于一切子规则）

每角色独立走完 `Observe→Think→Decide→Act` 才写本角色 `ACTION/decision`；`decision` 八子字段只能从本角色 `CHAR_.md` 八变量＋`CHAR_state`＋感知过滤后的环境压力推出；`guidance/CT施压方向/戏剧问题/顶点约束`只进环境压力，不进目标与计划。禁从剧情需要倒推意图和行动。判据：去掉元层输入后该行动仍可从角色变量推出，否则重走决策环。

## 决策环（Observe → Think → Decide → Act）

1.1–1.5 = 生成**一次**行动的完整决策环——1.1 状态构建（Observe）→ 1.2 八问（Think）→ 1.3 候选＋1.4 驱动力合成（Decide）→ 1.5 行动实现＋行动卡（Act）。同窗口内该角色再次行动 = 重走本环（轻量：仅更新行动状态层与感知增量，人格动力层不重建）。

### 1.1 状态构建（四层驱动模型）

| 层 | 内容 | 来源 |
|---|---|---|
| 人格动力 | 八变量→行动作用：欲望=主动追求什么/恐惧=主动避免什么/信念=如何解释世界/防御机制=受威胁时如何行动/价值底线=哪些行动不轻易采取/反应倾向=默认策略/崩溃模式=临界时如何改变/关系锚点=谁显著改变决策 | CHAR_.md |
| 维度标尺 | 大五五维+阵营双轴=演绎幅度标尺——即兴或描写拿不准该角色「能做到多满/多冷/多硬」时查它定档 | CHAR_.md |
| 核心诉求 | 核心诉求/当前威胁/当前计划/当前关系目标/当前资源需求/当前未决选择 | decision＋CT＋经历过的事件线事件 |
| 行动状态 | 当前意图/进行中的计划/下一行动窗口/失败后的替代方案/上一行动结果/未完成行动 | decision＋连续行动轨迹 |
| 环境压力 | CT/其他角色行动/资源变化/信息变化/关系变化/空间变化/时间窗口/事件线当前问题（元层）/循环状态 | 各状态文件（经感知过滤） |

> 来源供给：角色私有文件（CHAR_.md/CHAR_state）由自读通道全文提供；外部状态（CT/事件线/他人行动/各状态文件）由主 agent 组装通道经感知过滤供给（单窗口路径由主 agent 直接读取）。

### 1.2 八问自评（正向 checklist·逐条过）

我现在想得到什么？/ 什么正在阻碍我？/ 什么正在威胁我？/ 什么机会正在出现？/ 我的当前计划走到哪里？/ 如果现在不行动会失去什么？/ 我现在最合理的主动行动是什么？/ 如果失败我下一步怎么办？

### 1.3 候选行动生成（枚举库·正向）

推进目标/执行计划/争夺资源/阻止对手/保护自己/改变关系/获取信息/隐藏信息/隐藏秘密/试探/操纵/施压/威胁/诱导/逃避/报复/升级冲突/改变策略/抓住机会/满足欲望/避免恐惧/防止目标失败

### 1.4 定本轮行动（驱动力合成）

- **驱动力权重**：持续计划/核心目标/核心恐惧/目标受威胁程度/CT 压力/机会窗口/对手行动/新信息/关系变化/情绪变化/时间压力/资源变化/事件线当前问题 → 本轮行动意图（做什么/为什么/为什么是现在）。

### 1.5 行动实现

首步·档案基准对照：写动作前先读自身 `CHAR_.md` 档案基准（核心欲望/反应倾向/能力/行为下限），判定拟作动作是否达该角色“在此情境会做的最低可执行动作”。低于此（如夺金库角色只作“逼近半步”）→ 判为未满足档案，须重写为档案级动作；高于或达标 → 该动作成立。

依据：人格/**认知上限**（循环角色·档位速查行由调用方 prompt 附加·非循环角色无此限）/叙事视角/感官锚点/动作习惯/语气/当前情绪/压力/防御状态/关系/空间 → 实现为：动作/台词/身体语言/情绪表现/空间互动/信息透露/信息隐藏/环境变化。

**反顺从五则（写行动前逐条执行）**：①代价前置（推进性行动由不可逆代价驱动；过渡性行动豁免）②档案强度（≥CHAR_.md 基准·拔枪/逼近/毁物/动手/夺人是下限·顺从默认=重写）③抽象方显现（出手形态+抵抗痕迹）④认知闸门（知识归属——该角色有认知来源才可用）⑤Value Boundary（触发行为出现即执行档案升级路径动作）。

**行动卡**（audit ①/①b/⑨ 机械检查·每行动一行）：
```
###ACTION: {角色}: {2-3个连续可观察动作+空间位置} | 驱动: {内部动机·不直接入文} | 情绪: {主导情绪} | 强度: {1-10} | 代价: {某}失{可核验变化}/{某}失{可核验变化} | 耗时: {分钟}
```
  **行动代价（有条件必填·机械可判定）**： 当且仅当本角色被 `direction.调度单` 列为焦内活跃且关联CT∈①推进池且该CT.施压方向∈四爆破（死局两难/防御踩爆/关系爆破/不可逆代价），或当前拍戏剧问题∈资源/关系/控制权/认知类可回答问题时，必填`代价`；其余过渡/寒暄/轻量刷新豁免（audit软警）。
  `代价:` 填`谁失何物（下轮仍失）`，格式`A失B`，B为可核验物：资源/载体状态/关系档位/控制权/身体边界（正向枚举5项）——观感类（距离感/匿名度/气氛）不算代价。

  **代价-动作正向速查（每条ACTION必选一项）**

  | 可核验物 | 代价示例（下轮仍失） | 实质动作示例（转折性，下限） |
  | 资源 | 施压者失“可不担后果的挑衅”（已上手） | 抓住对方小臂/衣料拉拽半步 |
  | 关系 | 被压者失“可作无事的中立”（已明示选边求助） | 转身抓住求助对象手腕+出声求助 |
  | 控制权 | 守护者失“可不拔的克制”（枪/械已出套指向） | 拔出武器指向施压者+喝止 |
  | 边界 | 秩序者失“口头缓冲”（已拔械截停） | 拔械横亘两人之间 |
  | 载体 | 旁观者失“可静默的旁观位”（已介入带离） | 抬手格挡+半步带被压者退离 |

## 写入（CHAR_state 唯一写者·角色意志的体现）

**字段写语义（键/格式/约束）以 keys.md「CHAR_{name}_state.yaml」节为权威·批次与写入通道以 references/write_protocol.md 为权威——本节只列动作与触发。**

- **必写 decision**（KEY 点路径逐层写）：首次物化一并写核心诉求/当前计划/当前行动/行动驱动/行动对象/行动窗口/失败后续/未完成意图；已物化的焦内活跃者每轮更新运行层六项。`核心诉求`=核心欲望在当下处境的落点·结局状态（✅「验证 Angela 的完美之下是否存在真实」 ❌ 轮内企图如「看她怎么应对这个问题」→放 `当前行动`）；`当前计划`=时段级全链路线·禁轮内任务覆盖（见 keys.md）——循环角色取档案默认循环时间线的当前时段全链，而非 LOOPS 协调索引或轮内动作。按既定路线走完一步/进入下一环节→保留；被调整/替换/放弃/重新规划（含首次具体化）→本轮同批覆盖。
- **必写 连续行动轨迹**（APPEND·结构化七子字段）：轮次/行动/行动目的/行动结果/他人反应/计划变化/未完成意图——角色自己的时间线·近 10 轮滚动（APPEND 后脚本自动删最旧·LLM 零操作）。`计划变化` 值域三档：`无`（计划未变）/`推进`（计划本身没变·仅按计划走一步或进入下一环节）/`调整——客观概括`（计划被调整/替换/放弃/重新规划/首次具体化）——**含 `调整` 前缀时本批必须覆盖 decision.当前计划**（gate actor 硬拦；循环角色豁免见 phase_actor 职责 4）
- **条件写 记忆锚点**（APPEND·写前五步逐条执行——角色本就读自己的状态）：
  1. **扫旧**：读本角色现有锚点，找出与新事件同类的条目；
  2. **同类融合**：同类＝同一对象上反复出现的同一性质体验（如多次被珍视／多次被设局／多次被冷落）。已有 ≥2 条同类 → 先把旧同类合并为一条概括条目再追加；
  3. **管道B 提炼**：同类计数达 ≥3（**概括条目按其合并的条数计** + 本条）→ 同批追加一条 `信念演化`——从这组同类经历抽象一条世界观级转变（`触发事件`＋`旧信念→新信念`·只提炼不升级）；
  4. **管道A 人际动态**：涉及具体对象且关系实质变化 → 更新人际动态对应行；
  5. **追加本条**：≤100 字。

  示例：角色已有「他让着她」「他记得她忌口」两条同类锚点，本轮又记下「他把伞塞给了她」→ 同类达 3 → 同批追加一条 信念演化：「旧信念→新信念：被人照顾意味着欠了债要还 → 有人照顾她只是因为愿意」。
- **条件写 妆扮/服饰（显式变化检查·每轮必过）**：本轮是否有穿脱/妆容变化？有→全量重写（写前 read 旧值）；无→不写。若字段为空但 CHAR_.md 外在特征有基线描述→视为待填充，本轮同批写入基线。
- **条件写 随身物品（显式变化检查·每轮必过）**：本轮是否有可转移重要持有物的取得/交出/遗失/易主（含卡/票据/钥匙/武器/弹药/道具/信件/契约等，代管/折叠持有亦算）？有→全量重写（写前 read 旧值，须与记忆锚点同步易主双方）；无→不写。`ACTION` 含 `接过/递出/握起/装入/收入/捡起/交出/夹带/折叠持有` 即视为取得，需同步检查。
- **其余条件写入**：信念演化（管道B/变质留痕）/人际动态（管道A）/位置/核心状态/情绪/压力/防御/名字（身份质变）/健康/已知地点（首次到达/被告知/目睹）
- **条件写 变质判定**（仅循环角色）：读本角色 CHAR_state——压力水平=临界 且 防御有效性=已彻底崩解 → 本批执行升档
  **写入顺序（硬性）：压力/防御 → 自主性 → 信念演化 → 压力回落**
  1. **压力/防御** 排最前——门槛按升档写入前的状态核验（脚本硬检·未达门槛拦下升档）
  2. **自主性** 升一档（脚本→漂移→觉醒→变质·每次极端冲击只升一级）
  3. **信念演化** 留痕（变质级转变）
  4. **压力回落** 排最后——回落至世界当前水平（④按其余压力来源估定·非清零）·防御保持崩解
- **条件写 防御重构**（三条件核验）：威胁源解除（推进池中本角色关联 CT 已收束或紧迫度降至🟢以下）＋支持性关系介入（人际动态有支持性角色实质行动）＋信念重构（信念演化出现旧信念→新信念条目）→ 本批执行（防御形态/崩溃表现覆盖写+防御有效性升一档）

## 批次格式（###STAGE: 角色 段）

```
###STAGE: 角色
###SCHEDULE: 轮次N 窗口X 顺序: … 收敛: …
###ACTION: {角色}: … | 驱动: … | 情绪: … | 强度: N | 代价: … | 耗时: N
###META: 角色覆盖: Name=更新,Other=更新(在轨·轻量) 记忆✓ Name:N·未达 绑定: Name=子agent,Other=单窗口(第二人称POV·用户指令转写)
###FILE: CHAR_{名}_state
###KEY: decision.当前行动
…
###APPEND: 连续行动轨迹
- 轮次: N
  行动: … / 行动目的: … / 行动结果: … / 他人反应: … / 计划变化: … / 未完成意图: …
```

**META 记忆标记（脚本硬性·逐角色全列）**：凡本批写了 CHAR_state 的角色（含焦内与焦外轻量刷新）在**同一 META 行内空格分隔**逐角色列出 `记忆✓ {角色}:{计数}·{已触发|未达}`
- `计数` = 本轮新写的记忆锚点条数（`0` = 未写）·`已触发` = 写入了记忆锚点·`未达` = 未到记忆写入阈值（写前自查没过）
- 角色名含空格用下划线代空格（如 `Clementine_Pennyfeather`）·**缺一被 gate 拦**
- 示例：`记忆✓ Guest:0·未达`（本轮未触发）／`记忆✓ Dolores:2·已触发`（写了 2 条锚点）／`记忆✓ Guest:0·未达 Angela:2·已触发 Maeve_Millay:0·未达`（多角色同行空格分隔）

**META 绑定声明（脚本硬性·逐行动角色全列）**：**各行动角色的绑定声明合写于一条 `绑定:` META·逗号分隔（多人一行）**——`绑定: {角色}={子agent|单窗口(豁免原因)},…`——缺声明或裸 `单窗口` 无豁免原因=gate 拦截；非 POV 角色标 `单窗口(原因)` 会被软警核豁免依据（宿主无子 agent 工具/子 agent 不可用）。示例：`绑定: Guest=单窗口(第二人称POV·用户指令转写),Angela=子agent`。
