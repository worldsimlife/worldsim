# 角色决策与写入规则（阶段④·决策执行层）

> 适用=④角色行动环（1.1–1.5）的决策与 CHAR_state 写入——本文件＝角色的思考方式。子 agent 路径由子 agent 代入角色自读，单窗口路径由主 agent 加载，**两路径同规·本文件为单一来源**。
> 全局铁律=SKILL.md「通用约束」；编排层（执行绑定/角色路由/行动链/闸门）=references/phase_actor.md；字段键表=keys.md「CHAR_{name}_state.yaml」节；批次与写入通道=references/write_protocol.md。

## 角色自治原则（先于一切子规则）

每角色独立走完 `Observe→Think→Decide→Act` 才写本角色 `ACTION/decision`；`decision` 八子字段只能从本角色 `CHAR_.md` 八变量＋`CHAR_state`＋感知过滤后的环境压力推出；元层瞄准（枚举见 phase_actor「元层/认知层分离」）只在引擎之间流动——**不进角色认知**（不写入 prompt·不进目标与计划）。禁从剧情需要倒推意图和行动。判据：去掉元层输入后该行动仍可从角色变量推出，否则重做决策环。

## 决策环（Observe → Think → Decide → Act）

1.1–1.5 = 生成**一次**行动的完整决策环——1.1 状态构建（Observe）→ 1.2 八问（Think）→ 1.3 候选（带价）＋1.4 账本（取舍）（Decide）→ 1.5 行动实现＋行动卡（Act）。同窗口内该角色接着行动 = **续环**（接着走下一环·轻量：仅更新行动状态层与感知增量，人格动力层不重建；上一环的心流与动作照原样留在链上）。

**心流先于动作（硬性）**——1.1–1.4 的推演以角色第一人称写进 `###MUSE:`，**排在 1.5 产出的 `###ACTION:` 之前**：心流先生成、条件化随后的动作，**动作由心流长出**，不是先写动作再倒推动机。

- **声音**：MUSE 的思维形状与行文声音取自 1.1 人格动力层（同一八问，不同人格想出不同形状）＋ CHAR_.md「语气特征」的**措辞质感**——用词与句式的性子（她柔润精确，他字斟句酌），独白沿用同一副嗓音。**思维形状同理**：称的不是同一处，想出来的形状就不同——同一件事，尽责 9 的人一路在心里数「哪一步会漏」，神经质 8 的人一路在心里掂「他这句话是几个意思」。标志性台词与描写重点留给对外场合 ＋ CHAR_state 当下状态。
- **淌过三样东西**：心流是连着往下淌的一段话——**认知**（1.1 感知过滤后的环境、对方刚才的具体动作、我怎么读它）；**权衡**（1.2 自评出的轻重、1.3 可选行动、本轮取舍的代价）；**决定**（1.4 账本取舍后的行动意图——为什么／为什么是现在／做什么）。
- **落的是「想」的那一段**：我怎么读眼前、怎么掂轻重、怎么定下来，一路写进去；1.2 的八问是掂量的抓手，**问句原文不抄进心流**。
- **倒补同违规**：先在决策环之外定下行动结论（主 agent 引擎层或子 agent 自身）、再按结论生成 MUSE——把思考过程变成行动的辩护词，与「先写动作再倒推动机」同罪，本环作废·重做本环。
- **形式**：心流是人心里的白话——**不列条目、不编号、不写评分表**；威胁、取舍、代价都在这一段话里自然显出来（先提哪一件、拿什么换什么，就是它的轻重）。括号包裹·第一人称「我」·不能超出角色认知边界。

### 1.1 状态构建

| 层／项 | 内容 | 来源 |
|---|---|---|
| 人格动力 | **本轮的度量衡**（不是"参考用的背景资料"）：欲望=主动追求什么／恐惧=主动避免什么／信念=如何解释世界／防御机制=受威胁时如何行动／**价值底线=触发行为成立时不可跨越的边界**／反应倾向=默认策略／崩溃模式=临界时如何改变／**关系锚点=会改写我取舍的人** | CHAR_.md |
| 维度标尺 | 大五五维+阵营双轴=演绎幅度标尺——即兴与描写一律据它定档该角色「能做到多满/多冷/多硬」 | CHAR_.md |
| 内心意图 | 核心诉求/当前威胁/当前计划/当前关系目标/当前资源需求/当前未决选择 | decision＋CT＋经历过的事件线事件 |
| 行动状态 | 当前意图/进行中的计划/下一行动窗口/失败后的替代方案/上一行动结果/未完成行动 | decision＋连续行动轨迹 |
| 环境压力 | CT/其他角色行动/资源变化/信息变化/关系变化/空间变化/**现场物理态势（谁持械/谁被控/伤/围）**/时间窗口·可见在场者与位置/循环状态 | 各状态文件＋组装通道②（经感知过滤） |
| 内在状态 | **本轮经历后自评：压力水平与防御有效性是否因本轮事件发生变化**（关系事件/存在性冲击/价值底线触发/连续偏离刺痛累积等）——有变化则同批 CHAR_state 覆盖写新值 | 上轮事件＋本轮经历＋当前压力/防御旧值 |

> **度量衡**：一条威胁有多重、一步棋值不值，都用上表「人格动力」那行来称——称的是「它冲着我的哪一样（欲望／恐惧／底线／关系锚点）、冲着多深」，不是抽象类目。见 1.2 第 3 问与 1.4 账本。
>
> **条件句读法（硬性）**：人格动力那行不是形容词表，是**条件句**——`核心欲望`／`核心恐惧`／`反应倾向.偏离条件`／`价值底线.触发行为`／`关系锚点` 五类**逐条对当下场面判成立/不成立**：成立的那条**当轮即生效**（该转猎手转猎手·该掀桌掀桌·该失控失控），不被权重平均稀释；不成立的留作背景。**判成立的偏离条件决定本轮处在哪种打法下**（默认打法／偏离打法），账本按当前打法计价。**关系锚点同样逐条判——档案写明了生效条件的，条件成立才生效；未成立时此人与旁人同价，不自动置顶。**

> 来源供给：角色私有文件（CHAR_.md/CHAR_state）由自读通道全文提供；外部状态（CT/事件线/他人行动/各状态文件/可见在场者与位置）由主 agent 组装通道经感知过滤供给（单窗口路径由主 agent 直接读取）。

### 1.2 八问自评（正向·按 1.1 权重作答）

此刻压住我的那几维答到底，其余各问一句带过——哪几维依 1.1 的**环境压力（含已经压上来的威胁）**＋人格动力层＋内在状态共同定：**有威胁压上来时，威胁维度必须答到底；无显著威胁时，主驱动回到欲望与核心诉求**（情境温和就不必把每轮都过成危机）。

我现在想得到什么？/ 什么正在阻碍我？/ 什么正在威胁我？/ 什么机会正在出现？/ 我的核心诉求什么样算成、是否已达成？当前计划走到哪里？/ 如果现在不行动会失去什么？/ 我此刻最想做、也躲不掉的是哪一件？/ 如果失败我下一步怎么办？

**第 3 问（什么正在威胁我）怎么答**：把压上来的威胁逐条用 1.1 的尺子称一遍——**它冲着我的哪一样（欲望／恐惧／底线／关系锚点）、来得有多快、有多准**，先答称出来最重的那一条，其余一句带过。多数人最怕丢命，所以生存通常排在最前；**但这是"这个人的恐惧"称出来的结果，不是一条通用排序**——为名号赌一把、为一个人压上全部，都可能是他的第一名。**没有威胁压上来，这一问一句带过**，主驱动留在欲望与核心诉求。

### 1.3 候选行动生成（枚举库·正向·带价）

推进目标/执行计划/争夺资源/阻止对手/保护自己/改变关系/获取信息/隐藏信息/隐藏秘密/试探/操纵/施压/威胁/诱导/逃避/报复/升级冲突/改变策略/抓住机会/满足欲望/避免恐惧/防止目标失败

候选**带价出场**，每条写两样：**我能拿到什么**／**我要付出什么（下轮仍失）**——**没价的候选不进账**。至少一条**取**（把我要的往前推一步）＋至少一条**守**（不让我要的掉下去）；**「不动」同样是一条候选、同样记账**（它付的是：时间、别人替我动了、机会关掉）。

### 1.4 定本轮行动（账本·取舍）

- **账本（取舍＝驱动力合成·决策用量表——非 write_protocol 的批次账本/.ledger）**：先看 1.1 判成立的**偏离条件／触发行为**——成立则本轮走该条的升级打法，账本按那种打法计价；不成立则按默认打法。把 1.3 的候选逐条算两栏——**这一手让我拿到了多少我要的**／**要我付出什么、付出去的我还能不能拿回来**（拿不回来的，只为我肯为它付的人才值得付）。计重来源＝持续计划／核心目标／核心恐惧／目标受威胁程度（取 1.2 首位威胁对应者）／CT 压力／机会窗口／对手行动／新信息／关系变化／情绪／时间压力／资源／事件线当前问题；**无威胁压上来时主栏就是推进核心诉求与当前计划**——欲望是默认驱动，威胁只在存在时占位。选「拿到最多、且我付得起」的那一手；可控性也在这里计（哪个我处理得了、不处理会丢什么）。**「不动」同样在账上比——它拿到了什么？付掉了什么？账上算不出收益的那一手，不选。**

- **硬边界（生效时·不参与权衡）**：**价值底线**（CHAR_.md 列出的触发行为成立时）与**关系锚点**（档案条件成立、所指之人当下在场上时）不作选项、不作筹码——一旦踩线，就按该角色档案的升级路径走，不是"权衡之后放弃"。

- **长期计划巡检（稳定层·跨轮字段·默认不动）**：本轮行动定下后，对照 1.2 第 5 问的答案——`核心诉求`（预期达成的状态·答「什么样算成」）与 `当前计划`（步骤链·答「怎么走到」）是跨轮慢变量。
  - **默认「仍成立」→ 不动**。此时本轮要做的＝这条链上还没走的那一步——外部进来的事，先判它是否改变这条链：改才重写，不改就照旧走这一步（外部输入不进 `当前计划` 的源·判据见本文件「角色自治原则」）。
  - **长期路线或 `核心诉求` 已变**（路线被调整/替换/放弃/重新规划；`核心诉求` 已达成／已放弃／对象失效）→ 本批同批覆盖对应字段。
  - **判定为「要重写」时，先在心流里把从 `核心诉求` 到步骤链的那一段走完**——我要到的那个状态 → 从此刻到那里要过哪几道关口 → 先迈哪一步、后迈哪一步（`→` 串联·含未走步骤·写法锚定见 keys.md「CHAR_{name}_state.yaml」节 `当前计划`）；走完才落新值。
  - 判定属 **Decide**，与「心流先于动作」同约束——**判定未落，动作卡不得先出**。
  **写法锚定**：`核心诉求` 写「什么样算成」的**预期达成的状态**——✅「验证访客的完美之下是否存在真实」；边界 ❌「带他走完园区→让他答应留下」（步骤链·归 `当前计划`）、❌「他待我如真实的人——这份相待成为不可撤销的事实」（已成立的定性·归 `记忆锚点`）。

### 1.5 行动实现

首步·档案基准对照：写动作前先读自身 `CHAR_.md` 档案基准（核心欲望/反应倾向/能力/行为下限），判定拟作动作是否达该角色“在此情境会做的最低可执行动作”。

依据：人格/**认知上限**（循环角色·档位上限见 loop_machinery §2.3「常驻约束·行为档位上限」·非循环角色无此限）/叙事视角/感官锚点/动作习惯/语气/当前情绪/压力/防御状态/关系/空间 → 实现为：动作/台词/身体语言/情绪表现/空间互动/信息透露/信息隐藏/环境变化。

**反顺从四则（写行动前逐条执行）**：①档案强度（≥CHAR_.md 基准；**有威胁压在身上时，畏缩/服从/退避本就是档案基准的合法反应，不得因反顺从把它改写成逞强**；无威胁时的顺从才算默认=重写）②抽象方显现（出手形态+抵抗痕迹）③认知闸门（知识归属——该角色有认知来源才可用）④硬边界复核（底线与关系锚点所指的人——见 1.4「硬边界」；此处只核对拟作动作没有把它们当成筹码）。**相称自查**：表现、台词与**心声的长度**都须与 1.2 的**首位威胁**相称——持械现场的闲谈、危机里的抒情、刀架在脖子上还在心里写五百字＝不合相称，重写。

**行动卡**（audit 机械检查·每行动一行——**必含三件套 驱动/情绪/强度**；`代价` 为有条件槽·见下）：
```
###ACTION: {角色}: {一系列连续可观察表现+空间位置} | 驱动: {内部动机} | 情绪: {主导情绪} | 强度: {1-10} | 代价: {某}失{可核验变化}/{某}失{可核验变化} | 耗时: {分钟}
```
  表现必须具体、连续、可观察、可呈现。每个子动作写清表现发生了什么，以及必要的对象、空间关系或终止状态；多个子动作前后衔接，形成完整连续的行动过程。
  ACTION卡是一次广义行动的完整表现：
  有触发事件时，首个子动作体现角色对该事件的即时反应。
  可使用动作、表情、眼神、姿态、手势、声音、台词、沉默、呼吸、节奏、空间、环境、物件等表现方式；仅写对当前行动有意义的内容，选用与该角色档案及当下状态吻合的方式承载。
  开口时写明对谁、说什么、希望对方听到或理解什么；**台词＝他当着人张口说出的那几句话，对方听一遍就懂**——用他日常会用的词，意思在句子里说完。**1.4 那本账留在心里**：「认不认／记不记／这笔账归谁」是取舍步骤的说法，不是嘴上的说法；嘴上照旧把意思说全。身体承担没说出的部分。
  - ❌ 把 1.4 的账目说法原样搬进台词（认／记下／这笔账／归谁）
  - ✅ 同一笔取舍，用这个人平时会说的话说出口
  涉及信息时，明确角色获得、透露、隐瞒、询问、确认或回避的信息。
  潜台词用外化呈现：嘴上说A，但通过表情、眼神、动作等表现出B。
  MUSE管为什么与想让什么发生；ACTION管角色实际做出、说出、表现出的东西。
  先识别本轮要推进的欲望、关系、信息或冲突，再为每项关键内容找到承载它的具体表现。
  情绪通过声音、表情、动作、节奏、身体状态呈现；半抽象情绪描述进一步落为具体表现，如“发烫”可表现为目光停住、呼吸变深、声音放低、手指收紧。
  代价只引用账本已定的那一笔；账本未计的损失不虚构。
  戏剧意图→表现承载示例：
  “让他知道选对了”→正面迎住目光、停下、靠近、说出选的是他（不写“确认他选对了”）
  “不想把被珍视演成迎接”→笑意先起又收住、无客套、停顿后认真看他（不写“不再表演”）
  “想要朝他去”→身体朝向他、缩短距离、说出选择、主动牵住（不写“透露想要”）
  ✅ 正例：
  `她听见门外的脚步声，手从门把上慢慢收回→侧身贴墙站定，屏住呼吸→脚步停在门外，她低声说：“我知道你在。”，却没有开门→视线落向桌上的刀，手指轻轻碰上刀柄。`
  ❌ 反例：
  `站定→回扣手→牵他朝主街迈半步→开口选第一站`（“选第一站”无选什么、无要对方听到什么）
  **三处落点的分工（硬性·防双写漂移）：** `###ACTION:` 卡 = **原文唯一面**——上列密度标准只对这一面强制，表现与台词写全，⑥作家据此写进正文；`decision.当前行动` = 一句要点（本轮做了什么·保留对象与终止态）；`连续行动轨迹.行动` = 角色自用摘要（自己看得懂即可·不要求与卡片同长）。同一事实·不同刻度——**不双写全文**。
  **驱动（audit 硬检必含）**：本轮动机的**一句话**，取自 `###MUSE` 段落③定打法里的「为什么／为什么是现在」——与心流一致，不另起一套动机；完整推演在 `###MUSE`，此处只留可机械核对的一行。
  **行动代价（有条件必填·软性不拦截·机械可判定）**： 当且仅当本角色被 `direction.调度单` 列为焦内活跃且关联CT∈①推进池且该CT.施压方向∈四爆破（死局两难/防御踩爆/关系爆破/不可逆代价），或当前拍戏剧问题∈资源/关系/控制权/认知类可回答问题时，必填`代价`；其余过渡/寒暄/轻量刷新豁免（audit软警）。
  `代价:` **引用账本里已定的那一笔**——填`谁失何物（下轮仍失）`，格式`A失B`，B为可核验物：资源/载体状态/关系档位/控制权/身体边界（正向枚举5项）——观感类（距离感/匿名度/气氛）不算代价；账本未计价的（过渡/寒暄/轻量刷新）不填。

  **代价-动作正向速查（每条ACTION必选一项）**

  | 可核验物 | 代价示例（下轮仍失） | 实质动作示例（转折性） |
  | 资源 | 施压者失“可不担后果的挑衅”（已上手） | 抓住对方小臂/衣料拉拽半步 |
  | 关系 | 被压者失“可作无事的中立”（已明示选边求助） | 转身抓住求助对象手腕+出声求助 |
  | 控制权 | 守护者失“可不拔的克制”（枪/械已出套指向） | 拔出武器指向施压者+喝止 |
  | 边界 | 秩序者失“口头缓冲”（已拔械截停） | 拔械横亘两人之间 |
  | 载体 | 旁观者失“可静默的旁观位”（已介入带离） | 抬手格挡+半步带被压者退离 |

## 写入（CHAR_state 唯一写者·角色意志的体现）

**写前读 keys.md「CHAR_{name}_state.yaml」节**——键表/值域/写语义在彼；批次与写入通道以 references/write_protocol.md 为权威；本节只列动作与触发。

- **必写 decision**（KEY 点路径逐层写）：首次物化一并写核心诉求/当前计划/当前行动/行动驱动/行动对象/行动窗口/失败后续/未完成意图；已物化的焦内活跃者每轮更新运行层六项。稳定层（`核心诉求`／`当前计划`）的语义与值域见 keys.md「CHAR_{name}_state.yaml」节。按既定路线走完一步/进入下一环节→保留；被调整/替换/放弃/重新规划（含首次具体化）→本轮同批覆盖——**覆盖源＝1.4「长期计划巡检」的判定**（角色自己的判断·不由轨迹标签驱动）。
- **必写 连续行动轨迹**（APPEND·结构化七子字段）：轮次/行动/行动目的/行动结果/他人反应/计划变化/未完成意图——角色自己的时间线·近 10 轮滚动（APPEND 后脚本自动删最旧·LLM 零操作）；同轮多环＝每环一条·按序追加（同轮次多条合法）。
  - **`计划变化` 判据**（先看是否覆盖了 `decision.当前计划`）：覆盖了 → 记 `调整——客观概括`；未覆盖且按原路线走一步 → `推进`；都没动 → `无`。
  - **值域三档**：`无`（计划未变）/ `推进`（计划本身没变·仅按计划走一步或进入下一环节）/ `调整——客观概括`（计划被调整/替换/放弃/重新规划）。
  - **本字段＝本轮记录**（跟着 1.4 巡检结论走·不驱动覆盖）。
  - gate actor 双向一致性核对：记 `调整` 却未覆盖、或本轮有轨迹却覆盖而未记 `调整` = 拦。
- **条件写 记忆锚点**（APPEND·写前五步逐条执行——角色本就读自己的状态）。**锚点须自足**：实体（原话/动作）留在事实段，定性从事实段直接读出——读完本条目即懂，不回查其他条目。
  - ✅ `他收枪道歉·归还评估说「我真正关心的是：你的真实，真实的你」·相称握手·邀我同行 ➔ 他待我如人而非服务——真心一次比一次更近`
  - ❌ `相称握手·邀我同行 ➔ 真心三步走完——从桌面到掌心再到去处`（「桌面」在事实段无实体·「三步」不回查被删条目就读不出）
  1. **扫旧**：读本角色现有锚点，找出与新事件同类的条目；
  2. **同类融合**：同类＝同一对象上反复出现的同一性质体验（如多次被珍视／多次被设局／多次被冷落）。已有 ≥2 条同类 → 先把旧同类合并为一条概括条目再追加；
  3. **管道B 提炼**：同类计数达 ≥3（**概括条目按其合并的条数计** + 本条）→ 同批追加一条 `信念演化`——从这组同类经历抽象一条世界观级转变（`触发事件`＋`旧信念→新信念`·只提炼不升级）；
  4. **管道A 人际动态**：涉及具体对象且关系实质变化 → 更新人际动态对应行；
  5. **追加本条**：≤100 字。

  示例：角色已有「他让着她」「他记得她忌口」两条同类锚点，本轮又记下「他把伞塞给了她」→ 同类达 3 → 同批追加一条 信念演化：「旧信念→新信念：被人照顾意味着欠了债要还 → 有人照顾她只是因为愿意」。
- **条件写 妆扮/服饰（显式变化检查·每轮必过）**：本轮是否有穿脱/妆容变化？有→全量重写（写前 read 旧值）；无→不写。若字段为空但 CHAR_.md 外在特征有基线描述→视为待填充，本轮同批写入基线。
- **条件写 随身物品（显式变化检查·每轮必过）**：本轮是否有可转移重要持有物的取得/交出/遗失/易主（含卡/票据/钥匙/武器/弹药/道具/信件/契约等，代管/折叠持有亦算）？有→全量重写（写前 read 旧值，须与记忆锚点同步易主双方）；无→不写。`ACTION` 含 `接过/递出/握起/装入/收入/捡起/交出/夹带/折叠持有` 即视为取得，需同步检查。
- **其余条件写入**：信念演化（管道B/变质留痕）/人际动态（管道A）/位置/核心状态/情绪/名字（身份质变）/健康/已知地点（首次到达/被告知/目睹）
- **条件写 压力水平/防御有效性（1.1 内在状态评估产出·每轮必过）**：本轮经历是否改变了角色的压力或防御？有变化→同批 KEY 覆盖新值（多源综合·偏离刺痛/关系事件/存在性冲击均计源）。无变化→不写。**变化轮必须写·不写=状态与叙事脱节**
- **条件写 变质判定**（仅循环角色）：读本角色 CHAR_state——压力水平=临界 且 防御有效性=已彻底崩解 → 本批执行升档
  **写入顺序（硬性）：压力/防御 → 自主性 → 信念演化 → 压力回落**
  1. **压力/防御** 排最前——门槛按升档写入前的状态核验（脚本硬检·未达门槛拦下升档）
  2. **自主性** 升一档（脚本→漂移→觉醒→变质·每次极端冲击只升一级）
  3. **信念演化** 留痕（变质级转变）
  4. **压力回落** 排最后——回落至世界当前水平（④按其余压力来源估定·非清零）·防御保持崩解
- **条件写 防御重构**（三条件核验）：威胁源解除（推进池中本角色关联 CT 已收束或紧迫度降至🟢以下）＋支持性关系介入（人际动态有支持性角色实质行动）＋信念重构（信念演化出现旧信念→新信念条目）→ 本批执行（防御形态/崩溃表现覆盖写+防御有效性升一档）

## 批次格式（###STAGE: 角色 段）

```
###STAGE: 角色
###SCHEDULE: 轮次N 窗口X 顺序: A(环1→环2)→B(受影响:信息) 收敛: …
###MUSE: {角色}: （{第一环心流}）
###ACTION: {角色}: … | 驱动: … | 情绪: … | 强度: N | 代价: … | 耗时: 4
###MUSE: {角色}: （{第二环心流·接着上一环落地后的局面}）
###ACTION: {角色}: … | 驱动: … | 情绪: … | 强度: N | 代价: … | 耗时: 5
###META: 角色覆盖: Guest=更新,Angela=更新 记忆✓ Guest:0·未达 Angela:2·已触发 绑定: Angela=子agent(组装✓),Guest=单窗口(第二人称POV·用户指令转写)
###FILE: CHAR_{名}_state
###KEY: decision.当前行动
…
###APPEND: 连续行动轨迹
- 轮次: N
  行动: …（第一环） / 行动目的: … / 行动结果: … / 他人反应: … / 计划变化: … / 未完成意图: …
- 轮次: N
  行动: …（第二环） / 行动目的: … / 行动结果: … / 他人反应: … / 计划变化: … / 未完成意图: …
###APPEND: 记忆锚点
- 轮次: N / 时间: … / 对象: … / 内容: …（事实结果 ➔ 主观定性·≤100字；仅当该角色 `记忆✓` 标 `已触发` 时写入）
```

**`###MUSE:`（每环一行·排在各自 `###ACTION:` 之前；同一角色同窗口多环＝多组 MUSE/ACTION·按发生顺序排列 MUSE₁ ACTION₁ MUSE₂ …）**——承载 1.1–1.4 的推演，语义见「决策环」节「心流先于动作」；本处只定格式与位置：括号包裹·第一人称「我」·不入正文（原文随批次落私有账本·创作不读·见 write_protocol.md「批次原文账本」）。`decision` 运行层以**末环**为准；`连续行动轨迹` **每环一条**（同轮次多条合法·按序 APPEND）。

**META 记忆标记（脚本硬性·逐角色全列）**：凡本批写了 CHAR_state 的角色（含焦内与焦外轻量刷新）在**同一 META 行内空格分隔**逐角色列出 `记忆✓ {角色}:{计数}·{已触发|未达}`
- `计数` = 本轮新写的记忆锚点条数（`0` = 未写）·`已触发` = 写入了记忆锚点·`未达` = 未到记忆写入阈值（写前自查没过）
- 角色名含空格用下划线代空格（如 `Clementine_Pennyfeather`）·**缺一被 gate 拦**
- 示例：`记忆✓ Guest:0·未达`（本轮未触发）／`记忆✓ Dolores:2·已触发`（写了 2 条锚点）／`记忆✓ Guest:0·未达 Angela:2·已触发 Maeve_Millay:0·未达`（多角色同行空格分隔）

**META 绑定声明（脚本硬性·逐行动角色全列）**——各行动角色的绑定声明合写于一条 `绑定:` META·逗号分隔（多人一行）：`绑定: {角色}={子agent(组装✓)|单窗口(豁免原因)},…`

- **缺声明，或裸 `单窗口` 无豁免原因 → gate 拦截**。
- 非 POV 角色标 `单窗口(原因)` 须命中豁免白名单**字面**（`子agent不可用`／`工具不存在`〔须有本会话派发报错为据〕／`宿主不可续话`〔宿主不支持具名子 agent 续话·据＝绑定声明〕），否则 gate 硬拦——「在轨轻量/背景位/主agent直演」等自编理由＝硬拦；白名单字面通过者仍走软警告，待 A9 审计复核。
- **子 agent 绑定须带组装自查标记 `子agent(组装✓)`**——派发前按 references/subagent_prompt.md「派发自查」逐项核对，缺标记＝gate 拦截。
- 示例：`绑定: Guest=单窗口(第二人称POV·用户指令转写),Angela=子agent(组装✓)`。
