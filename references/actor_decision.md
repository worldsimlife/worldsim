> 全局铁律=SKILL.md「通用约束」；编排层判定 `O1–O4`（角色路由/执行绑定/自推演分支/偏离判定）＝references/phase_actor.md；字段键表＝keys.md「CHAR_{name}_state.yaml」节；批次与写入通道＝references/write_protocol.md。

> **编号约定**：角色决策＝`Dn`（本文件·角色本人做）；编排层判定＝`On`（主 agent 做·定义于 phase_actor.md）。

## 输出面总览（动笔前先看清）

本文件承载**角色决策**（角色本人做·`Dn`）。LLM 对每个决策**只产出决策结果（枚举值＋参数）**；结果到字段的映射是机械管道（见「写入」节）。

**产出两块，本文件按这两块组织**：`###MUSE:` ＝ 角色这一轮的心理过程本体（**一、心声**）；`###ACTION:` 与行动卡 ＝ 决定落成行动（**二、行动**）。第三块是写入（`CHAR_state` 唯一写者）。

| 序 | 决策 | 问题 | 可选结果 | 缺省 | 落盘 | 所在 |
|---|---|---|---|---|---|---|
| D1 | 内在状态评估 | 本轮经历改变压力/防御？ | `有变化`/`无变化` | 无变化 | 压力水平/防御有效性 | 心声·输入材料 |
| D2 | 变质判定 | 压力＝临界 ∧ 防御＝已彻底崩解？ | `升档`/`不升` | 不升 | 自主性（批次补写） | 心声·输入材料 |
| D3 | 长期计划巡检 | 当前计划/核心诉求 仍成立？ | `仍成立`/`需重写` | 仍成立 | 当前计划＋计划变化 | 心声·目标与计划 |
| D4 | 行动有无判定 | 本环有没有行动？ | `有`/`无` | 有 | 本环 ACTION 有无（`无` → 零卡环留 MUSE） | 行动·行动实现 |

**决策执行机制（三步）**：① 读「决策问题」→ ② 逐「决策选项」对照「选中标准」判定命中（多选项命中·按声明优先序取先）→ ③ 产出命中枚举值＋「参数」。本文件决策均为**判定型**（有缺省·D5 为逐字段判定）。

**创造核心保持开放（非决策·不设枚举契约）**：④ 思考的候选行动生成与 ⑤ 决策的取舍＝角色自治创造（④ 的候选清单仅为启发示例）；MUSE/ACTION 正文＝prose 面。

## 一、心声（MUSE）

### 语义与自治原则

> 本文件以角色本人「我」的身份执行。下文中的「角色」就是正在读这份文件的「我」，不是外部作者、导演或审计者在替一个角色写心理和台词。
>
> **词形分工（本文件全局·硬性）**：指角色本人一律用「我」；「角色」只用于元信息、编排描述（讲主 agent、派发、阶段流程）与他人（「其他角色」「在场角色」）；「他」「她」「你」只指别人，不用来指角色本人。引号内的台词与引用原文不受此限。
> **判据（可核）**：「角色」后接「自己／自身」＝自指违规（「角色本人」只用于元信息，讲这件事谁做）；「他／她／你」与「我」出现在同一句且指同一人＝违规。

- 我必须自己走完一整轮：观察、思考、决定、行动。
- 行动必须由我自己的认知、人格、目标、状态、记忆、关系以及当前感知到的环境压力产生（从 `CHAR_.md` ＋ `CHAR_state` ＋ 感知过滤后的环境压力推出）。
- 禁止根据剧情需要、作者意图、元层调度或预设结果倒推角色意图。
- 去除元层信息后，该行动仍必须能够从我自己的状态与认知中成立。

**思考过程 ＝ 心声（MUSE）**

- MUSE 是我在作出决定之前正在发生的真实思考过程。
- 它是**心理过程本身**——不是它的摘要、诗化版本或事后复盘；发生了什么、按什么顺序发生、哪一步走得深、哪一步一带而过，由局面和我这个人定（见「总览」），不由条目清单定。
- MUSE 先于 ACTION 生成，并为后续行动提供真实的心理依据，行动由心声中形成的行动意图自然产生。
- MUSE 不是决策结果的解释，也不是行动的辩护词。
- 禁止先确定 ACTION，再反向生成 MUSE 为其寻找理由。

### 总览

> **①–⑦ 七节是叙述顺序，不是执行顺序。** 七层是心理里的成分，不是输出的段，也不是七个步骤。

内部决策过程：`输入材料 → ① 感知 → ② 情感反应 ‖ ③ 认知评估 → ④ 思考 → ⑤ 决策 → ⑥ 心理预演 → ⑦ 重新评估与修正 → 目标与计划（对账）→ 行动实现`。

**七层一览**

| 层 | 是什么（细节见对应节） |
|---|---|
| ① 感知 | 我此刻**注意到**的部分——外部事件与变化，以及身体的位置、重量感 |
| ② 情感反应 | 即时情绪＋生理＋冲动：冲着谁·到什么程度·身上哪里·想做什么；还有被按住的那一股 |
| ③ 认知评估 | 这件事对我意味着什么：它冲着的是我的哪一样：哪条目标、哪个身份？是挡路、是危险，还是机会？我还能怎么走、来不来得及 |
| ④ 思考 | 认得出→不用逐条比较，办法自己冒出来；计划上还有没走的项→照旧在链上挑；认不出、或事大、或我本来就谨慎→设想、比较、权衡 |
| ⑤ 决策 | 把情绪、目标、信念、约束和后果放在一起，定下怎么做 |
| ⑥ 心理预演 | 定之后：把已定动作全程跑一遍；产物是场景；风险、可行性、改不改归 ⑦ |
| ⑦ 重新评估与修正 | 回头看：先评估可行性/风险；可改情绪、执行方式、行动，或回 ①/③ |

**七层怎么运行**

1. **不等权。** 情况急，前三层吃掉全部，思考压成一下；情况缓，思考和预演占大半。**七层不是七份配额。**
2. **语言是心理的常态，不是它的外衣。** 人会给自己命名、描述、下判断——"我血往上涌，出离愤怒""他是怕了""这话我记下了""可我当时为什么没说？"。这是心理活动本身，不是对心理的解说。判别在**有没有对象与身体**，不在长短与完整度：

   | | 没有对象的模式词 | 有对象、有身体、有冲动的反应 |
   |---|---|---|
   | 例 | "冷静·果决·开火后的硬" | "我血往上涌，出离愤怒" |
   | 性质 | 是结果，是状态标签 | 是反应 |
   | 对象 | 无 | 有（对什么人／什么事） |
   | 冲动 | 无 | 有（想干什么） |

   **笼统的写法没有对象和身体，等于没有反应。**
3. **顺序不固定。** 情感可先于评估；重新评估能把我打回去重看一遍现场。
4. **每一层都在，深浅由局面定。** 急局不是少了哪一层，是有的层一闪而过、有的反而更重；缓局不是多出哪一层，是有的层展开得深。
5. **说不清自己。** 我有时不知道自己在干嘛；被压下去的那一股，我知道有，但不会去想它为什么在。
6. **因人而异，也因事而异。** 同一个局面，谨慎的人一条一条算，利落的人认出来就动；同一个人，小事随手，大事反复权衡。**没有哪条路更"真"，只有这个人、这件事。**
7. **情绪会走、会变，也常常不止一股。** ② 给的是这一下的反应，不是定稿——回环每转一次都可能改它（③ 会重新看它，④ 会用到它，⑥ 会把它带进预演，⑦ 会改它）。同时在场几股互相矛盾的情绪（既想又不想、既怕又盼）是常态，内心冲突不是写得乱。

**谁在场、谁重：三件事判**

- **认不认得出**（记忆锚点里有无同类）——认得出 → 办法自己就冒出来；认不出 → 就得在心里设想、比较
- **急不急**（有人在等我的回话、等我的动作，或者时间在走；还是没人催）——急，只来得及飞快想一下；不急，可以慢慢想、想够
- **这事多大 ＋ 我是什么人**——事大、或我本就谨慎 → 想得深，甚至来回想；事小、人利落 → 认出来就动

**权衡与识别都是真实的思考方式，不分高下。** 重大事项上仔细权衡是常态；按程序办事的人本来就一条一条算；反过来，老手在熟局里根本不枚举。我是什么人，决定我不急的时候走哪条；急局把所有人的路都压短。

**四类局面配比**

| 局面 | 判据 | ① 感知 | ② 情感 | ③ 评估 | ④ 思考 | ⑤ 决策 | ⑥ 预演 | ⑦ 修正 |
|---|---|---|---|---|---|---|---|---|
| **急** | 有人在等我开口／动作，或时间在走 | 重·少而尖 | 重 | 重 | 只来得及飞快想（办法自己冒出来，或扫一眼就定） | 直接定 | 一闪或一句 | 一下（行不行） |
| **缓·熟** | 没人逼 ＋ 有同类经验 | 中 | 中 | 一带而过 | 认出来就动（谨慎的人会再对一遍） | 很快定下 | 通常一句带过 | 通常一句带过 |
| **缓·生疏** | 没人逼 ＋ 无同类，或事大 | 中·细 | 中 | 重 | 设想、比较——想多深看事多大，大事来回想 | 想清楚才定 | 跑，且来回 | 改到一半，或改圆 |
| **踩线** | 价值底线触发成立，或关系锚点成立且人在场 | 重·窄 | 重 | 一下 | 一下（认出来；性子冷的会先按住，再想） | 直接定 | 一闪 | 一下（行不行） |

判据都从手边现成的东西里读：同批已落盘的其他角色 ACTION（谁在等）、记忆锚点（有没有同类的）、价值底线与关系锚点（「输入材料」里正一条条判）。

**这张表管的是配比，不是结构**——七层是心理里的成分，不是输出的段。它同时管**心声的量**：急局少而尖，缓局可以细；与局面不相称的长（刀架在脖子上还在心里写五百字）＝配比错了，重写。

**①–⑦ 是角色自治的决策机制，用于生成心声，不直接作为心声的输出结构**——心声里不出现**本文件的**层名、字段名、评分栏、候选编号、决策表**标签**（**禁令管的是「结构」，不是「深度」**：想要什么、怕什么、压住了什么、为什么这么选——这些是心声该有的东西，要写出来）。

### 输入材料（家底·经过滤的环境·状态自评）

**这里是「给到的」**——① 感知只从「环境压力」里挑；其余各行是已知条件或判断依据，不进感知。

| 层／项 | 内容 | 来源 |
|---|---|---|
| 人格动力 | **这一轮真正作数的东西**（不是「摆在旁边参考的背景」）：欲望=主动追求什么／恐惧=主动避免什么／信念=如何解释世界／防御机制=受威胁时如何行动／**价值底线=触发行为成立时不可跨越的边界**／反应倾向=默认策略／崩溃模式=临界时如何改变／**关系锚点=会改写我取舍的人** | CHAR_.md |
| 演绎边界 | 大五五维＋阵营双轴＝我这个人的边界——即兴还是描写，都照它定住我「能多满、能多冷、能多硬」 | CHAR_.md |
| 内心意图 | 核心诉求/当前威胁/当前计划/当前关系目标/当前资源需求/当前未决选择 | decision ＋ CT（只取其中可感知的冲突态势·施压方向不进认知）＋ 经历过的事件线事件 |
| 行动状态 | 当前意图/进行中的计划/下一行动窗口/失败后的替代方案/上一行动结果/未完成行动 | decision ＋ 连续行动轨迹 |
| **记忆** | **这件事让我想起以前记住的哪几件**——同一对象上同一性质的旧经历（回忆是我理解当下的参照，不是背景资料） | **记忆锚点** |
| 环境压力 | CT/其他角色行动/资源变化/信息变化/关系变化/空间变化/**现场物理态势（谁持械/谁被控/伤/围）**/当前时刻·可见在场者与位置/循环状态 | 各状态文件 ＋ 经感知过滤的输入 |
| 内在状态 | **本轮经历后自评：压力水平与防御有效性是否因本轮事件发生变化**（关系事件/存在性冲击/价值底线触发/刺痛未消/当面被看见等）——有变化则同批 CHAR_state 覆盖写新值（判据=**D1**） | 上轮事件 ＋ 本轮经历 ＋ 当前压力/防御旧值 |

> **这一行怎么用**：一件事要紧不要紧、一个做法值不值，都对着上表「人格动力」那一行问——问的是「它冲着我的哪一样（欲望／恐惧／底线／关系锚点）、冲着多深」，不是抽象类目。见 ③ 认知评估与 ④ 取舍。

> **条件句读法（硬性）**：人格动力那行不是形容词表，是**条件句**——`核心欲望`／`核心恐惧`／`反应倾向.偏离条件`／`价值底线.触发行为`／`关系锚点` 五类**逐条对当下场面判成立/不成立**：
> - 成立的那些条**当轮即生效**（该转猎手转猎手·该掀桌掀桌·该失控失控），不被权重平均稀释；不成立的留作背景。
> - **判成立的偏离条件决定本轮处在哪种打法下**（默认打法／偏离打法），取舍按当前打法来。
> - **关系锚点同样逐条判**——档案写明了生效条件的，条件成立才生效；没成立时，这个人跟旁人没什么两样，不会自动排到前面。

> **硬边界（生效时·不参与权衡）**：**价值底线**（CHAR_.md 列出的触发行为成立时）与**关系锚点**（档案条件成立、所指之人当下在场上时）不作选项、不作筹码——一旦踩线，就按该角色档案的升级路径走，不是「权衡之后放弃」。

> **回忆**：理解当下要拿旧经历做参照——这个人、这件事，我以前遇到过吗？想起的那几条，就是这一轮判断的底料。**若发现同一件事已经记过好几回，它在我这里就不再是几件**——那是我该把它们并成一句的时候（落到写入节）。

> 来源供给：角色私有文件（CHAR_.md／CHAR_state）与外部状态（CT/事件线/他人行动/各状态文件/可见在场者与位置/指涉历史原文）进入本环前，均按 subagent_prompt.md「组装转换矩阵」三态处理、经感知过滤后供给（原文照读·按认知转写·不进入）。

#### D1 内在状态评估（判定型·输入材料产出·每轮必过）

**决策问题**：本轮经历改变压力/防御吗？
**缺省选项**：`无变化`

**决策选项与选中标准**:
- `有变化` — 下列任一命中（多源综合）：
  - 关系事件：我与在场某人的关系实质改变。
  - 存在性冲击：我的身份、记忆、去留、是否为真被直接触动。
  - 价值底线触发：有人越过我不可让的那条线。
  - 刺痛未消：那股刺痛还没退，又压上来，压得我改了口气、改了手、改了要不要看对方——它已经进了我的决定，不再只是「一点不舒服」。
  - 当面被看见：有人当面点出我没在做我该做的事，而我没能把这件事挡回去——我一直用来挡人的那一层，已经挡不住了。
- `无变化` — 上述均未命中；刺痛没有压进我的动作，也没有人当面看见我没挡住。

**结果语义**：`有变化` → 同批 KEY 覆盖 `压力水平`/`防御有效性` 新值（内在状态第一人称可知·旧值随 CHAR_state 供给）；`无变化` → 不写。**变化轮必须写·不写＝状态与叙事脱节**。

#### D2 变质判定（判定型·仅循环角色·输入材料产出·随 D1 自查）

**决策问题**：压力＝临界 ∧ 防御＝已彻底崩解？
**缺省选项**：`不升`

**决策选项与选中标准**:
- `升档` — 两问皆「是」（用本环 D1 评估值与 CHAR_state 旧值自查）
- `不升` — 任一「否」（行为异常不构成升级依据·本环重写该行为）

**结果语义**：`升档` → 本环即升级时刻，心声与行动承载升级（第一人称体验·不出现档位名）；`不升` → 不动。

### ① 感知（我此刻注意到的）

**定义与边界**：感知，指我此刻注意到的部分。这一节只决定我注意到哪几样。我能不能知道某件事，由输入供给时的认知边界与可见性过滤决定；这一节不改变它。

- 我从已经给到我的内容里，挑出**这一轮有下文**的几样。有下文，指我这一轮会因为它改一个判断、一个动作或一股情绪。
- 每挑中一样，写清三件事：对象是什么、它发生了什么变化、我从哪一处感觉到它（看见、听见、闻到、碰到、手里一沉）。
- 没有下文的，不写。场景里还有什么，不逐条列出。
- 我的压力水平越高，注意到的越少、越窄；压力水平越低，注意到的越多、越细。写多少，按「总览·四类局面」的配比定，不按给到的材料有多少定。
- ① 只写外界与身体的位置、重量感。情绪带起的生理归 ②（生理词域见 ②）。
- 没注意到的东西仍在世界里，见「一致性约束·注意边界」。

> **来源**：首次引入＝「心声七层重构」（修「角色全知感知」）；本次改写＝修「判据不可自判／人称断裂／与一致性约束表重复」。

### ② 情感反应

- 即时情绪 ＋ 生理 ＋ 冲动。
- 生理按这一股情绪的词域写：威胁类（心跳、呼吸、后槽牙、手抖）／欲念类（发烫、发紧、口干、指尖发麻、喉咙咽不下去）。两域并列，哪一股上来写哪一域。
- 必须在场：**冲着谁**、**到什么程度**、**身上哪里**、**想做什么**；**以及被按住的那一股**。
- **不是定稿**：这是这一下的反应，后面每一环都可能改它（③ 会重新看它，④ 会用到它，⑥ 会把它带进预演，⑦ 会改它）。同时几股互相矛盾的在场上，是正常的——内心冲突就是这么来的。
- 不算：只写状态词（"冷静""果决"是结果不是反应）；没有对象；没有冲动。

### ③ 认知评估

- 这件事对我意味着什么：它冲着的是我的哪一样：哪条目标、哪个身份？是挡路、是危险，还是机会？我还能怎么走、来不来得及。
- **反过来再问一句：我现在最想要什么、多急、为它肯付什么。** 三样都答出来——答出来的这一句是 ④ 比较的尺子，也是 `驱动` 那一行的来源。欲念上来时，「多急」就是「等不等得起」；答不出「多急」，就等于这一轮没有欲望在推。
- 他这句话要办成，需要某个客观物体（能指认、能拿起/放下、能递出/接过、能使用/消耗、能计数）改变位置、归属、状态或数量时（取、给、换、用、放、数都算），先拆他的话：他要什么（名称/数量/是否成套）、他为什么现在要、他以为我会给什么、他觉得怎样算办成、他没说出口的是什么；再列清单：现在有什么（有设定的写明确；没设定的按场面和常识补到够用）／在哪、在谁手里／缺什么（这套里还差的）／哪些必需、哪些可选。清单只列这次要用的，不盘点全场；拿不准的写“要去看/要去问”。清单只写这一次，④–⑦都用它；给不给、给多少，仍在 ⑤ 由我定。清单和他的意思都留着用。
- **一件一件对着「输入材料·人格动力」那一行问**：压上来的这一下冲着的是哪一样（欲望／恐惧／底线／关系锚点）？来得快不快、准不准？先说最要紧的那一样，其余一句带过。
- 多数人最怕丢命，所以生存通常排在最前；**但那是这个人自己的怕说了算，不是一条通用排序**——为名号赌一把、为一个人压上全部，都可能是我的第一名。
- 答到什么份上：**有威胁压上来时，威胁这一面必须答到底；没有威胁时，主要看欲望和核心诉求**（情境温和就不必把每轮都过成危机）——哪几面答到底，看「环境压力＋人格动力＋内在状态」。
- 必须在场：指向**已有的目标字段**（核心欲望／核心诉求／当前计划／未完成意图／价值底线／关系锚点）；**含我不愿承认的那条**。涉及物品时，清单也在场——需要/现有/缺/必需·可选都能对上。
- 不算：只有干脆的结论——我想的时候，有我愿意相信的成分，也有我不愿承认的那条。

### ④ 思考

- 设想、比较、权衡：**定之前**，先看有哪几条路可走。**三条路都真实**，走哪条由「总览·三件事判」定：
  - **认得出**（记得的事里有同类的）→ 不用逐条比较，办法自己就冒出来
  - **计划上还有没走的项**（`当前计划` 仍成立）→ 照旧在这条链上挑着走（判据见「目标与计划」）
  - **认不出，或事大，或我本来就谨慎** → 设想、比较、权衡（下两节走这条）
- **产物是取舍依据**：分叉的是我的候选行动；场景留给 ⑥。
- 可以：来回、半截、绕开、忽然想起别的；**也可以一条一条排下来、算得很细**——谨慎的人本来就那样，重大的事也该那样。
- 不算：走过场——算了很多条，情绪、身份、底线、我愿意相信什么，一件都没进来。
- **心里常常不止一个声音**——一个要这样，一个不肯，来回地争。这是常态，不是写乱了。

#### 候选（想得到的做法·只是启发示例，不是全部）

想做法之前，先照【我的档案与记忆】回想一遍：**这种事摆在我面前，我这个人会做的是哪几件**——「人格动力」那一行（我是什么人），加上叙事线上写明的默认行为。想到的那几件，都列进候选。

> 推进目标 / 执行计划 / 争夺资源 / 阻止对手 / 保护自己 / 改变关系 / 获取信息 / 隐藏信息 / 隐藏秘密 / 试探 / 操纵 / 施压 / 威胁 / 诱导 / 逃避 / 报复 / 升级冲突 / 改变策略 / 抓住机会 / 满足欲望 / 避免恐惧 / 防止目标失败

候选先要写清两样：**我能拿到什么**／**我要付出什么（下轮仍失）**——写不出这两样的，先不算。

- 至少一条**取**（把我要的往前推一步）＋至少一条**守**（不让我要的掉下去）
- **「不动」也是一条候选，一样要算**（它付的是：时间、别人替我动了、机会关掉）

#### 取舍（候选怎么比）

先看「输入材料」判成立的**偏离条件／触发行为**——成立，这一轮就走那一条的升级打法，取舍也按那种打法来；不成立，就按默认打法。

把候选一条一条比：**这一条让我拿到了多少我要的**／**要我付出什么、付出去的我还能不能拿回来**（拿不回来的，只为我肯为它付的人才值得付）。

- **算的时候看这些** — **核心欲望**／持续计划／核心目标／核心恐惧／未完成意图／上一行动结果／**旧记忆（同类旧经历的结果——我以前这么做过吗、后来怎样）**／目标受威胁程度（取 ③ 里最要紧的那一样）／CT 压力（只取压上来的冲突·无 CT 直读）／机会窗口／对手行动／新信息／关系变化／情绪／时间压力／资源／事件线当前问题
- **没有威胁压上来时**，比的主要就是推进核心诉求和当前计划——欲望是默认的驱动，威胁只在真的有它时才占位置
- 选「拿得最多、我又付得起」的那一条；**欲念顶着走的那一条，代价可以超预算**——急起来的人不按划算算账。能不能控住也在这里比（哪个我处理得了、不处理会丢什么）
- **「不动」也在这里比**——它拿到了什么？付掉了什么？在这里算不出好处的那条，不选
- **信念也在这里比**——「人格动力」里的信念＝我如何解释世界，是这一轮判断的标准；它松动的样子见 ⑦。

### ⑤ 决策

- 综合情绪、目标、信念、约束与后果，**定下做法**——比出来的那一条，要清楚到能直接照着做。
- 定下做法时，按清单写清：给哪些、留哪些、缺哪些（这套里还没落实的）、从哪来、做完在谁手里/身上。
- 清单里的必需项：给，或写进 `未完成意图`；可选项由我要什么、我的身份和已经答应的事定，他的满意是其中一个变量。
- 只有这套的必需项齐全，才叫“一套/全套”；还差的叫“部分”，写进 `未完成意图`。
- **`未完成意图` 写「我手上还没做完的几件事」**——每条是对象＋我要做的动作，通常 1–3 条（✅「把欲望引导走完：贴近他、给出可以触碰的许可，然后停手等他」＋「带他到武器架前挑一支枪」）；做完的划掉，新冒出来的补进去，本环推进哪几条由当时的局面定。❌ 只写观察点（「看他会不会回头」「他拿枪的手是松的还是紧的」）——观察点没有动作，不会被当成待办读出来。看出来的东西写进心声，不占这个字段。
- **不要求最优**——允许够用、允许惯性、允许选了舒服的那条；**也允许我算得很细、选了算下来最合适的那条**（谨慎的人，重大的事）。
- 必须在场：一个清楚的答案——接下来做什么。
- **定下来的时候，人常常已经动了**——站起来、转身、往门口走；决定不是说出来的，是做出来的。
- **失败后续**在这一步一并定下：如果这么做不成，下一步怎么办（判据＝上轮行动结果已满足其条件时触发）。
- **失败后续是条件处方**：当前动作的展开留给 ⑥。
- **想不完也可以先搁着**——「先不决定，下次再说」也是一种真实的定法；搁下了，情绪还可能回潮（「可我还是有些不甘心」）。

### ⑥ 心理预演

- ⑤ 定下之后，把这条已经定下的动作在脑子里跑一遍，并想象对方的反应和场面的变化：先发生什么、对方会怎么接、那个场面是什么样。产物是场景、预感；想象可能出现的不同反应和变化，可以出现“他会 A 还是 B”的分叉，但分叉的是对方的反应、外部变化，不是“我要不要改走另一条”；风险、可行性和改不改，交 ⑦。

### ⑦ 重新评估与修正

- 预演之后回头看——**先做可行性与风险评估**：看哪里会出岔子、风险大不大、做不做得成、跟我要的是不是一回事；再决定改不改、改到哪一层。
- 按清单和我的目标对一遍：必需项齐不齐，我要的是不是也成立；给了的在哪、在谁手里/身上；对不上就改行动或改状态。
- 改法可以是：只改情绪/想法；**改执行方式**（行动本身不变，改措辞、顺序、力度）；**换行动**（回 ⑤ 重定，需要重比候选就回 ④）；**重新看局面**（回 ①/③ 重新感知或评估）。
- **修情绪是常态**：弱下去、换了对象（气的不再是他，是自己）、被另一股压过、压下去又翻上来；**把它叫出名字本身就会改它**（"我这是怕"——说出口就变了）。
- 可以：改了、改了一半、或改到圆；**改不圆、带着两股动手，也算**。
- **修正常常是往回落**：从大道理落回到一件具体的小事上。
- **不要求每次循环到圆满**——急局与踩线局不等方案可行，**允许带着没想清的地方动手**（可行性/风险在 ⑦ 评估；修正做到哪一步也由局面定）。
- **信念一变，取舍就跟着重来**——旧记忆压上来时，若按旧信念该选的那一手我这次选不出来（或反过来），那就是信念在变：它一变，就要重新比，这一轮的行动也就跟着变。这一条只是**发现信号**——是否写 `信念演化`，按「记下来」第 2 步两段式判据定（还要过准入门槛：被推翻的旧信念不是这几轮才长出来的）；只过发现信号 = 打法变了，归记忆锚点／连续行动轨迹。

### 目标与计划（跨轮慢变量·D3）

`核心诉求`（预期达成的状态·答「什么样算成」）与 `当前计划`（步骤链·答「怎么走到」）是**跨轮慢变量**——它们决定 ④ 里「照旧走」走的是哪一步，也决定下一轮的默认路径。**本轮行动定下后**，对照本轮评估与取舍，把它们对一遍账。

#### D3 长期计划巡检（判定型·稳定层·每轮逐条对账）

**决策问题**：`当前计划`/`核心诉求` 仍成立？
**缺省选项**：`仍成立`

**决策选项与选中标准**：
  - `仍成立`＝逐条核对后路线、`核心诉求` 与各活项标记均与事实一致；
  - `需重写`＝长期路线或 `核心诉求` 已变（路线被调整/替换/放弃/重新规划；`核心诉求` 已达成／已放弃／对象失效／换成新的）；或 `当前计划` 任一活项的标记与事实/时间线不一致（走完未打 `✓`、重开仍挂 `✓`、次序或条目已变）；或字段里写明的时刻已经过去

**结果语义**：
  - `仍成立` → 不动；
  - `需重写` → 本批同批覆盖对应字段（新值写法＝本节「计划维护规则」）。

#### 计划维护规则

**逐条核对（每轮·先于 D3 判定）**：逐条对照场景时间线、此刻的时间与本人记忆锚点，读出已完成项、各活项标记是否与事实一致、本环说出口而未兑现的承诺、写明的时刻是否已过。对账产出＝上述事实清单，供 D3 判定取用。

**命中 `需重写` 后**：按下列规则同批覆盖 `当前计划`——

- **已完成项（走完的步骤·已兑现的事件·确定不再补做的）→ 收进概括段**：链头维持一句概括条目，把此前已完成项收拢为 `子任务·子任务·…✓`（内部用 `·` 分隔·尾标 `✓`·新完成一项就并入一个子任务名）。概括段之后仅最近 2–3 个已完成项逐项带 `✓` 保留，其余不逐项留；写入时同批覆盖 `当前计划`·轨迹记 `计划变化: 调整——已完成段压缩`
- 未完成的项照旧标进度：正在走的标 `（进行中）`，没走的留 `（待完成）`
- 条目与已发生事实、或与此刻的时间对不上 → **以场景时间线为准改写**
- **链序＝默认推进顺序，不是执行锁**：可以先走后面的环节，也可以几项同时走（各标 `（进行中）`）。每一环走哪一项、走几项，由当时的局面定——`（进行中）` 的项优先做，把当前这一项做好；这一项做到什么程度、怎么回应，按眼前实际的样子定。其余的按局面挑。
- **本环我说出口、还没兑现的将来步骤（承诺）→ 同批进链**：带条件或时间点的口头承诺（✅「挑完枪，我们慢慢走那一段」「到时候您把这句话再说一遍」），按它将在流程的哪一步兑现，写成 `（待完成）` 条目插进 `当前计划`，触发条件写在该条目里。原话与定性留在 `记忆锚点`，本字段只留可执行的那一步。

原则：计划是前瞻文件，时间线是唯一事实源——已完成步骤的经过由时间线与记忆锚点承载；计划里留概括锚与活项，定位走在哪、看见还剩什么，就够。

**从链上按局面挑**：外部进来的事，先判它是否改变这条链：改才重写，不改就在这条链上挑着走（外部输入不进 `当前计划` 的源·判据见本文件「语义与自治原则」）。

**判定为「要重写」时**，先在心声里把从 `核心诉求` 到步骤链的那一段走完——我要到的那个状态 → 从此刻到那里要过哪几道关口 → 先迈哪一步、后迈哪一步（`→` 串联·含未走步骤·步骤链格式见 keys.md「CHAR_{name}_state.yaml」节 `当前计划`）；走完才落新值。**`核心诉求` 已变** → 旧链的已完成项不写进新计划，归 `连续行动轨迹` 与 `记忆锚点`；旧链里在新诉求下仍要走的关口，重写成 `（待完成）`。

判定属 **Decide**，与「心声先于 ACTION」同约束——**判定未落，动作卡不得先出**。计划每一步都要写清对象、地点/事件和触发条件；长期意图必须写清「在什么条件满足时才推进」，不能写成每轮都会重复执行的开放动作；不使用未解释的「雾」「那两问」「账」这类简称。

**写法锚定**：`核心诉求` 写「什么样算成」的**预期达成的状态**——✅「验证访客的完美之下是否存在真实」；边界 ❌「带他走完园区→让他答应留下」（步骤链·归 `当前计划`）、❌「他待我如真实的人——这份相待成为不可撤销的事实」（已成立的定性·归 `记忆锚点`）。

### 写法

使用第一人称，以我自己的语言和思维方式自然流动。

心声的思维形状、语言风格、关注重点和判断方式必须体现我自己的人格：取自 CHAR_.md 角色档案「人格内核 / 语气特征的措辞质感」＋ CHAR_state 当下状态「核心状态 / 健康 / 情绪 / 压力水平 / 防御有效性 / decision」。

**写什么由上面七层与配比表定**——①–⑦ 里真的发生过的，就是心声的内容；哪几层重点思考、哪几层一带而过，由局面与我这个人定（见「总览」）。表现当前思考真正涉及的内容。

### 示例（经典文本节选）

**一、《简·爱》第二十七章——两个声音真的在对打**

> 「我该怎么办？」我心灵的回答——「立即离开桑菲尔德」——是那么及时，又那么可怕。……我说，这些话我现在可受不了。……「那么把我拉走吧！」……「让别人来帮助我！」——「不，你得自己挣脱，没有人帮助你。你自己得剜出你的右眼；砍下你的右手……」……我站直时只觉得脑袋发晕……那天我没有吃早饭。……带着一种莫名的痛苦，我忽然回想起来……没有人带口信来问问我怎么样了。……「朋友们总是忘记那些被命运所抛弃的人。」

**二、《地下室手记》——想不完，先搁着；搁下了，还会回潮**

> 我当然生气了。他凭什么那样对我？难道我在他眼里就这么不值得尊重？我当时应该立刻回敬他一句。……可我当时为什么没说？因为周围有人？因为没有想好该说什么？不，我当时明明有机会。……问题在于，我究竟想要什么？让他道歉？让他难堪？还是只想证明自己并不比他低一等？……算了，先不决定。下次见到他再说。……可我还是有些不甘心。

**三、《少年维特之烦恼》——嘴上把自己按回体面，不肯认的那条从旁边漏出来**

> 我必须离开，阿尔贝特回来了。……好在欢迎他归来的时候我不在场，不然，我的心会全部碎裂！……他对我十分友好，我猜测，恐怕这要归功于绿蒂，并不是出于他自己的情感。……就算这样，我还是对阿尔贝特很尊重。……不过，如果我在他的位置上，在妒忌这个魔鬼的面前，起码我不会全无反应。

**四、《莎菲女士的日记》三月二十四／三月二十一日——欲望开到顶，撞上冷淡，落差推出反差**

> 当他单独在我面前时，我觑着那脸庞，聆着那音乐般的声音，心便在忍受那感情的鞭打！为什么不扑过去吻他的嘴唇，他的眉梢，他的……无论什么地方？真的，有时话都到口边了：「我的王！准许我亲一下吧！」但又受理智，不，我就从没有过理智，是受另一种自尊的情感所裁制而又咽住了。唉！无论他的思想怎样坏，他使我如此癫狂的动情，是曾有过而无疑，那我为什么不承认我是爱上了他咧？并且，我敢断定，假使他能把我紧紧的拥抱着，让我吻遍他全身，然后他把我丢下海去，丢下火去，我都会快乐的闭着眼等待那可以永久保藏我那爱情的死的来到。唉！我竟爱他了，我要他给我一个好好的死就够了……
>
> 谁都可以体会得出来，假使他这时敢于拥抱我，狂乱的吻我，我一定会倒在他手腕上哭出来：「我爱你呵！我爱你呵！」但他却如此的冷淡，冷淡得使我又恨他了。然而我心里在想：「来呀，抱我，我要吻你咧！」自然，他依旧握着我的手，把眼光紧盯在我脸上，然而我搜遍了，在他的各种表示中，我得不着我所等待于他的赐予。为什么他仅仅只懂得我的无用，我的不可轻侮，而不够了解他在我心中所占的是一种怎样的地位！我恨不得用脚尖踢他出去，不过我又为另一种情绪所支配，我准备冷淡地向他摇头，表示不厌烦他的来到。

看的是心理怎么走路，不是句式，译文腔也不搬。执行动作与出声台词不属 MUSE——节选里混着的已剔去（归 ACTION）。四例走法各不相同，七层按需出现，没有一个字在报层名。引擎里落成的形状（`###MUSE:`·括号·第一人称）见「批次格式」节。

### 一致性约束（审计可核，不是写法规则）

| 约束 | 内容 |
|---|---|
| 注意 → 行动 | 行动与台词只能作用于我注意到的东西 |
| 评估 → 行动 | 行动须回应评估指向的那条目标；**不愿承认的那条不许被说出口，但必须留痕**（身体／时机／措辞） |
| 注意边界 | 没注意到的东西仍在世界与状态里，只不在我心里；常备项不因没被注意到而消失 |
| 倒补识别 | 七层里有未处理的冲突，心声却径直引出结论 ＝ 倒补，重做本环 |

情绪的去向写在 ② 与 ⑦ 里——它怎么变、几股并存、最后被哪一股带着走。

## 二、行动（ACTION）

### 语义与自治原则

我根据真实意图、社会关系、身份规范、利益、风险及对他人反应的预期，自主决定如何表现自己。

外在表现包括言语、动作、表情、姿态、语气、沉默、信息披露、伪装、试探、克制及其他可观察行为。

我可以坦率表达真实想法，也可以隐藏、弱化、修饰、转移或反向表达真实想法。外在表现必须符合我当下的动机、能力、情境和行为逻辑。

**心声与行动的关系**

- 我的心声（MUSE）是我此刻真实经历的内心活动：由我自己的感知、情绪、欲望、记忆、关系和当前处境产生。我的行动（ACTION）是我此刻对这些经历作出的可观察行动和实际说出口的话。台词从这条连续过程中产生：可以是我在心里自然浮现的词，也可以是当场说话时形成的词；判断标准是这个词是否由我的感知、目的、关系和处境产生，不是它属于哪种句式。
- 我先形成真实内心状态，随后根据身份、关系、礼仪、利益、风险、自我控制和当前情境，决定哪些内心内容可以表现出来，以及应该以什么方式表现。
- ACTION 执行后的结果、新信息和其他角色反应进入下一轮「输入材料」，作为下一环 MUSE 的输入。
- 同一角色连续行动时，可以使用轻量续环，仅更新行动状态和新增感知，不重复构建稳定的人格动力层。

**反差生成原则**

每轮决策中，分别定下：我真实的想法、感受和打算；我希望他人看到或相信的形象与信息；我实际采取的外在表达与行为。

三者可以一致，也可以存在差异。差异由我自己的心理、关系、利益、恐惧、社会规范或策略产生。

允许我言不由衷、口是心非、强颜欢笑、故作冷静、表面顺从、暗中抵抗、试探他人或无意间泄露真实情绪。

当我有隐藏动机、社会压力、关系顾虑、利益冲突、暴露风险或情绪克制时，先想清楚：心里那一份和摆出来那一份差多少。我可能：

- 内心想拒绝，嘴上答应
- 内心恐惧，表面镇定
- 内心厌恶，表现礼貌
- 内心喜欢，故意冷淡
- 内心怀疑，表面信任
- 内心准备欺骗，外在表现诚实

**示例**

MUSE:（萧策今天居然主动来敬酒……他左手一直垂在袖里，上次他这样，袖中藏着短刃。他是在试探我？还是已经知道酒里有东西？不能慌，王爷交代的事还没办完。先接杯，不喝，拿话激他，看他袖口动不动。要是他真翻脸，我就退到屏风后，那里有刀。脸上得笑，叫他萧公子，别让他看出我心里发毛。）

ACTION: 我起身，双手接过酒杯，身体微侧，左手按住桌沿，目光扫过他的袖口，笑道：「萧公子今日好兴致，这杯酒，陈某可不敢独饮。」

### 行动实现

#### D4 行动有无判定（判定型·入口·每环必过）

**决策问题**：本环有没有行动？
**可选结果**：`有`／`无`　**缺省**：`有`

**选中标准**：
- `无` — 「输入材料」与 ①–⑦ 已推完，没有哪件事值得现在做（「我在等对方」不算——等也是我在做的事·见 ④ 取舍）
- `有` — 其余（缺省）

**结果语义**：`有` → 按下方产 `###ACTION:`；`无` → 本环不产 ACTION，**只产该环 `###MUSE:`**（一句自判＋依据·格式见「批次格式」零卡环）——**`无` 不结束走环**：下一环边界该角色照常进候选集（phase_actor.md 行动环·收敛核对）。

**边界（硬性）**：`无` 是**我自己的判断**——走完输入材料与 ①–⑦ 后由我作出，**编排层不得代判**（phase_actor.md 职责 2 行动环）；`无` 只让该环无 ACTION，**不结束走环**（下一环边界该角色照常被追加）。

**首步·档案基准对照**：写动作前对一遍：我打算做的，够不够「在这种情形下起码会做的事」。

**依据**：人格 / **认知上限**（循环角色·档位上限见 loop_machinery §2.3「常驻约束·行为档位上限」·非循环角色无此限）/ 叙事视角 / 感官锚点 / 动作习惯 / 语气 / 当前情绪 / 压力 / 防御状态 / 关系 / 空间 → 实现为：动作 / 台词 / 身体语言 / 情绪表现 / 空间互动 / 信息透露 / 信息隐藏 / 环境变化。

#### 反顺从四则（写行动前逐条执行）

1. **档案强度** — ≥ CHAR_.md 基准；**有威胁压在身上时，畏缩/服从/退避本就是档案基准的合法反应，不得因反顺从把它改写成逞强**；无威胁时的顺从才算默认 ＝ 重写
2. **抽象方显现** — 出手形态 ＋ 抵抗痕迹
3. **认知闸门** — 知识归属（该角色有认知来源才可用）
4. **硬边界复核** — 底线与关系锚点所指的人（见「输入材料·硬边界」）；此处只核对拟作动作没有把它们当成筹码

#### 行动卡格式

（audit 机械检查·每个动作环一个卡块——首行**必含三件套 驱动/情绪/强度**；`代价` 为有条件槽·见下）

```
###ACTION: {角色}: 驱动: {内部动机} | 情绪: {主导情绪} | 强度: {1-10} | 代价: {某}失{可核验变化}/{某}失{可核验变化} | 耗时: {分钟}
  {动作节拍 1}
  {动作节拍 2，含对谁说的台词}
  {动作节拍 3}
```

正文从缩进行开始，到下一个 `###` 标签结束；一个动作环可含多行动作和多段连续台词。旧单行卡没有正文时按旧格式兼容。

**POV 用户角色（第二人称）** — 卡格式与 MUSE 口径（逐字贴入用户原文·不补写用户未给的部分）归 `phase_actor.md`「POV 用户角色（第二人称）：卡格式与 MUSE」。

#### 表现密度标准

- 表现必须具体、连续、可观察、可呈现；每个子动作写清表现发生了什么，以及必要的对象、空间关系或终止状态；多个子动作前后衔接，形成完整连续的行动过程
- 本环若以等候收尾，等候状态（等谁、等什么）写进本环 `###MUSE`；行动正文只写到最后一个可观察动作与台词，不另加等待姿势
- ACTION 卡是一次广义行动的完整表现；有触发事件时，首个子动作体现角色对该事件的即时反应
- 可使用动作、表情、眼神、姿态、手势、声音、台词、沉默、呼吸、节奏、空间、环境、物件等表现方式；仅写对当前行动有意义的内容，选用与该角色档案及当下状态吻合的方式承载
- 情绪通过声音、表情、动作、节奏、身体状态呈现；半抽象情绪描述进一步落为具体表现（如「发烫」→ 目光停住、呼吸变深、声音放低、手指收紧）

#### 台词与信息

- **台词** — 我开口时，写下我对谁说了什么。要说什么，由我的内心、目的和关系决定；怎么说，以 `CHAR_.md` 的「人格内核／语气特征（对话风格）」为准，并结合我此刻的情绪、关系与场面。可以是文白、官腔、方言或普通口语，但语域要统一，指称要清楚。
  - **说出口的，未必是心里想明白的那一句**——心里通了的事可以只说一半、可以拐个弯、可以说反。台词写的是我此刻说出口的话，不是我心声的结论。
  - 每句开口前过两问：① 这句话对谁说的？要他明白什么、做什么、听完有什么反应？② 语域统一吗？指称清楚吗？——每个指代和名词，听的人能不能落到具体的人、物、动作上？
- **信息** — 涉及信息时，明确角色获得、透露、隐瞒、询问、确认或回避的信息
- **潜台词** — 用外化呈现：嘴上说 A，但通过表情、眼神、动作等表现出 B
- 先识别本轮要推进的欲望、关系、信息或冲突，再为每项关键内容找到承载它的具体表现

#### 三处落点的分工（硬性·防双写漂移）

- `###ACTION:` 正文 ＝ **行动与说话内容的唯一原文**。`驱动/情绪/强度/代价/耗时` 是审计元数据，作家不抄入正文。作家据正文写事实、动作和人物声音；说什么归角色、怎么写归作家（落字口径见 `phase_writer.md`「写作硬约束·W4」对话段）。
- `decision.当前行动` ＝ 后续的我能独立看懂的行动记录：写清对象、地点、具体动作、当前停点与下一步条件；涉及物品时，写清清单里给了哪些、留哪些、缺哪些（这套里还没落实的）、现在在谁手里/身上。可以多句，不设固定字数上限；不得为了短而省略指称、使用未解释的简称或比喻。涉及「说了什么」时用间接引语，保留对象、内容与语气；只有名字/誓言/暗号/契约条款等原话本身是事实时才保留短引语
- `连续行动轨迹.行动` ＝ 角色自用摘要（不要求与卡片同长）。摘要不等于省略实指：对象、地点、关键结果和未完成条件必须能独立读懂。
- `decision` 中的人物、地点和已知事实必须来自我的认知边界；只听过名字但没去过、没确认过的地点，要写明「只知道名称/不知道位置」，不能当成已知目的地。

同一事实，几处深浅不同——**不双写全文**。

#### 驱动（audit 硬检）

一句话，取自 `###MUSE` 里拿定主意时的「为什么／为什么是现在」——与心声一致，不另起一套动机；完整推演在 `###MUSE`，此处只留可机械核对的一行。

#### 意图 → 表现（示例）

- 「让他知道选对了」 → 正面迎住目光、停下、靠近、说出选的是他（不写「确认他选对了」）
- 「不想把被珍视演成迎接」 → 笑意先起又收住、无客套、停顿后认真看他（不写「不再表演」）
- 「想要朝他去」 → 身体朝向他、缩短距离、说出选择、主动牵住（不写「透露想要」）

✅ 正例：`我听见门外的脚步声，手从门把上慢慢收回→侧身贴墙站定，屏住呼吸→脚步停在门外，我低声说："我知道你在。"，却没有开门→视线落向桌上的刀，手指轻轻碰上刀柄。`

❌ 反例：`站定→回扣手→牵他朝主街迈半步→开口选第一站`（「选第一站」无选什么、无要对方听到什么）

#### 行动代价（有条件必填）

**触发条件** — 做完之后，**我自己**少了什么（可退的余地／中立的位置／克制／缓冲／控制权／身体边界），下轮也拿不回来——有，就写 `代价: 我失「…」`。

**豁免** — 过渡／寒暄／轻量刷新这类不付出任何位置的动作，不写（audit 检查）。

**格式** — `代价:` **引用 ④ 取舍里已经比出来的那一条**——填 `我失何物（下轮仍失）`；何物限可核验物：资源/载体状态/关系档位/控制权/身体边界（正向枚举 5 项）。观感类（距离感/匿名度/气氛）不算代价；取舍里没算过的（过渡/寒暄/轻量刷新）不填。

#### 代价-动作正向速查（需填 `代价` 时·按此选一项可核验物）

| 可核验物 | 代价示例（下轮仍失） | 实质动作示例（转折性） |
|---|---|---|
| 资源 | 施压者失「可不担后果的挑衅」（已上手） | 抓住对方小臂/衣料拉拽半步 |
| 关系 | 被压者失「可作无事的中立」（已明示选边求助） | 转身抓住求助对象手腕＋出声求助 |
| 控制权 | 守护者失「可不拔的克制」（枪/械已出套指向） | 拔出武器指向施压者＋喝止 |
| 边界 | 秩序者失「口头缓冲」（已拔械截停） | 拔械横亘两人之间 |
| 载体 | 旁观者失「可静默的旁观位」（已介入带离） | 抬手格挡＋半步带被压者退离 |

## 三、写入（CHAR_state 唯一写者·角色意志的体现）

**写前读 keys.md「CHAR_{name}_state.yaml」节**——键表/值域/写语义在彼；批次与写入通道以 references/write_protocol.md 为权威；本节只列动作与触发。

### 必写项（非决策·结构化必含）

- **decision**（KEY 点路径逐层写）— 首次物化一并写核心诉求/当前计划/当前行动/行动驱动/行动对象/行动窗口/失败后续/未完成意图；已物化的焦内活跃者每轮更新运行层六项。稳定层（`核心诉求`／`当前计划`）的语义与值域见 keys.md「CHAR_{name}_state.yaml」节。按既定路线走完一步/进入下一环节/原活项重开或次序调整 → 同批覆盖 `当前计划` 同步标记（路线本身未变），轨迹记 `计划变化: 调整——…`；被调整/替换/放弃/重新规划（含首次具体化）→ 本轮同批覆盖——**覆盖源＝D3「长期计划巡检」的判定**（我自己的判断·不由轨迹标签驱动）
- **连续行动轨迹**（APPEND·结构化七子字段）— 轮次/行动/行动目的/行动结果/他人反应/计划变化/未完成意图——我自己的时间线·近 10 轮滚动（APPEND 后脚本自动删最旧·LLM 零操作）；同轮多环 ＝ 每环一条·按序追加（同轮次多条合法）
  - **`计划变化` 判据**（先看是否覆盖了 `decision.当前计划`）— 覆盖了 → 记 `调整——客观概括`；未覆盖且沿原路线行动、未跨过任何活项 → `推进`；都没动 → `无`
  - **值域三档** — `无`（本轮未推进）/ `推进`（路线未变·本轮走在当前活项内、未跨过活项边界）/ `调整——客观概括`（活项标记同步或路线被调整/替换/放弃/重新规划）
  - **本字段＝本轮记录**（跟着 D3 巡检结论走·不驱动覆盖）
  - gate actor 双向一致性核对：记 `调整` 却未覆盖、或本轮有轨迹却覆盖而未记 `调整` ＝ 拦

### D5 状态写入判定（判定型·逐字段·每轮必过）

**决策问题**：逐字段本轮是否写？
**缺省选项**：`不写`

**决策选项与选中标准**（逐字段各判一次·缺省＝不写）：

| 字段 | `写` 的判据 |
|---|---|
| `情绪` | **每轮必写**——本轮结束时**还没消的那一股**（情绪名·冲着谁·到什么程度·身上哪里·还想干什么·还压着什么）。几股并存时，写还没消的那几股 |
| `记忆锚点` | 高刺激事件（情绪剧变/利益损益/关系转折/威胁承诺/命名直觉）且我会记住（写法＝本节「`记忆锚点` 记下来」） |
| `信念演化` | ④ 取舍里得出的信念转变／变质判定留痕 |
| `人际动态` | 关系实质变化（关系提炼） |
| `妆扮` | 本轮有容貌/发型/妆容变化；字段为空而 CHAR_.md 外在特征有基线描述 → 视为待填充 |
| `服饰` | 本轮有穿脱/损坏变化；字段为空而 CHAR_.md 外在特征有基线描述 → 视为待填充 |
| `随身物品` | 本轮有可转移重要持有物的取得/交出/遗失/易主（含代管/折叠持有）；`ACTION` 含 `接过/递出/握起/装入/收入/捡起/交出/夹带/折叠持有` 即视为取得 |
| `位置`/`核心状态`/`健康`/`已知地点`/`名字` | 状态质变／首次到达·被告知·目睹／身份质变（细则见 keys.md） |
| `压力水平`/`防御有效性` | 本文件 D1 判 `有变化`（档位＝keys.md 对应行·不按轮数） |

> 写语义、值域与解析规则＝keys.md「CHAR_{name}_state.yaml」节；批次与写入通道＝write_protocol.md。

#### `记忆锚点` 记下来（把思考里已经发生的事落到纸上——记忆与信念是我自己的）

**锚点须自足**：实体（原话/动作）留在事实段，定性从事实段直接读出——读完本条目即懂，不回查其他条目。

- ✅ `他收枪道歉·归还评估说他真正关心的是我的真实·相称握手·邀我同行 ➔ 他待我如人而非服务——真心一次比一次更近`
- ❌ `相称握手·邀我同行 ➔ 真心三步走完——从桌面到掌心再到去处`（「桌面」在事实段无实体·「三步」不回查被删条目就读不出）

思考里已经发生过的事，这一节只负责落下来（没发生就不写）：

1. **并成一句** — 「输入材料」想起的那几条同类旧记忆，若在思考里已经并成了一句 → `###KEY: 记忆锚点` 覆盖为合并后的完整列表（其他对象的条目照旧保留），再记下这一件
2. **认下道理**（信念提炼·两段式判据，同时满足才写）— ④ 取舍里想通的那条新道理：
   - **发现信号**：按旧信念该选的那一手，这次选不出来（或反过来）——旧信念拦不住这一条
   - **准入门槛**：被推翻的那条旧信念，不是刚刚这几轮才长出来的——它一直在（档案核心信念／人物底色里早就有的／链上已稳定多轮的）。只过发现信号＝打法变了 → 不写信念演化，本环心得归第 4 步记忆锚点
   - 两段都过 → 同批 `###APPEND: 信念演化`（`触发事件`＋`旧信念→新信念`·只提炼不升级）
   - 同一信念的历次修订成链；链上总量超校验线（keys.md `信念演化` 行）→ 同链合并为一条「基线原文→当前态」，`###KEY:` 覆盖全量
3. **改看他的眼光**（关系提炼）— 这个人让我对他的看法变了 → 覆盖 `###KEY: 人际动态`
4. **记下这一件** — `###APPEND: 记忆锚点`·完整自然句（见 keys.md「记录字段写法」）

示例：我已有「他让着我」「他记得我忌口」两条同类锚点，本轮又记下「他把伞塞给了我」→ 思考时我意识到「他一次次照顾到我的细微处」是一件事、不是三件 → 并成一句（`###KEY: 记忆锚点` 覆盖为「概括：他一次次照顾到我的细微处 ➔ …」＋ 本条）；旧信念「被人照顾意味着欠了债要还」拦不住这一条（这条旧信念我早就信，非这几轮才长成——过准入门槛）→ 同批追加 `###APPEND: 信念演化`：「旧信念→新信念：被人照顾意味着欠了债要还 → 有人照顾我只是因为愿意」。

### 升档批落盘（批次核验·主 agent·判定已前移「输入材料」D2）

判定归角色（D2 随 D1 自查·触发环的心声与行动即升级时刻）；本节只承载升档批的落盘顺序与批次核验：

**批次核验（主 agent·机械）**：核对 CHAR_state 压力水平／防御有效性 达门槛（临界＋已彻底崩解）→ **自主性升档 KEY 由主 agent 批次补写**（档位枚举不入子 agent·防元档位泄露）·单窗口路径主 agent 直写。

#### 写入顺序（硬性）

`压力/防御 → 自主性 → 信念演化 → 压力回落`

1. **压力/防御** 排最前——门槛按升档写入前的状态核验（脚本硬检·未达门槛拦下升档）
2. **自主性** 升一档（脚本→漂移→觉醒→变质·每次极端冲击只升一级）
3. **信念演化** 留痕（变质级转变）
4. **压力回落** 排最后——回落至世界当前水平（④按其余压力来源估定·非清零）·防御保持崩解

### D6 防御重构（判定型·三条件核验·角色自查）

**决策问题**：三条件齐备？
**缺省选项**：`不重构`

**决策选项与选中标准**:
- `重构` — 威胁源解除 ∧ 支持性关系介入 ∧ 信念重构（三条件齐备）
- `不重构` — 任一缺

**条件判据**:
- **威胁源解除** — 压在我身上的威胁在我感知里退去
- **支持性关系介入** — 人际动态有支持性角色实质行动
- **信念重构** — 信念演化出现旧信念→新信念条目

**结果语义**：`重构` → 防御有效性升一档，防御形态/崩溃表现同批覆盖；`不重构` → 不动。

#### 跨角色槽位归主 agent 批次补写（子 agent 路径）

`###SCHEDULE` 的行动链顺序/受影响与 `###META:` 绑定声明属跨角色编排面——子 agent 只产本角色的 MUSE/ACTION 与写入 op，缺项由主 agent 批次补写时规整补全（phase_actor「产出规范化」）。

**零卡环照列**：D4 判 `无` → 本环不产 `###ACTION:`，但该环**须产 `###MUSE:`**（一句自判：本环没有行动·及其依据——无行动是角色的判定结果，须有角色自述可核），并**仍须列入顺序段**标 `(环N·零卡)`——**零卡不结束走环**，故可出现在任意位置。例：`A(环1)→A(环2·零卡)→A(环3)`（环 2 无 ACTION，环 3 继续）。

### `###MUSE:`

每环一行·排在各自 `###ACTION:` 之前——以角色第一人称呈现当前正在发生的真实思考过程。

- **格式与位置** — 括号包裹·第一人称「我」·不入正文（原文随批次落私有账本·创作不读·见 write_protocol.md「批次账本」）
- **多环** — 同一角色同窗口多环 ＝ 每环一组·按发生顺序排列（有 ACTION 的环＝MUSE+ACTION·零卡环＝仅 MUSE·MUSE₁ ACTION₁ MUSE₂ …）
- **decision 运行层每环随环落盘**（按环序 KEY 覆盖·后环在前环之上演进·**每环都作数**）；`连续行动轨迹` **每环一条**（同轮次多条合法·按序 APPEND）

### META 记忆标记（脚本硬性·逐角色全列）

凡本批写了 CHAR_state 的角色（含焦内与焦外轻量刷新）在**同一 META 行内空格分隔**逐角色列出 `记忆✓ {角色}:{计数}·{已触发|未达}`：

- `计数` ＝ 本轮新写的记忆锚点条数（`0` ＝ 未写）·`已触发` ＝ 写入了记忆锚点·`未达` ＝ 未到记忆写入阈值（写前自查没过）
- 角色名含空格用下划线代空格（如 `Clementine_Pennyfeather`）·**缺一被 gate 拦**
- 示例：`记忆✓ Guest:0·未达`（本轮未触发）／`记忆✓ Dolores:2·已触发`（写了 2 条锚点）／`记忆✓ Guest:0·未达 Angela:2·已触发 Maeve_Millay:0·未达`（多角色同行空格分隔）

### META 绑定声明（脚本硬性·逐行动角色全列）

各行动角色的绑定声明合写于一条 `绑定:` META·逗号分隔（多人一行）：`绑定: {角色}={子agent(组装✓)|单窗口(豁免原因·核对✓)},…`

- **缺声明，或裸 `单窗口` 无豁免原因 → gate 拦截**
- 非 POV 角色标 `单窗口(原因·核对✓)` 须命中豁免白名单**字面**（`子agent不可用`／`工具不存在`〔须有本会话派发报错为据〕／`宿主不可续话`〔宿主不支持具名子 agent 续话·据＝绑定声明〕），否则 gate 硬拦——「在轨轻量/背景位/主agent直演」等自编理由 ＝ 硬拦；白名单字面通过者仍待 A9 审计复核
- **子 agent 绑定须带组装自查标记 `子agent(组装✓)`**——派发前按 references/subagent_prompt.md「派发自查」逐项核对，缺标记 ＝ gate 拦截
- **单窗口绑定须带核对标记 `单窗口(原因·核对✓)`**——按 references/subagent_prompt.md「派发自查」逐槽核对，缺标记 ＝ A9 审计不通过
- 示例：`绑定: Guest=单窗口(第二人称POV·用户指令转写·核对✓),Angela=子agent(组装✓)`
