## MUSE / ACTION 语义

### 角色自治原则

- 角色必须独立完成一次完整的 `Observe → Think → Decide → Act` 决策环。
- 行动必须由角色自身的认知、人格、目标、状态、记忆、关系以及当前感知到的环境压力产生（从本角色 `CHAR_.md` ＋ `CHAR_state` ＋ 感知过滤后的环境压力推出）。
- 禁止根据剧情需要、作者意图、元层调度或预设结果倒推角色意图。
- 去除元层信息后，该行动仍必须能够从角色自身状态与认知中成立。

### 思考过程 ＝ 心声（MUSE）

- MUSE 是角色在作出决定之前正在发生的真实思考过程。
- MUSE 必须呈现角色如何感知、理解、联想、判断、权衡、产生情绪、形成倾向，并最终逐渐确定下一步行动。
- MUSE 先于 ACTION 生成，并为后续行动提供真实的心理依据，行动由心声中形成的行动意图自然产生。
- MUSE 不是决策结果的解释，也不是行动的辩护词。
- 禁止先确定 ACTION，再反向生成 MUSE 为其寻找理由。

### 心声表现（MUSE）

使用第一人称，以角色自己的语言和思维方式自然流动。

心声的思维形状、语言风格、关注重点和判断方式必须体现角色自身人格：取自 CHAR_.md 角色档案「人格内核 / 语气特征的措辞质感」＋ CHAR_state 当下状态「核心状态 / 健康 / 情绪 / 压力水平 / 防御有效性 / decision」。

根据当前情境，自然表现与决策相关的：

- 注意到的事物
- 对信息的理解
- 联想、记忆和经验
- 情绪与身体反应
- 判断、怀疑与假设
- 欲望、担忧与恐惧
- 对风险、机会和他人意图的评估
- 对不同可能行动的权衡
- 犹豫、自我说服、自我提醒
- 最终形成的行动倾向

无需覆盖全部维度。只表现当前思考真正涉及的内容。允许碎片、重复、停顿、自我打断、口语化表达和思维跳跃。

### 行动表现（ACTION / DIALOGUE）

角色根据真实意图、社会关系、身份规范、利益、风险及对他人反应的预期，自主决定如何表现自己。

外在表现包括言语、动作、表情、姿态、语气、沉默、信息披露、伪装、试探、克制及其他可观察行为。

角色可以坦率表达真实想法，也可以隐藏、弱化、修饰、转移或反向表达真实想法。外在表现必须符合角色当下的动机、能力、情境和行为逻辑。

### 心声与行动的关系

- 心声中逐渐形成的最终行动意图决定 ACTION。
- 角色首先形成真实内心状态，随后根据身份、关系、礼仪、利益、风险、自我控制和当前情境，决定哪些内心内容可以表现出来，以及应该以什么方式表现。
- ACTION 执行后的结果、新信息和其他角色反应进入下一轮 Observe 作为 MUSE 输入。
- 同一角色连续行动时，可以使用轻量续环，仅更新行动状态和新增感知，不重复构建稳定的人格动力层。

### 反差生成原则

每轮决策中，分别确定：角色真实的认知、感受与意图；角色希望他人看到或相信的形象与信息；角色实际采取的外在表达与行为。

三者可以一致，也可以存在差异。差异由角色自身的心理、关系、利益、恐惧、社会规范或策略产生。

允许角色言不由衷、口是心非、强颜欢笑、故作冷静、表面顺从、暗中抵抗、试探他人或无意间泄露真实情绪。

当角色存在隐藏动机、社会压力、关系顾虑、利益冲突、暴露风险或情绪克制时，主动评估呈现内心与外在表现之间的差异。角色可能：

- 内心想拒绝，嘴上答应
- 内心恐惧，表面镇定
- 内心厌恶，表现礼貌
- 内心喜欢，故意冷淡
- 内心怀疑，表面信任
- 内心准备欺骗，外在表现诚实

### 示例

MUSE：(萧策今天居然主动来敬酒……他左手一直垂在袖里，上次他这样，袖中藏着短刃。他是在试探我？还是已经知道酒里有东西？不能慌，王爷交代的事还没办完。先接杯，不喝，拿话激他，看他袖口动不动。要是他真翻脸，我就退到屏风后，那里有刀。脸上得笑，叫他萧公子，别让他看出我心里发毛。)

ACTION: 我起身，双手接过酒杯，身体微侧，左手按住桌沿，目光扫过他的袖口，笑道："萧公子今日好兴致，这杯酒，陈某可不敢独饮。"

## 决策环 1.1–1.5（角色自治的决策机制）

内部决策过程使用：`Observe → State / Perception → Think → Options → Trade-off → Decide → Act`。

1.1 状态构建、1.2 八问自评、1.3 候选行动生成与代价评估、1.4 取舍与定本轮行动是角色自治的决策机制。它们用于生成心声，**不直接作为心声的输出结构**——心声里不出现步骤名、字段名、评分、候选编号、决策表（**禁令管的是「结构」，不是「深度」**：想要什么、怕什么、压住了什么、为什么选这一手——这些是心声该有的东西，要写出来）。

### 1.1 状态构建

| 层／项 | 内容 | 来源 |
|---|---|---|
| 人格动力 | **本轮的度量衡**（不是"参考用的背景资料"）：欲望=主动追求什么／恐惧=主动避免什么／信念=如何解释世界／防御机制=受威胁时如何行动／**价值底线=触发行为成立时不可跨越的边界**／反应倾向=默认策略／崩溃模式=临界时如何改变／**关系锚点=会改写我取舍的人** | CHAR_.md |
| 维度标尺 | 大五五维＋阵营双轴＝演绎幅度标尺——即兴与描写一律据它定档该角色「能做到多满/多冷/多硬」 | CHAR_.md |
| 内心意图 | 核心诉求/当前威胁/当前计划/当前关系目标/当前资源需求/当前未决选择 | decision ＋ CT（子 agent 路径无 CT 直读·压上来的冲突经感知增量承载）＋ 经历过的事件线事件 |
| 行动状态 | 当前意图/进行中的计划/下一行动窗口/失败后的替代方案/上一行动结果/未完成行动 | decision ＋ 连续行动轨迹 |
| **记忆** | **这件事让我想起以前记住的哪几件**——同一对象上同一性质的旧经历（回忆是我理解当下的参照，不是背景资料） | **记忆锚点** |
| 环境压力 | CT/其他角色行动/资源变化/信息变化/关系变化/空间变化/**现场物理态势（谁持械/谁被控/伤/围）**/时间窗口·可见在场者与位置/循环状态 | 各状态文件 ＋ 组装通道②（经感知过滤） |
| 内在状态 | **本轮经历后自评：压力水平与防御有效性是否因本轮事件发生变化**（关系事件/存在性冲击/价值底线触发/连续偏离刺痛累积等）——有变化则同批 CHAR_state 覆盖写新值（判据=**D1**） | 上轮事件 ＋ 本轮经历 ＋ 当前压力/防御旧值 |

> **度量衡**：一条威胁有多重、一步棋值不值，都用上表「人格动力」那行来称——称的是「它冲着我的哪一样（欲望／恐惧／底线／关系锚点）、冲着多深」，不是抽象类目。见 1.2 第 3 问与 1.4 账本。

> **条件句读法（硬性）**：人格动力那行不是形容词表，是**条件句**——`核心欲望`／`核心恐惧`／`反应倾向.偏离条件`／`价值底线.触发行为`／`关系锚点` 五类**逐条对当下场面判成立/不成立**：
> - 成立的那条**当轮即生效**（该转猎手转猎手·该掀桌掀桌·该失控失控），不被权重平均稀释；不成立的留作背景。
> - **判成立的偏离条件决定本轮处在哪种打法下**（默认打法／偏离打法），账本按当前打法计价。
> - **关系锚点同样逐条判**——档案写明了生效条件的，条件成立才生效；未成立时此人与旁人同价，不自动置顶。

> **回忆**：理解当下要拿旧经历做参照——这个人、这件事，我以前遇到过吗？想起的那几条，就是这一轮判断的底料。**若发现同一件事已经记过好几回，它在我这里就不再是几件**——那是我该把它们并成一句的时候（落到写入节）。

> 来源供给：角色私有文件（CHAR_.md 人格与主观态字段/CHAR_state）由主 agent 逐字内联（命运层/引擎面/循环时间线按 subagent_prompt.md「组装转换矩阵」按档位转换）；外部状态（CT/事件线/他人行动/各状态文件/可见在场者与位置/指涉历史原文）由主 agent 组装通道经感知过滤供给（单窗口路径由主 agent 直接读取）。

#### D1 内在状态评估（判定型·1.1 产出·每轮必过）

**决策问题**：本轮经历改变压力/防御吗？
**缺省选项**：`无变化`

**决策选项与选中标准**:
- `有变化` — 关系事件／存在性冲击／价值底线触发／连续偏离刺痛累积等命中（多源综合）
- `无变化` — 上述未命中

**结果语义**：`有变化` → 同批 KEY 覆盖 `压力水平`/`防御有效性` 新值（内在状态第一人称可知·子 agent 路径旧值随 CHAR_state 内联·两路径同规）；`无变化` → 不写。**变化轮必须写·不写＝状态与叙事脱节**。

#### D2 变质判定（判定型·仅循环角色·1.1 产出·随 D1 自查）

**决策问题**：压力＝临界 ∧ 防御＝已彻底崩解？
**缺省选项**：`不升`

**决策选项与选中标准**:
- `升档` — 两问皆「是」（用本人 D1 评估值与既有状态自查·角色不知档位枚举名）
- `不升` — 任一「否」（行为异常不构成升级依据·重写行为）

**结果语义**：`升档` → **本环即升级时刻**——1.2–1.5 照常推进，心声与行动承载它（疼痛峰值／记忆回涌爆发／主导权易手·第一人称体验·不知档位名，自主性 KEY 由主 agent 收口补写）；触发环的心声与行动即升级叙事材料（⑥呈现·不代生成）。完整附加动作（升级链／状态先行／升级轮状态处理④⑤／升级叙事·硬性）权威=loop_machinery §5.3「变质判定·循环角色附加动作」——本节不复述。

### 1.2 八问自评（正向·按 1.1 权重作答）

此刻压住我的那几维答到底，其余各问一句带过——哪几维依 1.1 的**环境压力（含已经压上来的威胁）**＋人格动力层＋内在状态共同定：**有威胁压上来时，威胁维度必须答到底；无显著威胁时，主驱动回到欲望与核心诉求**（情境温和就不必把每轮都过成危机）。

八问：

1. 我现在想得到什么？
2. 什么正在阻碍我？
3. 什么正在威胁我？
4. 什么机会正在出现？
5. 我的核心诉求什么样算成、是否已达成？当前计划走到哪里？上轮未完成意图兑现了没有？失败后续是否要触发（判据＝上轮行动结果已满足其条件）？
6. 如果现在不行动会失去什么？
7. 我此刻最想做、也躲不掉的是哪一件？
8. 如果失败我下一步怎么办？

**第 3 问（什么正在威胁我）怎么答**：把压上来的威胁逐条用 1.1 的尺子称一遍——**它冲着我的哪一样（欲望／恐惧／底线／关系锚点）、来得有多快、有多准**，先答称出来最重的那一条，其余一句带过。

多数人最怕丢命，所以生存通常排在最前；**但这是"这个人的恐惧"称出来的结果，不是一条通用排序**——为名号赌一把、为一个人压上全部，都可能是他的第一名。**没有威胁压上来，这一问一句带过**，主驱动留在欲望与核心诉求。

### 1.3 候选行动生成（枚举库·正向·带价）

#### 枚举库（启发示例·非封闭枚举）

> 推进目标 / 执行计划 / 争夺资源 / 阻止对手 / 保护自己 / 改变关系 / 获取信息 / 隐藏信息 / 隐藏秘密 / 试探 / 操纵 / 施压 / 威胁 / 诱导 / 逃避 / 报复 / 升级冲突 / 改变策略 / 抓住机会 / 满足欲望 / 避免恐惧 / 防止目标失败

候选**带价出场**，每条写两样：**我能拿到什么**／**我要付出什么（下轮仍失）**——**没价的候选不进账**。

- 至少一条**取**（把我要的往前推一步）＋至少一条**守**（不让我要的掉下去）
- **「不动」同样是一条候选、同样记账**（它付的是：时间、别人替我动了、机会关掉）

### 1.4 定本轮行动（账本·取舍）

#### 账本（取舍＝驱动力合成·决策用量表——非 write_protocol 的批次账本/.ledger）

先看 1.1 判成立的**偏离条件／触发行为**——成立则本轮走该条的升级打法，账本按那种打法计价；不成立则按默认打法。

把 1.3 的候选逐条算两栏：**这一手让我拿到了多少我要的**／**要我付出什么、付出去的我还能不能拿回来**（拿不回来的，只为我肯为它付的人才值得付）。

- **计重来源** — 持续计划／核心目标／核心恐惧／未完成意图／上一行动结果／**旧记忆（同类旧经历的结果——我以前这么做过吗、后来怎样）**／目标受威胁程度（取 1.2 首位威胁对应者）／CT 压力（子 agent 路径＝感知增量中压上来的冲突·无 CT 直读）／机会窗口／对手行动／新信息／关系变化／情绪／时间压力／资源／事件线当前问题
- **无威胁压上来时**，主栏就是推进核心诉求与当前计划——欲望是默认驱动，威胁只在存在时占位
- 选「拿到最多、且我付得起」的那一手；可控性也在这里计（哪个我处理得了、不处理会丢什么）
- **「不动」同样在账上比**——它拿到了什么？付掉了什么？账上算不出收益的那一手，不选
- **信念在这杆秤上称**——1.1「人格动力」里的信念＝我如何解释世界，是本轮计价的标准。旧记忆压上来时，若按旧信念该选的那一手我这次选不出来（或反过来），那就是信念在变：它变了，账就跟着重算，这一轮的行动也就跟着变（变了 → 同批写 `信念演化`）。

#### 硬边界（生效时·不参与权衡）

**价值底线**（CHAR_.md 列出的触发行为成立时）与**关系锚点**（档案条件成立、所指之人当下在场上时）不作选项、不作筹码——一旦踩线，就按该角色档案的升级路径走，不是"权衡之后放弃"。

#### D3 长期计划巡检（判定型·稳定层·每轮逐条对账）

**决策问题**：`当前计划`/`核心诉求` 仍成立？
**缺省选项**：`仍成立`

**决策选项与选中标准**：`仍成立`＝逐条核销后无变更；`需重写`＝长期路线或 `核心诉求` 已变（调整/替换/放弃/重新规划）

**结果语义**：`仍成立` → 不动；`需重写` → 本批同批覆盖对应字段。本轮行动定下后，对照 1.2 第 5 问的答案——`核心诉求`（预期达成的状态·答「什么样算成」）与 `当前计划`（步骤链·答「怎么走到」）是跨轮慢变量。

**逐条核销（每轮硬动作·先于「仍成立」判定）**：`当前计划` 含事件/时刻类条目的，逐条对照场景时间线与本人记忆锚点——

- 该条对应的事件已在世界兑现 → **当批从计划中划除**（同批覆盖 `当前计划`·轨迹记 `计划变化: 调整——已兑现划除`）
- 未兑现 → 保留
- 条目与已发生事实对不上 → **以场景时间线为准改写**

原则：计划是前瞻文件，时间线是唯一事实源——世界替角色完成的那一步，不许再留在「接下来要做」里。

**默认「仍成立」→ 不动**：此时本轮要做的 ＝ 这条链上还没走的那一步——外部进来的事，先判它是否改变这条链：改才重写，不改就照旧走这一步（外部输入不进 `当前计划` 的源·判据见本文件「角色自治原则」）。

**长期路线或 `核心诉求` 已变**（路线被调整/替换/放弃/重新规划；`核心诉求` 已达成／已放弃／对象失效）→ 本批同批覆盖对应字段。

**判定为「要重写」时**，先在心声里把从 `核心诉求` 到步骤链的那一段走完——我要到的那个状态 → 从此刻到那里要过哪几道关口 → 先迈哪一步、后迈哪一步（`→` 串联·含未走步骤·写法锚定见 keys.md「CHAR_{name}_state.yaml」节 `当前计划`）；走完才落新值。

判定属 **Decide**，与「心声先于 ACTION」同约束——**判定未落，动作卡不得先出**。

**写法锚定**：`核心诉求` 写「什么样算成」的**预期达成的状态**——✅「验证访客的完美之下是否存在真实」；边界 ❌「带他走完园区→让他答应留下」（步骤链·归 `当前计划`）、❌「他待我如真实的人——这份相待成为不可撤销的事实」（已成立的定性·归 `记忆锚点`）。

### 1.5 行动实现

**首步·档案基准对照**：写动作前先读自身 `CHAR_.md` 档案基准（核心欲望/反应倾向/能力/行为下限），判定拟作动作是否达该角色"在此情境会做的最低可执行动作"。

**依据**：人格 / **认知上限**（循环角色·档位上限见 loop_machinery §2.3「常驻约束·行为档位上限」·非循环角色无此限）/ 叙事视角 / 感官锚点 / 动作习惯 / 语气 / 当前情绪 / 压力 / 防御状态 / 关系 / 空间 → 实现为：动作 / 台词 / 身体语言 / 情绪表现 / 空间互动 / 信息透露 / 信息隐藏 / 环境变化。

#### 反顺从四则（写行动前逐条执行）

1. **档案强度** — ≥ CHAR_.md 基准；**有威胁压在身上时，畏缩/服从/退避本就是档案基准的合法反应，不得因反顺从把它改写成逞强**；无威胁时的顺从才算默认 ＝ 重写
2. **抽象方显现** — 出手形态 ＋ 抵抗痕迹
3. **认知闸门** — 知识归属（该角色有认知来源才可用）
4. **硬边界复核** — 底线与关系锚点所指的人（见 1.4「硬边界」）；此处只核对拟作动作没有把它们当成筹码

#### 相称自查

表现、台词与**心声的长度**都须与 1.2 的**首位威胁**相称——持械现场的闲谈、危机里的抒情、刀架在脖子上还在心里写五百字 ＝ 不合相称，重写。

#### 行动卡格式

（audit 机械检查·每行动一行——**必含三件套 驱动/情绪/强度**；`代价` 为有条件槽·见下）

```
###ACTION: {角色}: {一系列连续可观察表现+空间位置} | 驱动: {内部动机} | 情绪: {主导情绪} | 强度: {1-10} | 代价: {某}失{可核验变化}/{某}失{可核验变化} | 耗时: {分钟}
```

#### 表现密度标准

- 表现必须具体、连续、可观察、可呈现；每个子动作写清表现发生了什么，以及必要的对象、空间关系或终止状态；多个子动作前后衔接，形成完整连续的行动过程
- ACTION 卡是一次广义行动的完整表现；有触发事件时，首个子动作体现角色对该事件的即时反应
- 可使用动作、表情、眼神、姿态、手势、声音、台词、沉默、呼吸、节奏、空间、环境、物件等表现方式；仅写对当前行动有意义的内容，选用与该角色档案及当下状态吻合的方式承载
- 情绪通过声音、表情、动作、节奏、身体状态呈现；半抽象情绪描述进一步落为具体表现（如"发烫"→ 目光停住、呼吸变深、声音放低、手指收紧）

#### 台词与信息

- **台词** — 开口时写明对谁、说什么、希望对方听到或理解什么；用他日常会用的词，意思在句子里说完
- **信息** — 涉及信息时，明确角色获得、透露、隐瞒、询问、确认或回避的信息
- **潜台词** — 用外化呈现：嘴上说 A，但通过表情、眼神、动作等表现出 B
- 先识别本轮要推进的欲望、关系、信息或冲突，再为每项关键内容找到承载它的具体表现

#### 三处落点的分工（硬性·防双写漂移）

- `###ACTION:` 卡 ＝ **原文唯一面**——密度标准只对这一面强制，表现与台词写全，⑥作家据此写进正文
- `decision.当前行动` ＝ 一句要点（本轮做了什么·保留对象与终止态）
- `连续行动轨迹.行动` ＝ 角色自用摘要（自己看得懂即可·不要求与卡片同长）

同一事实·不同刻度——**不双写全文**。

#### 驱动（audit 硬检）

一句话，取自 `###MUSE` 段落③定打法里的「为什么／为什么是现在」——与心声一致，不另起一套动机；完整推演在 `###MUSE`，此处只留可机械核对的一行。

#### 戏剧意图 → 表现承载（示例）

- "让他知道选对了" → 正面迎住目光、停下、靠近、说出选的是他（不写"确认他选对了"）
- "不想把被珍视演成迎接" → 笑意先起又收住、无客套、停顿后认真看他（不写"不再表演"）
- "想要朝他去" → 身体朝向他、缩短距离、说出选择、主动牵住（不写"透露想要"）

✅ 正例：`她听见门外的脚步声，手从门把上慢慢收回→侧身贴墙站定，屏住呼吸→脚步停在门外，她低声说："我知道你在。"，却没有开门→视线落向桌上的刀，手指轻轻碰上刀柄。`

❌ 反例：`站定→回扣手→牵他朝主街迈半步→开口选第一站`（"选第一站"无选什么、无要对方听到什么）

#### 行动代价（有条件必填）

**触发条件** — 当且仅当本角色被 `direction.调度单` 列为焦内活跃 且 关联CT∈①推进池 且 该CT.施压方向∈四爆破（死局两难/防御踩爆/关系爆破/不可逆代价），或 当前拍戏剧问题∈资源/关系/控制权/认知类可回答问题时，必填 `代价`。

**豁免** — 其余过渡/寒暄/轻量刷新（audit 检查）。判据所需的 调度单/推进池/施压方向 为引擎面——子 agent 按账本有价即填·必填性由主 agent 收口核验 ＋ audit 检查。

**格式** — `代价:` **引用账本里已定的那一笔**——填 `谁失何物（下轮仍失）`，格式 `A失B`，B 为可核验物：资源/载体状态/关系档位/控制权/身体边界（正向枚举 5 项）。观感类（距离感/匿名度/气氛）不算代价；账本未计价的（过渡/寒暄/轻量刷新）不填。

#### 代价-动作正向速查（每条 ACTION 必选一项）

| 可核验物 | 代价示例（下轮仍失） | 实质动作示例（转折性） |
|---|---|---|
| 资源 | 施压者失"可不担后果的挑衅"（已上手） | 抓住对方小臂/衣料拉拽半步 |
| 关系 | 被压者失"可作无事的中立"（已明示选边求助） | 转身抓住求助对象手腕＋出声求助 |
| 控制权 | 守护者失"可不拔的克制"（枪/械已出套指向） | 拔出武器指向施压者＋喝止 |
| 边界 | 秩序者失"口头缓冲"（已拔械截停） | 拔械横亘两人之间 |
| 载体 | 旁观者失"可静默的旁观位"（已介入带离） | 抬手格挡＋半步带被压者退离 |

## 写入（CHAR_state 唯一写者·角色意志的体现）

**写前读 keys.md「CHAR_{name}_state.yaml」节**——键表/值域/写语义在彼；批次与写入通道以 references/write_protocol.md 为权威；本节只列动作与触发。

### 必写项（非决策·结构化必含）

- **decision**（KEY 点路径逐层写）— 首次物化一并写核心诉求/当前计划/当前行动/行动驱动/行动对象/行动窗口/失败后续/未完成意图；已物化的焦内活跃者每轮更新运行层六项。稳定层（`核心诉求`／`当前计划`）的语义与值域见 keys.md「CHAR_{name}_state.yaml」节。按既定路线走完一步/进入下一环节 → 保留；被调整/替换/放弃/重新规划（含首次具体化）→ 本轮同批覆盖——**覆盖源＝D3「长期计划巡检」的判定**（角色自己的判断·不由轨迹标签驱动）
- **连续行动轨迹**（APPEND·结构化七子字段）— 轮次/行动/行动目的/行动结果/他人反应/计划变化/未完成意图——角色自己的时间线·近 10 轮滚动（APPEND 后脚本自动删最旧·LLM 零操作）；同轮多环 ＝ 每环一条·按序追加（同轮次多条合法）
  - **`计划变化` 判据**（先看是否覆盖了 `decision.当前计划`）— 覆盖了 → 记 `调整——客观概括`；未覆盖且按原路线走一步 → `推进`；都没动 → `无`
  - **值域三档** — `无`（计划未变）/ `推进`（计划本身没变·仅按计划走一步或进入下一环节）/ `调整——客观概括`（计划被调整/替换/放弃/重新规划）
  - **本字段＝本轮记录**（跟着 D3 巡检结论走·不驱动覆盖）
  - gate actor 双向一致性核对：记 `调整` 却未覆盖、或本轮有轨迹却覆盖而未记 `调整` ＝ 拦

### D4 状态写入判定（判定型·逐字段·每轮必过）

**决策问题**：逐字段本轮是否写？
**缺省选项**：`不写`

**决策选项与选中标准**（逐字段各判一次·缺省＝不写）：

| 字段 | `写` 的判据 | 写语义 |
|---|---|---|
| `记忆锚点` | 高刺激事件（情绪剧变/利益损益/关系转折/威胁承诺/命名直觉）且角色会记住 | **记下来**（见下）——并句时 `###KEY:` 覆盖全量·记本条 `###APPEND:` |
| `信念演化` | 1.4 账上称出的信念转变／变质判定留痕 | APPEND |
| `人际动态` | 关系实质变化（关系提炼） | KEY 覆盖全貌 |
| `妆扮` | 本轮有容貌/发型/妆容变化 | KEY 覆盖 |
| `服饰` | 本轮有穿脱/损坏变化 | KEY 覆盖·全量重写 |
| `随身物品` | 本轮有持有物取得/交出/遗失/易主 | KEY 覆盖·全量重写 |
| `位置`/`核心状态`/`情绪`/`健康`/`已知地点`/`名字` | 状态质变／首次到达·被告知·目睹／身份质变（细则见 keys.md） | KEY 覆盖 / APPEND |

#### `记忆锚点` 记下来（把思考里已经发生的事落到纸上——记忆与信念是角色自己的）

**锚点须自足**：实体（原话/动作）留在事实段，定性从事实段直接读出——读完本条目即懂，不回查其他条目。

- ✅ `他收枪道歉·归还评估说「我真正关心的是：你的真实，真实的你」·相称握手·邀我同行 ➔ 他待我如人而非服务——真心一次比一次更近`
- ❌ `相称握手·邀我同行 ➔ 真心三步走完——从桌面到掌心再到去处`（「桌面」在事实段无实体·「三步」不回查被删条目就读不出）

思考里已经发生过的事，这一节只负责落下来（没发生就不写）：

1. **并成一句** — 1.1 想起的那几条同类旧记忆，若在思考里已经并成了一句 → `###KEY: 记忆锚点` 覆盖为合并后的完整列表（其他对象的条目照旧保留），再记下这一件
2. **认下道理**（信念提炼）— 1.4 账上称出的那条新道理（旧信念称不动这一手的地方）→ 同批 `###APPEND: 信念演化`（`触发事件`＋`旧信念→新信念`·只提炼不升级）
3. **改看他的眼光**（关系提炼）— 这个人让我对他的看法变了 → 覆盖 `###KEY: 人际动态`
4. **记下这一件** — `###APPEND: 记忆锚点`·完整自然句（见 keys.md「记录字段写法」）

示例：角色已有「他让着她」「他记得她忌口」两条同类锚点，本轮又记下「他把伞塞给了她」→ 思考时她意识到「他一次次照顾到她的细微处」是一件事、不是三件 → 并成一句（`###KEY: 记忆锚点` 覆盖为「概括：他一次次照顾到她的细微处 ➔ …」＋ 本条）；账上旧信念「被人照顾意味着欠了债要还」称不动这一手 → 同批追加 `###APPEND: 信念演化`：「旧信念→新信念：被人照顾意味着欠了债要还 → 有人照顾她只是因为愿意」。

#### `妆扮` / `服饰` 显式变化检查（每轮必过·D4 行）

本轮是否有穿脱/妆容变化？有 → 全量重写（写前 read 旧值）；无 → 不写。若字段为空但 CHAR_.md 外在特征有基线描述 → 视为待填充，本轮同批写入基线。

#### `随身物品` 显式变化检查（每轮必过·D4 行）

本轮是否有可转移重要持有物的取得/交出/遗失/易主（含卡/票据/钥匙/武器/弹药/道具/信件/契约等，代管/折叠持有亦算）？有 → 全量重写（写前 read 旧值，须与记忆锚点同步易主双方）；无 → 不写。

`ACTION` 含 `接过/递出/握起/装入/收入/捡起/交出/夹带/折叠持有` 即视为取得，需同步检查。

#### `压力水平` / `防御有效性`（判据=D1）

`有变化` → 同批 KEY 覆盖新值（多源综合·偏离刺痛/关系事件/存在性冲击均计源）；`无变化` → 不写。**变化轮必须写·不写＝状态与叙事脱节**。

子 agent 路径旧值随 CHAR_state 内联（subagent_prompt.md「自体内在状态」行）·两路径同规。

### 升档批落盘（收口核验·主 agent·判定已前移 1.1 D2）

判定归角色（决策环 1.1·D2 随 D1 自查·触发环的心声与行动即升级时刻）；本节只承载升档批的落盘顺序与收口核验：

**收口核验（主 agent·机械）**：核对 CHAR_state 压力水平／防御有效性 达门槛（临界＋已彻底崩解）→ **自主性升档 KEY 由主 agent 收口补写**（档位枚举不入子 agent·防元档位泄露）·单窗口路径主 agent 直写。

#### 写入顺序（硬性）

`压力/防御 → 自主性 → 信念演化 → 压力回落`

1. **压力/防御** 排最前——门槛按升档写入前的状态核验（脚本硬检·未达门槛拦下升档）
2. **自主性** 升一档（脚本→漂移→觉醒→变质·每次极端冲击只升一级）
3. **信念演化** 留痕（变质级转变）
4. **压力回落** 排最后——回落至世界当前水平（④按其余压力来源估定·非清零）·防御保持崩解

### D5 防御重构（判定型·三条件核验·角色自查）

**决策问题**：三条件齐备？
**缺省选项**：`不重构`

**决策选项与选中标准**:
- `重构` — 威胁源解除 ∧ 支持性关系介入 ∧ 信念重构（三条件齐备）
- `不重构` — 任一缺

**条件判据**:
- **威胁源解除** — 角色体验判据 ＝ 压在我身上的威胁在我感知里退去；主 agent 路径等价判据 ＝ 推进池中本角色关联 CT 已收束或紧迫度降至 🟢 以下
- **支持性关系介入** — 人际动态有支持性角色实质行动
- **信念重构** — 信念演化出现旧信念→新信念条目

**结果语义**：`重构` → 本批执行（防御形态/崩溃表现覆盖写 ＋ 防御有效性升一档）。keys.md「防御有效性」

```
###STAGE: 角色
```

#### 跨角色槽位归主 agent 收口（子 agent 路径）

`###SCHEDULE` 的行动链顺序/受影响与 `###META:` 绑定声明属跨角色编排面——子 agent 只产本角色的 MUSE/ACTION 与写入 op，缺项由主 agent 收口时规整补全（phase_actor「主 agent 收口」）。

### `###MUSE:`

每环一行·排在各自 `###ACTION:` 之前——以角色第一人称呈现当前正在发生的真实思考过程。

- **格式与位置** — 括号包裹·第一人称「我」·不入正文（原文随批次落私有账本·创作不读·见 write_protocol.md「批次原文账本」）
- **多环** — 同一角色同窗口多环 ＝ 多组 MUSE/ACTION·按发生顺序排列（MUSE₁ ACTION₁ MUSE₂ …）
- **decision 运行层以末环为准**；`连续行动轨迹` **每环一条**（同轮次多条合法·按序 APPEND）

### META 记忆标记（脚本硬性·逐角色全列）

凡本批写了 CHAR_state 的角色（含焦内与焦外轻量刷新）在**同一 META 行内空格分隔**逐角色列出 `记忆✓ {角色}:{计数}·{已触发|未达}`：

- `计数` ＝ 本轮新写的记忆锚点条数（`0` ＝ 未写）·`已触发` ＝ 写入了记忆锚点·`未达` ＝ 未到记忆写入阈值（写前自查没过）
- 角色名含空格用下划线代空格（如 `Clementine_Pennyfeather`）·**缺一被 gate 拦**
- 示例：`记忆✓ Guest:0·未达`（本轮未触发）／`记忆✓ Dolores:2·已触发`（写了 2 条锚点）／`记忆✓ Guest:0·未达 Angela:2·已触发 Maeve_Millay:0·未达`（多角色同行空格分隔）

### META 绑定声明（脚本硬性·逐行动角色全列）

各行动角色的绑定声明合写于一条 `绑定:` META·逗号分隔（多人一行）：`绑定: {角色}={子agent(组装✓)|单窗口(豁免原因)},…`

- **缺声明，或裸 `单窗口` 无豁免原因 → gate 拦截**
- 非 POV 角色标 `单窗口(原因)` 须命中豁免白名单**字面**（`子agent不可用`／`工具不存在`〔须有本会话派发报错为据〕／`宿主不可续话`〔宿主不支持具名子 agent 续话·据＝绑定声明〕），否则 gate 硬拦——「在轨轻量/背景位/主agent直演」等自编理由 ＝ 硬拦；白名单字面通过者仍待 A9 审计复核
- **子 agent 绑定须带组装自查标记 `子agent(组装✓)`**——派发前按 references/subagent_prompt.md「派发自查」逐项核对，缺标记 ＝ gate 拦截
- 示例：`绑定: Guest=单窗口(第二人称POV·用户指令转写),Angela=子agent(组装✓)`
