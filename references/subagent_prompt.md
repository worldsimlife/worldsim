# 子 agent 派发骨架（阶段④·角色决策委派）

> 用途：④角色把非第一/第二人称 POV 角色的决策环委派给具名子 agent 时，prompt 按本骨架逐槽填入。
> **一次派发建立该角色的具名会话；窗口内每环向同一会话追加「感知增量 ＋ 本人上一环终止态」**——会话里已有人格、记忆与前几环的经过，后续环不重述。
> **通道口径：世界素材一律由主 agent 逐字原文内联（组装通道）**——只做「选哪段／剔哪段」，禁止转述摘要；仅过程规则（actor_decision.md）走路径自读。命运层／默认循环时间线／引擎面字段按下方「组装转换矩阵」裁剪或转换为该档位可知形式——档位语义以 loop_machinery §2.3 为唯一权威，本文件只写怎么转。产出格式＝actor_decision「批次格式」。

## 一、首环派发（建立会话·素材全量）

> **组装转换矩阵（素材 × 自主性档位·触发条件＝素材类型 × 档位 × 特殊状态〔偏离在场→行为按偏离模型限幅·伴随第一人称刺痛自察〕）：**

| 素材 | 脚本 | 漂移 | 觉醒/变质 |
|---|---|---|---|
| 默认循环时间线 | 不注原文·转写为第一人称当前计划（角色不知来源） | 同脚本＋决策环自生碎片级裂缝（不注原文） | 注入原文·当前计划仍转写 |
| 命运层 | 全档位不注入（显影只经作家层档案裂缝规则·不进决策输入） | 同左 | 同左 |
| 元档位/引擎簿记（自主性/偏离登记/维护名单/压力评估结论） | 全档位剔除（自主性入内＝向未觉醒档位泄露元档位；偏离刺痛以第一人称体验形式随「偏离在场」转换进入） | 同左 | 同左 |
| 自体内在状态（压力水平/防御有效性/防御形态/崩溃表现/健康） | 全档位原文内联——第一人称可知·**D1** 内在状态评估/**D2** 变质门槛/**D5** 防御重构自查的判定输入 | 同左 | 同左 |
| 自体可见状态（位置/妆扮/服饰/随身物品/已知地点） | 全档位原文内联——**D5**「写前读旧值」基底 | 同左 | 同左 |
| 主观态字段（核心状态/情绪/decision/连续行动轨迹/记忆锚点/信念演化/人际动态） | 全档位原文内联 | 同左 | 同左 |
| 场景五节＋相关时间线条目＋指涉历史原文 | 全档位原文内联·按该角色**在场与感知范围**过滤（不在场的事不进） | 同左 | 同左 |

> **指涉历史判据（硬性）：** 本轮对话/行动**指涉历史事件或历史台词**时，该事件的权威原文（场景时间线相应条目）必须随批注入【我所在之处】——不给解读，解读归属角色。

> **POV 用户角色输入口径（硬性·第二人称）：** 该角色的行动**由用户输入给出**——凡涉及它的槽**只填用户本轮输入的原文**（原话／明示行动），**用户未给出的部分一律不填**：**不得补写其动作、表情、注视、沉默、心理**（「他一动不动」「他任我」「他迈了半步」「他眼底掠过」＝代写·禁止）。用户给出的**授权**（如「接受全套服务」）＝其本轮行动的全部内容，角色据此**可自主推进多环**——**授权不等于允许主 agent 替该角色补反应**。角色对该角色的感知**只有两个来源**：用户输入原文 ＋ 其既有状态中未变的部分（他仍在那儿）。**判据：写「他站在那儿」＝观察（可）；写「他一动不动」＝替其断言行为（禁）。**


## 二、后续环追加（同一会话·只加增量）

```
【刚刚发生的变化】
- 时间推进到：{…}
- 我上一环已经做过的、做到哪里（原文＋终止态）：{本轮我自己已落地的 ###ACTION 与它停在哪一步·我站在哪·手上有什么}
- 新落地的、我能看见听见感觉到的行动·台词·情绪（原文）：{其他角色已落盘 ###ACTION 卡原文（含 情绪: 字段）·经可见性过滤}
- 新出现的变化：{…}
- 偏离刺痛（条件槽·仅当主 agent 按 O4 偏离判定判我偏离/累积偏离时填·否则省略·本会话已给过且体验无变化不重附）：{同首环该槽——第一人称异常体验·按自主性档位·不注来源}
- 细看所见（仅当我上一环含打量/端详/注视/细看等感知动作时填·未细看则省略·本会话已给过且对象外观无变化不重附）：{感知对象的可见细节·一小段≤120字·取值来源同首环该槽}

【接着走下一环】
按同一决策环接着走下一环：从我现在停的地方重新看清 → 想清楚 → 拿定主意 → 做出来（上一环我做过的事照旧算数）。
我的人格、记忆与前几环的经过都在本会话里。
```

> **指涉历史（续环同规）：** 新落地的台词/行动指涉历史事件或历史台词时，主 agent 在本段末附该事件权威原文（场景时间线相应条目·逐字）——不给解读，解读归属角色。

> **续环同规（POV 用户角色·硬性）：** 后续环**同样只追加用户本轮输入的原文**；用户未给的部分不填、**不补写其反应**——由角色自己判断。她可以按已获授权继续推进，但**不得以「他如何反应」为前提**（授权 ≠ 反应）。

## 三、派发自查（组装✓）

派发前逐槽对照，确认每一行都在写这个槽的使命、且取自本槽标注的取值来源：

| 槽 | 这一行的使命 | 取值来源 |
|---|---|---|
| 【我的档案与记忆】 | 逐字内联·按骨架【我的档案与记忆】槽清单与组装转换矩阵处理（循环时间线按档位转写） | CHAR_{名}.md（内联清单＝本骨架该槽·**外在特征·整体形象＋外貌须内联**·对应 CHAR_state 妆扮/服饰/健康 的档案基线）＋ CHAR_{名}_state.yaml（矩阵：本文件§一·档位语义：loop_machinery §2.3） |
| 【我所在之处】 | 场景五节＋相关时间线条目·按我感知范围过滤·指涉历史附权威原文 | scene_state 五节＋场景时间线相关条目（逐字） |
| 【我此刻看得见、听得到的】 | 我当场看得见听见感觉到的东西（含我自己刚做过的事） | 骨架各槽后标注的字段 |
| 【偏离刺痛】（条件槽） | 我身体里此刻的异常体验（第一人称·不知来源） | 主 agent 的 O4 偏离判定结果（phase_actor 职责4）＋ loop_machinery §3 强度公式按自主性档位 |
| 【细看所见】（条件槽） | 我主动细看过谁/什么·所见细节 | 本人上一落盘行动含感知动作 → 角色对象=其 CHAR_.md「外在特征」＋CHAR_state 可见层派生·物件对象=道具表/关键场景信息 |
| 【刚刚发生的变化】（后续环） | 我当场新看到的 ＋ 我自己上一环停在哪 | 骨架各槽后标注的字段 |
| 【我的认知边界】 | 我能想到什么程度（循环角色必填） | loop_machinery §2.3 该自主性档位的行为与认知上限原文 |
| 【怎么想、怎么写】 | 塑形来源（腔调与思维形状从哪来） | CHAR_{名}.md 人格内核八变量 ＋ 语气特征／能力 ＋ CHAR_state 当下状态 |
| 【产出格式】 | 字段清单与格式来源 | actor_decision.md 批次格式节 |

角色的内心体验、对事件的解读、情绪反应、本轮的行动结论、稳定层的巡检结论——这五样归属角色的 1.1–1.5，由角色自己生成。

**POV 用户角色自查（硬性）：** 凡涉及第二人称 POV 用户角色的行，逐行问「**这是用户输入原文吗？**」——不是 → 删（判据见上方「POV 用户角色输入口径」）。

各槽对照通过 → 带 `子agent(组装✓)` 标记。后续环只追加「刚刚发生的变化」段。
