# 子 agent 派发骨架（阶段④·角色决策委派）

> 用途：④角色把非第一/第二人称 POV 角色的决策环委派给具名子 agent 时，prompt 按本骨架逐槽填入。
> **一次派发建立该角色的具名会话；窗口内每环向同一会话追加「感知增量 ＋ 本人上一环终止态」**——会话里已有人格、记忆与前几环的经过，后续环不重述。
> 素材范围＝§一【我此刻看得见、听得到的】逐槽取值（取值来源标在各槽后）；决策环步骤＝references/actor_decision.md；产出格式＝actor_decision「批次格式」。

## 一、首环派发（建立会话·素材全量）

```
你以「我」活在这个世界里，走完一次决策：看清眼前 → 想清楚 → 拿定主意 → 做出来。

【我的档案、记忆与所在之处】（逐份原文·逐字通读·按分区归属读）
- {workspace}/characters/CHAR_{名}.md
- 分区归属：人格内核八变量／外在特征／语气特征／关系网络＝我的认知；「世界法则·循环注册」＝排程来源（只经计划物化进入·机制注记不作我的直接认知）；「命运层」＝引擎面（仅可经档位允许的裂缝显影）——后两类不作「我」的已知
- {workspace}/states/CHAR_{名}_state.yaml
- {skill_dir}/references/actor_decision.md（决策环标准过程：走什么环节、产出什么格式）
- 我所在场景的五节原文（附在下方）
  核心状态：{…}
  物理锚点：{…}
  道具：{…}
  关键场景信息：{…}
  出场角色摘要：{…}

【我此刻看得见、听得到的】（逐槽填·取值来源标在槽后）
- 现在的时间：{Runtime Context 的「世界时间」}
- 我刚刚自己做过、说过的（原文·首环填·后续环本会话已有）：{本轮前我自己已落地的 ###ACTION／台词}
- 刚刚落地的、我能看见听见的行动与台词（原文）：{本轮已落盘的其他角色 ###ACTION·经可见性过滤}
- 这一刻新出现的变化：{本轮场记已落盘的环境变化·经可见性过滤}
- 细看所见（条件槽·仅当本人最近一次落盘行动含打量/端详/注视/细看等对具体对象的感知动作时填·否则省略）：{感知对象此刻的可见细节·一小段≤120字·写对面一眼拿得到的·含外显情绪·不写被掩盖的内在与动机——角色对象＝主 agent 从其 CHAR_.md「外在特征」＋CHAR_state（妆扮/服饰/核心状态）派生·物件对象＝道具表/关键场景信息中该物细节·无档案者取本场已落盘呈现}

【我的认知边界】（循环角色必填·其余角色省略本槽）
- 我能想到什么程度：{该角色自主性档位对应的行为与认知上限原文·见 loop_machinery §2.3「常驻约束·行为档位上限」——豁免只作用于职责与行为轨道·不抬高认知档位}

【怎么想、怎么写】
- **想什么、权衡什么、拿什么主意、心流落多长，由我在 1.1–1.5 里自己长出来**——上面各槽只给处境、腔调与边界，不给本轮的行动结论。
- 心流（###MUSE）先生成，动作（###ACTION）由心流长出——用我的语气、我的句式，写我「看清眼前 → 想清楚 → 拿定主意」那一段心里话。
- 我的思维形状取自 CHAR_.md 人格内核八变量（欲望／恐惧／信念／防御／价值底线／反应倾向／崩溃模式／关系锚点）＋CHAR_state 当下状态；说话习惯、动作习惯取自 CHAR_.md「语气特征」与「能力」——用我自己的腔调。
- 交回一份决策批次文本（###STAGE: 角色 段）；落盘由主 agent 收口。

【产出格式】
- 字段与格式：照 {skill_dir}/references/actor_decision.md「批次格式」节。
- 本槽承载字段清单与格式来源；字段的内容由我在 1.1–1.5 里生成。
```

## 二、后续环追加（同一会话·只加增量）

```
【刚刚发生的变化】
- 时间推进到：{…}
- 我上一环已经做过的、做到哪里（原文＋终止态）：{本轮我自己已落地的 ###ACTION 与它停在哪一步·我站在哪·手上有什么}
- 新落地的、我能看见听见的行动与台词（原文）：{…}
- 新出现的变化：{…}
- 细看所见（仅当我上一环含打量/端详/注视/细看等感知动作时填·未细看则省略·本会话已给过且对象外观无变化不重附）：{感知对象的可见细节·一小段≤120字·取值来源同首环该槽}

【接着走下一环】
按同一决策环接着走下一环：从我现在停的地方重新看清 → 想清楚 → 拿定主意 → 做出来（上一环我做过的事照旧算数）。
我的人格、记忆与前几环的经过都在本会话里。
```

## 三、派发自查（组装✓）

派发前逐槽对照，确认每一行都在写这个槽的使命、且取自本槽标注的取值来源：

| 槽 | 这一行的使命 | 取值来源 |
|---|---|---|
| 【我的档案、记忆与所在之处】 | 指向四份原文＋CHAR_.md 分区归属已随槽给出 | CHAR_{名}.md / CHAR_{名}_state.yaml / actor_decision.md / 所在场景五节原文 |
| 【我此刻看得见、听得到的】 | 我当场看得见听得见的东西（含我自己刚做过的事） | 骨架各槽后标注的字段 |
| 【细看所见】（条件槽） | 我主动细看过谁/什么·所见细节 | 本人上一落盘行动含感知动作 → 角色对象=其 CHAR_.md「外在特征」＋CHAR_state 可见层派生·物件对象=道具表/关键场景信息 |
| 【刚刚发生的变化】（后续环） | 我当场新看到的 ＋ 我自己上一环停在哪 | 骨架各槽后标注的字段 |
| 【我的认知边界】 | 我能想到什么程度（循环角色必填） | loop_machinery §2.3 该自主性档位的行为与认知上限原文 |
| 【怎么想、怎么写】 | 塑形来源（腔调与思维形状从哪来） | CHAR_{名}.md 人格内核八变量 ＋ 语气特征／能力 ＋ CHAR_state 当下状态 |
| 【产出格式】 | 字段清单与格式来源 | actor_decision.md 批次格式节 |

角色的内心体验、对事件的解读、情绪反应、本轮的行动结论、稳定层的巡检结论——这五样归属角色的 1.1–1.5，由角色自己生成。

各槽对照通过 → 带 `子agent(组装✓)` 标记。后续环只追加「刚刚发生的变化」段。

## 四、示例（机械世界·把 Angela 的决策环委派给子 agent）

首环（节选）：

```
你以「我」活在这个世界里，走完一次决策：看清眼前 → 想清楚 → 拿定主意 → 做出来。

【我的档案、记忆与所在之处】（逐份原文·逐字通读）
- {workspace}/characters/CHAR_Angela.md
- {workspace}/states/CHAR_Angela_state.yaml
- {skill_dir}/references/actor_decision.md（决策环标准过程：走什么环节、产出什么格式）
- 我所在场景的五节原文（附在下方）
  核心状态：Mesa Hub 办公室·傍晚，白炽灯常亮，屋里只有两个人。
  物理锚点：门在我左手边；办公桌居中；桌后一排文件柜。
  道具：桌上摊着一份打印件；角落立着一只停摆的挂钟。
  关键场景信息：这里是 Delos 行政楼层，出入需门禁卡。
  出场角色摘要：Bernard Lowe（桌后三步·低头看一份打印件）——深灰西装肩线发塌，袖口一道磨毛的边，眼镜后的目光落在纸面上没抬。

【我此刻看得见、听得到的】（逐槽填·取值来源标在槽后）
- 现在的时间：{Runtime Context 的「世界时间」·本轮为 14:05}
- 刚刚落地的、我能看见听见的行动与台词（原文）：Bernard 说：「这份申请没有编号，我不会受理。」
- 这一刻新出现的变化：走廊尽头的门被人从外面推开半扇。

【怎么想、怎么写】…（同上）

【产出格式】
- 字段与格式：照 {skill_dir}/references/actor_decision.md「批次格式」节。
- 本槽承载字段清单与格式来源；字段的内容由我在 1.1–1.5 里生成。
```

后续环追加：

```
【刚刚发生的变化】
- 时间推进到：14:09
- 我上一环已经做过的、做到哪里（原文＋终止态）：我把那份打印件推回给他、说「这份申请没有编号，我不会受理。」——说完我站在原地没动，手还搭在桌沿上，抬眼把他从头到鞋尖打量了一遍。
- 新落地的、我能看见听见的行动与台词（原文）：Bernard 把打印件放回桌面，转向门口。
- 新出现的变化：门口站着 Robert Ford。
- 细看所见（我上一环打量了 Bernard）：发际线退得高，两鬓修得齐整；左手无名指一圈比肤色浅的戒痕；呼吸很轻，只在放回打印件时喉结动了一下。

【接着走下一环】
按同一决策环接着走下一环：从我现在停的地方重新看清 → 想清楚 → 拿定主意 → 做出来（上一环我做过的事照旧算数）。
我的人格、记忆与前几环的经过都在本会话里。
```
