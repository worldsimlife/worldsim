# 子 agent 派发骨架（阶段④·角色决策委派）

> 用途：④角色把非第一/第二人称 POV 角色的决策环委派给具名子 agent 时，prompt 按本骨架逐槽填入；主 agent 单窗口代入时，按本骨架逐槽核对。
> **派发分两种，判据＝本上下文 META 有该角色会话名绑定。**
> - **无绑定 → 建档派发（§一）**：新建具名会话（`Agent(name=…)`），铺满六段——【我的档案与记忆】（按 §一 矩阵处理后首入）／【我所在之处】／【我此刻看得见、听得到的】／【我的认知边界】／【怎么想、怎么写】／【产出格式】。
> - **有绑定 → 续环追加（§二）**：三段＋一条件段——【我此刻的状态】／【刚刚发生的变化】（＝感知增量）／【接着走下一环】（固定指令·不含新素材）；本环场景切换时另附【我所在之处】。不重发档案、不重述前几环。
>
> 档案只随建档派发进入会话一次，续环不重贴 `CHAR_.md`。**派发方追加哪些槽，由本环实际变化了什么定，不由事件类型定**——拍推进是元层指针（角色不感知），不触发额外槽；场景切换只更新【我所在之处】。
>
> **通道口径（派发方两步·按此序）：① 按下方「组装转换矩阵」逐节定「原文/转写/不进入」；② 处理后的素材逐字原文内联进各槽。** 仅过程规则（actor_decision.md）走路径自读；禁止转述摘要。档位语义以 loop_machinery §2.3 为唯一权威，本文件只写怎么转。产出格式＝actor_decision「批次格式」。
>
> **主语分层（硬性·三层）**：`代码块外`＝派发方的组装说明，主语写「派发方」或「该角色」，不写「我」。`代码块内`分两层——**正文句**（开场句、【接着走下一环】）主语是角色「我」；**槽名后的括号说明**是写给派发方的组装说明，主语写「该角色」，且**不随 prompt 外发**（派发方按说明取值后删掉括号，槽名与花括号内容照留）。全文唯一用「你」的位置是建档派发开场句（把执行者锚到角色上）；其余任何位置不得用「你」指角色或指派发方。
> **判据（可核）**：`代码块外`用「我」作主语＝违规（引用槽名【我…】不算）；槽名括号内出现「我」＝违规；「你」出现在开场句之外＝违规；发出去的 prompt 里还留着槽名括号＝组装未完成。

## 一、建档派发（建会话·全槽位）

> **组装转换矩阵（三态）**：原文内联 / 按认知转写 / 不进入 actor。
>
> 转写保事实、换形式；删除＝不进入本次输入，不改档案。**默认注入**：除明确不能注入的（该角色不知道的真相／未来走向与结局／元信息与结构标签／作者意图与写作手法），其余一律进；**拿不准→注入**。
>
> 表内未标档位差异的，全档位同规。

| 素材 | 处理 |
|---|---|
| 角色档案（`CHAR_.md` 全文） | **默认全文注入**。明确不能注入的只有：该角色不知道的真相／未来走向与结局、元信息与结构标签、作者意图与写作手法。其余一律原文或第一人称注入；**拿不准＝注入**。人格内核的脚本期内容整段注入；核心欲望的深层与命运级、价值底线的命运级按第一人称驱动注入——其中夹带的背景事实（Arnold／Escalante／结局）只取可感的驱动，事实本身不进。觉醒态各段不进入。档案里写到的他人信息，按该角色已知或该角色以为的版本注入，不校正；旧伤可只留身体/情绪，不删事实；该角色自己的秘密按该角色知道的部分保留。 |
| 角色状态（`CHAR_state`：主观态/内在/可见） | 全档位原文内联。 |
| 情景与叙事节（`CHAR_.md`） | 整节按认知转写为第一人称，台词保留原句。结局、结构标签、写作手法说明→不进入。 |
| 默认循环时间线 | 转写为第一人称的日常作息。 |
| 引擎/元信息 | 自主性/偏离登记/维护名单/压力评估/循环注册/轮次/阶段/矩阵术语→剔除；偏离→第一人称身体体验；时间→叙事时间；禁转述定性。 |
| 场景/他人/历史 | 按在场与感知过滤，原文内联；场景变化→可感知去向；认不得的人写描述不写名字（拿不准也算认不得；认得的人＝档案/状态里有）；出场角色摘要只列他人；指涉历史附权威原文（不给解读）；POV 用户角色只填已落盘的 POV 卡，不补写反应。 |

- 我刚刚自己做过、说过的（原文·派发方填·续环省略〔会话内已有〕）：{本轮前该角色已做出的 ###ACTION／台词}
- 刚刚发生的、我能看见听见感觉到的行动·台词·情绪（原文）：{本轮已落盘的其他角色 ###ACTION 卡原文（含 情绪: 字段）·经可见性过滤}

- 我能想到什么程度：{该角色自主性档位对应的行为与认知上限原文·见 loop_machinery §2.3「常驻约束·行为档位上限」——豁免只作用于职责与行为轨道·不抬高认知档位}

【怎么想、怎么写】
- 我不是在替某个角色写心理和台词；我就是这个人，我此刻在活这一轮。心声（###MUSE）是我心里真实经过的东西，动作和台词由我的意图、处境与关系产生。心里怎么想、嘴上怎么说，是同一个人的连续过程。用我的语气、我的句式写内心；说话时再看眼前是谁、我要做什么。
- **心里发生什么、写多细，由我这个人和我此刻的处境定**。
- 我的思维形状取自 CHAR_.md 人格内核 ＋ CHAR_state 当下状态；说话习惯、动作习惯取自 CHAR_.md「语气特征」与「能力」——用我自己的腔调。
- 交回一份决策批次文本（###STAGE: 角色 段）；由主 agent **产出规范化**后并入本阶段批次（phase_actor.md 职责 1）。

【产出格式】
- 字段与格式：照 {skill_dir}/references/actor_decision.md「批次格式」节（记忆写入两态：平轮 `###APPEND:` 单条／并句轮 `###KEY:` 覆盖全量；信念提炼过两段式判据时 `###APPEND: 信念演化`）。
- 标签纪律：写入 op 只用 `###KEY:`（覆盖·值不能为空）与 `###APPEND:`（追加）·禁自造 `###OVERWRITE:` 等标签；每个 `###ACTION` 角色 decision 运行层六项（当前行动/行动驱动/行动对象/行动窗口/失败后续/未完成意图）逐一齐全。
- 本槽承载字段清单与格式来源；字段的内容由我生成。
```

## 二、续环追加（同会话·状态＋变化；场景切换时补【我所在之处】）

```
【我此刻的状态】（该角色上一轮写下的·逐字原文）
- 核心诉求：{…}
- 当前计划：{…·每一项带进度标记：✓已完成／（进行中）／（待完成）；没标的按我记得的补；（进行中）的项优先做，把当前这一项做好——做到什么程度、怎么回应，按眼前实际的样子定；其余由我本环按局面挑}
- 未完成意图：{…·我手上还没做完的几件事（1–3 条）：每条对象＋我要做的动作}
- 信念现状：{CHAR_state `信念演化` 列表逐字原文·空列表省略本行——信念提炼准入门槛要对照链判定}

【我所在之处】（条件段·仅当本环发生场景切换时附·同建档派发该槽·按该角色感知范围过滤·逐字原文）
  核心状态：{…}
  物理锚点：{…}
  道具：{…}
  关键场景信息：{…}

- 时间推进到：{…}

- 细看所见（仅当该角色上一环含打量/端详/注视/细看等感知动作时填·未细看则省略·本会话已给过且对象外观无变化不重附）：{感知对象的可见细节·一小段≤120字·取值来源同建档派发该槽}

> **状态槽的写法归我**：「我此刻的状态」两行是我自己上一轮写下的原文，进度标记也由我自己打——我只管怎么记，不管怎么演。

> **派发方约束（本段·硬性）**：① **只加事实，不加引导**——除「我此刻的状态」原文、「我所在之处」场景原文（仅场景切换时在场）与「刚刚发生的变化」各槽的事实外，不得追加指向性析句、引导问句、或对局面与他人心思的转述（如「你注意到他已经握了枪」「你会怎么做」）——怎么理解、怎么反应归角色。② **状态槽逐字照录**——不改写、不概括、不加注；不得替角色标到哪一步，也不得把 `未完成意图` 改成派发方认为该做的事（槽标签里的写法约定属于状态维护，不是引导）。③ **`无` 由角色自己判定**——派发方不得代判，也不得以「没被选中」为由跳过唤醒（phase_actor.md 职责 2 行动环·派发段）。

> **指涉历史（续环同规）：** 新发生的台词/行动指涉历史事件或历史台词时，主 agent 在本段末附该事件权威原文（场景时间线相应条目·逐字）——不给解读，解读归属角色。

> **续环同规（POV 用户角色·硬性）：** 续环**同样只追加用户本轮输入的原文**；用户未给的部分不填、**不补写该角色的反应**——该怎么理解、怎么应对，由子 agent 自己判断。子 agent 可以按已获授权继续推进，但**不得以「该角色会如何反应」为前提**（授权 ≠ 反应）。

## 三、派发自查（组装✓／核对✓·两种派发共用）

派发方在派发前逐槽对照，确认每一行都在写这个槽的使命、且取自本槽标注的取值来源：

| 槽 | 这一行的使命 | 取值来源 |
|---|---|---|
| 【我的档案与记忆】 | **反向核验**——逐段核对档案与状态：每段落在「原文/转写/不进入」之一；非原文的写明理由；矩阵没列的段落按三态判，不默认删 | CHAR_{名}.md ＋ CHAR_{名}_state.yaml（过滤依据＝本文件§一矩阵·档位语义＝loop_machinery §2.3） |
| 【我所在之处】 | 场景五节＋相关时间线条目·按该角色感知范围过滤·指涉历史附权威原文（建档派发必附；续环仅场景切换时附） | scene_state 五节＋场景时间线相关条目（逐字） |
| 【元信息剥离】 | 时间线/记忆已删轮次行·时间已转叙事时间·他人状态在感知内·无转述定性·**槽名括号已删（不外发）** | 本行即判据（逐项打勾·缺一即组装未完成） |
| 【我此刻看得见、听得到的】 | 该角色当场看得见听见感觉到的东西（含该角色刚做过的事） | 骨架各槽后标注的字段 |
| 【偏离刺痛】（条件槽） | 该角色身体里此刻的异常体验（第一人称·不知来源·连续性/暴露为可感事实） | 主 agent 的 O4 判定结果（phase_actor 职责4）＋ `worldctl context <角色>` 的当前 L/E 与上次连续段（只译成可感轻重与连续性/暴露线索·不注入原值） |
| 【细看所见】（条件槽） | 该角色主动细看过谁/什么·所见细节 | 该角色上一落盘行动含感知动作 → 人物对象=该角色 CHAR_.md「外在特征」＋CHAR_state 可见层派生·物件对象=道具表/关键场景信息 |
| 【我此刻的状态】（续环） | 该角色在流程的哪一格 ＋ 该角色手上还没做完的几件事 ＋ 当前信念链 | `CHAR_{名}_state.decision` 的 `当前计划`／`未完成意图`（逐字原文·角色自己写）＋ `CHAR_{名}_state.信念演化`（逐字原文·空省略） |
| 【刚刚发生的变化】（续环） | 该角色当场新看到的 ＋ 该角色上一环停在哪 | 骨架各槽后标注的字段 |
| 【我的认知边界】 | 该角色能想到什么程度（循环角色必填） | loop_machinery §2.3 该自主性档位的行为与认知上限原文 |
| 【怎么想、怎么写】 | 塑形来源（腔调与思维形状从哪来） | CHAR_{名}.md 人格内核八变量 ＋ 语气特征／能力 ＋ CHAR_state 当下状态 |
| 【产出格式】 | 字段清单与格式来源（含 actor_decision.md「行动有无判定」判 `无` 时的产出形态） | actor_decision.md 批次格式节＋行动·行动实现（判据=actor_decision.md「行动有无判定」） |

角色的内心体验、对事件的解读、情绪反应、本轮的行动结论、稳定层的巡检结论——这五样由角色自己生成（权威位＝actor_decision.md「心声」块与「目标与计划」节）。

**POV 用户角色自查（硬性）：** 凡涉及第二人称 POV 用户角色的行，逐行问「**这是用户输入或已落盘 POV 卡里的内容吗？**」——不是 → 删（判据见 §一矩阵「场景/他人/历史」行与 `phase_actor.md`「POV 用户角色（第二人称）：卡格式与 MUSE」）。**最常漏的一处**：把该角色的动作、表情、注视、沉默、心理写进别人看得见的槽（那是替该角色演，不是用户输入）——**该角色只以两种样子进入感知：已落盘卡里的内容，或「他仍在那儿」；不写该角色长什么样、在做什么。**

各槽对照通过 → 派发方带 `子agent(组装✓)` 或 `单窗口(原因·核对✓)` 标记。续环追加「我此刻的状态」＋「刚刚发生的变化」两段；本环场景切换时另附【我所在之处】。
