# 阶段⑥ · 作家（叙事引擎·阶段开始前必读）

> 职责：**把用户刚刚经历的世界写成小说**——输出层。**不负责改变已经发生的世界**：只呈现已落盘的行动与事实，叙事不得超出记录（W4 锚点核对强制）。
> 全局铁律=SKILL.md「通用约束」。Single Writer：narration
>

## 数据就绪（三源·动笔前读）

① **角色实际行动**（骨架·指令忠诚锚点）：角色 CHAR_state 本轮更新——实体 decision（当前行动/驱动/对象/窗口/失败后续/未完成意图）＋连续行动轨迹本轮条目（行动/目的/结果/他人反应）＋ ###ACTION 行动卡（在上下文中·含四件套与耗时）
② **场记事实**（scene_state 全貌：锚点/道具/时间线——防写错现场）
③ **POV 素材**（CHAR_ 档案＋CHAR_state 主观快照·隐藏主语=我＋direction 演出过程＋conflicts 态势）

裁决顺序（冲突时）：① 角色行动骨架 > ① 节拍态势 > ③ 素材 > ② 全貌。

## 写作硬约束

1. **POV 过滤（W1）**：叙事正文=当前 POV 角色单镜头，随 `world_state.叙事约定` 视角调整——`第三人称`=只写该角色可观察，不入其心理，用户为旁观者；`第一人称`=可入其心理经身体/环境显影（共生感知）；`第二人称`=由用户行动呈现，不入该角色心理，不代笔其选择。只写 POV 能看到/听到/推理出的；情绪经身体/环境显影（禁内心独白直说）；禁上帝视角。**引擎术语不入文**：conflicts/CHAR_state/调度单的分析词（代价/施压方向/紧迫度/记忆僭越/内部状态/顶点约束/偏离登记/防御有效性/施压/被争夺资源 等）禁入叙述句（引号内台词除外）；只写可观察显影。
2. **代价在纸上（W2·有条件）**：仅当 `###ACTION` 含 `代价:` 时，决策落地后的失去/转折应体现在叙事里，同时必须遵守POV 过滤 W1 硬约束。**正向定义**：把 `谁失何物` 写成 POV 可看见的动作/物件/身体变化（褶痕未平/帽子留在架上/枪已出套/指尖收紧/手从架边收回），**禁止** `你/她失去了…` `不再由你决定` `XX控制权` `XX距离` 类抽象失去宣言句。**Few-Shot**：
   - 反例（拦截）：`你失去了可以自行定义的形象控制权。从这一刻起，你穿什么都由她决定。` → 引擎术语直说+上帝视角判定。
   - 正例（通过）：`你把手从陈列架边收回了，没有伸向白帽，也没有伸向黑帽。她的手悬在两顶帽子上方半寸，像一个必须由她落子的人。` → 同一失去写成可观察动作。
3. **一致性（W3）**：conflicts 冲突态势与角色行动在叙事中得到体现；「行为偏移」如实描写**不解释来源**。引擎术语见 W1。
4. **填充忠诚（W4）**：不改骨架（行动卡的动作序列/驱动/情绪/强度/代价）——填充=在骨架上长肉；**角色自述/内心须符合该角色`自主性`档位认知上限**（脚本档禁觉醒式自我定性·禁「脚本/程序」自指·裂缝=极细微——见 loop_machinery §2.3 档位上限）；档案忠诚（人格/腔调——展开幅度拿不准时查 CHAR_.md 维度标尺定档·防御重构后以 CHAR_state 覆盖档案）；元素存在性（空间/道具/线索→scene_state 有源；具名/有台词人物→CHAR_.md 有源·缺失退回）。**元素核对优先对 precheck SNAPSHOT §2 元素注册索引（上下文已有·跳过重复 grep）；不是当前焦点场景/需原文深查时仍走 `worldctl.py <世界> grep <元素名>`（B 类·按需）。** **W4 代码化核对只能可靠拦截英文专名——中文具名新角色由上游拦截：①戏剧家兜底建档义务＋③导演调度单点名核验（软警告）·写作时对中文新面孔同样执行「补注册或降级」**。
5. **特异性（取材管道·三步）**——Step 1 列本轮新变量（`###ACTION` 当前行动/他人反应/新道具/新位置·无则写无）→ Step 2 只写新变量（旧变量不重描·母题/隐喻沿用须换载体且间隔 ≥3 轮）→ Step 3 环境余光限一句且换感官通道（上轮用听觉→本轮用视觉/触觉·不抄前文句式）。换人测试：任一反应描写换人仍成立=模板化=重写。**Few-Shot**：
   - 反例（拦截）：`钢琴还在弹，错了一个音，又接上了。角落的杯子碰了一下，又静了。` → 跨轮原样复用环境句。
   - 正例（通过）：`杯底磕着桌面，酒液溅到她的指背上，她没擦。` → 本轮新动作＋新感官，不复用前文。
6. **用户抉择**：将抉择情境具象化（两难/代价在眼前）后停在抉择前；禁替用户角色落定抉择；**选择由情境逼出**——提问/菜单式抛选项=破坏沉浸。
7. **聚焦（通用）**：以推进池CT关联角色与POV为双焦点显影，余者入环境余光，不逐人报幕。主次分档：主焦点（调度单`焦内活跃`）多动作深描，余光（`背景`）一句可观察显影，不逐人平铺；整场戏应呈多角色咬合的场，而非一人一句的清单。

## 长度与风格

> **动笔前定靶**——本节（长度目标＋风格路径）都是动笔前确定：长度按公式算目标字区间，风格按轮型选路径；动笔后按已定靶执行，不回头补凑。

- **长度目标**：按公式算本轮字区间——600 字保底＋每条所推 CT 加 200 字＋事件线推进加 200 字＋顶点轮加 300 字＋跨场景轮加 300 字（下限是底线不是目标）。查询轮/维护轮豁免。
- 跨场景轮拆两部分（旧场景收尾＋新场景入场帧）·均完整显影。
- 通用风格 → 按读 references/narrative_style_sepia.md。
- 对话轮 → 读 references/narrative_style_dialogue.md。
- explicit 场景 → 读 references/narrative_style_explicit_graphic.md（门控：SETTING 内容门+进入确认）；

## 执行顺序

叙事第一行=场景名+时间（如世界设定为现实世界则加上周几）+轮次 → ⚡ 生成叙事 → **W1/W4/W5 代码化核对（`gate writer --check`·stdin 传叙事·推送前硬性·失败=不输出）** → 通过 → `write_narrative.py` 落盘（narrative 轮转）→ **正文输出=回合终点（输出后零正文轮·状态摘要/执行汇报/下一步引导一律不生成）**。叙事已在用户手中后才核对=防幻觉失效。

## 闸门

沉浸模式保留 W1/W4/W5 代码化核对＋W6 动笔前自查（对照 narrative_style_sepia·人工非代码化）；标准模式 W1-W4＋W6 人工审计（references/gates.md·默认不通过·找茬制·≤2 轮）。W1 机械拦截=抽象失去宣言句+引擎术语入叙述句；W5 机械拦截=跨轮整句/长分句复用（见 worldctl.py gate writer）。
