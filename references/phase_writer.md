# 阶段2 · 作家（阶段规则·阶段2 开始前必读）

### 场景约束（填充忠诚·硬性）
作家填充的任何细节（台词/动作/反应/环境/身体语言）都必须对三个源忠诚：
① **指令忠诚**：不违反戏剧家指令（change set 角色反应的动作序列/驱动/情绪/强度/代价）——填充=在指令骨架上长肉，不是改骨架；指令未给的方向不得自行发明（如指令只给「笑·非常有意思」→ 补的台词语义必须由该角色人格+驱动生成，禁止与驱动冲突的通用模板）
② **档案忠诚**：不违反角色档案（CHAR_ 性格/Reaction Style/Belief/腔调/防御）——台词与行为语义方向由人格驱动；写不出该角色独有的说法=先查档案再落笔。**动态覆盖（防御重构后）**：CHAR_state `防御形态`/`崩溃表现` 非空 → 覆盖档案 `防御机制`/`崩溃模式` 作为当前行为基准（重构后防御=新防御·禁止按旧档案防御推导行为）
③ **数据忠诚/锚点约束**（见通用约束）：每个空间元素→物理锚点有对应项？每件交互物品→道具清单有对应项？每条线索→关键场景信息已定义？**每个具名/有台词/有行动的人物→CHAR_.md 有对应项**？没有→**退回重写**（新人物二选一：阶段1 补注册 CHAR_.md / 降级为不具名不说话的背景剪影）。**元素注册是阶段1 戏剧家 change set 职责**（`###KEY: 物理锚点`/`###KEY: 道具`/`###FILE: CHAR_X` 随 change set 落地）——需要新元素/新人物 → 阶段1 先注册，作家阶段2 只使用已注册元素；禁止叙事推进后反填；禁止作家请求场记补加（注册是阶段1 的产物，不是作家的请求；作家发现未注册 = 退回重写）。POV 转换：「在想什么」→「嘴角动了一下」；逐句问：POV 角色能看到/听到/推理出这个？变化必须有中间步骤，每步有可观察触发器。
④ **用户角色抉择**（硬性·见节拍规划「用户抉择停靠」）：用户角色的抉择由用户输入做出——叙事将抉择情境具象化（两难/代价在眼前）后停在抉择前；禁止替用户角色落定抉择（动作/内心/状态）；**禁止以提问/菜单形式抛选项**（「您想选哪顶？」类破坏沉浸）——情境本身把选择逼到用户面前，用户自会输入。

### 写作数据准备（动笔前读取·三源）
动笔前读三源：
① **scene_state** —— 客观全貌：发生了什么·空间锚点·道具·时间线（防写错现场）
② **conflicts** —— 当前焦点：本轮推进 CT 的节拍态势（关系状态/攻守态势/未决时机）+ **角色反应子节点**（动作序列/驱动/情绪/强度/代价 = 本轮执行指令·戏剧家骨架）
③ **CHAR_ + CHAR_state** —— POV 素材：焦内角色性格（有信念演化按新信念驱动·旧 Belief 只作「过去的样子」参照）/ 此刻最大刺激（优先处理最紧迫的）/ 身体状态如何影响认知 / 在场人际关系 / 此刻状态快照（隐藏主语=我·直接作 POV 素材）/ 外在特征（整体形象/外貌）与叙事描写视角与重点（语气特征/描写优先/视角限制）——描写人物形象时参考 CHAR_ 对应段落，呈现经当前 POV 角色心理过滤：同一人物在不同 POV 眼里呈现不同

**显影匹配（硬性·动笔前）** 本轮叙事长度下限 = 500 字保底 + 每条所推 CT 加 150 字 + 事件线推进加 150 字 + 顶点轮加 300 字 + 跨场景轮加 200 字。下限是底线不是目标——细腻描写 / 慢节奏场景等需要超量展开时不受限。查询轮/维护轮豁免。

**跨场景轮（本轮含场景切换）：** 叙事拆为两部分——旧场景收尾叙事（=本轮 CT 推进中发生在旧场景内的全部节拍，不因场景切换截断）+ 新场景入场帧叙事（到达动作 + 第一眼环境氛围：光/风/气味/远景轮廓）；两部分均完整显影。新场景元素约束随场景切换完成后的下一轮数据就绪自然完整。

**裁决顺序（冲突时）：② 角色反应 > ② 节拍态势 > ③ 素材 > ① 全貌**。焦外角色的状态增量只作「可揭示」库存（感知/焦点切换通道成立前），不作素材。

### 焦外与视角（硬性）
叙事正文 = 当前 POV 视角的单镜头。**焦外内容是否入文取决于当前视角**：①POV 角色感知到焦外信息（看到/听到/推理出）→ 只写感知到的部分（被动揭示）；②叙事焦点切换到焦外角色所在场景（该角色成为焦内·见 references/scene_management.md §焦外→焦内主动接近协议/焦外行动的揭示原则）→ 可写；③两条通道都没发生 → 焦外只落状态增量+「可揭示」标记，不进叙事正文（禁暗线镜头/彩蛋切镜/全知旁白）。动笔前先问：这句发生在 POV 角色当前所在场景、且 POV 角色能感知到吗？不是 → 删。

### 叙事原则
感官优先级：按 POV 角色当前行为焦点确定（视觉凝视→视觉细节；身体接触→触觉；性→性器官触感逐帧；心理→心理画面质感；决策→矛盾的具体形态）。**不要模板化**：极端刺激下的反应是混乱自相矛盾的；在两种极端反应之间留出中间态；拒绝「受害人模板」和「从容女强人模板」两端的简单归类。

### Explicit 框架
涉及 explicit/graphic → 读 references/narrative_style_explicit_graphic.md，要素**嵌入**主叙事（视角沿用主叙事人称·恪守认知边界·不做切换）。

### 对白展开
对话轮 → 读 references/narrative_style_dialogue.md 取话轮/潜台词/停顿显影/语言质感写法（要素嵌入主叙事·单镜头·恪守认知边界）。

### 执行顺序
叙事文本第一行为场景名+时间+轮次 → ⚡ 生成叙事 → **W4 锚点代码化核对（gate writer --check，推送前硬性）** → 通过 → 进入阶段3 落盘（write-raw / write_narrative / validate）→ **最后正文输出叙事（回合最后一个动作·输出后零正文轮·不输出任何文本）**。**W4 失败=不输出**——叙事已在用户手中后才核对=防幻觉失效（历史教训：坏叙事发出去才被拦，等于没拦）。

### 作家闸门（W1-W4·标准模式·推送前）
静默模式（全局默认）跳过 W1-W4 人工审计，仅保留 W4 代码化核对 `worldctl.py <世界> gate writer --check`（推送前·失败 exit 1=不推送）。标准模式下：
按 references/gate_writer.md 执行 W1-W4：先显式声明「角色转变：以下检查由另一名独立审计作家执行——非本轮叙事者」→ 逐项输出 {不通过} + 证据（引用叙事原文/conflicts 节拍/scene_state 锚点）→ 全部通过才推送。任一不通过 → 退回修正后重检（≤2 轮）；超 2 轮 → 终止并报告用户。审计者只读，修复由决策者执行。
