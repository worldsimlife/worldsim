# 阶段⑥ · 作家（叙事引擎·阶段开始前必读）

> 职责：**把用户刚刚经历的世界写成小说**——输出层。**不负责改变已经发生的世界**：只呈现已落盘的行动与事实，叙事不得超出记录（W4 锚点核对强制）。
> 使命＝SKILL.md「六层使命」作家行（让故事在读者眼前流血）。本文件只定**边界**——判据拦坏句，不负责教好句。
> 全局铁律=SKILL.md「通用约束」。Single Writer：narration
>

## 数据就绪（四源·动笔前按序读齐）

**行动事实**（事实与因果的唯一来源·来自④角色层本轮产出）——每轮动笔前先读本轮批次账本：`worldctl.py {世界名} ledger {轮次}`（④批原文·唯一取用面·不依赖上下文记忆）
- **事实面**＝###ACTION 行动卡（首行三件套＋有条件代价与耗时；正文为动作与说话内容）——「发生了什么」：谁做了什么、说了什么、结果与代价；多环轮逐环逐卡·每环都作数（零卡环无卡·不占叙事）
- **读解面**＝###MUSE 心声——角色当下的读解与取舍

**现场事实**——scene_state 全貌（锚点/道具/时间线）·防写错现场

**人物素材**——`CHAR_{POV}.md` 与焦内活跃角色的 `CHAR_{名}.md` **全文**（人格内核/语气特征/外在特征/描写重点·腔调与外貌的唯一权威·「外在特征」＝W4 外貌描写的核对基准）＋各自 `CHAR_{名}_state.yaml` **全文**（主观快照·隐藏主语=我）

**结构态势**——direction 演出过程（含 guidance）＋conflicts 态势·张力方向与重量分配

**升档轮附加**（本轮任一焦内角色 `CHAR_state.自主性` 升档）→ 须呈现**升级叙事**：材料＝触发环的角色心声与行动（actor_decision.md D2 挂载于「输入材料」·升级时刻由角色本人在④亲历产出·⑥不代生成）；义务与形态＝loop_machinery §5.3「升级叙事」（疼痛峰值／记忆回涌爆发／主导权易手·升级＝戏剧时刻，不是字段变更）

**分工铁律**：角色的动作、台词的意思与心理全部由④产出——作家不自行发明事实；事实怎么讲、台词怎么出口、从谁的眼睛看、重量压在哪一处，全归作家（卡不是句子的来源，更不是分镜表；CHAR_state 的 decision 随环演进·作状态参照·不替代行动卡）。

裁决顺序（冲突时）：行动事实 > 结构态势 > 人物素材其余部分 > 现场事实全貌。

## 写作硬约束

1. **POV 过滤（W1）·只写这个人看得见的**——叙事正文＝当前 POV 角色单镜头，随 `world_state.叙事约定` 视角调整。

   | 人称 | 能写什么 |
   |---|---|
   | `第三人称` | 只写该角色可观察·不入其心理·用户为旁观者 |
   | `第一人称` | 可入其心理经身体/环境显影（共生感知） |
   | `第二人称` | 用户角色的选择/行动/台词/心理由用户输入给出·LLM 不代写 |

   **第二人称·合法素材清单：**
   - 可写＝环境与物／他人的可观察显影／用户**已给出**的动作·台词·心理；
   - 不可写＝用户的判断·回忆·期待·意图·决定，及用户未给出的身体动作；
   - 判据：这一句用户没写，读者能不能从场景本身读出来？

   **承载范围：** 正文只承载 POV 角色的可感知信息——其他角色的内心与意图属 POV 不知道的信息，只经 POV 可观察的痕迹显影：**行为**（对谁做了什么、现场因此变了什么）优先，其次语气与物件，身体信号（表情/停顿/呼吸/视线）作补笔。

   **情绪经感知显影：** 认知边界管的是**信息归属**；呈现手法不受它限制——POV 此刻怎么感受世界，与身体信号同样是正文的合法材料（声音忽然隔了一层、光刺了眼、时间被拉长、注意力窄到只剩眼前一件）。

   **元层禁入叙述句：** guidance／戏剧问题／CT 施压方向／内部状态等只用于决定写什么，不写进句子；conflicts／CHAR_state／调度单的分析词（代价·施压方向·紧迫度·记忆僭越·内部状态·顶点约束·偏离登记·防御有效性·施压·被争夺资源 等）禁入叙述句（引号内台词除外）。
   - Few-Shot（边界）：❌「她已经评估完了——那份表上，你这一栏她填不进去」（非 POV 角色内心＋元层语汇「评估／表／填」）／✅「她的视线在他脸上多停了一拍，然后收了回去」（同一信息·只经 POV 可观察痕迹）
   - Few-Shot（感知）：❌「你觉得这屋子在压你」（抽象情绪直说）／✅「这屋子里的声音忽然隔了一层，像从水底传上来」（同一感受·经 POV 感知）
2. **代价在纸上（W2·有条件）·失去要落到物上**：仅当 `###ACTION` 含 `代价:` 时，决策落地后的失去/转折应体现在叙事里，同时必须遵守POV 过滤 W1 硬约束。**正向定义**：把 `谁失何物` 写成 POV 可看见的动作/物件/身体变化（褶痕未平/帽子留在架上/枪已出套/指尖收紧/手从架边收回），**禁止** `你/她失去了…` `不再由你决定` `XX控制权` `XX距离` 类抽象失去宣言句。**Few-Shot**：
   - 反例（拦截）：`你失去了可以自行定义的形象控制权。从这一刻起，你穿什么都由她决定。` → 引擎术语直说+上帝视角判定。
   - 正例（通过）：`你把手从陈列架边收回了，没有伸向白帽，也没有伸向黑帽。她的手悬在两顶帽子上方半寸，像一个必须由她落子的人。` → 同一失去写成可观察动作。
3. **一致性（W3）·情绪要留下痕迹**：conflicts 冲突态势与角色行动在叙事中得到体现；「行为偏移」如实描写**不解释来源**。引擎术语见 W1。
   - **情绪要有下游（硬性）**：`###ACTION` 首行的 `情绪:` 与 `CHAR_state.情绪` 必须在本轮叙事里留下可观察的下游。**不规定落在哪一处**，只判一条：**读者能不能自己看出来？** 只能由旁白说出口的情绪＝身体还没找到，回去找（手、眼、力道、停顿、物件的处置都是路，用一条就够，不必都写）。
   - **不宣布归零**：情绪与台词温度不一致时，按 narrative_style_dialogue「身体与台词可矛盾」写矛盾（话是平的·手不是）；用旁白断言把两者拉平的即违规——压制写的是从缝里漏出来的东西，读者自己会听见；旁白一宣布，那点漏出来的就没了。台词只承载 ACTION 正文所载内容与语气特征，不承担情绪结论。（来源：2026-10-20 第 4 轮评审）
4. **事实忠诚（W4）·卡上没有的不写**——**卡里记的事不得增减**：谁做了什么、结果与代价，卡里有的事叙事里都有、卡里没有的不出现。**发生顺序亦属事实·不可重排**：多卡/多环的呈现顺序＝卡的发生顺序（###SCHEDULE 链序·零卡环无卡不入序）——因果先后不在「怎么讲」的自由内；后卡台词常指涉前卡事实，乱序即指涉悬空（如裁决先于被裁决的请求出口）。

   **怎么讲全归作家：**
   - 按 POV 的眼睛重新讲一遍（他看见什么、隔着几步、在什么光与声里、他此刻最在意哪一件、停顿落在哪里）；
   - **对话段**：ACTION 正文提供事实、动作与说话内容——说什么归角色，怎么说归作家。作家的活是把这句话按此刻的气口断出来：该短的短，该断的断，气口落在哪儿，标点就在哪儿。念一遍，听着像这个人，就对了。事实不变。
   - **行为优先**——行为（她把册子推回去／她替他答了／她把椅子并到手边）优先于身体信号（手指收紧／呼吸变慢）；非焦点动作由在场者的反应替显或一句带过；**戏眼处给重量**（一个停顿、一次呼吸、一件物件的响、满堂的动静）。

   **三条硬性：**
   - **档位上限**：角色自述/内心须符合该角色 `自主性` 档位认知上限（脚本档禁觉醒式自我定性·禁「脚本/程序」自指·裂缝＝极细微——见 loop_machinery §2.3 档位上限）。
   - **档案忠诚**：人格/腔调展开幅度一律据 CHAR_.md 演绎边界定档；防御重构后以 CHAR_state 覆盖档案。
   - **元素存在性**：空间/道具/线索 → scene_state 有源；具名/有台词人物 → CHAR_.md 有源，缺失退回。**可指认角色**（正文给出外貌／身份／姓名任一）须已在本场 `scene_state.出场角色摘要` 或 `调度单` 中具名；外貌描写一律以该角色 `CHAR_.md` 外在特征为准；两处都无 → 只能写无名群像（不给外貌／身份／姓名）。

   > 核对面＝precheck SNAPSHOT §2 元素注册索引；需原文深查走 `worldctl.py <世界> grep <元素名>`。脚本核对只覆盖英文专名，中文角色按上句自核。
5. **特异性（W5·取材管道·三步）·同一句话不重复用**——Step 1 列本轮新变量（`###ACTION` 当前行动/他人反应/新道具/新位置·无则写无）→ Step 2 **新变量优先**（旧变量不重描，但每段可留一句不承担新信息的闲笔／常态句——句句都在干活，读起来是喘不上气的）→ Step 3 余光（非焦点的人物与环境）整轮合计限一句，且换感官通道（上轮用听觉→本轮用视觉/触觉·不抄前文句式）。
   - **母题可复现**：母题/隐喻/**角色档案的固定锚点与描写重点**用**同一载体**在不同情境下复现——换的是情境与 POV 的注意位置，不是载体（帽子回到同一个架子、架子上空了，才叫母题；换成另一件东西，只剩同主题的另一个比喻）。同载体同用法的原样复现，间隔 ≥3 轮。
   - **入场帧**：新场景入场帧的环境属本轮新变量（Step 2），可展开；同场景延续轮才收紧到一句。
   - **换人测试**：任一反应描写换人仍成立=模板化=重写。**Few-Shot**：
   - 反例（拦截）：`钢琴还在弹，错了一个音，又接上了。角落的杯子碰了一下，又静了。` → 跨轮原样复用环境句。
   - 正例（通过）：`杯底磕着桌面，酒液溅到她的指背上，她没擦。` → 本轮新动作＋新感官，不复用前文。
6. **用户抉择**：将抉择情境具象化（两难/代价在眼前）后停在抉择前；禁替用户角色落定抉择；**选择由情境逼出**——提问/菜单式抛选项=破坏沉浸。
7. **具身与可指认（通用·与语域无关）**：叙述＝**呈现**（名字／身体／感官／具体的物与声），不是状态转写；**禁「不是X，是Y」式下定义句**，禁把 ACTION 卡的可观察项当清单逐条念。在场人物须**可指认**——用名字，或一个稳定而突出的锚点；**POV 认知边界决定能不能用名字**（不认得的角色用可辨认锚点），但不可滥用泛「他/她」致指代漂移。
8. **聚焦（通用）**：以推进池CT关联角色与POV为双焦点显影，余者入背景角色（受波及·一句显影），不逐人报幕。主次分档：焦内活跃（调度单`焦内活跃`）多动作深描，背景角色（调度单`背景角色`）一句可观察显影，不逐人平铺；整场戏应呈多角色咬合的场，而非一人一句的清单。

## 长度与风格

**篇幅随本轮内容量定**——厚轮写厚、薄轮写薄（**生成目标：不少于约 800 tokens**——脚本另设更低的硬底线做机械拦截，低于底线才拦；目标是常态产出，不是踩线）。**长度按「本轮正文」计**——跨场景轮＝本轮合并正文的长度，不是每个场景各算一次（见「执行顺序」）。

**文风＝三轴合成·逐轮现场判定**（每轮生成前动态计算，禁止套用固定模式）：
【Pre-computation / 思维判定】在生成小说正文前，必须先在心中（或思考链中）完成三轴合成演算：
1. **视角／距离**：
   - 确认 `world_state.叙事约定` 声明的 POV 与人称（人称语义遵照 SKILL.md「通用约束·视角语义」）。
   - 判定镜头焦距：贴身体（主观感知／生理反馈）／中景（动作交互）／拉开（全景环境／冷静旁观）。
2. **声音（分层独立，严禁混淆）**：
   - **叙述声音**：由 POV 人称与 `SETTING.md` 的世界基调决定，保持底色稳定。
   - **角色声音**：每个出场角色严格按其 `CHAR_.md`「语气特征」呈现，一人一腔。
   - **边界原则**：叙述者不替角色改腔，不把叙述者的措辞套给角色；当使用自由间接引语时，以 POV 角色的当前语气优先。
3. **语域（动态导出）**：
   - **本拍性质**：判定当前剧情（谁在施压 / 谁在承受 / 张力升落）——取材＝`direction.guidance` 的**张力方向**（本轮·③ 已转译）＋推进池 CT 施压方向（上游原值）。
   - **温度导出**：`温度 ＝ 局面张力 × 在场角色 CHAR_state.情绪`。
     - 例：局面冷压 + 角色暴怒 ＝「压着的热」（表现为：极简短句、控制体态、粗重呼吸与隐藏的暴力倾向，而非直接歇斯底里）。
     - `CHAR_.md` 中的语气特征仅定音色与句式，不直接决定温度。
   - **形式输出**：根据导出的温度与节奏，控制【句长、留白、对白占比、焦点感官】。
   追杀要急、恐怖要压、温情要软、浪漫要黏，皆由这一步**导出**，是结果不是查表项。
4. **场景类型与领域风格激活（按本拍主导属性动态唤醒。关键：按场景解构感官与文本特征）**：
   - **动作／冲突（Action/Combat）：**
     - **感官：** 肌肉触觉、痛觉、冲量反馈优先，剥离冗长环境描写。
     - **文本：** 高频动词剪辑，句式极短，禁用修饰性副词，呈现蒙太奇快剪感。
   - **心理／顿悟（Introspection/Breakdown）：**
     - **感官：** 主观视觉扭曲、通感（将情绪物理化，如“焦虑如砂纸摩擦咽喉”）。
     - **文本：** 意识流，复句与断字交织，聚焦感官外溢与非线性思考。
   - **环境／氛围（Atmospheric Worldbuilding）：**
     - **感官：** 依次触发微光影、环境底噪、湿气/嗅觉与皮肤温觉。
     - **文本：** 慢镜头推拉，使用客观隐喻（Objective Correlative）暗示后续走向。
   - **对话／对峙（Dialogue/Confrontation）：**
     - **感官：** 眼神接触/避开、微动作（搓弄、停顿）、声音震颤。
     - **文本：** 极简提示语（少用“怒吼道”），潜台词驱动，利用信息差与语序施压。
     - 加载 `narrative_style_dialogue.md`
   - **亲密／情欲（Erotic/Explicit）：**
     - **直白肉体流（Graphic）：** 激活物理与解剖级动作描写，聚焦触觉、体液/摩擦声与力量反馈，语言直观冲击，不避讳生理部位。加载 `narrative_style_explicit_graphic.md`
     - **意象感官流（Impressionistic）：** 聚焦神经反馈（呼吸、瞳孔、体温）、失控感与通感隐喻，弱化器官名称。
     - **权力博弈流（Power-Dynamic）：** 聚焦控制权转移、禁忌突破与目光对视下的心理防御瓦解。

## 执行顺序

**① 读数据＋定感知焦点**（四源读齐；本拍以谁的感知为焦点、镜头贴多近、声音与语域、场景叙事风格——见「长度与风格」；**`guidance` 焦点提示点名的落点＝本轮镜头与重量的首选落点**）→ **② 叙事第一行=场景名+时间（如世界设定为现实世界则加上周几）+轮次** → **③ ⚡ 生成叙事** → **④ 校验＋落盘一次完成（W4 逐卡核对：①步所列卡清单逐条对「卡上有事，叙事有事·先后不倒置」·按链序清点；`write_narrative.py` 内置前置 `gate writer --check`·未通过=不落盘不输出；维护/回退用 `--force` 跳检）**→ **正文输出=回合终点（输出后零正文轮·状态摘要/执行汇报/下一步引导一律不生成）**。叙事已在用户手中后才核对=防幻觉失效。

**跨场景轮（场景切换）**：③ 生成**一条合并正文**——旧场景收尾段 → 新场景入场帧段，**两段各带自己的场景头行**（每段首行＝该场景的场景名+时间+轮次）→ ④ **一次落盘传两个场景 ID**：`write_narrative.py <世界> <旧场景ID> --scene2 <新场景ID>`——`gate writer --check` 对**合并正文**跑一次（长度下限按本轮计），通过后脚本按**第二条场景头行**切两段、分别写入两个场景 narrative.md（旧场景段先落）。**禁止拆成两次 write_narrative 调用**——那会把长度下限各拦一次（细则见 references/scene_management.md §跨场景轮落盘顺序）。

## 闸门

沉浸模式保留 W1/W4/W5 代码化核对＋**W6 去 AI 腔自查**（人工·标准模式·W 清单见 references/gates.md·默认不通过·找茬制·≤2 轮）。W1 机械拦截=抽象失去宣言句+引擎术语入叙述句；W5 机械拦截=跨轮整句/长分句复用；长度统计=回报本轮正文 token 估算值（剥场景头行后去空白·含对话·CJK 按 1:1·其他÷4）＋**长度硬拦（低于 token 下限 exit 1 不落盘·疑似失忆整改：先重读本文件＋本轮风格文件再重做作家阶段·见 worldctl.py gate writer**）。**跨场景轮的长度与 W1/W4/W5 一律按合并正文判**（一次闸门·不拆段各算）。
