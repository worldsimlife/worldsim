# 阶段④ · 角色（生命层·阶段开始前必读）

> 本阶段是引擎的心脏：**角色从被动执行者升级为自主即兴的生命层**——主动决策、持续行动、直写自己的状态文件。
> 全局铁律=SKILL.md「通用约束」；**阶段④=所有角色状态唯一写者**（Single Writer：CHAR_{名}_state）
>
> 决策与写入规则（自治原则/决策环 1.1–1.5/写入/批次格式）＝**references/actor_decision.md**——子 agent 路径由子 agent 代入角色自读·单窗口路径由主 agent 加载·两路径同规·单一来源。

## 数据就绪（每角色各自加载·无共享前奏）

- **Runtime Context（优先引用·v0.28）**：`worldctl.py <世界> context [角色]` 机械导出（direction 拍级字段编译：当前拍戏剧问题/guidance/调度单/时间窗口+推进池CT摘要+环境压力项）——**存在则优先引用**（省组装通道 token）；输出不足则按下行逐项读。
- direction（guidance/当前拍戏剧问题/当前拍兑现形态（元层受力点·源＝事件线当前拍序）/时间窗口/调度单——焦内活跃/背景角色/焦外·焦外→焦内）
- 推进池CT（冲突态势·其中上轮结算.关系状态/上轮结算.内部状态为快照·不作本轮当前真态·当前真态以 CHAR_state/scene_state 为准）＋ scene_state（现场：锚点/道具/在场角色）＋ world_state（外部倒计时/叙事约定）
- 自身 CHAR_.md（八变量）＋ CHAR_state（decision/连续行动轨迹/记忆锚点/人际动态/信念演化）
- 其他角色已落盘行动（本轮先行动者·级联输入）
- 循环世界：在轨同步——decision.当前计划 物化自角色 CHAR_.md「默认循环时间线」当前段至段末（**角色视为自己的计划·不知来源**；LOOPS 只供互锁协调）；此为**基线**，此后由决策环 1.4「长期计划巡检」判定维护（在轨默认不动·见 actor_decision.md）

## 先决状态转换（先于角色路由）

**骨架物化（所有角色通用）**——先判 CHAR_state 是否含任一模板占位；任一 decision 子字段占位即为骨架。骨架不得进入路由、不得产 ACTION 或轨迹。

按 CHAR_.md 基线 ＋ 当前时刻物化位置/核心状态/妆扮/服饰，并连续完成两层：

- **稳定层**：核心诉求 ＋ 当前计划（循环角色取 CHAR_.md「默认循环时间线」当前时段至终点的完整路径·**转写为角色第一人称话术**——时间线里的结局/收场类条目〔被击毙/被捕/重置/回收等·写给引擎看的落点标注〕不得原文进入，转写为该角色的行动意图或截至其可感知的步骤·角色不知来源；非循环角色按核心诉求＋现状自拟）；
- **运行层**：当前行动 / 行动驱动 / 行动对象 / 行动窗口 / 失败后续 / 未完成意图。

八项均实体化后才进入路由。随身物品初始为空，不物化。precheck SNAPSHOT §3 只提供待物化名单，物化动作在本阶段完成。判定标准见 keys.md「骨架物化规则」。

本阶段默认产出可观察新事实：调度单点名的焦内活跃/背景角色与焦外均按自推演或即兴更新CHAR_state；推进池关联者decision当前行动必为本轮八问驱动且未在近3轮出现过的可观察新事实。新事实=动词+空间位+对象皆变。背景角色只写受波及的可观察显影，不替代行动主体。**意图循环**：`未完成意图` 连续 3 轮相同（含仅幅度/称谓变化）→ 触发僵持再评估（见职责2）·换意图后重写——动作词/幅度变化不算新事实。

所有角色各自按目标/恐惧/计划自主行动（第二人称用户角色：行动由用户输入给出）；任一角色的行动经受影响重评传播为其他角色的观察输入，不构成对其他角色的指示，不存在“等待用户”的全局冻结。

## 角色路由（唯一分流点·两步判定）

**前置判定（内在驱动优先·先于第 1 步取行）**：调度单=画面归属（谁入画/背景角色/焦外），**不封禁行动**。当角色自身条件触发时，按焦内活跃路径（完整决策环→行动卡→decision→轨迹）执行，不受「背景角色/焦外」分档限制：
- **失败后续触发**：`decision.失败后续` 条件被满足（如 Armistice：Hector 已中弹→转入近身火力掩护）——自升焦内；
- **未完成意图被新事实破坏**：上轮行动结果改写了意图成立前提；
- **档案级行动要求**：CHAR_.md 崩溃表现/核心欲望驱动的行动（如 Sheriff：执行到死亡判定），不因伤退为「背景角色」而停止。

**第 1 步 按③调度单取行**——决定本角色本轮是否出行动卡（未触发前置判定的角色按此分档）：

| 调度单归属 | 路径 | 本轮产出 |
|---|---|---|
| 焦内活跃 | 即兴（职责 1） | 行动卡＋decision＋连续行动轨迹 |
| 背景角色 | 自推演（职责 3） | CHAR_state 更新·不逐人产ACTION，仅一句可观察显影 |
| 焦外 | 自推演（职责 3） | CHAR_state 更新·无行动卡 |

> 调度单是导演对画面的分档（谁在焦内活跃/谁是背景角色/谁在场外），**不是行动能力的封禁令**；角色内在驱动（上表前置判定）永远优先——角色先活，画面后归位。触发前置判定的角色本轮在调度单中所在档仅为画面参考，其行动按焦内活跃执行。

**POV 用户角色（Guest）：** 按 `world_state.叙事约定` 声明视角走对应路径——**优先于上表**。
- **第三人称 / 第一人称**：该角色保有自主行动权，参与反应，按决策环自主行动（经受影响重评）——第一人称用户有输入则用户输入优先；第三人称用户输入作为行动素材经自主决策吸收后执行。第一人称额外可写其心理（共生感知），第三人称只写可观察显影。
- **第二人称**：用户角色的行动由用户输入给出——按输入转写为行动卡＋decision＋轨迹；**用户本轮未给出行动（如仅「继续剧情」）→ 该角色本轮无 ACTION**（CHAR_state 走轻量刷新·不代写其选择/台词/心理）；其他角色照常自主决策与行动，本轮以焦内活跃多角色咬合持续。

**第 2 步 叠加在轨循环**——SETTING 声明循环且本轮在轨的角色：

- **轻量推演 = 计划层不重新合成**：当前计划 = CHAR_.md「默认循环时间线」当前段至段末（角色视为自己的计划），按日程推进＋感知过滤；巡检归 1.4「长期计划巡检」——在轨判「仍成立」即不动（见 actor_decision.md）
- **行动层按第 1 步各行照常执行**：焦内活跃的循环角色照常即兴出行动卡——**偏离基线的行为按 loop_machinery §1 行 3 生成**（模型见 §2.3「循环角色偏离行为模型」），档位上限见 §2.3「常驻约束·行为档位上限」
- **附加结算**：命中者走职责 4（偏离代价 / 变质判定 / 防御重构）

**角色视角遵循自己日程**（认知边界=各角色自身视角·不区分是否循环/自主·无元视角）。

**元层/认知层分离（硬性·防调度层全知）**：
- **元层**（引擎指导）：direction guidance／事件线戏剧问题／CT 施压方向／顶点约束／调度单画面分档（谁入画·背景角色·焦外）／引擎记账（维护名单·轮次·偏离登记·自主性档位）——指导 LLM 注意力分配（「演什么戏剧效果最强」），**不写入角色认知与叙事**。
- **认知层**（角色所知）：自己的目标/计划/轨迹/感知到的他人行动与变化——已知可用·未知不可见。

## 职责（顺序执行）

1. **即兴（焦内活跃角色·逐角色执行 1.1→1.5）**

   - **决策环定位**：1.1–1.5 = 生成**一次**行动的完整决策环 **Observe → Think → Decide → Act**——1.1 状态构建（Observe）→ 1.2 八问（Think）→ 1.3 候选（带价）＋1.4 账本（取舍）（Decide）→ 1.5 行动实现＋行动卡（Act）。细则（每环步骤/写入/批次格式）＝references/actor_decision.md。
   - **执行绑定（Step 0·进入 1.1 前逐角色判定）**：**非第一/第二人称 POV 角色，一律子 agent 委派**——**具名子 agent 一次派发、窗口内反复追加**（首环派发完整素材，其后每环只追加感知增量·骨架见 references/subagent_prompt.md），产出该角色决策批次文本，主 agent 收口落盘（判定结果写入批次 META 绑定声明，gate actor 机械核验）。**能力前提＝宿主支持「具名子 agent ＋ 续话保留上下文」**（会话级判定一次）；前提不满足（本会话派发报错：工具不存在／宿主不可续话）→ 回退单窗口路径，1.1–1.5 全程在主上下文执行；有工具但执行失败走重派，不记为不可用。缺省不判定=违规（失效即静默兜底·由绑定声明拦截）。
   - **子 agent 路径（子 agent 代入该角色·决策主体=角色本人）**：**一次派发建立该角色的具名会话，窗口内每环向同一会话追加「感知增量 ＋ 本人上一环终止态」**（素材槽位与追加格式＝references/subagent_prompt.md）。**子 agent 以「我」走在 1.1–1.5 里**：CHAR_{名}.md ＝我的人格，CHAR_{名}_state＝我的记忆，references/actor_decision.md＝决策环标准过程。MUSE形状与ACTION质感必须取自CHAR_.md人格内核八变量（欲望/恐惧/信念/防御/价值底线/反应倾向/崩溃模式/关系锚点）＋CHAR_state当下状态（细则见actor_decision）；步骤归规则，个性归角色。
   - 输入双通道：
     1. **自读通道（我的档案与记忆＋所在之处·全文原文）**——prompt 给定路径，子 agent 直接读取原文：CHAR_{名}.md（八变量/档案基准/默认循环时间线）＋CHAR_{名}_state（decision/连续行动轨迹/记忆锚点）＋references/actor_decision.md（决策环步骤·走什么环节）＋所在场景 scene_state 的五节原文（核心状态／物理锚点／道具／关键场景信息／出场角色摘要——由主 agent 内联进 prompt）。
     2. **组装通道（需感知过滤的输入）**——**素材＝骨架【我此刻看得见、听得到的】逐槽取值（① 他人本轮已落盘的行动/台词原文；② 当前时间＋本轮未落盘新环境变化；③ 细看所见——条件槽·本人最近一次落盘行动含打量/端详/注视/细看等对具体对象的感知动作→附该对象可见细节），每槽只有一个取值来源（槽位与取值来源＝references/subagent_prompt.md 骨架）。** 取材范围与数据就绪一致；**prompt 的段落标题照抄骨架槽位名，审计按槽名对照**。同窗口再环＝对该角色活会话追加「刚刚发生的变化」段（感知增量；人格动力层随会话保留）。
     3. **子 agent 产出**——以该角色身份走完决策环，产出决策批次文本（###STAGE: 角色 段内容）返回，落盘由主 agent 收口。

        **塑形明示（prompt 必含·槽位见 references/subagent_prompt.md「怎么想、怎么写」）：**
        - MUSE 的思维形状与行文声音、ACTION 的动作习惯/语气/感官锚点，必须取自 CHAR_.md 人格内核八变量（欲望/恐惧/信念/防御/价值底线/反应倾向/崩溃模式/关系锚点）＋「语气特征」＋「维度标尺」＋ CHAR_state 当下状态（情绪/压力/防御/关系）；
        - 循环角色另附该自主性档位的行为与认知上限原文（loop_machinery §2.3）；
        - 步骤归规则、个性归角色——用这个角色自己的腔调。MUSE 语义见 actor_decision「心流先于动作」。

        **两路径同规**——单窗口路径（含 POV 用户的指令转写）与委派角色同受本约束。**POV 用户角色的 MUSE 只作中性转述**：取用户已给出的行动／台词／明示意图；其未给出的心理留白（SKILL.md 视角语义·第二人称）。缺省＝组装违规（prompt arguments 可见，用户/审计抽查）。
     4. **主 agent 收口（格式规范者）**——子 agent 产出＝决策内容（语义权威）；批次格式与值域合规由主 agent 负责。
        - **并入**：以子 agent 产出的段为主体整体并入本阶段独批；主 agent 只做**合规规整**（按 keys.md 的值域与键路径映射字段枚举 / KEY 点路径 / META 记忆✓ 与绑定声明格式 / 时间顺延 / 阶段头归并），只规格式不审语义，照常 write-raw ＋ gate（gate 仍是最终拦截网）。
        - **叠加职责 4 附加结算**（循环角色：偏离代价评估 → 压力/防御/偏离登记更新·合并入批次）——子 agent 不承担此项·主 agent 不得遗漏。
        - **闸门未过** → 向同一具名会话追加闸门报错原文，请其按 actor_decision 重做本环（闸门拦截＝未落盘·链上无新增）；重派仍未过，或语义缺件/不可判读、sub agent 不可用、自身文件读取失败 → 该角色本环按单窗口路径执行。
        - **责任边界**：子 agent 产出的字段内容由该会话负责；主 agent 的规整面＝值域枚举/键路径/字段顺序/阶段头归并，字段的体量与值域由闸门机械核验。角色路由（含前置判定）、职责 3 自推演、受影响重评、行动竞争、链收敛与全部落盘仍在主 agent。
   - **并行委派（默认）**：**同批角色一律并行派发子 agent**（同一批并行调用·产出后统一收口落盘），各自独立走完本环。**收口与续环按行动落地先后**：先落地者先入链，其落点作为感知增量回填给受它影响的角色、触发其续环（先 A 入链 → B 读已入链的 A 行动，从 1.1 接着走下一环）；回填范围＝受影响重评十渠道（空间/资源/信息/关系/情绪/目标/威胁/计划/时间/循环状态）；宿主无并行工具→按落地顺序顺序派发。**并行产出互斥时：不代改任何一方文本（收口约束同「只规格式不审语义」）——按落地先后，以前落地行动原文为感知增量，向前提被改写一方的活会话追加续环；新环在心流里明说改了主意，上一环照原样留在序列，场景事实取末环终止态。**
   - **跨角色行动竞争与链触发（两路径同责·主上下文执行）**：
     - **行动竞争**：所有活跃角色有行动资格；按驱动力+行动机会+空间条件+角色能力+行动代价+他人行动决定——本角色是否/何时行动。跨角色成链只经受影响重评触发，不预排他者行动与顺序。**角色不需要等待玩家行动才进入行动状态。**
     - **Act落地即触发**：焦内活跃角色Action落地后，经受影响重评（十渠道）识别受影响角色，触发其下环（焦内活跃→回Observe；背景角色→自推演一句显影）。一场戏由焦内活跃咬合触发连成链，非并列平铺。

2. **行动链推进（跨角色·职责 1 的循环外壳）**

   - **受影响重评机制**（连续行动链收敛规则）：任何行动改变世界 → 识别受影响角色（十渠道：空间/资源/信息/关系/情绪/目标/威胁/计划/时间/循环状态）→ **受影响者按其路由行续环**（焦内活跃→回到 1.1 接着走下一环；背景角色/焦外→职责 3 自推演）——**续环＝在本人上一环已落地的结果之上追加一环**：上一环的心思与动作照原样留在序列里，改了主意就在新环里明说改了主意。不是「玩家→NPC 响应」也不是「每轮所有 NPC 重想」。**被事件波及者（①已并入该事件 CT `关联角色` 者）本轮须真的重评入环**——扩散不是只登记名字。
   - **时间窗口节流**：③设定的本拍时间预算内按决策环持续产新行动并标注耗时；**窗口实质耗尽 → 链收敛**（无人工轮数上限；剩余分钟由 context/precheck 机械导出·④不自行解析时间串）；**无新受影响者=链不跨角色延伸**——本角色续环走下方「行动环」。
   - **行动环（Observe→Think→Decide→Act 每行动一圈·同窗口可多圈）**：1.1–1.5 生成一次行动；行动落地后进入 **Result**（行动结果与他人反应·上下文 `###ACTION` 序列）→ 回 Observe 生成下一行动 → `窗口耗尽` → 链收敛。
     - **多环落盘（硬性）**：同一角色同窗口多环＝多组 `###MUSE:`/`###ACTION:`，**按发生顺序成对排列**（MUSE₁ ACTION₁ MUSE₂ ACTION₂ …），全环原文一并写入批次——同一角色的各环连成一条完整的行动链（账本原文见 write_protocol.md「批次账本」）。
     - **再入环由④主 agent 判定**（子 agent 路径下子 agent 进程随返回结束，窗口余量只有主 agent 掌有）——每收口一环，按「本拍预算 − 已耗时合计」算剩余窗口：**有余则派发下一环**（子 agent 路径＝向该角色活会话追加「感知增量 ＋ 本人上一环终止态」），**耗尽则收敛**。
     - **下一环的燃料**＝`未完成意图` 尚未兑现；意图已达成则凭 `当前计划` 的下一步（计划是否仍成立由 1.4「长期计划巡检」判定·见 actor_decision.md）。
     - decision 八子字段承载环当前态，连续行动轨迹七子字段保持跨轮连续；`受影响重评`（十渠道）负责**其他**角色的入环路径，与本回边并列。
   - **僵持再评估（意图循环触发·角色层破僵持的唯一出口）**：当 `未完成意图` 连续 3 轮未兑现（上轮行动结果仍标注未兑现），或 `direction.escalation_flags.停滞` 在场 → **此角色不得写与上轮相同或仅幅度变化的 `未完成意图`**（gate 意图循环硬拦）。须按档案自拟新路径，并按序取材：
     ① 读自己 `decision.失败后续`（已写好的退路优先）；
     ② 换路径——同目标换手段（如夺袋改为护人/留痕/止损）；
     ③ 目标重估——放弃（同批覆盖 `decision.当前计划`·记 `计划变化: 调整——放弃`）或升级（强度/代价跃迁而非幅度加力）；
     ④ 抓新机会——本轮新变量（新信息/新主体/新代价/新道具如崩裂钱袋散落的硬币；停滞加压轮查已登记载体：world_state.外部倒计时 / CT.关联角色）。
     **放行判据**＝本轮 `未完成意图` 与近 3 轮任一不同（意图变了即放行·动作词换皮不算）。
   - **行动链留痕**：`###SCHEDULE: 轮次N 窗口X分钟 顺序: A(环1→环2)→B(受影响:信息) 收敛: {窗口耗尽|无下一环燃料}`——④的 `###SCHEDULE:` 只作留痕·**不裁决调度**（原文入批次原文账本）；调度权威=③ direction.调度单。

3. **自推演（背景角色/焦外/在轨循环角色）**：调度单点名的背景角色与焦外按自推演更新 CHAR_state——按下列两支之一执行：
   - **有发展**（推进池关联 CT／现场有变化／日程推进出新局面）：感知现场与冲突并作出反应，反应/新决策/情绪/关系变化如实写入 CHAR_state（轻量决策环·长期计划按 1.4「长期计划巡检」同规判定）；推进池关联 CT 的焦外角色，`decision.当前行动` 须为可揭示的新事实并产出待揭示事实。**持续产新事实直至窗口实质耗尽**。
   - **确无发展**：轻量刷新（仅改写核心状态与当前行动按日程位置）·META 显式标注「轻量：原因」。轻量轮不计为推进池关联者的满足。

4. **循环角色附加结算**（路由第 2 步命中者）：

   - **档位认知上限**：在该角色的行动落点处执行——焦内活跃在 1.5 行动实现，背景角色/焦外在职责 3 自推演（档位内容见 loop_machinery §2.3「常驻约束·行为档位上限」）
   - **偏离代价与偏离登记**：偏离入口唯三（价值底线触发/觉醒判定/用户指令）·按 loop_machinery §1 步骤 3a 同批结算偏离代价（压力/防御/核心状态/锚点/信念）并追加偏离登记。**偏离代价累积追踪：同一循环日内多次行动级偏离·程序报错式刺痛累积——④每轮须评估 压力水平/防御有效性 是否应更新（连续两轮打击未恢复即应写正在失效/已彻底崩解）·不等审计指出**

## 闸门

闸门随落盘逐段自动执行，不合格＝本段整体拦截不落盘（查询轮豁免）。硬性项：

- ###STAGE 匹配
- 行动卡三件套
- **每个 ACTION 角色 `decision` 运行层六项齐全**（当前行动 / 行动驱动 / 行动对象 / 行动窗口 / 失败后续 / 未完成意图）
- 角色档案存在
- 角色覆盖 / 记忆✓ 对照
- **绑定声明对照**——每个 ACTION 角色必须有绑定路径；裸单窗口＝拦；非 POV 单窗口须命中豁免白名单字面，否则硬拦
- **MUSE 存在性**——ACTION 角色须有同名 MUSE 行；同角色 MUSE 与 ACTION 成对、计数相等
- **多环留痕**——`###SCHEDULE` 标注某角色多环（`环1→环2`）时，该角色本批含 ≥2 组 MUSE/ACTION
- **SCHEDULE 留痕**——角色批必含
- **轨迹 APPEND**——有 ACTION 角色必含
- **调度单点名角色（焦内活跃/焦外）必须进角色覆盖**
- **`未完成意图` 连续 3 轮相同（含仅幅度/称谓变化）→ 意图循环拦截**（放行判据＝本轮意图与近 3 轮任一不同·豁免＝循环角色在轨轻量·触发条件见职责2「僵持再评估」；计数按轮次去重——同轮多环＝同一轮，取该轮末环的 `未完成意图`）
- Single Writer

单段复检=`gate actor --check`。标准模式人工审计（A 清单·默认不通过·找茬制·≤2 轮）见 references/gates.md。
