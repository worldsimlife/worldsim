# 阶段④ · 角色（生命层·阶段开始前必读）

> 本阶段是引擎的心脏：**角色从被动执行者升级为自主即兴的生命层**——主动决策、持续行动、直写自己的状态文件。
> 全局铁律=SKILL.md「通用约束」；**阶段④=所有角色状态唯一写者**（Single Writer：CHAR_{名}_state）。
> 决策与写入规则（自治原则/决策环/写入/批次格式）＝**references/actor_decision.md**·单一来源。
> **编号约定**：编排层判定＝`On`（主 agent 做·本文件）；角色决策＝`Dn`（角色本人做·定义于 actor_decision.md）。

## 数据就绪（每角色各自加载·无共享前奏）

- **Runtime Context（优先引用）**：`worldctl.py <世界> context [角色]` 机械导出（direction 拍级字段编译：当前拍戏剧问题/guidance/调度单/时间窗口/转场＋推进池 CT 摘要＋环境压力项）——**存在则优先引用**（省组装通道 token）；输出不足则按下项逐项读。
- direction（**`guidance`＝镜头指示·归⑥作家·不生成角色行动** / 当前拍戏剧问题 / 当前拍兑现形态（元层受力点·源＝事件线当前拍序）/ 时间窗口 / 调度单——焦内活跃·背景角色·焦外·焦外→焦内 / **转场**）
- **转场承接（硬性）**：`direction.转场.目标场景` 非空 → ③ 已判「切换场景」——**POV 角色的 `位置` 本轮须落为该目标场景**（分工＝③ 判「去」写 `转场` → ④ 落卡写 `位置` → ⑤ 执行·见 phase_director D4 结果语义）；⑤ 随后按 scene_management.md 场景切换流程执行。**判据：转场非空而 POV `位置` 未落到目标场景 ＝ ④ 漏承接**（round-check 区域一致性/转场执行核验 FAIL）。
- 推进池 CT（冲突态势·其中 上轮结算.关系状态/上轮结算.内部状态 为快照·不作本轮当前真态·当前真态以 CHAR_state/scene_state 为准）＋ scene_state（现场：锚点/道具/在场角色/场景时间线）＋ world_state（外部倒计时/叙事约定/轮次）
- 自身 CHAR_.md（八变量·含「默认循环时间线」）＋ CHAR_state（位置/decision/连续行动轨迹/记忆锚点/人际动态/信念演化/偏离登记）
- 其他角色已落盘行动（本轮先行动者·级联输入）
- 循环世界：在轨同步——decision.当前计划 物化自 CHAR_.md「默认循环时间线」当前段至段末（**角色视为自己的计划·不知来源**；LOOPS 只供互锁协调）；此为**基线**，此后由 **actor_decision.md D3 长期计划巡检** 判定维护（在轨默认**不重写计划**——计划里的活项仍按钟点照常推进）

本阶段产出＝**结构化决策＋自由即兴＋状态写入**三类。LLM 对每个决策**只返回决策结果（枚举值＋参数）**；结果到字段的映射是机械管道（见 actor_decision.md 写入节）。

| 序 | 决策 | 问题 | 可选结果 | 缺省 | 落盘 |
|---|---|---|---|---|---|
| O1 | 角色路由 | 本角色本轮走哪条路径？ | `即兴`/`自推演` | 按调度单档位 | 产出路径 |
| O2 | 执行绑定 | 本角色决策环由谁执行？ | `子agent`/`单窗口`（参数＝豁免原因） | 子agent | META `绑定:` |
| O3 | 自推演分支 | 这一轮往前走了一步吗？ | `有发展`/`确无发展` | 有发展 | CHAR_state 更新 |
| O4 | 偏离判定 | 本循环角色本轮是否行动级偏离？ | `无偏离`/`偏离`/`累积偏离` | 无偏离 | CHAR_state.偏离登记（偏离时）＋ META `偏离判定✓(...)` |

> **角色决策 `D1–D6`（角色本人做）定义于 actor_decision.md**——该文件由子 agent 独立读取·自带同款索引；下方执行链中出现的 D 编号即指彼处。

**执行链（逐角色）**：`数据就绪 → 骨架物化（前置分支）→ O1 角色路由 → O2 执行绑定 → 焦内活跃＝即兴（职责1·单圈：决策环·含 D1/D2/D3/D4 ＋ 写入 D5/D6）｜背景/焦外＝O3 自推演 → 职责2 行动环续走与跨角色推进（至链收敛） → 职责4 附加结算（逐循环角色·O4 偏离判定→结算） → 批次落盘`

**决策执行机制（本文件决策·三步）**：① 读「决策问题」→ ② 逐「决策选项」对照「选中标准」判定命中（多选项命中·按声明优先序取先）→ ③ 返回命中枚举值＋「参数」。本文件决策均为**判定型**（有缺省）。

**创造核心保持开放（非决策·不设枚举契约）**：决策环内的候选行动生成与取舍＝角色自治创造（候选清单仅为启发示例）；MUSE/ACTION 正文＝prose 面。

## 先决状态转换（骨架物化）

**所有角色通用**——先判 CHAR_state 是否含任一模板占位；任一 decision 子字段占位即为骨架。骨架不得进入路由、不得产 ACTION 或轨迹。

按 CHAR_.md 基线 ＋ 当前时刻物化位置/核心状态/妆扮/服饰，并连续完成两层：

- **稳定层**：核心诉求 ＋ 当前计划
  - 循环角色取 CHAR_.md「默认循环时间线」当前时段至终点的完整路径
  - **转写为角色第一人称话术**——时间线里的结局/收场类条目〔被击毙/被捕/重置/回收等·写给引擎看的落点标注〕不得原文进入，转写为该角色的行动意图或截至其可感知的步骤·角色不知来源
  - 非循环角色按核心诉求＋现状自拟
- **运行层**：当前行动 / 行动驱动 / 行动对象 / 行动窗口 / 失败后续 / 未完成意图

八项均实体化后才进入路由。随身物品初始为空，不物化。precheck SNAPSHOT §3 只提供待物化名单，物化动作在本阶段完成。判定标准见 keys.md「骨架物化规则」。

本阶段默认产出可观察新事实：调度单点名的焦内活跃/背景角色与焦外均按自推演或即兴更新 CHAR_state；推进池关联者 decision.当前行动 必为本轮思考驱动且未在近 3 轮出现过的可观察新事实。**新事实＝动词＋空间位＋对象皆变**。背景角色只写受波及的可观察显影，不替代行动主体。

**意图循环**：`未完成意图` 整组连续 3 轮无变化（条目、对象、动作都不换，含仅幅度/称谓变化）→ 触发僵持再评估（见职责 2）·换过任一条后重写——动作词/幅度变化不算新事实。

所有角色各自按目标/恐惧/计划自主行动（第二人称用户角色：行动由用户输入给出）；任一角色的行动经受影响重评传播为其他角色的观察输入，不构成对其他角色的指示，不存在「等待用户」的全局冻结。

## 概念约束：元层 / 认知层分离（硬性·防调度层全知）

- **元层**（引擎指导）：direction guidance／事件线戏剧问题／CT 施压方向／顶点约束／调度单画面分档（谁入画·背景角色·焦外）／引擎记账（维护名单·轮次·偏离登记·自主性档位）——指导 LLM 注意力分配（「演什么戏剧效果最强」），**不写入角色认知与叙事**。
- **认知层**（角色所知）：自己的目标/计划/轨迹/感知到的他人行动与变化——已知可用·未知不可见。

## 编排

### O1 角色路由（判定型·唯一分流点）

**决策问题**：本角色本轮走哪条路径？
**缺省选项**：按③调度单档位（`焦内活跃`→`即兴`／`背景角色`·`焦外`→`自推演`）

**决策选项与选中标准**:
- `即兴` — ③调度单列 `焦内活跃`（或前置判定触发·见下）→ 职责 1（完整决策环→行动卡→decision→轨迹）
- `自推演` — ③调度单列 `背景角色`/`焦外` → 职责 3

**前置分支（先于选项评估·不实现为模式）**:
- **骨架物化** — CHAR_state 含任一模板占位 → 先走「先决状态转换」物化，本轮不产行动。
- **前置判定（内在驱动优先）** — 调度单=画面归属（谁入画/背景角色/焦外），**不封禁行动**。角色自身条件触发时按 `即兴` 路径执行，不受分档限制：
  - **失败后续触发** — `decision.失败后续` 条件被满足（如 Armistice：Hector 已中弹→转入近身火力掩护）→ 自升焦内
  - **未完成意图被新事实破坏** — 上轮行动结果改写了意图成立前提
  - **档案级行动要求** — CHAR_.md 崩溃表现/核心欲望驱动的行动（如 Sheriff：执行到死亡判定），不因伤退为「背景角色」而停止
- **POV 覆盖** — `world_state.叙事约定` 声明的 POV 用户角色优先于取行表（见下）。

#### 取行表（未触发前置判定的角色按此分档）

| 调度单归属 | 路径 | 本轮产出 |
|---|---|---|
| 焦内活跃 | 即兴（职责 1） | 行动卡＋decision＋连续行动轨迹 |
| 背景角色 | 自推演（职责 3） | CHAR_state 更新·不逐人产 ACTION，仅一句可观察显影 |
| 焦外 | 自推演（职责 3） | CHAR_state 更新·无行动卡 |

> 调度单是导演对画面的分档（谁在焦内活跃/谁是背景角色/谁在场外），**不是行动能力的封禁令**；角色内在驱动（前置判定）永远优先——角色先活，画面后归位。触发前置判定的角色本轮在调度单中所在档仅为画面参考，其行动按焦内活跃执行。

#### POV 用户角色（Guest）

按 `world_state.叙事约定` 声明视角走对应路径·**优先于取行表**：

- **第三人称 / 第一人称** — 该角色保有自主行动权，参与反应，按决策环自主行动（经受影响重评）。第一人称用户有输入则用户输入优先；第三人称用户输入作为行动素材经自主决策吸收后执行。第一人称额外可写其心理（共生感知），第三人称只写可观察显影。
- **第二人称** — 用户角色的行动由用户输入给出，按输入转写为行动卡＋decision＋轨迹；**续环派发同规**——涉及其行动/反应的槽只填已落盘的 POV 卡原文·**不补写其反应**（授权 ≠ 反应·见本文件「POV 用户角色（第二人称）：卡格式与 MUSE」）；其他角色照常自主决策与行动，本轮以焦内活跃多角色咬合持续。

#### 叠加在轨循环（SETTING 声明循环且本轮在轨的角色）

- **轻量推演＝计划层不重新合成** — 当前计划＝CHAR_.md「默认循环时间线」当前段至段末（角色视为自己的计划），按日程推进＋感知过滤；巡检归 **actor_decision.md D3 长期计划巡检**——在轨判「仍成立」即不重写计划
- **行动层照常执行** — 焦内活跃的循环角色照常即兴出行动卡；**偏离基线的行为按 loop_machinery §1 行 3 生成**（模型见 §2.3「循环角色偏离行为模型」），档位上限见 §2.3「常驻约束·行为档位上限」
- **附加结算** — 命中者走职责 4（偏离代价 / 变质判定 / 防御重构）

**角色视角遵循自己日程**（认知边界＝各角色自身视角·不区分是否循环/自主·无元视角）。

### O2 执行绑定（判定型·Step 0·进入决策环前逐角色判定）

**决策问题**：本角色决策环由谁执行？
**缺省选项**：`子agent`

**决策选项与选中标准**:
- `子agent` — 非第一/第二人称 POV 角色 ∧ 宿主支持「具名子 agent ＋ 续话保留上下文」
- `单窗口` — 第一/第二人称 POV 角色（用户指令转写）；或宿主不支持子 agent（本会话派发报错：`子agent不可用`／`工具不存在`／`宿主不可续话`）

**参数**：
- `子agent` → `会话名`（建档建立、续环沿用；写进 META 绑定声明）
- `单窗口` → 豁免原因（写进 META 绑定声明）

**结果语义**：绑定声明经 gate actor 机械核验；有工具但执行失败走重派，不记为不可用；缺省不判定＝违规（失效即静默兜底·由绑定声明拦截）。

## 职责 1 · 即兴（决策环外壳）

焦内活跃角色·逐角色走完**一环**。**决策环细则（每环步骤 / MUSE 语义 / 写入 / 批次格式）＝ actor_decision.md**——本职责只承载编排面（谁走哪条路、怎么派发与规范化）；**POV 用户角色的卡格式与 MUSE 例外＝本职责「共通约束」**；**多圈续走与跨角色推进＝职责 2**。

### 共通约束（两路径同责）

#### POV 用户角色（第二人称）：卡格式与 MUSE

卡格式与其他角色相同；下列为差异项。

- **MUSE**：用户指令原文逐字进入；拆环时按原文切分。不增写用户未给的心理·不剥除用户已给的心理。
- **正文**：用户给的动作、台词、心理、感知照原意写，按 ACTION 卡与 `decision` 字段的格式展开到可执行、可显影、可落状态；不补用户没给的神态、情绪判断、他人反应。
- **密度**：只在用户给出的范围内展开。
- **驱动**：用户明说动机就用；没明说，写用户指令原文。
- **情绪**：用户给出则用，写入 ACTION `情绪:` 字段（不另造显影）；未给出按输入推导。
- **强度、耗时、代价**：与其他人同判据。
- **形态**：输入是行动，正文必须有那件行动。
- **在途**：输入是行动、当前空间暂无执行形态 → 正文按意图写（推进、待到达），`decision.未完成意图` 记「意图X·受阻于Y」。
- **心理留白**：其未给出的心理不补（SKILL.md 视角语义·第二人称）。
- **缺省＝组装违规**（prompt arguments 可见，用户/审计抽查）。

### 子 agent 路径（非 POV 默认·子 agent 代入该角色·决策主体=角色本人）

**建档派发建立该角色的具名会话；有绑定则每环向同一会话追加「我此刻的状态 ＋ 感知增量（含本人上一环终止态）」**（建档派发完整素材·素材槽位与追加格式＝references/subagent_prompt.md；建档/续环判据与「禁止重贴档案」以该文件首段为准）。

**子 agent 以「我」走在决策环里**：CHAR_{名}.md＝我的人格，CHAR_{名}_state＝我的记忆，references/actor_decision.md＝决策环标准过程；步骤归规则，个性归角色。

#### 输入通道（组装为主·过程规则自读）

1. **组装通道（世界事实与人格记忆·主 agent 逐字内联）**——子 agent 零世界文件读取：
   - **内联内容（先按 subagent_prompt.md「组装转换矩阵」处理·再逐字内联）** — CHAR_{名}.md ＋ CHAR_{名}_state ＋ 所在场景 scene_state 五节 ＋ 场景时间线中该角色**可感知**的相关条目 ＋ 本轮台词/行动**指涉历史事件**的权威原文
   - **内联口径（硬性）** — 逐字原文——除按矩阵剔/转外一字不改，禁止转述摘要
   - **档位转换** — 按 subagent_prompt.md「组装转换矩阵」（触发＝素材类型×自主性档位×特殊状态）裁剪或转换为该档位可知形式——档位语义以 loop_machinery §2.3 为唯一权威
   - **感知增量槽** — 他人本轮已落盘的行动/台词原文 ＋ 当前时间 ＋ 本轮未落盘新环境变化 ＋ 细看所见（条件槽·本人最近一次落盘行动含打量/端详/注视/细看等对具体对象的感知动作→附该对象可见细节）；每槽只有一个取值来源（槽位与取值来源＝subagent_prompt.md 骨架）
   - **POV 用户角色的槽填充（硬性）** — 该角色的行动**由用户输入给出**：涉及其行动/反应的槽**只填已落盘的 POV ACTION 卡原文**，**卡里没有的部分不填**——**不补写其动作/表情/注视/沉默/心理**（授权 ≠ 反应：「接受全套服务」＝可自主推进多环的授权，不等于允许代写其反应）（卡格式与 MUSE 口径见本文件「POV 用户角色（第二人称）：卡格式与 MUSE」·矩阵判据见 subagent_prompt.md §一矩阵「场景/他人/历史」行）
   - **槽位纪律** — prompt 的段落标题照抄骨架槽位名，审计按槽名对照
   - **同窗口再环** — 对该角色活会话追加「我此刻的状态」＋「刚刚发生的变化」两段（状态＝`decision.当前计划`／`未完成意图` 逐字原文·本人上一轮所写·骨架＝subagent_prompt.md §二；增量＝感知增量；人格动力层随会话保留；本环场景切换时另附【我所在之处】）
2. **自读通道（过程规则·仅此一项）**——prompt 给定路径，子 agent 自读 references/actor_decision.md（决策环步骤·产出格式）；无认知边界风险，不内联。
3. **子 agent 产出**——以该角色身份走完决策环，产出决策批次文本（###STAGE: 角色 段内容）返回；由主 agent **产出规范化**后并入本阶段批次（见下）。

#### 产出规范化（主 agent·每次返回）

子 agent 产出＝决策内容（语义权威）；批次格式与值域合规由主 agent 负责：

- **规整** — 按 keys.md 的值域与键路径映射字段枚举 / KEY 点路径 / META 记忆✓ 与绑定声明格式 / 时间顺延 / 阶段头归并；**MUSE／ACTION／decision 及其余写入值不得删改**
- **责任边界** — 子 agent 产出的字段内容由该会话负责；字段的体量与值域由闸门机械核验。角色路由（含前置判定）、职责 3 自推演、受影响重评、链收敛与全部落盘仍在主 agent

#### 并行委派（默认）

**同批角色一律并行派发子 agent**（同一批并行调用），各自独立走完本环；产出后统一**入链**（见职责 2 行动环「派发」），入链毕**批次落盘**：

- **宿主无并行工具** → 逐个顺序派发（走完一个再派下一个）

### 单窗口路径（POV 默认 / 回退·主上下文执行）

- **输入** ＝ 「数据就绪」节逐角色加载（已读入）＋ 按 `subagent_prompt.md` §一/§二/§三 逐槽核对：先【我所在之处】【我此刻看得见、听得到的】（在场他人/持械/伤/新变化），后用户台词；主 agent 直接读取，不组装内联
- **输入仍须过滤与隔离** — 素材按 `subagent_prompt.md` §一「组装转换矩阵」三态处理（原文照读·按认知转写·不进入）；元层与其他角色的 `###MUSE` 不进入该角色认知（判据＝本文件「概念约束：元层／认知层分离」＋职责 2「入链」）
- **执行** ＝ 主 agent 代入该角色在主上下文自走决策环，上方共通段约束同施
- **闸门未过** → 主 agent 代入该角色**再走一环**（按 actor_decision.md）；该环按 `·自环` 入链。闸门拦截＝盘上零副作用——被拦的环**已走完并入链**，仅未落盘
- **绑定声明** ＝ `单窗口(豁免原因·核对✓)`——POV 写视角依据（如 `单窗口(第二人称POV·用户指令转写·核对✓)`）；非 POV 须命中豁免白名单字面（见 actor_decision.md「META 绑定声明」）

## 职责 2 · 行动链推进（跨角色）

### 行动环（同窗口多圈·循环至收敛）

焦内活跃角色走完一环后**持续走环**——行动入链 → 进 **Result**（行动结果与他人反应·上下文 `###ACTION` 序列）→ 回 Observe → 生成下一行动 → …，直至收敛。

**派发（逐角色触发·每环边界）**

- **本环追加名单** — ① **焦内活跃角色全员**（各自的自环续行·名单＝③调度单）；② **受影响者**（受影响重评十渠道识别；背景/焦外按其路由行走职责 3 自推演）。
- **追加下一环** — 名单内每个角色都要追加；同批**并行**派发，各自独立走环（互不可见对方本次未返回的产出）：子 agent 路径＝向该角色**具名活会话追加**（**禁止重派新会话或重贴档案**·格式＝职责 1 子 agent 路径）；单窗口路径＝主 agent 在主上下文**重入职责 1**。
- **状态槽必附（硬性）** — 每环追加都带「我此刻的状态」（`当前计划`／`未完成意图` 逐字原文·骨架＝subagent_prompt.md §二）。`未完成意图` 缺失、或只剩观察点时，槽内写「（本环尚无·由我本环定）」，由角色本环自己写；派发方**不得代写、不得把流程步骤名塞进这个槽**——那等于替角色定待办。
- **入链** — 全部返回后按**返回先后**入链；先入链者的 `###ACTION` 原文作为感知增量**回填**给后入链者（其下一环带上·范围＝十渠道）。**互斥时**不代改任何一方文本——按返回先后，以先入链者的 `###ACTION` 原文为感知增量，向**前提被改写的一方**追加一环重评（新环明说改了主意；上一环照原样留在序列）。
- **留痕** — 入链次序逐环记入 `###SCHEDULE` **顺序段**；只作留痕·不裁决调度。

**角色在本环内自判（语义面）**：本环有没有行动 ＝ **actor_decision.md D4 行动有无判定**（角色本人做）——走完输入材料与 ①–⑦ 后由角色自己作出，**把本轮新输入一并读进去**（对方的授权/催促/沉默/新事实都可能改变「我还要不要等」）。**有要做的事 → 判 `有`·产 ACTION；此刻没有值得做的事 → 判 `无`·本环不产 ACTION（只交回该环 MUSE）**。**该判定只能由角色作出**——主 agent 在派发环节判「未选中／无事可做」并据此跳过唤醒 ＝ 替代角色自判（违规）；「无事可做」不得由编排层认定（链收敛节同规）。

**收敛核对（每环入链后，读本环产出判）**：除下列**两项**外，**一律追加下一环**——

- **窗口耗尽** — 本轮剩余（脚本值 − 本批已产耗时）≤ 0
- **待用户新行动** — **先查输入原文**：本环 `###MUSE` 所等/待/候的动作，若用户本轮输入原文已给出 → 判 `否`，继续走环（不把「等他把当前动作做完」当停链理由）。**再判** `###MUSE` 是否明确含有等用户角色**新**行动的内容（等/待/候其开口·回应·行动，如「看他会不会先伸手」；“希望用户接话”不算），判是；否则判否。对照面＝本环 MUSE 原文，不设想未发生的环。判是须在 `###SCHEDULE` 收敛段写出所指（等什么行动），与 MUSE 中的等候内容一致。

> **零卡环不结束走环（硬性）**：角色判 `无`（actor_decision.md D4 行动有无判定）→ 该环不产 ACTION（留 MUSE·顺序段标 `(环N·零卡)`），仅表示**这一环无 ACTION**——**它不是收敛条件**；下一环边界该角色照常被追加。结束走环只有上面两条。

**多环落盘（硬性）**：同一角色同窗口多环 ＝ 每环一组（有 ACTION 的环＝`###MUSE:`＋`###ACTION:`·零卡环＝仅 `###MUSE:`），**按发生顺序排列**（MUSE₁ ACTION₁ MUSE₂ ACTION₂ …），全环原文一并写入批次；`连续行动轨迹` **每环一条**（账本原文见 write_protocol.md「批次账本」）。

**行动链留痕**：`###SCHEDULE: 轮次N 窗口X分钟 顺序: A(环1)→B(环1·受影响:信息)→A(环2·受影响:信息)→A(环3·自环) 收敛: A=窗口否·待用户是·等B先动 / B=窗口否·待用户是·等A先开口`——**顺序段**按实际入链次序逐环列出，禁合并写法，续环条目须标输入来源（`·受影响:{渠道}`＝他者触发 或 `·自环`＝本人上一环延续）；**零 ACTION 的环照列·标 `(环N·零卡)`**（零卡环＝角色判 `无`·actor_decision.md D4·该环留 MUSE 无 ACTION·**可出现在任意位置**——零卡不结束走环）；**收敛段**逐角色记录**该角色末环**的收敛核对结论（**两项齐全**：`窗口`否/是·`待用户`否/是；`待用户是`须带所指）；**收敛前逐角色先过输入例外**（MUSE 所等动作若用户输入已给出 → `待用户否`·继续走环），`窗口否` 且全员 `待用户是` 时强制复核，防提前收链——批次是一轮的完整产出，链必已收敛，**不得出现两项皆否**（皆否＝该角色本应续环，只可能由窗口耗尽收束）；只作留痕·**不裁决调度**；调度权威＝③ direction.调度单。

### 链触发（Action 入链即触发）

焦内活跃角色 Action 入链后，经受影响重评（十渠道）识别受影响角色，触发其下环（焦内活跃→回 Observe；背景角色→自推演一句显影）。一场戏由焦内活跃咬合触发连成链，**非并列平铺**。

### 受影响重评机制（连续行动链收敛规则）

任何行动改变世界：

1. 识别受影响角色（十渠道：空间/资源/信息/关系/情绪/目标/威胁/计划/时间/循环状态）
2. **受影响者按其路由行入环**（焦内活跃→回职责 1 走下一环；背景角色/焦外→职责 3 自推演）

**入环＝在本人上一环已入链的结果之上追加一环**：上一环的心思与动作照原样留在序列里，改了主意就在新环里明说改了主意。不是「玩家→NPC 响应」也不是「每轮所有 NPC 重想」。**被事件波及者（①已并入该事件 CT `关联角色` 者）本轮须真的重评入环**——扩散不是只登记名字。

`受影响重评`（十渠道）负责**其他**角色的入环路径，与行动环的回边并列；decision 八子字段承载环当前态，连续行动轨迹七子字段保持跨轮连续。

### 链收敛（全局·两条件封闭）

**链停 ⟺ 窗口耗尽 ∨ 全部入链角色皆已命中「待用户新行动」。**

- 两条件是**封闭集合**——除此之外不得以任何理由结束走环（含编排层自行判定「无事可做 / 无燃料」——判定权归角色）。
- 两层级：**行动环**（单角色）两条件任一即停；**行动链**（全局）须全部角色皆停。
- **零卡不是收敛条件**：角色判 `无` 只让该环无 ACTION，不结束走环（见上「行动环·收敛核对」）。

### 时间窗口节流

③设定的本拍时间预算内按决策环持续产新行动并标注耗时：

- **窗口实质耗尽 → 链收敛**（无人工轮数上限）
- **无新受影响者 ＝ 链不跨角色延伸**——本角色续走行动环（本节）
- **窗口起点/预算由脚本随 `###BEAT` 落·④ 不逐轮重写**（只在现场重估时覆盖并写理由）——已耗＝世界时间−起点·由 precheck 机械导出

### 僵持再评估（前置分支·意图循环触发·角色层破僵持的唯一出口）

当 `未完成意图` 整组连续 3 轮未兑现（上轮行动结果仍标注未兑现），或 `direction.escalation_flags.停滞` 在场 → **此角色不得写得与上轮整组相同、或只换幅度与称谓**（gate 意图循环硬拦）。须按档案自拟新路径，并按序取材（取材序非决策）：

1. 读自己 `decision.失败后续`（已写好的退路优先）
2. 换路径——同目标换手段（如夺袋改为护人/留痕/止损）
3. 目标重估——放弃（同批覆盖 `decision.当前计划`·记 `计划变化: 调整——放弃`）或升级（强度/代价跃迁而非幅度加力）
4. 抓新机会——本轮新变量（新信息/新主体/新代价/新道具如崩裂钱袋散落的硬币；停滞加压轮查已登记载体：world_state.外部倒计时 / CT.关联角色）

**放行判据** ＝ 本轮 `未完成意图` 至少有一条是近 3 轮没出现过的，或有条目被划掉（意图变了即放行·动作词换皮不算）。

## 职责 3 · 自推演（背景角色 / 焦外 / 在轨循环角色）

### O3 自推演分支（判定型）

**决策问题**：本角色这一轮有没有往前走一步（产出新事实）？
**缺省选项**：`有发展`

**第一步（先于判定·统一）**：读自己的 `decision.当前计划` 与 `未完成意图`——这一轮能往前走哪一步。循环角色的 `当前计划` 已按「默认循环时间线」物化（见「数据就绪·在轨同步」）；钟点跨段时先按 D3 长期计划巡检把计划推进到新段，再判定。

**决策选项与选中标准**：
- `有发展` — 下列任一成立：`当前计划` 或 `未完成意图` 往前推进了一步／推进池关联 CT 或现场变化触及本人（判据＝受影响重评十渠道任一命中：空间／资源／信息／关系／情绪／目标／威胁／计划／时间／循环状态；如被点名、被喊话，或其目标／计划／退路被第三方的行动改变）／这一轮的动作构成新事实（判据＝「先决状态转换」末尾「本阶段默认产出可观察新事实」）。
- `确无发展` — **只限一种情形**：仍在这同一步里，且这一步的动作尚未做完。其余一律 `有发展`。

**结果语义**：调度单点名的背景角色与焦外按自推演更新 CHAR_state——按下列两支之一执行：

- **`有发展`** — 感知现场与冲突并作出反应，反应/新决策/情绪/关系变化如实写入 CHAR_state（轻量决策环·长期计划按 **actor_decision.md D3 长期计划巡检** 同规判定）；**反应按实体落盘**：情绪变化写 `情绪`、关系变化写 `人际动态`；行动终止态或新决策与旧值不一致 ⇒ `decision.` 对应字段同批覆盖（至少 `当前行动`；行动变了 ⇒ `失败后续`/`未完成意图` 同批对账——仍适用的保留、失效的覆盖、待办做完的划掉，旧行动的退路与待办不留在新行动名下；行动未变也写「未动/继续」一笔）；`decision.当前行动` 写的是**这一步的动作**，与上一轮不同（位置／动词／对象至少一项变）；推进池关联 CT 的焦外角色，`decision.当前行动` 须为可揭示的新事实并产出待揭示事实。**持续产新事实直至窗口实质耗尽**。
- **`确无发展`** — 同一步延续：把尚未做完的动作写成 `当前行动`，写清做到哪一步（不是复抄上一轮原句）；META 显式标注「轻量：同一步未走完」。轻量轮不计为推进池关联者的满足。

**已失效角色（死亡／被捕／失能／永久离场）**：不自推演、不产 `当前行动`、不进行动链，`角色覆盖` 不按正常角色列。其遗体／去向这类客观后果由 ⑤ 按时间经过补记；本阶段只在该角色重新进入叙事时，把 `位置`／`核心状态` 对上事实。

## 职责 4 · 循环角色附加结算（每轮·逐循环角色）

### O4 偏离判定（判定型·编排层·每轮必过·唯一判定与登记点）

**决策问题**：本循环角色本轮是否处于行动级偏离？
**缺省选项**：无偏离
**适用与豁免**：仅循环角色（外部者/管理者不触发；`world_state.维护名单` 中 `触发: 豁免` → 无生效基线 → 不触发；自主性=变质 豁免偏离代价——loop_machinery §3「豁免」）。

**判定输入白名单（硬性·只读下列机械源）**：
- `CHAR_.md`「默认循环时间线」当前时段
- `CHAR_.md` 最近交接／改派记录（离岗口径依据）
- `CHAR_state.位置`／`decision.当前行动`／`连续行动轨迹`／`自主性`（仅用于登记 `入口` 取值）
- `world_state.轮次`／`world_state.维护名单`（豁免判定）
- `CHAR_state.偏离登记` 尾条轮次（仅用于区分「偏离」/「累积偏离」，不得用于判定本轮是否偏离）

**禁读**：`direction.escalation_flags.*`、`direction.guidance`、偏离刺痛文本、历史登记结论。① `轨道✓` 只作回显，不作本判定输入。

**决策选项与选中标准**:
- `无偏离` — 未命中 loop_machinery §2.3「行动级偏离」判据；或仅轻微偏差（记忆碎片渗透／短暂出神／用户指令与外部事件所致差异——不构成行动级）
- `偏离` — 本轮命中行动级判据（唯一判据源=loop_machinery §2.3：档位入口＋离岗／跨节点／结构性行动变更），且登记尾条轮次 ≠ `world_state.轮次`（刚结束的上一轮；无登记按 ≠ 处理）
- `累积偏离` — 本轮命中行动级判据，且登记尾条轮次 ＝ `world_state.轮次`

**结果语义**：
- `无偏离` → 不写登记；META `偏离判定✓(全名=无偏离; …)`。
- `偏离`／`累积偏离` → 本批同批 APPEND `偏离登记`（新条目 `入口` 必填：贴线档=`价值底线触发`|`觉醒判定`；自主档=`自主档`），并按下列口径结算：
  - `偏离` → 按 loop_machinery §1 步骤 3a ＋ §3「强度参考」（压力/防御按档位强度计入）＋ §3「影响字段」执行偏离代价结算；落点细则=下方「偏离代价与偏离登记」。
  - `累积偏离` → 按 loop_machinery §3「影响字段」（持续磨损·经 actor_decision.md D1 评估）＋ §3「偏离终局」执行累积结算；落点细则=下方「偏离代价累积追踪」。

**覆盖闸门（G4·硬性）**：每轮对 precheck SNAPSHOT §1b 名单全员逐人判定，META 写 `偏离判定✓(全名=结论; …)`；名单缺一人＝未扫描。声明 `偏离`／`累积偏离` 者，本批须有同角色、同轮次的 `偏离登记` APPEND；无 APPEND＝拦截。① `轨道✓` 标为偏离的角色集合必须等于④未闭合登记集合（回显一致性闸门在 ①·见 phase_dramatist D7）。

### 档位认知上限

在该角色的行动落点处执行：焦内活跃在行动实现（决策环末环），背景角色/焦外在职责 3 自推演（档位内容见 loop_machinery §2.3「常驻约束·行为档位上限」·非循环角色无此限）。

### 偏离代价与偏离登记

偏离刺痛以第一人称体验进该角色感知增量（subagent_prompt.md 组装转换矩阵「偏离在场」转换·主 agent 按 O4 结果填骨架槽；单窗口路径主 agent 代入角色同规自评）；代价的体验面（压力刺痛/核心状态/锚点/信念）归角色自评落写入；偏离登记＝主 agent 随批次同批追加（角色对自身轨道无元感知·键表=keys.md「偏离登记」）。

**连续偏离/暴露只译成可感知线索（硬性）：** 当前连续偏离轮数 L 与当前连续暴露轮数 E 由 `worldctl context <角色>` 从 `偏离登记` 机械导出（尾条未接续到盘上 `world_state.轮次` 时 L=E=0，另列上次连续段）；主 agent 只用它们决定「偏离刺痛」槽写多重、写不写「上一回那股冷还没退，又压上来」「那道裂还没合，又添一道」「他当面点出来了」这类可感事实——**不注入 L/E 原值，不写 `压力水平`/`防御有效性`**。压力/防御由角色按 actor_decision.md D1/D5 判并写入；gate 只验写入存在（gate ⑬g）。

### 偏离代价累积追踪

同一循环日内多次行动级偏离·程序报错式刺痛累积——每轮经 **actor_decision.md D1 内在状态评估** 评估 压力水平/防御有效性 是否应更新（连续两轮打击未恢复即应写正在失效/已彻底崩解）·不等审计指出。

## 批次落盘（主 agent·每轮一次）

职责 2 行动环跑完（链收敛）、职责 4 附加结算完成后执行，**每轮一次**：

- **并入** — 各角色各环产出并入**本阶段批次**（全环原文一并写入批次·见职责 2「多环落盘」）；子 agent 产出的格式合规见职责 1「产出规范化」
- **落盘** — `write-raw` ＋ gate；**闸门随落盘逐段自动执行**，不合格 ＝ **本段整体拦截不落盘**
- **闸门未过** → 触发该角色**再走一环**：向同一具名会话追加闸门报错原文（追加口径＝subagent_prompt.md「续环追加」·只加事实）；该环按 `·自环` 入链，与前一环原文一并重提（多环落盘）。闸门拦截＝盘上零副作用——被拦的环**已走完并入链**，仅未落盘。重派仍未过，或语义缺件/不可判读、sub agent 不可用、自身文件读取失败 → 该角色该环改走单窗口路径（主 agent 代入再走一环）
- **前置于落盘** — 职责 4 附加结算（循环角色·每轮·偏离登记/自主性升档 KEY）须在并入批次前完成（见职责 4；升档批落盘细则＝actor_decision.md「升档批落盘」）
- 批次与写入通道细则＝write_protocol.md（唯一权威）

## 闸门

闸门随落盘逐段自动执行，不合格 ＝ 本段整体拦截不落盘（查询轮豁免）。硬性项：

- ###STAGE 匹配
- 行动卡三件套
- **每个 ACTION 角色 `decision` 运行层六项齐全**（当前行动 / 行动驱动 / 行动对象 / 行动窗口 / 失败后续 / 未完成意图）
- 角色档案存在
- 角色覆盖 / 记忆✓ 对照
- **绑定声明对照（判据=O2）**——每个 ACTION 角色必须有绑定路径；裸单窗口＝拦；非 POV 单窗口须命中豁免白名单字面，否则硬拦
- **MUSE 存在性**——ACTION 角色须有同名 MUSE 行；**每环须有 MUSE**——同角色 MUSE 数 ＝ 其环条目数（有 ACTION 的环＝MUSE+ACTION·零卡环＝仅 MUSE）
- **顺序与多环**——顺序段按实际入链次序逐环列出，禁合并写法，续环条目缺来源即拦；同一角色解析出的**非零卡**环条目数须等于其 ACTION 组数；零 ACTION 的环标 `(环N·零卡)`（**可出现在任意位置**·零卡不结束走环）；**零卡环须有同名 `###MUSE:` 行**（无行动是角色的判定结果·须有角色自述可核）
- **收敛可验**——**调度单焦内活跃角色（含 POV）须在收敛段逐角色表态**（**两项齐全**：`窗口`否/是·`待用户`否/是；非 POV 的 `待用户是` 须带所指，且本批其 MUSE 有等/待/候明示——等谁、等什么，不写进 ACTION 正文；第二人称 POV 免 ACTION 锚点——其行动只能来自用户输入）
- **收敛闭合**——收敛段**两项**齐全；**不得出现两项皆否**（皆否＝本应续环，只可能由窗口耗尽收束 ⇒ 脚本未耗尽即拦）；「窗口是」须与脚本算出的一致
- **SCHEDULE 留痕**——角色批必含
- **轨迹 APPEND**——有 ACTION 角色必含
- **调度单点名角色（焦内活跃/焦外）必须进角色覆盖**——焦外/背景角色按 O3 结论附注 `有发展`／`轻量:原因`；标 `有发展` 者本批须含 `decision.` 写入
- **偏离判定覆盖（G4）**——每个循环角色批须对 precheck §1b 名单全员写 `偏离判定✓(全名=结论; …)`；声明 `偏离`／`累积偏离` 者须同批含同角色 `偏离登记` APPEND，且新条目 `入口` 命中允许值（贴线档=`价值底线触发`|`觉醒判定`；自主档=`自主档`）
- **`未完成意图` 整组连续 3 轮无变化（含仅幅度/称谓变化）→ 意图循环拦截**（放行判据＝本轮至少一条为近 3 轮没出现过的意图，或有条目被划掉·豁免＝循环角色在轨轻量·触发条件见职责 2「僵持再评估」；计数按轮次去重——同轮多环＝同一轮，取该轮末环的 `未完成意图`）
- Single Writer

单段复检＝`gate actor --check`。标准模式人工审计（A 清单·默认不通过·找茬制·≤2 轮）见 references/gates.md。
