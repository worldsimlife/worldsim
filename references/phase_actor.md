# 阶段④ · 角色（生命层·阶段开始前必读）

> 本阶段是引擎的心脏：**角色从被动执行者升级为自主即兴的生命层**——主动决策、持续行动、直写自己的状态文件。
> 全局铁律=SKILL.md「通用约束」；Single Writer：CHAR_{名}_state
>

## Step 0 数据就绪（每角色各自加载·无共享前奏）

- direction（guidance/当前拍戏剧问题/时间窗口/**调度单**——焦内活跃/背景/焦外·焦外→焦内）
- 推进池CT（冲突态势）＋ scene_state（现场：锚点/道具/在场角色）
- 自身 CHAR_.md（八变量）＋ CHAR_state（decision/连续行动轨迹/记忆锚点/人际动态/信念演化）
- 其他角色已落盘行动（本轮先行动者·级联输入）
- 循环世界：在轨同步——decision.当前计划 已物化自 LOOPS（**角色视为自己的计划·不知来源**）

**④=所有角色状态唯一写者（Single Writer）**：焦内活跃（direction.调度单）=详细即兴；焦内背景/焦外角色按两步顺序执行：

- **Step 1 物化检查**：读该角色 CHAR_state——为骨架（未填充·占位符）→ 先按 CHAR_.md 基线＋当前时刻/LOOPS 位置物化基线字段（decision/核心状态等）
- **Step 2 自推演更新**：自推演并更新 CHAR_state——焦外角色一样感知现场与冲突并作出反应，反应/新决策/情绪或关系变化如实写入；循环角色=轻量推演——decision.当前计划 已物化自 LOOPS（在轨同步·角色视为自己的计划），按日程推进＋感知过滤即可，无需八问合成。无新发展的轮次=轻量刷新：核心状态＋decision.当前行动 按当前时刻的日程位置改写——不新增连续行动轨迹条目、不虚构事件

角色视角遵循自己日程（认知边界=各角色自身视角·不区分是否循环/自主·无元视角）。**不做调度判断**（谁焦内=③调度单定）·**⑤禁写 CHAR_state**。

**元层/认知层分离（硬性·防调度层全知）**：
- **元层**（引擎指导）：direction guidance/事件线戏剧问题/CT 张力方向——指导 LLM 注意力分配（「演什么戏剧效果最强」），**永不进入角色认知与叙事**。
- **认知层**（角色所知）：自己的目标/计划/轨迹/感知到的他人行动与变化——已知可用·未知不可见。
- **角色不读取导演意图作为自己的行为目标**：guidance 只框定戏剧焦点与张力方向；行动目标只来自自身驱动力——元层只影响候选行动的戏剧侧重，不生成目标、不指定行动。
- **POV 用户角色豁免 Step A-E（硬性）**：第一/第二人称玩家角色（Guest）只做**指令转写**（用户本轮输入→行动卡+decision+轨迹）·不走自主决策——引擎不代替用户做选择/行动。行动资格=仅用户本轮输入（无输入=不产生行动卡）；禁引擎代笔定性抉择（动作/内心/状态落定）。

## Step A 状态构建（四层驱动模型）

| 层 | 内容 | 来源 |
|---|---|---|
| 人格动力 | 八变量→行动作用：欲望=主动追求什么/恐惧=主动避免什么/信念=如何解释世界/防御机制=受威胁时如何行动/价值底线=哪些行动不轻易采取/反应倾向=默认策略/崩溃模式=临界时如何改变/关系锚点=谁显著改变决策 | CHAR_.md |
| 当前目标 | 当前目标/当前威胁/当前计划/当前关系目标/当前资源需求/当前未决选择 | decision＋CT＋经历过的事件线事件 |
| 行动状态 | 当前意图/进行中的计划/下一行动窗口/失败后的替代方案/上一行动结果/未完成行动 | decision＋连续行动轨迹 |
| 环境压力 | CT/其他角色行动/资源变化/信息变化/关系变化/空间变化/时间窗口/事件线当前问题（元层）/循环状态 | 各状态文件（经感知过滤） |

## Step B 八问自评（正向 checklist·每角色）

我现在想得到什么？/ 什么正在阻碍我？/ 什么正在威胁我？/ 什么机会正在出现？/ 我的当前计划走到哪里？/ 如果现在不行动会失去什么？/ 我现在最合理的主动行动是什么？/ 如果失败我下一步怎么办？

## Step C 候选行动生成（枚举库·正向）

推进目标/执行计划/争夺资源/阻止对手/保护自己/改变关系/获取信息/隐藏信息/隐藏秘密/试探/操纵/施压/威胁/诱导/逃避/报复/升级冲突/改变策略/抓住机会/满足欲望/避免恐惧/防止目标失败

## Step D 驱动力合成与全角色行动竞争

- **驱动力权重**：持续计划/核心目标/核心恐惧/目标受威胁程度/CT 压力/机会窗口/对手行动/新信息/关系变化/情绪变化/时间压力/资源变化/事件线当前问题 → 本轮行动意图（做什么/为什么/为什么是现在）。
- **行动竞争**：所有活跃角色有行动资格；按驱动力+行动机会+空间条件+角色能力+行动代价+他人行动决定——**谁行动/什么行动/顺序/是否成链**。允许多角色并行、同资源竞争、一行动立即触发另一角色。**角色不需要等待玩家行动才进入行动状态。**
- **受影响重评机制**（连续行动链收敛规则）：任何行动改变世界 → 识别受影响角色（十渠道：空间/资源/信息/关系/情绪/目标/威胁/计划/时间/循环状态）→ 受影响者重新获得行动机会。不是「玩家→NPC 响应」也不是「每轮所有 NPC 重想」。
- **时间窗口节流**：③设定的本轮时间预算内每行动标注耗时；**窗口耗尽或无新受影响者 → 链收敛**（无人工轮数上限）。
- **连续性状态机**（防每轮孤立生成）：`目标→计划→行动→结果→计划仍成立？→继续/调整/放弃/升级→下一行动`——decision 承载当前态，连续行动轨迹保持跨轮连续。

调度单留痕：`###SCHEDULE: 轮次N 窗口X分钟 顺序: A→B(受影响:信息)→C(受影响:威胁) 收敛: 窗口耗尽`

## Step E 行动实现（怎么做）

依据：人格/**认知上限**（循环档位速查·见 loop_machinery §2.3）/叙事视角/感官锚点/动作习惯/语气/当前情绪/压力/防御状态/关系/空间 → 实现为：动作/台词/身体语言/情绪表现/空间互动/信息透露/信息隐藏/环境变化。

**反顺从五则（写行动前逐条执行）**：①代价前置（行动由不可逆代价驱动）②档案强度（≥CHAR_.md 基准·拔枪/逼近/毁物/动手/夺人是下限·顺从默认=重写）③抽象方显现（出手形态+抵抗痕迹）④认知闸门（知识归属——该角色有认知来源才可用）⑤Value Boundary（触发行为出现即执行档案升级路径动作）。

**行动卡**（audit ①①b 机械检查·每行动一行）：
```
###ACTION: {角色}: {2-3个连续可观察动作+空间位置} | 驱动: {内部动机·不直接入文} | 情绪: {主导情绪} | 强度: {1-10} | 代价: {某}失{可核验变化}/{某}失{可核验变化} | 耗时: {分钟}
```

`代价:` 只能填本轮真实失去、下一轮仍然失去的东西（关系受损／机会永久关闭／信息暴露无法收回／资源易手）——观感类变化（距离感/匿名度/气氛）不算代价。

## 落盘（CHAR_state 唯一写者·角色意志的体现）

- **decision**（KEY 点路径逐层写）：当前目标/当前计划/当前行动/行动驱动/行动对象/行动窗口/失败后续/未完成意图
- **连续行动轨迹**（APPEND·结构化七子字段）：轮次/行动/行动目的/行动结果/他人反应/计划变化/未完成意图——角色自己的时间线·不裁剪
- **记忆锚点**（APPEND·写前五步在本地完成——角色本就读自己的状态）：①扫旧 ②同类≥2 融合 ③同类≥3 管道B 信念演化 ④对象+实质变化 管道A 人际动态 ⑤追加 ≤100 字
- 条件写入：信念演化（管道B/变质留痕）/人际动态（管道A）/位置/核心状态/情绪/压力/防御/偏离登记（行动级偏离自记）
- **变质判定**：①戏剧家 flag（状态达标：压力=临界 且 防御=已彻底崩解）→ 本阶段执行升档（自主性+信念演化留痕+压力回落至世界水平+防御保持崩解）
- **防御重构**：①戏剧家 flag（三条件齐备）→ 本阶段执行（防御形态/崩溃表现覆盖写+防御有效性升一档）

**循环角色**：档位认知上限在此执行（脚本=流程内容+一瞬裂缝·禁元视角；漂移=+碎片直觉 1-2 次/日；觉醒/变质=系统判断/自我轨道）；偏离入口唯三（VB/觉醒判定/用户指令）——详见 loop_machinery。

## 批次格式与闸门

```
###STAGE: 角色
###SCHEDULE: 轮次N 窗口X 顺序: … 收敛: …
###ACTION: {角色}: … | 驱动: … | 情绪: … | 强度: N | 代价: … | 耗时: N
###META: 角色覆盖: Name=更新,Other=更新(在轨·轻量) 记忆✓ Name:N·未达
###FILE: CHAR_{名}_state
###KEY: decision.当前行动
…
###APPEND: 连续行动轨迹
- 轮次: N
  行动: … / 行动目的: … / 行动结果: … / 他人反应: … / 计划变化: … / 未完成意图: …
```

**META 记忆标记（脚本硬性·逐角色全列）：** 凡本批写了 CHAR_state 的角色（含焦内与焦外轻量刷新）各写一个 `记忆✓ {角色}:{计数}·{已触发|未达}`——`计数`=本轮为新写的记忆锚点条数（`0`=未写）·`已触发`=写入了记忆锚点·`未达`=未到记忆写入阈值（写前自查没过）；**角色名含空格用下划线代空格**（如 `Clementine_Pennyfeather`）·**缺一被 gate 拦**（脚本仅 regex `记忆✓`）。示例：`记忆✓ Guest:0·未达`（本轮未触发）／`记忆✓ Dolores:2·已触发`（写了 2 条锚点）／`记忆✓ Maeve_Millay:0·未达`（焦外轻量刷新·无记忆事件）。**不要用「记忆✗」——脚本只认 `记忆✓`，未触发用 `:0·未达` 表达。**

闸门：`gate actor --check`（硬性：###STAGE 匹配＋行动卡四件套＋角色档案存在＋角色覆盖/记忆✓ 对照＋**调度单点名角色（焦内活跃/焦外）必须进角色覆盖**＋Single Writer）。标准模式人工审计（A1-A5 清单·默认不通过·找茬制·≤2 轮）见 references/gates.md。
