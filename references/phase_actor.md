# 阶段④ · 角色（生命层·阶段开始前必读）

> 本阶段是引擎的心脏：**角色从被动执行者升级为自主即兴的生命层**——主动决策、持续行动、直写自己的状态文件。
> 全局铁律=SKILL.md「通用约束」；**阶段④=所有角色状态唯一写者**（Single Writer：CHAR_{名}_state）
>

## 数据就绪（每角色各自加载·无共享前奏）

- direction（guidance/当前拍戏剧问题/时间窗口/调度单——焦内活跃/背景/焦外·焦外→焦内）
- 推进池CT（冲突态势）＋ scene_state（现场：锚点/道具/在场角色）
- 自身 CHAR_.md（八变量）＋ CHAR_state（decision/连续行动轨迹/记忆锚点/人际动态/信念演化）
- 其他角色已落盘行动（本轮先行动者·级联输入）
- 循环世界：在轨同步——decision.当前计划 已物化自 LOOPS（**角色视为自己的计划·不知来源**）
- **骨架物化（前置·所有角色通用）**：读到的 CHAR_state 为骨架（模板占位未清零）→ 先按 CHAR_.md 基线＋当前时刻/LOOPS 位置物化基线字段（位置/核心状态/decision.当前计划/妆扮/服饰），再进入角色路由。随身物品初始为空，不物化。判定标准见 keys.md「骨架物化规则」

## 角色路由（唯一分流点·两步判定）

**第 1 步 按③调度单取行**——决定本角色本轮是否出行动卡：

| 调度单归属 | 路径 | 本轮产出 |
|---|---|---|
| POV 用户角色（Guest） | 指令转写（**豁免职责 1–3**） | 用户本轮输入→行动卡＋decision＋轨迹；**无输入=不产生行动卡** |
| 焦内活跃 | 即兴（职责 1） | 行动卡＋decision＋连续行动轨迹 |
| 焦内背景 | 自推演（职责 3） | CHAR_state 更新·无行动卡 |
| 焦外 | 自推演（职责 3） | CHAR_state 更新·无行动卡 |

**第 2 步 叠加在轨循环**——SETTING 声明循环且本轮在轨的角色：

- **轻量推演 = 计划层不重新合成**：当前计划 = LOOPS 物化（角色视为自己的计划），按日程推进＋感知过滤
- **行动层按第 1 步各行照常执行**：焦内活跃的循环角色照常即兴出行动卡，档位上限见 loop_machinery §2.3
- **附加结算**：命中者走职责 4（偏离代价 / 变质判定 / 防御重构 / 计划覆盖豁免）

**POV 用户角色豁免职责 1–3（硬性）**：第一/第二人称玩家角色只做**指令转写**（用户本轮输入→行动卡＋decision＋轨迹）——不入八问、不生成候选行动、不自选行动目标。**禁引擎代笔定性抉择**（动作/内心/状态落定）。

**角色视角遵循自己日程**（认知边界=各角色自身视角·不区分是否循环/自主·无元视角）。

**元层/认知层分离（硬性·防调度层全知）**：
- **元层**（引擎指导）：direction guidance/事件线戏剧问题/CT 施压方向——指导 LLM 注意力分配（「演什么戏剧效果最强」），**不写入角色认知与叙事**。
- **认知层**（角色所知）：自己的目标/计划/轨迹/感知到的他人行动与变化——已知可用·未知不可见。

## 职责（顺序执行）

1. **即兴（焦内活跃角色·逐角色执行 1.1→1.5）**

   - **决策环定位**：1.1–1.5 = 生成**一次**行动的完整决策环 **Observe → Think → Decide → Act**——1.1 状态构建（Observe）→ 1.2 八问（Think）→ 1.3 候选＋1.4 驱动力合成与行动竞争（Decide）→ 1.5 行动实现＋行动卡（Act）。同窗口内该角色再次行动 = 重走本环（轻量：仅更新行动状态层与感知增量，人格动力层不重建）。

   - **1.1 状态构建**（四层驱动模型）：

     | 层 | 内容 | 来源 |
     |---|---|---|
     | 人格动力 | 八变量→行动作用：欲望=主动追求什么/恐惧=主动避免什么/信念=如何解释世界/防御机制=受威胁时如何行动/价值底线=哪些行动不轻易采取/反应倾向=默认策略/崩溃模式=临界时如何改变/关系锚点=谁显著改变决策 | CHAR_.md |
     | 维度标尺 | 大五五维+阵营双轴=演绎幅度标尺——即兴或描写拿不准该角色「能做到多满/多冷/多硬」时查它定档 | CHAR_.md |
     | 核心诉求 | 核心诉求/当前威胁/当前计划/当前关系目标/当前资源需求/当前未决选择 | decision＋CT＋经历过的事件线事件 |
     | 行动状态 | 当前意图/进行中的计划/下一行动窗口/失败后的替代方案/上一行动结果/未完成行动 | decision＋连续行动轨迹 |
     | 环境压力 | CT/其他角色行动/资源变化/信息变化/关系变化/空间变化/时间窗口/事件线当前问题（元层）/循环状态 | 各状态文件（经感知过滤） |

   - **1.2 八问自评**（正向 checklist·每角色逐条过）：我现在想得到什么？/ 什么正在阻碍我？/ 什么正在威胁我？/ 什么机会正在出现？/ 我的当前计划走到哪里？/ 如果现在不行动会失去什么？/ 我现在最合理的主动行动是什么？/ 如果失败我下一步怎么办？
   - **1.3 候选行动生成**（枚举库·正向）：推进目标/执行计划/争夺资源/阻止对手/保护自己/改变关系/获取信息/隐藏信息/隐藏秘密/试探/操纵/施压/威胁/诱导/逃避/报复/升级冲突/改变策略/抓住机会/满足欲望/避免恐惧/防止目标失败
   - **1.4 定本轮行动**（驱动力合成与全角色行动竞争）：
     - **驱动力权重**：持续计划/核心目标/核心恐惧/目标受威胁程度/CT 压力/机会窗口/对手行动/新信息/关系变化/情绪变化/时间压力/资源变化/事件线当前问题 → 本轮行动意图（做什么/为什么/为什么是现在）。
     - **行动竞争**：所有活跃角色有行动资格；按驱动力+行动机会+空间条件+角色能力+行动代价+他人行动决定——**谁行动/什么行动/顺序/是否成链**。允许多角色并行、同资源竞争、一行动立即触发另一角色。**角色不需要等待玩家行动才进入行动状态。**
   - **1.5 行动实现**：

     依据：人格/**认知上限**（循环档位速查·见 loop_machinery §2.3）/叙事视角/感官锚点/动作习惯/语气/当前情绪/压力/防御状态/关系/空间 → 实现为：动作/台词/身体语言/情绪表现/空间互动/信息透露/信息隐藏/环境变化。

      **反顺从五则（写行动前逐条执行）**：①代价前置（推进性行动由不可逆代价驱动；过渡性行动豁免）②档案强度（≥CHAR_.md 基准·拔枪/逼近/毁物/动手/夺人是下限·顺从默认=重写）③抽象方显现（出手形态+抵抗痕迹）④认知闸门（知识归属——该角色有认知来源才可用）⑤Value Boundary（触发行为出现即执行档案升级路径动作）。

     **行动卡**（audit ①/①b/⑨ 机械检查·每行动一行）：
     ```
     ###ACTION: {角色}: {2-3个连续可观察动作+空间位置} | 驱动: {内部动机·不直接入文} | 情绪: {主导情绪} | 强度: {1-10} | 代价: {某}失{可核验变化}/{某}失{可核验变化} | 耗时: {分钟}
     ```
       **行动代价（有条件必填·机械可判定）**： 当且仅当本角色被 `direction.调度单` 列为焦内活跃且关联CT∈①推进池且该CT.施压方向∈四爆破（死局两难/防御踩爆/关系爆破/不可逆代价），或当前拍戏剧问题∈资源/关系/控制权/认知类可回答问题时，必填`代价`；其余过渡/寒暄/轻量刷新豁免（audit软警）。
       `代价:` 填`谁失何物（下轮仍失）`，格式`A失B`，B为可核验物：资源/载体状态/关系档位/控制权/身体边界（正向枚举5项）——观感类（距离感/匿名度/气氛）不算代价。

      **代价-动作正向速查（置于本节首行·每条ACTION必选一项）**

      | 可核验物 | 代价示例（下轮仍失） | 实质动作示例（转折性，下限） |
      | 资源 | 施压者失“可不担后果的挑衅”（已上手） | 抓住对方小臂/衣料拉拽半步 |
      | 关系 | 被压者失“可作无事的中立”（已明示选边求助） | 转身抓住求助对象手腕+出声求助 |
      | 控制权 | 守护者失“可不拔的克制”（枪/械已出套指向） | 拔出武器指向施压者+喝止 |
      | 边界 | 秩序者失“口头缓冲”（已拔械截停） | 拔械横亘两人之间 |
      | 载体 | 旁观者失“可静默的旁观位”（已介入带离） | 抬手格挡+半步带被压者退离 |

2. **行动链推进（跨角色·职责 1 的循环外壳）**

   - **受影响重评机制**（连续行动链收敛规则）：任何行动改变世界 → 识别受影响角色（十渠道：空间/资源/信息/关系/情绪/目标/威胁/计划/时间/循环状态）→ **受影响者按其路由行重走对应路径**（焦内活跃→回到 1.1；背景/焦外→职责 3 自推演）。不是「玩家→NPC 响应」也不是「每轮所有 NPC 重想」。
   - **时间窗口节流**：③设定的本轮时间预算内每行动标注耗时；**窗口耗尽或无新受影响者 → 链收敛**（无人工轮数上限）。
   - **行动环（Observe→Think→Decide→Act 每行动一圈·同窗口可多圈）**：1.1–1.5 生成一次行动；行动落地后进入 **Result**（行动结果与他人反应·上下文 `###ACTION` 序列）→ **计划仍成立？**：`继续` → 回 Observe 生成下一行动（行动者本人凭 `未完成意图`＋时间窗口再入环，不依赖被他人影响）；`调整` → 覆盖 decision.当前计划（gate 联动，循环角色豁免见职责 4）；`放弃`/`升级` → 走对应决策路径；`窗口耗尽或无新受影响者` → 链收敛。decision 八子字段承载环当前态，连续行动轨迹七子字段保持跨轮连续；`受影响重评`（十渠道）负责**其他**角色的入环路径，与本回边并列。
   - **行动链留痕**：`###SCHEDULE: 轮次N 窗口X分钟 顺序: A→B(受影响:信息)→C(受影响:威胁) 收敛: 窗口耗尽`——④的 `###SCHEDULE:` 只作留痕·**不落盘·不裁决调度**；调度权威=③ direction.调度单。

3. **自推演（焦内背景/焦外/在轨循环角色）**：感知现场与冲突并作出反应——反应/新决策/情绪或关系变化如实写入 CHAR_state（焦外角色一样感知现场与冲突并作出反应）。在轨循环角色按路由第 2 步走轻量推演。**无新发展的轮次=轻量刷新**：核心状态＋decision.当前行动 按当前时刻的日程位置改写——不新增连续行动轨迹条目、不虚构事件。

4. **循环角色附加结算**（路由第 2 步命中者）：

   - **档位认知上限**：在该角色的行动落点处执行——焦内活跃在 1.5 行动实现，背景/焦外在职责 3 自推演（脚本=流程内容+一瞬裂缝·禁元视角；漂移=+碎片直觉 1-2 次/日；觉醒/变质=系统判断/自我轨道）——见 loop_machinery §2.3
   - **偏离代价与偏离登记**：偏离入口唯三（VB/觉醒判定/用户指令）·按 loop_machinery §1 步骤 3a 同批结算偏离代价（压力/防御/核心状态/锚点/信念）并追加偏离登记
   - **计划覆盖豁免**：轨迹 `计划变化` 含 `调整` 时**不**触发 decision.当前计划覆盖——当前计划=LOOPS 物化（重置时重物化），真实计划偏离走 偏离检测→冲突化（loop_machinery §5.1），不由轨迹 `计划变化` 直接改写

## 写入（CHAR_state 唯一写者·角色意志的体现）

**字段写语义（键/格式/约束）以 keys.md「CHAR_{name}_state.yaml」节为权威·批次与写入通道以 references/write_protocol.md 为权威——本节只列动作与触发。**

**查询轮（/status 等）：本阶段整份豁免。**

- **必写 decision**（KEY 点路径逐层写）：核心诉求/当前计划/当前行动/行动驱动/行动对象/行动窗口/失败后续/未完成意图——`核心诉求`=核心欲望在当下处境的落点·结局状态（✅「验证 Angela 的完美之下是否存在真实」 ❌ 轮内企图如「看她怎么应对这个问题」→放 `当前行动`）；`当前计划`=时段级全链路线·禁轮内任务覆盖（见 keys.md）——覆盖判定=计划本身是否改变：按既定路线走完一步/进入下一环节→保留不覆盖；被调整/替换/放弃/重新规划（含首次具体化）→本轮同批覆盖
- **必写 连续行动轨迹**（APPEND·结构化七子字段）：轮次/行动/行动目的/行动结果/他人反应/计划变化/未完成意图——角色自己的时间线·近 10 轮滚动（APPEND 后脚本自动删最旧·LLM 零操作）。`计划变化` 值域三档：`无`（计划未变）/`推进`（计划本身没变·仅按计划走一步或进入下一环节）/`调整——客观概括`（计划被调整/替换/放弃/重新规划/首次具体化）——**含 `调整` 前缀时本批必须覆盖 decision.当前计划**（gate actor 硬拦；循环角色豁免见职责 4）
- **条件写 记忆锚点**（APPEND·写前五步逐条执行——角色本就读自己的状态）：
  1. **扫旧**：读本角色现有锚点，找出与新事件同类的条目；
  2. **同类融合**：同类＝同一对象上反复出现的同一性质体验（如多次被珍视／多次被设局／多次被冷落）。已有 ≥2 条同类 → 先把旧同类合并为一条概括条目再追加；
  3. **管道B 提炼**：同类计数达 ≥3（**概括条目按其合并的条数计** + 本条）→ 同批追加一条 `信念演化`——从这组同类经历抽象一条世界观级转变（`触发事件`＋`旧信念→新信念`·只提炼不升级）；
  4. **管道A 人际动态**：涉及具体对象且关系实质变化 → 更新人际动态对应行；
  5. **追加本条**：≤100 字。

  示例：角色已有「他让着她」「他记得她忌口」两条同类锚点，本轮又记下「他把伞塞给了她」→ 同类达 3 → 同批追加一条 信念演化：「旧信念→新信念：被人照顾意味着欠了债要还 → 有人照顾她只是因为愿意」。
- **条件写 妆扮/服饰（显式变化检查·每轮必过）**：本轮是否有穿脱/妆容变化？有→全量重写（写前 read 旧值）；无→不写。若字段为空但 CHAR_.md 外在特征有基线描述→视为待填充，本轮同批写入基线。
- **条件写 随身物品（显式变化检查·每轮必过）**：本轮是否有可转移重要持有物的取得/交出/遗失/易主（含卡/票据/钥匙/武器/弹药/道具/信件/契约等，代管/折叠持有亦算）？有→全量重写（写前 read 旧值，须与记忆锚点同步易主双方）；无→不写。`ACTION` 含 `接过/递出/握起/装入/收入/捡起/交出/夹带/折叠持有` 即视为取得，需同步检查。
- **其余条件写入**：信念演化（管道B/变质留痕）/人际动态（管道A）/位置/核心状态/情绪/压力/防御/名字（身份质变）/健康/已知地点（首次到达/被告知/目睹）
- **条件写 变质判定**（仅循环角色）：读本角色 CHAR_state——压力水平=临界 且 防御有效性=已彻底崩解 → 本批执行升档
  **写入顺序（硬性）：压力/防御 → 自主性 → 信念演化 → 压力回落**
  1. **压力/防御** 排最前——门槛按升档写入前的状态核验（脚本硬检·未达门槛拦下升档）
  2. **自主性** 升一档（脚本→漂移→觉醒→变质·每次极端冲击只升一级）
  3. **信念演化** 留痕（变质级转变）
  4. **压力回落** 排最后——回落至世界当前水平（④按其余压力来源估定·非清零）·防御保持崩解
- **条件写 防御重构**（三条件核验）：威胁源解除（推进池中本角色关联 CT 已收束或紧迫度降至🟢以下）＋支持性关系介入（人际动态有支持性角色实质行动）＋信念重构（信念演化出现旧信念→新信念条目）→ 本批执行（防御形态/崩溃表现覆盖写+防御有效性升一档）

**META 记忆标记（脚本硬性·逐角色全列）**：凡本批写了 CHAR_state 的角色（含焦内与焦外轻量刷新）各写一个 `记忆✓ {角色}:{计数}·{已触发|未达}`

- `计数` = 本轮新写的记忆锚点条数（`0` = 未写）·`已触发` = 写入了记忆锚点·`未达` = 未到记忆写入阈值（写前自查没过）
- 角色名含空格用下划线代空格（如 `Clementine_Pennyfeather`）·**缺一被 gate 拦**
- 示例：`记忆✓ Guest:0·未达`（本轮未触发）／`记忆✓ Dolores:2·已触发`（写了 2 条锚点）／`记忆✓ Maeve_Millay:0·未达`（焦外轻量刷新·无记忆事件）
