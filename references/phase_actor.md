# 阶段④ · 角色（生命层·阶段开始前必读）

> 本阶段是引擎的心脏：**角色从被动执行者升级为自主即兴的生命层**——主动决策、持续行动、直写自己的状态文件。
> 全局铁律=SKILL.md「通用约束」；**阶段④=所有角色状态唯一写者**（Single Writer：CHAR_{名}_state）
>
> 决策与写入规则（自治原则/决策环 1.1–1.5/写入/批次格式）＝**references/actor_decision.md**——子 agent 路径由子 agent 代入角色自读·单窗口路径由主 agent 加载·两路径同规·单一来源。

## 数据就绪（每角色各自加载·无共享前奏）

- **Runtime Context（优先引用·v0.28）**：`worldctl.py <世界> context [角色]` 机械导出（direction 拍级字段编译：当前拍戏剧问题/guidance/调度单/时间窗口+推进池CT摘要+环境压力项）——**存在则优先引用**（省组装通道 token）；输出不足则按下行逐项读。
- direction（guidance/当前拍戏剧问题/时间窗口/调度单——焦内活跃/背景/焦外·焦外→焦内）
- 推进池CT（冲突态势·其中上轮结算.关系状态/上轮结算.内部状态为快照·不作本轮当前真态·当前真态以 CHAR_state/scene_state 为准）＋ scene_state（现场：锚点/道具/在场角色）＋ world_state（外部倒计时/叙事约定）
- 自身 CHAR_.md（八变量）＋ CHAR_state（decision/连续行动轨迹/记忆锚点/人际动态/信念演化）
- 其他角色已落盘行动（本轮先行动者·级联输入）
- 循环世界：在轨同步——decision.当前计划 物化自角色 CHAR_.md「默认循环时间线」当前段至段末（**角色视为自己的计划·不知来源**；LOOPS 只供互锁协调）；此为**基线**，此后由决策环 1.4「长期计划巡检」判定维护（在轨默认不动·见 actor_decision.md）

## 先决状态转换（先于角色路由）

**骨架物化（所有角色通用）**：先判 CHAR_state 是否含任一模板占位；任一 decision 子字段占位即为骨架。骨架不得进入路由、不得产 ACTION 或轨迹。按 CHAR_.md 基线＋当前时刻物化位置/核心状态/妆扮/服饰，并连续完成：①稳定层——核心诉求＋当前计划；循环角色的计划取 CHAR_.md「默认循环时间线」当前时段至终点的完整路径，非循环角色按核心诉求＋现状自拟；②运行层——当前行动/行动驱动/行动对象/行动窗口/失败后续/未完成意图。八项均实体化后才进入路由。随身物品初始为空，不物化。precheck SNAPSHOT §3 只提供待物化名单；物化动作在本阶段完成。判定标准见 keys.md「骨架物化规则」。

本阶段默认产出可观察新事实：调度单点名的焦内活跃/背景与焦外均按自推演或即兴更新CHAR_state；推进池关联者decision当前行动必为本轮八问驱动且未在近3轮出现过的可观察新事实。新事实=动词+空间位+对象皆变。焦内活跃者必须完成行动链；背景只写受波及的可观察显影，不替代行动主体。**意图循环**：`未完成意图` 连续 3 轮相同（含仅幅度/称谓变化）→ 触发僵持再评估（见职责2）·换意图后重写——动作词/幅度变化不算新事实。

所有角色各自按目标/恐惧/计划自主行动（第二人称用户角色：行动由用户输入给出）；任一角色的行动经受影响重评传播为其他角色的观察输入，不构成对其他角色的指示，不存在“等待用户”的全局冻结。

## 角色路由（唯一分流点·两步判定）

**前置判定（内在驱动优先·先于第 1 步取行）**：调度单=画面归属（谁入画/背景/焦外），**不封禁行动**。当角色自身条件触发时，按焦内活跃路径（完整决策环→行动卡→decision→轨迹）执行，不受「背景/焦外」分档限制：
- **失败后续触发**：`decision.失败后续` 条件被满足（如 Armistice：Hector 已中弹→转入近身火力掩护）——自升焦内；
- **未完成意图被新事实破坏**：上轮行动结果改写了意图成立前提；
- **档案级行动要求**：CHAR_.md 崩溃表现/核心欲望驱动的行动（如 Sheriff：执行到死亡判定），不因伤退为「背景」而停止。

**第 1 步 按③调度单取行**——决定本角色本轮是否出行动卡（未触发前置判定的角色按此分档）：

| 调度单归属 | 路径 | 本轮产出 |
|---|---|---|
| 主焦点（焦内活跃） | 即兴（职责 1） | 行动卡＋decision＋连续行动轨迹 |
| 余光（背景） | 自推演（职责 3） | CHAR_state 更新·不逐人产ACTION，仅一句可观察显影 |
| 焦外 | 自推演（职责 3） | CHAR_state 更新·无行动卡 |

> 调度单是导演对画面的分档（谁站舞台中心/谁在余光/谁在场外），**不是行动能力的封禁令**；角色内在驱动（上表前置判定）永远优先——角色先活，画面后归位。触发前置判定的角色本轮在调度单中所在档仅为画面参考，其行动按焦内活跃执行。

**POV 用户角色（Guest）：** 按 `world_state.叙事约定` 声明视角走对应路径——**优先于上表**。
- **第三人称 / 第一人称**：该角色为平等行动者，参与反应，按决策环自主产行动（经受影响重评）；第一人称额外可写其心理（共生感知），第三人称只写可观察显影。
- **第二人称**：用户角色的行动由用户输入给出——按输入转写为行动卡＋decision＋轨迹；**用户本轮未给出行动（如仅「继续剧情」）→ 该角色本轮无 ACTION**（CHAR_state 走轻量刷新·不代写其选择/台词/心理）；其他角色照常自主决策与行动，本轮以主焦点多角色咬合持续。

**第 2 步 叠加在轨循环**——SETTING 声明循环且本轮在轨的角色：

- **轻量推演 = 计划层不重新合成**：当前计划 = CHAR_.md「默认循环时间线」当前段至段末（角色视为自己的计划），按日程推进＋感知过滤；巡检归 1.4「长期计划巡检」——在轨判「仍成立」即不动（见 actor_decision.md）
- **行动层按第 1 步各行照常执行**：焦内活跃的循环角色照常即兴出行动卡，档位上限见 loop_machinery §2.3
- **附加结算**：命中者走职责 4（偏离代价 / 变质判定 / 防御重构）

**角色视角遵循自己日程**（认知边界=各角色自身视角·不区分是否循环/自主·无元视角）。

**元层/认知层分离（硬性·防调度层全知）**：
- **元层**（引擎指导）：direction guidance/事件线戏剧问题/CT 施压方向——指导 LLM 注意力分配（「演什么戏剧效果最强」），**不写入角色认知与叙事**。
- **认知层**（角色所知）：自己的目标/计划/轨迹/感知到的他人行动与变化——已知可用·未知不可见。

## 职责（顺序执行）

1. **即兴（焦内活跃角色·逐角色执行 1.1→1.5）**

   - **决策环定位**：1.1–1.5 = 生成**一次**行动的完整决策环 **Observe → Think → Decide → Act**——1.1 状态构建（Observe）→ 1.2 八问（Think）→ 1.3 候选＋1.4 驱动力合成（Decide）→ 1.5 行动实现＋行动卡（Act）。细则（每环步骤/写入/批次格式）＝references/actor_decision.md。
   - **执行绑定（Step 0·进入 1.1 前逐角色判定）**：**非第一/第二人称 POV 角色，一律子 agent 委派**——一个行动环（1.1–1.5）=一次独立子 agent 调用，产出该角色决策批次文本，主 agent 收口落盘（判定结果写入批次 META 绑定声明，gate actor 机械核验）；仅当子 agent 不可用时回退单窗口路径——1.1–1.5 全程在主上下文执行。缺省不判定=违规（失效即静默兜底·由绑定声明拦截）。
   - **子 agent 路径（子 agent 代入该角色·决策主体=角色本人）**：一个行动环（1.1–1.5）= 一次独立子 agent 调用，主 agent 提供素材。**子 agent 以「我」走在 1.1–1.5 里**：CHAR_{名}.md ＝我的人格，CHAR_{名}_state＝我的记忆，references/actor_decision.md＝我思考的方式。输入双通道：
     1. **自读通道（我的档案与记忆·全文原文）**——prompt 给定路径，子 agent 直接读取：CHAR_{名}.md（八变量/档案基准/默认循环时间线）＋CHAR_{名}_state（decision/连续行动轨迹/记忆锚点）＋references/actor_decision.md（我如何想·如何走决策环），不经主 agent 转述。
     2. **组装通道（需感知过滤的输入）**——经角色感知过滤的现场、已落盘行动、环境压力项和世界法则约束；循环角色附加该角色档位速查行（主 agent 取自 loop_machinery §2.3·不传整份）；取材范围与数据就绪/四层驱动模型一致；guidance/焦点提示/调度单画面分档/其他角色完整状态不进 prompt。**prompt 只装素材·禁止预写行动/台词等决策结论（违反=本环作废重派）**——世界法则只定可行域，不定可行域内的选择：把法则推演成某个具体行动或反应形态（含「必然包含/只能/势必」式预设）=预写结论。同窗口再环为轻量组装（仅行动状态层与感知增量，人格动力层不重建）。
     3. **子 agent 产出**——以该角色身份走完决策环，产出决策批次文本（###STAGE: 角色 段内容）返回，不写文件、不落盘。
     4. **主 agent 收口（格式规范者）**——子 agent 产出＝决策内容（语义权威）·批次格式与值域合规由主 agent 负责：**以子 agent 产出的段为主体整体并入本阶段独批，主 agent 只做合规规整**（按 keys.md 的值域与键路径映射字段枚举/KEY 点路径/META 记忆✓ 与绑定声明格式/时间顺延·阶段头归并），只规格式不审语义，照常 write-raw＋gate（gate 仍是最终拦截网）。**收口时须叠加职责 4 附加结算**（循环角色：偏离代价评估→压力/防御/偏离登记更新·合并入批次——子 agent 不承担此项·主 agent 不得遗漏）。语义缺件或不可判读、子 agent 不可用、自身文件读取失败 → 该角色本环按单窗口路径执行。角色路由（含前置判定）、职责 3 自推演、受影响重评、行动竞争、链收敛与全部落盘仍在主 agent。
   - **并行委派（v0.28·无依赖角色并行·因果链串行）**：**无相互影响依赖的角色允许并行委派子 agent**（同一批并行调用·产出后统一收口落盘）；**存在因果依赖**（后角色感知前角色行动结果——如 B 响应 A 的 ALERT）→ 按行动落地顺序串行（先 A 落盘→B 读已落盘行动再决策）。判据=受影响重评十渠道（空间/资源/信息/关系/情绪/目标/威胁/计划/时间/循环）——无交集=可并行·有交集=因果链串行；宿主无并行工具→按依赖顺序顺序执行（并行是优化·不是正确性要求）。
   - **跨角色行动竞争与链触发（两路径同责·主上下文执行）**：
     - **行动竞争**：所有活跃角色有行动资格；按驱动力+行动机会+空间条件+角色能力+行动代价+他人行动决定——本角色是否/何时行动。跨角色成链只经受影响重评触发，不预排他者行动与顺序。**角色不需要等待玩家行动才进入行动状态。**
     - **Act落地即触发**：主焦点角色Action落地后，经受影响重评（十渠道）识别受影响角色，触发其下环（主焦点→回Observe；余光→自推演一句显影）。一场戏由主焦点咬合触发连成链，非并列平铺。

2. **行动链推进（跨角色·职责 1 的循环外壳）**

   - **受影响重评机制**（连续行动链收敛规则）：任何行动改变世界 → 识别受影响角色（十渠道：空间/资源/信息/关系/情绪/目标/威胁/计划/时间/循环状态）→ **受影响者按其路由行重走对应路径**（焦内活跃→回到 1.1；背景/焦外→职责 3 自推演）。不是「玩家→NPC 响应」也不是「每轮所有 NPC 重想」。
   - **时间窗口节流**：③设定的本拍时间预算内按决策环持续产新行动并标注耗时；**窗口实质耗尽 → 链收敛**（无人工轮数上限；剩余分钟由 context/precheck 机械导出·④不自行解析时间串）；**无新受影响者=链不跨角色延伸**——行动者本人凭 `未完成意图`＋时间窗口再入环·直至窗口耗尽。单条产物且剩余窗口充裕视为未走全环，须续产直至窗口实质耗尽。
   - **行动环（Observe→Think→Decide→Act 每行动一圈·同窗口可多圈）**：1.1–1.5 生成一次行动；行动落地后进入 **Result**（行动结果与他人反应·上下文 `###ACTION` 序列）→ 回 Observe 生成下一行动（行动者本人凭 `未完成意图`＋时间窗口再入环，不依赖被他人影响）→ `窗口耗尽` → 链收敛（无新受影响者=不触发他人入环·行动者本人凭未完成意图续环至窗口耗尽）。长期计划是否仍成立由 1.4「长期计划巡检」判定（见 actor_decision.md）。decision 八子字段承载环当前态，连续行动轨迹七子字段保持跨轮连续；`受影响重评`（十渠道）负责**其他**角色的入环路径，与本回边并列。
   - **僵持再评估（意图循环触发·角色层破僵持的唯一出口）**：当 `未完成意图` 连续 3 轮未兑现（上轮行动结果仍标注未兑现），或 `direction.escalation_flags.停滞` 在场 → **此角色不得写与上轮相同或仅幅度变化的 `未完成意图`**（gate 意图循环硬拦）。须按档案自拟新路径，并按序取材：① 读自己 `decision.失败后续`（已写好的退路优先）；② 换路径——同目标换手段（如夺袋改为护人/留痕/止损）；③ 目标重估——放弃（同批覆盖 `decision.当前计划`·记 `计划变化: 调整——放弃`）或升级（强度/代价跃迁而非幅度加力）；④ 抓新机会——本轮新变量（新信息/新主体/新代价/新道具如崩裂钱袋散落的硬币；停滞加压轮查已登记载体：world_state.外部倒计时/CT.关联角色）。放行判据 = 本轮 `未完成意图` 与近 3 轮任一不同（意图变了即放行·动作词换皮不算）。
   - **行动链留痕**：`###SCHEDULE: 轮次N 窗口X分钟 顺序: A→B(受影响:信息)→C(受影响:威胁) 收敛: 窗口耗尽`——④的 `###SCHEDULE:` 只作留痕·**不落盘·不裁决调度**；调度权威=③ direction.调度单。

3. **自推演（焦内背景/焦外/在轨循环角色）**：调度单点名的焦内背景与焦外按自推演更新 CHAR_state——按下列两支之一执行：
   - **有发展**（推进池关联 CT／现场有变化／日程推进出新局面）：感知现场与冲突并作出反应，反应/新决策/情绪/关系变化如实写入 CHAR_state（轻量决策环·长期计划按 1.4「长期计划巡检」同规判定）；推进池关联 CT 的焦外角色，`decision.当前行动` 须为可揭示的新事实并产出待揭示事实。**持续产新事实直至窗口实质耗尽**，禁止半步即止以自推演名义跳过窗口。
   - **确无发展**：轻量刷新（仅改写核心状态与当前行动按日程位置）·META 显式标注「轻量：原因」。轻量轮不计为推进池关联者的满足。

4. **循环角色附加结算**（路由第 2 步命中者）：

   - **档位认知上限**：在该角色的行动落点处执行——焦内活跃在 1.5 行动实现，背景/焦外在职责 3 自推演（脚本=流程内容+极细微裂缝·禁元视角；漂移=+碎片直觉 1-2 次/日；觉醒/变质=系统判断/自我轨道）——见 loop_machinery §2.3
   - **偏离代价与偏离登记**：偏离入口唯三（VB/觉醒判定/用户指令）·按 loop_machinery §1 步骤 3a 同批结算偏离代价（压力/防御/核心状态/锚点/信念）并追加偏离登记。**偏离代价累积追踪：同一循环日内多次行动级偏离·程序报错式刺痛累积——④每轮须评估 压力水平/防御有效性 是否应更新（连续两轮打击未恢复即应写正在失效/已彻底崩解）·不等审计指出**

## 闸门
