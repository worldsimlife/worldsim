# 阶段④ · 角色（生命层·阶段开始前必读）

> 本阶段是引擎的心脏：**角色从被动执行者升级为自主即兴的生命层**——主动决策、持续行动、直写自己的状态文件。
> 全局铁律=SKILL.md「通用约束」；**阶段④=所有角色状态唯一写者**（Single Writer：CHAR_{名}_state）。
> 决策与写入规则（自治原则/决策环/写入/批次格式）＝**references/actor_decision.md**——子 agent 路径由子 agent 自读（过程规则·世界素材经 subagent_prompt.md 组装内联）·单窗口路径由主 agent 加载·两路径同规·单一来源。
> **编号约定**：编排层判定＝`On`（主 agent 做·本文件）；角色决策＝`Dn`（角色本人做·定义于 actor_decision.md）。

## 数据就绪（每角色各自加载·无共享前奏）

- **Runtime Context（优先引用）**：`worldctl.py <世界> context [角色]` 机械导出（direction 拍级字段编译：当前拍戏剧问题/guidance/调度单/时间窗口＋推进池 CT 摘要＋环境压力项）——**存在则优先引用**（省组装通道 token）；输出不足则按下项逐项读。
- direction（guidance / 当前拍戏剧问题 / 当前拍兑现形态（元层受力点·源＝事件线当前拍序）/ 时间窗口 / 调度单——焦内活跃·背景角色·焦外·焦外→焦内）
- 推进池 CT（冲突态势·其中 上轮结算.关系状态/上轮结算.内部状态 为快照·不作本轮当前真态·当前真态以 CHAR_state/scene_state 为准）＋ scene_state（现场：锚点/道具/在场角色）＋ world_state（外部倒计时/叙事约定）
- 自身 CHAR_.md（八变量）＋ CHAR_state（decision/连续行动轨迹/记忆锚点/人际动态/信念演化）
- 其他角色已落盘行动（本轮先行动者·级联输入）
- 循环世界：在轨同步——decision.当前计划 物化自 CHAR_.md「默认循环时间线」当前段至段末（**角色视为自己的计划·不知来源**；LOOPS 只供互锁协调）；此为**基线**，此后由 **D2「长期计划巡检」** 判定维护（在轨默认不动·见 actor_decision.md）

## 输出面总览（动笔前先看清）

本阶段产出＝**结构化决策＋自由即兴＋状态写入**三类。LLM 对每个决策**只返回决策结果（枚举值＋参数）**；结果到字段的映射是机械管道（见 actor_decision.md 写入节）。

#### 编排层判定（主 agent·`On`）

| 序 | 决策 | 问题 | 可选结果 | 缺省 | 落盘 |
|---|---|---|---|---|---|
| O1 | 角色路由 | 本角色本轮走哪条路径？ | `即兴`/`自推演` | 按调度单档位 | 产出路径 |
| O2 | 执行绑定 | 本角色决策环由谁执行？ | `子agent`/`单窗口`（参数＝豁免原因） | 子agent | META `绑定:` |
| O3 | 自推演分支 | 有发展？ | `有发展`/`确无发展` | 确无发展 | CHAR_state 更新 |

> **角色决策 `D1–D5`（角色本人做）定义于 actor_decision.md**——该文件由子 agent 独立读取·自带同款索引；下方执行链中出现的 D 编号即指彼处。

**执行链（逐角色）**：`数据就绪 → 骨架物化（前置分支）→ O1 角色路由 → O2 执行绑定 → 焦内活跃＝行动环（决策环 1.1–1.5·含 D1/D2/D3 ＋ 写入 D4/D5·循环至收敛）｜背景/焦外＝O3 自推演 → 职责4 附加结算（逐循环角色·O4 偏离判定→结算） → 写入`

**决策执行机制（本文件决策·三步）**：① 读「决策问题」→ ② 逐「决策选项」对照「选中标准」判定命中（多选项命中·按声明优先序取先）→ ③ 返回命中枚举值＋「参数」。本文件决策均为**判定型**（有缺省）。

**创造核心保持开放（非决策·不设枚举契约）**：决策环内的候选行动生成与账本取舍＝角色自治创造（候选清单仅为启发示例）；MUSE/ACTION 正文＝prose 面。

## 先决状态转换（骨架物化）

**所有角色通用**——先判 CHAR_state 是否含任一模板占位；任一 decision 子字段占位即为骨架。骨架不得进入路由、不得产 ACTION 或轨迹。

按 CHAR_.md 基线 ＋ 当前时刻物化位置/核心状态/妆扮/服饰，并连续完成两层：

- **稳定层**：核心诉求 ＋ 当前计划
  - 循环角色取 CHAR_.md「默认循环时间线」当前时段至终点的完整路径
  - **转写为角色第一人称话术**——时间线里的结局/收场类条目〔被击毙/被捕/重置/回收等·写给引擎看的落点标注〕不得原文进入，转写为该角色的行动意图或截至其可感知的步骤·角色不知来源
  - 非循环角色按核心诉求＋现状自拟
- **运行层**：当前行动 / 行动驱动 / 行动对象 / 行动窗口 / 失败后续 / 未完成意图

八项均实体化后才进入路由。随身物品初始为空，不物化。precheck SNAPSHOT §3 只提供待物化名单，物化动作在本阶段完成。判定标准见 keys.md「骨架物化规则」。

本阶段默认产出可观察新事实：调度单点名的焦内活跃/背景角色与焦外均按自推演或即兴更新 CHAR_state；推进池关联者 decision.当前行动 必为本轮八问驱动且未在近 3 轮出现过的可观察新事实。**新事实＝动词＋空间位＋对象皆变**。背景角色只写受波及的可观察显影，不替代行动主体。

**意图循环**：`未完成意图` 连续 3 轮相同（含仅幅度/称谓变化）→ 触发僵持再评估（见职责 2）·换意图后重写——动作词/幅度变化不算新事实。

所有角色各自按目标/恐惧/计划自主行动（第二人称用户角色：行动由用户输入给出）；任一角色的行动经受影响重评传播为其他角色的观察输入，不构成对其他角色的指示，不存在"等待用户"的全局冻结。

## 概念约束：元层 / 认知层分离（硬性·防调度层全知）

- **元层**（引擎指导）：direction guidance／事件线戏剧问题／CT 施压方向／顶点约束／调度单画面分档（谁入画·背景角色·焦外）／引擎记账（维护名单·轮次·偏离登记·自主性档位）——指导 LLM 注意力分配（「演什么戏剧效果最强」），**不写入角色认知与叙事**。
- **认知层**（角色所知）：自己的目标/计划/轨迹/感知到的他人行动与变化——已知可用·未知不可见。

## 编排

### O1 角色路由（判定型·唯一分流点）

**决策问题**：本角色本轮走哪条路径？
**缺省选项**：按③调度单档位（`焦内活跃`→`即兴`／`背景角色`·`焦外`→`自推演`）

**决策选项与选中标准**:
- `即兴` — ③调度单列 `焦内活跃`（或前置判定触发·见下）→ 职责 1（完整决策环→行动卡→decision→轨迹）
- `自推演` — ③调度单列 `背景角色`/`焦外` → 职责 3

**前置分支（先于选项评估·不实现为模式）**:
- **骨架物化** — CHAR_state 含任一模板占位 → 先走「先决状态转换」物化，本轮不产行动。
- **前置判定（内在驱动优先）** — 调度单=画面归属（谁入画/背景角色/焦外），**不封禁行动**。角色自身条件触发时按 `即兴` 路径执行，不受分档限制：
  - **失败后续触发** — `decision.失败后续` 条件被满足（如 Armistice：Hector 已中弹→转入近身火力掩护）→ 自升焦内
  - **未完成意图被新事实破坏** — 上轮行动结果改写了意图成立前提
  - **档案级行动要求** — CHAR_.md 崩溃表现/核心欲望驱动的行动（如 Sheriff：执行到死亡判定），不因伤退为「背景角色」而停止
- **POV 覆盖** — `world_state.叙事约定` 声明的 POV 用户角色优先于取行表（见下）。

#### 取行表（未触发前置判定的角色按此分档）

| 调度单归属 | 路径 | 本轮产出 |
|---|---|---|
| 焦内活跃 | 即兴（职责 1） | 行动卡＋decision＋连续行动轨迹 |
| 背景角色 | 自推演（职责 3） | CHAR_state 更新·不逐人产 ACTION，仅一句可观察显影 |
| 焦外 | 自推演（职责 3） | CHAR_state 更新·无行动卡 |

> 调度单是导演对画面的分档（谁在焦内活跃/谁是背景角色/谁在场外），**不是行动能力的封禁令**；角色内在驱动（前置判定）永远优先——角色先活，画面后归位。触发前置判定的角色本轮在调度单中所在档仅为画面参考，其行动按焦内活跃执行。

#### POV 用户角色（Guest）

按 `world_state.叙事约定` 声明视角走对应路径·**优先于取行表**：

- **第三人称 / 第一人称** — 该角色保有自主行动权，参与反应，按决策环自主行动（经受影响重评）。第一人称用户有输入则用户输入优先；第三人称用户输入作为行动素材经自主决策吸收后执行。第一人称额外可写其心理（共生感知），第三人称只写可观察显影。
- **第二人称** — 用户角色的行动由用户输入给出，按输入转写为行动卡＋decision＋轨迹；**用户本轮未给出行动（如仅「继续剧情」）→ 该角色本轮无 ACTION**（CHAR_state 走轻量刷新·不代写其选择/台词/心理）；**续环派发同规**——涉及其行动/反应的槽只填用户输入原文·**不补写其反应**（授权 ≠ 反应·见 subagent_prompt.md「POV 用户角色输入口径」）；其他角色照常自主决策与行动，本轮以焦内活跃多角色咬合持续。

#### 叠加在轨循环（SETTING 声明循环且本轮在轨的角色）

- **轻量推演＝计划层不重新合成** — 当前计划＝CHAR_.md「默认循环时间线」当前段至段末（角色视为自己的计划），按日程推进＋感知过滤；巡检归 **D2「长期计划巡检」**——在轨判「仍成立」即不动（见 actor_decision.md）
- **行动层照常执行** — 焦内活跃的循环角色照常即兴出行动卡；**偏离基线的行为按 loop_machinery §1 行 3 生成**（模型见 §2.3「循环角色偏离行为模型」），档位上限见 §2.3「常驻约束·行为档位上限」
- **附加结算** — 命中者走职责 4（偏离代价 / 变质判定 / 防御重构）

**角色视角遵循自己日程**（认知边界＝各角色自身视角·不区分是否循环/自主·无元视角）。

### O2 执行绑定（判定型·Step 0·进入决策环前逐角色判定）

**决策问题**：本角色决策环由谁执行？
**缺省选项**：`子agent`

**决策选项与选中标准**:
- `子agent` — 非第一/第二人称 POV 角色 ∧ 宿主支持「具名子 agent ＋ 续话保留上下文」
- `单窗口` — 第一/第二人称 POV 角色（用户指令转写）；或宿主不支持子 agent（本会话派发报错：工具不存在／宿主不可续话）

**参数**：`单窗口` → 豁免原因（写进 META 绑定声明）

**结果语义**：绑定声明经 gate actor 机械核验；有工具但执行失败走重派，不记为不可用；缺省不判定＝违规（失效即静默兜底·由绑定声明拦截）。

## 职责 1 · 即兴（决策环外壳）

焦内活跃角色·逐角色走完决策环。**决策环细则（每环步骤 / MUSE 语义 / 写入 / 批次格式）＝ actor_decision.md**——本职责只承载编排面（谁走哪条路、怎么派发与收口）。

### 共通约束（两路径同责）

#### POV 用户角色的 MUSE 转述

不增写用户未给的心理·不剥除用户已给的心理：

- 用户给出的行动/台词/情绪定性完整进入 MUSE
- 情绪定性写入 ACTION `情绪:` 字段并落为可观察显影（表情/视线/力道/停顿）
- 其未给出的心理留白（SKILL.md 视角语义·第二人称）
- 缺省＝组装违规（prompt arguments 可见，用户/审计抽查）

#### 跨角色行动竞争与链触发（主上下文执行）

- **行动竞争** — 所有活跃角色有行动资格；按驱动力＋行动机会＋空间条件＋角色能力＋行动代价＋他人行动决定本角色是否/何时行动。跨角色成链只经受影响重评触发，不预排他者行动与顺序。**角色不需要等待玩家行动才进入行动状态。**
- **Act 落地即触发** — 焦内活跃角色 Action 落地后，经受影响重评（十渠道）识别受影响角色，触发其下环（焦内活跃→回 Observe；背景角色→自推演一句显影）。一场戏由焦内活跃咬合触发连成链，非并列平铺。

### 子 agent 路径（非 POV 默认·子 agent 代入该角色·决策主体=角色本人）

**一次派发建立该角色的具名会话，窗口内每环向同一会话追加「感知增量 ＋ 本人上一环终止态」**（首环派发完整素材·素材槽位与追加格式＝references/subagent_prompt.md）。

**子 agent 以「我」走在决策环里**：CHAR_{名}.md＝我的人格，CHAR_{名}_state＝我的记忆，references/actor_decision.md＝决策环标准过程；步骤归规则，个性归角色。

#### 输入通道（组装为主·过程规则自读）

1. **组装通道（世界事实与人格记忆·主 agent 逐字内联）**——子 agent 零世界文件读取：
   - **内联内容** — CHAR_{名}.md（清单见 subagent_prompt.md【我的档案与记忆】槽·**外在特征·整体形象＋外貌须内联**——对应 CHAR_state 妆扮/服饰/健康 的档案基线）＋ CHAR_{名}_state（主观态/自体内在状态/自体可见状态字段·按组装转换矩阵）＋ 所在场景 scene_state 五节 ＋ 场景时间线中该角色**可感知**的相关条目 ＋ 本轮台词/行动**指涉历史事件**的权威原文
   - **内联口径（硬性）** — 逐字原文——主 agent 只做「选哪段/剔哪段」，禁止转述摘要
   - **档位转换** — 命运层/默认循环时间线/引擎面字段按 subagent_prompt.md「组装转换矩阵」（触发＝素材类型×自主性档位×特殊状态）裁剪或转换为该档位可知形式——档位语义以 loop_machinery §2.3 为唯一权威
   - **感知增量槽** — 他人本轮已落盘的行动/台词原文 ＋ 当前时间 ＋ 本轮未落盘新环境变化 ＋ 细看所见（条件槽·本人最近一次落盘行动含打量/端详/注视/细看等对具体对象的感知动作→附该对象可见细节）；每槽只有一个取值来源（槽位与取值来源＝subagent_prompt.md 骨架）
   - **POV 用户角色（第二人称）口径（硬性）** — 该角色的行动**由用户输入给出**：涉及其行动/反应的槽**只填用户本轮输入原文**，**用户未给的部分不填**——**不补写其动作/表情/注视/沉默/心理**（授权 ≠ 反应：「接受全套服务」＝可自主推进多环的授权，不等于允许代写其反应）。判据＝写「他站在那儿」可 · 写「他一动不动」禁（详见 subagent_prompt.md「POV 用户角色输入口径」）
   - **槽位纪律** — prompt 的段落标题照抄骨架槽位名，审计按槽名对照
   - **同窗口再环** — 对该角色活会话追加「刚刚发生的变化」段（感知增量；人格动力层随会话保留）
2. **自读通道（过程规则·仅此一项）**——prompt 给定路径，子 agent 自读 references/actor_decision.md（决策环步骤·产出格式）；无认知边界风险，不内联。
3. **子 agent 产出**——以该角色身份走完决策环，产出决策批次文本（###STAGE: 角色 段内容）返回，落盘由主 agent 收口。

#### 主 agent 收口（格式规范者）

子 agent 产出＝决策内容（语义权威）；批次格式与值域合规由主 agent 负责：

- **并入** — 以子 agent 产出的段为主体整体并入本阶段独批；主 agent 只做**合规规整**（按 keys.md 的值域与键路径映射字段枚举 / KEY 点路径 / META 记忆✓ 与绑定声明格式 / 时间顺延 / 阶段头归并），只规格式不审语义，照常 write-raw ＋ gate（gate 仍是最终拦截网）
- **叠加职责 4 附加结算**（循环角色·收口时执行）— 偏离登记追加（偏离判定与登记归主 agent·角色对自身轨道无元感知·按 loop_machinery §1 步骤 3a）；角色批内 压力水平=临界 且 防御有效性=已彻底崩解 时补写自主性升档 KEY（档位枚举不入子 agent·脚本按门槛硬检）。压力/防御（**D1**）与防御重构（**D5**）自查归角色本人（actor_decision.md·旧值随 CHAR_state 内联）——主 agent 不代评不代写，偏离刺痛以第一人称体验进该角色感知增量
- **闸门未过** → 向同一具名会话追加闸门报错原文，请其按 actor_decision 重做本环（闸门拦截＝未落盘·链上无新增）；重派仍未过，或语义缺件/不可判读、sub agent 不可用、自身文件读取失败 → 该角色本环按单窗口路径执行
- **责任边界** — 子 agent 产出的字段内容由该会话负责；主 agent 的规整面＝值域枚举/键路径/字段顺序/阶段头归并，字段的体量与值域由闸门机械核验。角色路由（含前置判定）、职责 3 自推演、受影响重评、行动竞争、链收敛与全部落盘仍在主 agent

#### 并行委派（默认）

**同批角色一律并行派发子 agent**（同一批并行调用·产出后统一收口落盘），各自独立走完本环：

- **收口与入环按行动落地先后** — 先落地者先入链，其落点作为感知增量回填给受它影响的角色、触发其入环（先 A 入链 → B 读已入链的 A 行动，从 Observe 接着走下一环）；回填范围＝受影响重评十渠道（空间/资源/信息/关系/情绪/目标/威胁/计划/时间/循环状态）
- **宿主无并行工具** → 按落地顺序顺序派发
- **并行产出互斥时** — 不代改任何一方文本（收口约束同「只规格式不审语义」）：按落地先后，以前落地行动原文为感知增量，向前提被改写一方的活会话追加下一环；新环在心声里明说改了主意，上一环照原样留在序列，场景事实取末环终止态

### 单窗口路径（POV 默认 / 回退·主上下文执行）

- **输入** ＝ 「数据就绪」节逐角色加载 ＋ 感知增量同规（他人本轮已落盘的行动/台词原文·当前时间＋未落盘新环境变化等）——主 agent 直接读取，不经组装内联
- **执行** ＝ 主 agent 代入该角色在主上下文自走决策环，上方共通段约束同施
- **闸门未过** → 主 agent 按 actor_decision.md 重做本环（闸门拦截＝未落盘·链上无新增）
- **绑定声明** ＝ `单窗口(豁免原因)`——POV 写视角依据（如 `单窗口(第二人称POV·用户指令转写)`）；非 POV 须命中豁免白名单字面（见 actor_decision.md「META 绑定声明」）

### 行动环（同窗口多圈·循环至收敛）

焦内活跃角色走完一环后**持续走环**——行动落地 → 进 **Result**（行动结果与他人反应·上下文 `###ACTION` 序列）→ 回 Observe → 生成下一行动 → …，直至收敛。**「走一环就停」不是默认，而是收敛条件成立后的结论。**

**派发（主 agent·只判机械面）**：主 agent 只判两个机械事实，**不判角色该不该继续**——「要不要继续、还要不要等」是角色的决策，不是调度层的判断（角色自治原则：禁止元层判断替代角色意图）：

- **窗口还有没有余量** — 有余才谈派发（余量为 0 即收敛）
- **下一环会不会需要用户角色作出新的行动/选择**（＝**超出用户已给授权**）→ **不派发·等用户**：引擎无法代用户角色行动（第二人称 POV 约定），继续派发只会导致「代写用户角色」或空环。**判据**＝该角色本轮行动链是否已走到「兑现条件指向用户角色的一个动作」（他接／他答／他选／他走）而该动作尚未由用户给出

> **窗口余量决定「能不能派」·用户授权决定「该不该派」——两者取与（AND），不是前者单独决定。**

**角色在本环内自判（语义面）**：该不该继续，由该环 1.1 状态构建／1.2 八问／1.4 定行动推出——**把本轮新输入一并读进去**（对方的授权/催促/沉默/新事实都可能改变「我还要不要等」）。**有要做的事 → 产 ACTION；判定此刻无事可做（选择继续等）→ 本环不产 ACTION。**

**收敛条件（三者之一·循环终止）**:

- **剩余窗口 = 0** — 剩余分钟由 context/precheck 机械导出（④ 不自行解析时间串）
- **角色本环产出无 ACTION** — 角色自己判定此刻无事可做；此时链由职责 2「受影响重评」接手
- **下一环需要用户角色的新行动**（超出已给授权）— **等用户**；链停在用户输入处，不由引擎续

**多环落盘（硬性）**：同一角色同窗口多环 ＝ 多组 `###MUSE:`/`###ACTION:`，**按发生顺序成对排列**（MUSE₁ ACTION₁ MUSE₂ ACTION₂ …），全环原文一并写入批次；`连续行动轨迹` **每环一条**（账本原文见 write_protocol.md「批次账本」）。

**行动链留痕**：`###SCHEDULE: 轮次N 窗口X分钟 顺序: A(环1→环2)→B(受影响:信息) 收敛: {窗口耗尽|角色无行动|待用户授权}`——只作留痕·**不裁决调度**（原文入批次原文账本）；调度权威＝③ direction.调度单。

## 职责 2 · 行动链推进（跨角色）

### 受影响重评机制（连续行动链收敛规则）

任何行动改变世界：

1. 识别受影响角色（十渠道：空间/资源/信息/关系/情绪/目标/威胁/计划/时间/循环状态）
2. **受影响者按其路由行入环**（焦内活跃→回职责 1 走下一环；背景角色/焦外→职责 3 自推演）

**入环＝在本人上一环已落地的结果之上追加一环**：上一环的心思与动作照原样留在序列里，改了主意就在新环里明说改了主意。不是「玩家→NPC 响应」也不是「每轮所有 NPC 重想」。**被事件波及者（①已并入该事件 CT `关联角色` 者）本轮须真的重评入环**——扩散不是只登记名字。

`受影响重评`（十渠道）负责**其他**角色的入环路径，与行动环的回边并列；decision 八子字段承载环当前态，连续行动轨迹七子字段保持跨轮连续。

### 时间窗口节流

③设定的本拍时间预算内按决策环持续产新行动并标注耗时：

- **窗口实质耗尽 → 链收敛**（无人工轮数上限）
- **无新受影响者 ＝ 链不跨角色延伸**——本角色续走行动环（职责 1）
- **窗口起点/预算由脚本随 `###BEAT` 落·④ 不逐轮重写**（只在现场重估时覆盖并写理由）——已耗＝世界时间−起点·由 precheck 机械导出

### 僵持再评估（前置分支·意图循环触发·角色层破僵持的唯一出口）

当 `未完成意图` 连续 3 轮未兑现（上轮行动结果仍标注未兑现），或 `direction.escalation_flags.停滞` 在场 → **此角色不得写与上轮相同或仅幅度变化的 `未完成意图`**（gate 意图循环硬拦）。须按档案自拟新路径，并按序取材（取材序非决策）：

1. 读自己 `decision.失败后续`（已写好的退路优先）
2. 换路径——同目标换手段（如夺袋改为护人/留痕/止损）
3. 目标重估——放弃（同批覆盖 `decision.当前计划`·记 `计划变化: 调整——放弃`）或升级（强度/代价跃迁而非幅度加力）
4. 抓新机会——本轮新变量（新信息/新主体/新代价/新道具如崩裂钱袋散落的硬币；停滞加压轮查已登记载体：world_state.外部倒计时 / CT.关联角色）

**放行判据** ＝ 本轮 `未完成意图` 与近 3 轮任一不同（意图变了即放行·动作词换皮不算）。

## 职责 3 · 自推演（背景角色 / 焦外 / 在轨循环角色）

### O3 自推演分支（判定型）

**决策问题**：本角色本轮有发展吗？
**缺省选项**：`确无发展`

**决策选项与选中标准**：`有发展`＝推进池关联 CT／现场有变化／日程推进出新局面；`确无发展`＝上述未命中

**结果语义**：调度单点名的背景角色与焦外按自推演更新 CHAR_state——按下列两支之一执行：

- **`有发展`** — 感知现场与冲突并作出反应，反应/新决策/情绪/关系变化如实写入 CHAR_state（轻量决策环·长期计划按 **D2「长期计划巡检」** 同规判定）；推进池关联 CT 的焦外角色，`decision.当前行动` 须为可揭示的新事实并产出待揭示事实。**持续产新事实直至窗口实质耗尽**。
- **`确无发展`** — 轻量刷新（仅改写核心状态与当前行动按日程位置）·META 显式标注「轻量：原因」。轻量轮不计为推进池关联者的满足。

## 职责 4 · 循环角色附加结算（每轮·逐循环角色）

### O4 偏离判定（判定型·编排层·每轮必过）

**决策问题**：本循环角色本轮是否处于行动级偏离？
**缺省选项**：无偏离
**适用与豁免**：仅循环角色（外部者/管理者不触发；自主性=变质 豁免偏离代价——loop_machinery §3「豁免」）。

**决策选项与选中标准**:
- `无偏离` — precheck SNAPSHOT §1b 该角色「预设 vs 实际」无差异；或仅轻微偏差（记忆碎片渗透/短暂出神——不构成行动级）
- `偏离` — 本轮命中行动级判据（离岗/跨节点/结构性行动变更·判据权威=loop_machinery §2.3·本节不复述），且 CHAR_state.偏离登记 的最近条目不属上一轮
- `累积偏离` — 本轮命中行动级判据，且 CHAR_state.偏离登记 的最近条目属上一轮（同一循环日内连续）

**输入取用序**（机械源·两处同据 loop_machinery §2.3）：①本轮已唤醒 → 以①轨道✓结论为准；①未唤醒 → precheck §1b 对照（每轮恒有）。

**结果语义**：
- `无偏离` → 本轮无偏离结算。
- `偏离` → 按 loop_machinery §1 步骤 3a ＋ §3「强度公式」（压力/防御按档位强度计入）＋ §3「影响字段」执行偏离代价结算；落点细则=下方「偏离代价与偏离登记」。
- `累积偏离` → 按 loop_machinery §3「影响字段」（持续磨损·经 D1 评估）＋ §3「偏离终局」执行累积结算；落点细则=下方「偏离代价累积追踪」。

### 档位认知上限

在该角色的行动落点处执行：焦内活跃在行动实现（决策环末环），背景角色/焦外在职责 3 自推演（档位内容见 loop_machinery §2.3「常驻约束·行为档位上限」·非循环角色无此限）。

### 偏离代价与偏离登记

偏离刺痛以第一人称体验进该角色感知增量（subagent_prompt.md 组装转换矩阵「偏离在场」转换·主 agent 按 O4 结果填骨架槽；单窗口路径主 agent 代入角色同规自评）；代价的体验面（压力刺痛/核心状态/锚点/信念）归角色自评落写入；偏离登记＝主 agent 收口同批追加（角色对自身轨道无元感知·键表=keys.md「偏离登记」）。

### 偏离代价累积追踪

同一循环日内多次行动级偏离·程序报错式刺痛累积——每轮经 **D1 内在状态评估** 评估 压力水平/防御有效性 是否应更新（连续两轮打击未恢复即应写正在失效/已彻底崩解）·不等审计指出。

## 闸门

闸门随落盘逐段自动执行，不合格 ＝ 本段整体拦截不落盘（查询轮豁免）。硬性项：

- ###STAGE 匹配
- 行动卡三件套
- **每个 ACTION 角色 `decision` 运行层六项齐全**（当前行动 / 行动驱动 / 行动对象 / 行动窗口 / 失败后续 / 未完成意图）
- 角色档案存在
- 角色覆盖 / 记忆✓ 对照
- **绑定声明对照（判据=O2）**——每个 ACTION 角色必须有绑定路径；裸单窗口＝拦；非 POV 单窗口须命中豁免白名单字面，否则硬拦
- **MUSE 存在性**——ACTION 角色须有同名 MUSE 行；同角色 MUSE 与 ACTION 成对、计数相等
- **多环留痕**——`###SCHEDULE` 标注某角色多环（`环1→环2`）时，该角色本批含 ≥2 组 MUSE/ACTION
- **SCHEDULE 留痕**——角色批必含
- **轨迹 APPEND**——有 ACTION 角色必含
- **调度单点名角色（焦内活跃/焦外）必须进角色覆盖**
- **`未完成意图` 连续 3 轮相同（含仅幅度/称谓变化）→ 意图循环拦截**（放行判据＝本轮意图与近 3 轮任一不同·豁免＝循环角色在轨轻量·触发条件见职责 2「僵持再评估」；计数按轮次去重——同轮多环＝同一轮，取该轮末环的 `未完成意图`）
- Single Writer

单段复检＝`gate actor --check`。标准模式人工审计（A 清单·默认不通过·找茬制·≤2 轮）见 references/gates.md。
