# WorldSim — 回退协议（rollback.md）

> 回退/重置/重来的全规格。触发「回退」「重置」「重来」「撤销 XX」时读取；不逐轮加载。
> **原则：回退是低频例外——正常每轮零额外动作。成本只在回退发生时承担。**

---

## 触发场景

- 用户**明确**表达回退意图（「回退」「重置」「重来」「撤销 XX」等词**且指代世界操作**）——**叙事台词/角色对话/引用语境中出现这些词不触发**；触发前回显将执行的动作与范围，用户确认后执行
- 叙事推进出错需回到某状态：规则冲突（法则忠诚违反）、编造设定（无来源知识）、用户不满当前走向——先向用户说明原因与回退范围，确认后执行

## 回退通道（按可用性优先）

| 优先级 | 通道 | 命令 | 说明 |
|--------|------|------|------|
| 1 | 快照恢复 | `python3 scripts/snap.py <世界> load <快照名>` | 最可靠。snap.py save 是**主动存档**（关键节点/剧情转折/重置前手动执行·自动命名带 r<轮次> 前缀便于识别），不是每轮自动。load 为破坏性操作（覆盖当前状态·自动备份 _before_）——交互提示确认 / 非交互加 `--force` |
| 2 | 场景级重置 | `python3 scripts/reset_scene.py <世界> [<场景ID>] [--force]` | 重置场景到 start_snapshot 开场（世界时间/轮次回退至场景开场·CHAR_state 记忆保留）。破坏性操作——交互提示确认 / 非交互加 `--force` |
| 3 | 手工重建 | 见下方「降级路径」 | 无快照时从历史痕迹反推目标状态（不保证完整） |

**为什么没有每轮自动机制：** 快照（全量）和 undo 日志（增量）都会给每轮高频流程加负担——而回退是低频操作。正确权衡：**负担放在回退发生时**（主动存档一次 / 手工重建一次），不放每轮。

## 涉及文件清单（回退时逐项核对）

| 文件 | 每轮变化方式 | 回退处理 |
|------|-------------|---------|
| world_state.yaml | 轮次/时间/前情/外部倒计时/时间线/焦点场景（覆盖） | 快照恢复；手工重建时：焦点场景/轮次/时间/前情/倒计时逐项回退 |
| conflicts.yaml | CT 状态字段（关系状态/内部状态/相位·覆盖）·新 CT（注册） | 恢复旧状态；删除回退期间注册的 CT；direction 指针对照回退 |
| CHAR_{X}_state.yaml | 核心状态/情绪/位置/decision（覆盖）·记忆锚点/连续行动轨迹/信念演化/偏离登记（APPEND 累积·旧字段反应轨迹同理） | 恢复覆盖字段；裁剪 APPEND 条目到目标轮；**一律用 `write-raw --batch --force` 覆盖** |
| scenes/{S}/scene_state.yaml | 场景时间线（APPEND·按轮次）·核心状态/出场摘要/关键信息（覆盖） | 按 轮次 字段裁剪到目标轮（元数据过滤）；恢复覆盖字段 |
| scenes/INDEX.md | 场景状态 ACTIVE/COMPLETED·新场景登记 | 恢复旧状态；删除回退期间创建的场景行 |
| scenes/{S}/narrative*.md | write_narrative 轮转（narrative.md=最新·旧文件轮转保留） | narrative.md 恢复目标轮叙事（从轮转文件还原）；删除回退期间产生的轮转文件 |
| scenes/{当前焦点场景}/pending_actions.yaml | 覆盖 | **最易漏**：删除回退期间新增条目；恢复旧条目 |
| world_map.yaml | 新区域登记 | 删除回退期间登记 |
| scenes/{新建场景目录} | init_scene.py 创建 | 回退到创建前 → 删除整个场景目录 |

## 硬性规则（经验教训·2026-08 Westworld 回退实战）

1. **回退优先 snap.py load / reset_scene.py（脚本·最可靠）**；无快照手工重建走 **`write-raw --batch --force`**（显式回退·绕过 audit ④ 轮次单调/⑬b 轨迹覆盖写·其余硬性检查照常）——**不加 `--force` 的 write-raw 会被 audit 顶回**（防误操作·正合意图）；回退豁免的是**正常推进的写前自动拦截**（回退是显式用户指令）；**不豁免事后核验：回退后必做残留扫描 + validate + audit 全通过才算完成**（见本章 4/5 条）。
2. **无快照时回退只能靠历史痕迹重建（不保证完整）**：conflicts 状态字段被覆盖后旧值丢失（从 scene_state 时间线/出场摘要/连续行动轨迹反推）；CHAR_state 裁剪 APPEND；narrative 从轮转文件还原。**关键节点主动 snap.py save 可避免降级。**
3. **回退字段修改（脚本·硬性）：** 一律 **`write-raw --batch --force`**（显式回退·绕过 ④ 轮次单调/⑬b 反应轨迹覆盖写·yaml.dump 序列化·无闭合引号破坏风险）——记忆锚点/信念演化/偏离登记/连续行动轨迹/场景时间线（yaml 列表）`###KEY:` 覆盖为按轮次裁剪后的列表·反应轨迹（字符串·旧字段）`###KEY:` 覆盖为裁剪后文本。**yaml 库不再用于回退**（仅坏文件修复例外·见 phase_keeper.md 例外①·脚本对无法解析的文件拒绝写入时直接修引号后回归脚本）；回退后必须过 validate。
4. **写入重定向意识**——write-raw 的 scene_state 落点 = world_state.焦点场景。创建新场景（init_scene.py）后，后续批次写 scene_state 会**落到新场景**而非你以为的旧场景。回退前先确认内容实际落点，再决定删哪。
5. **回退后必做残留扫描**——grep 目标轮次之后的时间戳/轮次号/场景ID/被撤销台词关键词；**逐文件核对含 scenes/{当前焦点场景}/pending_actions.yaml**（本次实战即漏在此）。参考扫描面：
   - 时间戳：回退后时段的 `13:54`、`13:56` 等
   - 轮次号：`第32轮`、`第33轮`（CHAR_state 连续行动轨迹/记忆锚点）
   - 场景ID：`S06`、新场景名
   - 台词/设定：被撤销的台词关键词（如「演了这么多年」「回收借口」）
6. **回退后必跑 validate**——`python3 scripts/worldctl.py <世界> validate` 全部文件通过才算完成。历史 ASCII 引号污染会让 yaml 解析静默失败（worldctl 容错返回空）——validate 是唯一防线。
7. **修改前自动备份**——snap.py load / reset_scene.py 内置 `_before_` 备份；手工文件级回退前先 `snap.py save`。

## 手工文件级回退的兜底顺序（快照缺失时）

按依赖顺序逐层处理，每层处理完立即 validate：

1. **先删后补**：删除回退期间创建的物理物（场景目录/INDEX 行/world_map 登记）
2. **world_state**：焦点场景/轮次/时间/前情/外部倒计时
3. **conflicts/direction**：CT 状态字段（按 scene_state 时间线+出场摘要反推）·拍指针回退
4. **scene_state**：时间线裁剪 + 核心状态/出场摘要恢复
5. **CHAR_state**：核心状态/情绪/位置/decision 恢复 + 记忆锚点/连续行动轨迹/信念演化/偏离登记按轮次裁剪（`write-raw --batch --force` 覆盖）
6. **pending_actions**：条目回退（最易漏）
7. **narrative**：主叙事恢复目标轮
8. **残留扫描 + validate**：全仓 grep + worldctl validate

## 场景级重置（reset_scene.py）

- 已有能力：narrative 归档置空 + 场景时间线清空 + 核心状态待填充 + 静态基线保留（物理锚点/道具/关键信息/出场摘要）+ 自动存档 + **world_state 时间/轮次回退至场景开场**（start_snapshot 冻结时间/开场轮次）
- 用途：场景重开（不撤销世界进度）
- 注意：CHAR_state（角色记忆/情绪）不因场景重置而清空；若需要角色记忆也重置 → 走 LOOPS 重置机制
- 重置后必查（脚本不自动处理·LLM 按本文件「涉及文件清单」逐项核对）：conflicts CT 节拍回退（对照 snapshot 开场节拍态）·CHAR_state 快照/记忆（累积字段按开场轮次裁剪·轮N≥开场轮次→删）·world_state 前情/倒计时/标记（前情可重写·倒计时/标记对照 snapshot）·scene_state 核心状态/出场摘要·scenes/{当前焦点场景}/pending_actions 焦外条目（揭示场景=本场景→snapshot 恢复·纯背景→清空重生成·最易漏）·world_map 新登记
