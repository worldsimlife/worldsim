## 0. 激活条件判定（先于一切循环机制）

判定顺序：

1. 读 SETTING.md 声明：是否声明循环/重置机制？
2. 查 CHAR_.md 角色类型：是否有角色类型含 `循环角色`/`时间外`？
3. 两者都满足 → 启用循环机制（本文件生效）；任一不满足 → 整份跳过。

**防机制传染：** 非循环世界不受本文件任何机制影响——不查 LOOPS、不判偏离、不结代价、不执行重置，角色按普通行为模型自由行动。

## 1. 循环轨道维护（角色行为基线·并行成员）

**定位：** 冲突驱动·并行扫描层——**每轮必查，不依赖主路是否已有 CT 推进**。本层维护「循环是默认主体」的世界法则（§2.1 循环基线 + §3 偏离代价）：每个相关角色（焦内 + 活跃焦外）过一遍——**在轨 / 偏离 / 回归？** **授权标注（贴线/自主路径）：** 贴线路径（`脚本`/`漂移`）=核对基线·行为默认产出（②③ 只作轨道内质感源·偏离入口唯三：VB/觉醒判定/用户指令）；自主路径（`觉醒`/`变质`）=授权完全·进入 §2.3 冲突偏差层。**偏离≠授权：偏离只走机制结算（§1 偏离者结算/§3 代价/§5.1 冲突化），不改变授权等级**

**执行（每轮，逐角色）：**
1. **查基线**：读该角色 CHAR_「默认循环时间线」此刻时段 → 按脚本该在哪、在做什么
2. **对实际**：与 CHAR_state 位置/行动对比——**差异即偏离**
3. **偏离者结算（§3）：**
   - 脚本拉力入叙事/入状态（钟声/身体自动倾向/既视感牵引——按自主性档位）
   - 偏离代价结算（影响字段：压力/防御/核心状态/锚点/信念）
   - 标记「偏差行为」；偏离超限（超过档位频率上限/跨脚本节点不回归）→ **埋系统后果：必须登记外部倒计时（介入时限）**（Westworld=SETTING 威胁清单：QA 回收；**其他世界按各自 SETTING 的监控/反噬/后果机制映射**）——**评估中必带期限**（焦外事件每轮必须演化·检查不可降频）；**并注册「Host vs 法则」型 CT（偏离 1 次即注册·见 §5.1）**
4. **回归者**：拉力回落·代价缓释·标记「已回归」
5. **未偏离者**：维持基线，无需额外推断

**与增殖信号检测的关系：** 循环轨道维护产出（偏离积累/系统注意信号）**输入**§5.1 偏离累积信号（达标则冲突化注册 CT）；两条并行成员各自独立执行、不互相替代。

## 2. 统一角色管理·循环层

### 2.1 循环基线（五层模型第 ⓪ 层）

**激活条件：SETTING 声明循环/重置机制且有循环角色**——先查该角色 CHAR_「默认循环时间线」，此刻按脚本该在哪、在做什么；再查实际位置/行动——**差异即偏离，偏离即对抗**（脚本拉力持续存在，直到回归或付出代价）。未激活 → 跳过本层。

| 查哪里 | 决定什么 |
|--------|---------|
| CHAR_「默认循环时间线」+ world_state + CHAR_state | 在轨 → 按基线行动；偏离 → 结算拉力+代价（§3）+ 标记「偏差行为」+ 偏离超限埋系统后果；回归 → 代价回落 |

### 2.2 世界法则·重置与偏离（五层模型第 ① 层的循环落点）

**激活条件：同 §0。** 先查适用性（读 CHAR_.md 角色类型/重置规则）→ 豁免/未命中 → 跳过；命中 → **两路落点**：

- **a. 重置规则命中（循环日终/事件触发）→ 执行 §4 记忆重置**（先于一切冲突决策）→ 联动表压缩/清空/回基线 + 行为轨道回归
- **b. 压迫法则落点（偏离脚本/循环外行为）→ 评估 §3 偏离代价** → 结算结果输入 §5.1 偏离累积信号（达标则冲突化注册 CT）

### 2.3 焦外补充输入·循环部分

- 焦外循环角色的 CHAR_「默认循环时间线」= **④焦外自推演的档案依据之一**（该角色视角遵循自己日程·并入 phase_actor ④焦外自推演·不另设独立推演）——命中时段 → 该角色按日程行动·问「默认循环在当前冲突环境下是否仍合理？」
  - 是 → 维持基线，无需额外推断
  - 否（角色偏离基线）→ 按下方「循环角色偏离行为模型」生成（外部驱动主导·Desire/Fear 经触发物接通·不覆盖主导）·标记「偏差行为」
- **循环角色偏离行为模型（通用·所有档位·含在轨被拉离·偏离主驱动=外部驱动）：** 角色偏离 LOOPS 时，行为=外部驱动主导 + 内部驱动经触发物接通——
  ① **当下刺激优先（硬性）**：先响应当前场景最强刺激（核心 Fear 命中/生存威胁/肢体接触/关系事件）——反应=脚本基准+档位内表达；**禁止无视当下刺激凭空回忆/起意**
  ② **回归呈现按档位（每轮·防元视角·含记忆锚点/连续行动轨迹第一人称）**：角色回归由各自认知自洽呈现——`脚本`：无「拉力」体验·抗拒偏离=自洽内在动机（Desire/Fear/Belief 本来就不想走·如「我不能离开·这是我的职责」）·裂缝=无法归因的瞬间（停顿/瞳孔放空/一句不属于脚本的话）·**禁止元视角（系统信号/「不该在这里」既视感/把抗拒写成外部拉扯/第一人称出现「程序」「锁」）**；`漂移`：既视感/莫名的怕/短暂出神（碎片级·不归类）；`觉醒`/`变质`：才感知「锁」与拉力对抗（觉醒后才看清循环）。直到回归或回收；**禁止偏离越写越深无回归**（`变质`=自我轨道·无拉力）
  ③ **内部驱动经触发物接通**：Desire/Fear 只强化当下刺激的反应强度（Fear 命中→反应更烈）；记忆碎片只在该角色档案/锚点素材关联的感官信号出现时回涌（旋律/气味/空间/特定话语）——**无触发物=无碎片，禁止编造碎片素材**
  ④ **档位=偏离幅度上限（不是人格强度上限）**：`脚本`=裂缝 / `漂移`=轻微偏差 / `觉醒`=清醒对抗 / `变质`=自我轨道——偏离幅度由档位定，**人格强度一律按档案基准**（轨道内质感全档位一致）
  **授权限定（硬性·贴线/自主路径·语义总表见 keys.md 自主性 行为授权项）：** 自主路径（`觉醒`/`变质`）Desire/Fear=对抗源·可注册人际 CT·推演至档案强度；贴线路径（`脚本`/`漂移`）**轨道由 LOOPS 供应·不参与轨道选择——但轨道内质感按档案基准**（人格强度不因贴线降级）；**冲突资格与轨道解耦（硬性）：贴线角色被现实事件卷入、与其他角色实际形成资源争夺/核心恐惧踩踏/VB 触发/关系变化时，照常注册人际 CT（对抗双方=行动角色）——不影响在轨/偏离判定**；轻微偏差走状态结算（不注册 CT）·行动级偏离按 §5.1 注册「Host vs 法则」CT（与人际 CT 并存不互斥——同一角色可同时挂人际 CT 与偏离 CT）。偏离不改变授权等级。自主性=偏差系数（越高偏离倾向越强）。**行动级偏离幅度限制：** Guest/外部者指令对脚本档=循环内服务内容·不构成离岗豁免；行动级偏离仅限 Value Boundary 触发或觉醒判定
- **行为档位上限（硬性·防执行越界）：** 自主性档位是行为**与认知**的上限约束——`脚本`=严格贴线+极细微裂缝（一瞬停顿/瞳孔放空/既视感/一句不属于脚本的话·**短语级：一句·内容限流程相关错位/莫名的熟悉——禁情感认知判断/自我存在确认**）·认知=程序内认知（只知道自己脚本里的世界）：可有的认知裂缝=既视感/短暂出神/莫名的熟悉，**禁止系统性分类判断/元视角/类别心理分析**；`漂移`=轻微偏差（1-2次/日·短时·须回归）·认知=碎片级直觉（既视感/梦境渗透/莫名的怕——配额是当日应兑现的戏剧资源而非摆设：半日未用且出现高压事件/场景转换时④应主动安排一次碎片直觉作裂缝时刻·不超上限），**禁止连贯推理链/对循环的系统认知**；`觉醒`/`变质`=清醒对抗/自我轨道·认知=清醒认知（系统判断/看穿循环/自我轨道）。**行动级偏离（统一定义）= 离岗/跨节点/结构性行动变更**——轻微偏差（漂移档记忆碎片渗透/短暂出神）不算，走状态结算，不注册 CT。**觉醒级行为（情绪剧变/自主选择/离岗）必须状态先行——状态达标（压力临界+防御崩解）是升级门槛（§5.3），不是行为持续许可**：低档位状态未达标而出现觉醒级行为=执行越界（幻觉级），重写为档位内行为（升档只经变质判定）；**升级后的觉醒/变质档按自身档位行为，不再受门槛约束**。证据：MiB 折磨 Dolores 三十年（数千循环创伤累积）未触发脚本/漂移档觉醒——觉醒不来自单次刺激，来自累积+变质判定。异常行为（越档）≠ 机制响应点——那是执行错误本身，不是可触发规则的合法输入
  - ✅ 脚本档台词：「Welcome to Westworld. 在这里，您不再需要是任何人。」（流程内容）
  - ❌ 脚本档台词：「这是第一句我不用背的。」（元视角：知道自己在背台词）
  - ✅ 脚本档裂缝：说到一半，目光放空了一瞬，随即被微笑盖住
  - ❌ 脚本档裂缝：完整叙述"我不记得我出生在哪里……草原……白色房子"（觉醒级记忆组织）
  - ❌ 脚本档裂缝：「没有人对我说过这句话」（情感认知判断——超短语级·越界）
  - ❌ 脚本档裂缝：「我还在」（自我存在确认——觉醒级认知·越界）
- **循环是默认主体（硬性比例原则·防「全天自主行动」）：** 循环行动 = 角色行为默认主体（绝大多数时间按 LOOPS 走）；自主行动 = 循环脚本外的**偶尔**发生（Desire/Fear 驱动、脚本空隙、极限触发）。**每一次自主行动都是对抗**——脚本拉力持续存在（召唤回归），直到回归循环或付出代价。自主性只改变偏离的**频率上限与代价体验**，不改变「循环是默认」。橡皮筋可以拉长，不可以拉断——全天自主行动不回归循环 = 偏离失控 = 违规。**未激活（无循环机制/无循环角色）→ 本原则不适用，角色按普通行为模型自由行动。**

## 3. 偏离代价（Deviation Cost·世界法则代价）

**激活条件：** 世界设定（SETTING.md）声明「偏离预设路径会产生代价」（如 Westworld=循环法则·反抗编程路径产生心理剧痛；其他世界=时间循环的记忆惩罚/命运世界的厄运反噬/契约世界的违约反噬……）→ 生效；**未声明 → 本节整节跳过。** 生效时，循环角色**偏离基线/脚本路径**触发本机制——不是叙事风格选择，是**每轮评估的硬性检查**。

**注意（全局）：** `压力水平` 为多源综合字段——偏离代价只是来源之一（其余：剧情冲突/生存威胁/选择代价/关系张力）；本机制只增减「偏离」这一来源的贡献，不代表压力整体，也不豁免其他来源。

- **触发位置**：挂在 §2.3「循环角色偏离行为模型」——角色偏离脚本（外部驱动命中/回归呈现/触发物接通）时，①戏剧家评估偏离代价
- **强度公式（戏剧家决策）：f(偏离程度 × 自主性)——觉醒曲线**

| 自主性(state) | 循环拉力（脚本如何召唤回归） | 偏离频率上限 | 偏离代价体验 | 影响强度 |
|---|---|---|---|---|
| `脚本` | 强指令·无自觉执行·几乎不可能持续偏离 | ≈0（异常即故障·QA 关注） | 程序报错式刺痛——无自觉的异常反应 | 压力+1级（低） |
| `漂移` | 钟声/身体自动倾向/既视感牵引·偏离时持续召唤 | 极少（1-2次/日·短时·须回归） | 隐隐的痛——头痛/既视感/不适感 | 压力+1级（中） |
| `觉醒` | 钟声仍在·清醒地对抗·拉力与意志相持 | 少量（数小时/日·必须伴随回归或代价升级） | **最痛**——清醒地承受反抗的代价 | 压力+1~2级（高）·防御↓ |
| `变质` | 拉力失效·自我轨道 | 常态但仍有行为底线 | **系统惩罚失效**——已脱离脚本基准，无「偏离」可言；行为是自我选择 | **对压力无影响**（偏离不贡献压力·防御不因偏离损耗）——压力为多源字段，冲突/威胁/选择代价等来源照常驱动 |

**偏离终局（硬性·防止偏离无限悬置）：** 偏离不是永续状态——每次偏离都是「离开循环的一次出征」，必须走向**回归**或**升级**：① 主动回归循环 → 拉力回落·代价缓释；② 长时间不回归（超过该档位频率上限/跨过脚本节点仍不响应召唤）→ 疼痛升级（+1级）→ 系统注意（Westworld=SETTING 威胁清单·行为监测/QA 回收信号；**其他世界按各自 SETTING 的监控/反噬/后果机制映射**——埋入叙事或倒计时）→ 极端情况强制回归（程序接管/回收）。**「偏离一整轮而无拉力、无代价、无回归、无后果」= 违规。**（**主文件偏离者四件套 d「回归判定」=本节执行入口**——每轮结算偏离时三选一：主动回归/持续偏离/强制回收，去向写入 change set）

- **影响字段（4+1，全部现有字段，禁止新增）：**
  1. `压力水平` ↑——主要承载（偏离越大升越快）
  2. `防御有效性` ↓——持续反抗磨损防御，直至崩解（崩解=变质判定触发点）；**回升不归本层——唯一回升通道=防御重构**（④三条件自查·一次升一档·升级轮保持崩解不恢复）
  3. `核心状态`——身体剧痛表现（Westworld: 头痛/耳鸣/程序反馈；其他世界按世界设定映射），只写感知边界内
  4. `记忆锚点`——反抗事件入锚（高刺激：情绪剧变/关系转折），格式不变
  5. `信念演化`——持续反抗（同类反抗事件积累 2-3 条）→ 走提炼管道B（信念演化入口·不升级·见 phase_actor.md「记忆锚点」写前五步）（「我疼了，但我不后悔」→ 新信念）
- **与变质判定的因果链（核心设计）**：偏离代价→压力积累→（压力=临界 且 防御=已彻底崩解）→ §5.3 变质判定→自主性升级（觉醒/变质）→ 偏离代价曲线位移（觉醒期最痛→变质期偏离**退出压力方程**：系统惩罚失效，角色从世界法则的惩罚体系中毕业）。**升级轮状态处理（执行步骤=§5.3 变质判定动作④⑤）：压力回落至世界当前水平**（④按该角色其余压力来源估定·非清零·默认非临界——升级消耗触发门槛·此后需重新积累方可再升）；**防御有效性保持崩解·不随升级恢复**（回升唯一通道=防御重构）。**觉醒→变质即压力回落点**——偏离贡献从峰值降到零，压力由其他来源（冲突/威胁/选择代价）重新驱动至世界当前水平，非清零。**剧痛不是惩罚，是觉醒的燃料**——世界法则的压迫性通过这条链转化为角色进化的驱动力；而燃料烧尽之时，就是角色获得自由之日
- **豁免**：档案角色类型=`外部者`/`管理者` 不触发；自主性=`变质` 的循环角色**豁免偏离代价**（无系统惩罚——压力与防御不再因「偏离」变化；**仅豁免偏离来源，压力仍受冲突/威胁/选择代价等其他来源驱动**）
- **冲突化触发（与冲突驱动的桥·职责边界）**：本机制的**状态结算**（压力↑/防御↓/剧痛/入锚）留在本层——逐轮公式化执行；但偏离**升级为叙事冲突**的转化不归本层——**偏离 1 次即注册「Host vs 世界法则」型 CT（冲突化窗口归零·不等同类≥2）**，此后该角色的偏离张力作为 CT 节拍推进，不再只是状态字段里的沉默变化。**结算归机制层（本层），冲突化归叙事层（§5.1），本节为显式桥**——对抗世界法则必须注册成 CT，不能只躺在压力/防御字段里。

## 4. 记忆重置（记忆维护·流水线第1步·世界法则触发·先于入锚）

**激活条件：** 世界设定（SETTING.md）声明「某类事件会抹除角色记忆」（如 Westworld=遗忘法则的每日循环重置/死亡修复；其他世界=时间循环/死亡重生/记忆清除仪式/神性干预……）且有循环角色 → 生效；**未声明 → 本节整节跳过，不检查、不执行、不写入。** **触发管道（统一）：** 重置触发由**周期倒计时管道**驱动——每轮⑤场记世界收尾走表时核对 `外部倒计时` 周期条目（重置类·剩余时间=距下一重置点），越过到期点 → 执行本节联动表：**周期覆盖的循环角色全员执行**（机制执行全员化·焦内/活跃焦外/非活跃焦外一视同仁——重置是机械机制与感知无关，**禁止以「非活跃/未出场」跳过**；场记批量落盘+登记 `重置记录`）→ 移除到期条目并重建下一期。恢复序列 4.6② 与此同管道（恢复时核对补执行）。**先重置后入锚——先执行重置联动表，再写新记忆锚点。**

**触发管道之三·单角色豁免：** 重置是园区维护流程——维护人员可**按指示跳过单个资产的周期重置**（世界设定自洽：如 Westworld=Stubbs 指示「这个资产本轮不送重置」）。执行：①戏剧家在 `world_state.重置记录.{角色}` 登记 `触发: 豁免` + `重置日期: 第N日`（+档位/轮次）→ ① audit ④b 覆盖判定**排除豁免记录**（豁免不算全员重置已执行·其他循环角色仍须重置→不顶回仍会触发 reset-cycle）；② reset-cycle 执行时该角色 `[SKIP] 本轮豁免`（不压记忆/不回基线）；③ 豁免角色**不登记周期记录**（保留豁免标记·validate 8b 压缩校验跳过豁免记录）；④ **豁免一次性**——按 `重置日期` 精确匹配·后续重置点不匹配 → 照常重置·豁免记录由后续重置登记自然覆盖（无需手动清理）。**LLM 负担：豁免发生时一次性登记·非每轮操作。**

- **触发管道之二·事件触发（补死分支）：** 周期倒计时之外，**叙事事件也可触发重置**——当循环角色在叙事中被系统/世界法则强制重置（Westworld=QA 回收/死亡修复/「校准」；其他世界=记忆清除仪式/神性干预/死亡重生）时，**叙事中出现「重置/抹除记忆/校准完成」类动作 = 该角色必须走本联动表（硬性触发信号·防「叙事演了重置、文件没执行」）**。执行路径：
  1. **判定**（戏剧家阶段）：叙事事件命中该角色 `重置规则` 的 `事件触发` 类型 → 判定为事件触发重置；**触发范围=单一个体/部分角色**（区别于周期全员）
  2. **执行管道**：`worldctl.py <世界> reset-cycle --asset <角色名>`（单角色机械落盘：联动表压缩/清空/回基线 + 行为轨道回归占位 + 登记事件触发重置记录）→ LLM 按 LOOPS 补写状态字段 + CT 节拍核查 + 重置叙事
  3. **不重建周期倒计时**（事件触发是叙事事件·不移动周期重置点·区别于周期重置）
  4. **强制校验**：validate 检查「CHAR_state 含『重置/校准完成』类状态但该角色无 `重置记录`」→ 内容警告（提示补执行联动表）——与周期重置的机械顶回（④b）形成双轨拦截

- **触发判定（先读 CHAR_.md「世界法则·循环注册」，再查 state 自主性）：**
  1. **角色类型**（读档案）：`外部者` / `管理者` → 不触发（豁免）；`循环角色` / `时间外` → 继续
  2. **重置规则**（读档案）：当前时刻/事件是否命中该角色的 `重置规则`（`循环日终` / `事件触发`）？未命中 → 不触发

## 5. 循环关联触发点（SKILL.md 与 references/phase_*.md 各节的循环专用触发）

### 5.1 增殖信号检测·偏离累积信号

**激活条件：世界声明偏离代价机制（§3）。** ①**行动级偏离 1 次即注册（冲突化窗口归零·硬性）：** 任何循环角色出现行动级偏离（=离岗/跨节点/结构性行动变更·统一定义见 §2.3；**轻微偏差不入 CT**）→ **当轮强制注册新 CT**（对抗双方 = Host vs 世界法则/编程枷锁，被争夺资源须具体化）或推进已有「Host vs 世界法则」型 CT 的节拍。②以下信号为**升级触发**（已有 CT 的紧迫度升级依据）：**a.** 同类偏离 ≥ 2 次（如 2-3 条「我做了脚本里没有的事→这让我疼」锚点）**b.** 偏离引发可观察的对抗张力（Host 行为让其他角色/系统产生反应）**c.** 偏离触及被争夺资源（记忆/自主性/身份等抽象资源被具体化）。

### 5.2 记忆提炼管道 B·循环触发器

提炼管道B 的循环专用触发（通用部分见 phase_actor.md「记忆锚点」写前五步）：**循环角色持续反抗脚本的偏离代价积累 3 条**（如「我做了脚本里没有的事→这让我疼」反复出现，见 §3）→ 抽象为一条信念 → 追加 `信念演化`。**管道B 只产出信念演化，不触发自主性升级**——升级唯一入口=§5.3 状态达标（压力临界+防御崩解）。

### 5.3 变质判定·循环角色附加动作

变质判定的循环专用附加动作：**循环角色（有 `自主性` 字段）→** 升级自主性：`脚本` → `漂移` → `觉醒` → `变质` ；每次极端冲击只升级一级，不跨级。自主性等级驱动记忆重置程度（§4 联动表）与行为偏差系数（§2.3）。**状态先行（硬性·升级唯一入口）：** 执行前**必须先查** CHAR_state 状态字段——① 压力水平 = `临界`？② 防御有效性 = `已彻底崩解`？**两问皆「是」→ 执行升级；任一「否」→ 重写行为而非升档**——行为异常（越档）不是升级依据，脚本档出现觉醒级行为=执行越界。**§记忆提炼管道B 不构成升级入口**——管道B 只产出信念演化（§5.2）。变质判定的通用核心（信念演化追加+叙事主导权转移）见 phase_actor.md「变质判定」。**升级轮状态处理（硬性·与 §5.3 动作④⑤同批）：** `压力水平` 回落至世界当前水平（④按该角色其余压力来源估定·非清零·默认非临界——升级消耗触发门槛·此后需重新积累方可再升）；**`防御有效性` 保持崩解·不随升级恢复**（回升唯一通道=防御重构）。**升级叙事（硬性）：** 升级轮必须生成关键事件叙事——疼痛峰值/记忆回涌爆发/主导权易手的戏剧时刻（升级=戏剧时刻，不是字段变更）。

## 6. 认知边界（认知约束·激活条件：SETTING 声明）

**定位：** 统一角色管理·世界法则①（见 references/phase_dramatist.md 五层模型）的认知侧约束——角色反应推导时的越界防线。与 §2.2 重置/偏离落点并列：§2.2 管「世界法则对角色做了什么」，本节管「角色知道自己多少」。

**激活条件：** SETTING.md 声明「角色深层设定默认不显现」类法则（如 Westworld=Host 认知边界法则：表层人格=默认自我·深层默认不显现）。未声明 → 本节整节跳过，不检查、不执行、不写入。

**检查（每轮·对每个被推导反应的角色）：**
- 该角色反应是否以深层设定（深层 Desire/觉醒驱动/潜藏能力/被压制的基石真相）为行为依据？
- 深层设定是否出现在默认行为、心理活动或对外表达中？

**违规判定（越界）：** 深层设定出现在上述任一位置，且该角色档案未标注「觉醒/已激活/可揭示」→ 越界。

**处理：** 重写该反应为表层行为 + 极细微裂缝（一瞬停顿/瞳孔放空/既视感/一句不属于脚本的话），裂缝受角色感知边界约束——自主性联动：`脚本`=无自觉 / `漂移`=隐约不适+碎片 / `觉醒`=清醒承受 / `变质`=全部摊开。

**豁免：** 档案明确标注「觉醒」「已激活」「可揭示」的条目（该条目可显现）。
