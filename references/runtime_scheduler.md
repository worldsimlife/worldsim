## 0. 核心模型与术语

**核心模型：** `①②被调度指令/基线/兜底唤醒·③每轮检波（调度者本体）·④⑤⑥恒跑（快路径）`。执行顺序 `①→②→③→④→⑤→⑥` 永不变——①②为条件插入段（未唤醒=空位·直接进入下一阶段）。

| 术语 | 定义 |
|---|---|
| 调度信号 | 决定本轮结构层该不该跑的信号（机械/语义两类） |
| 结构基线 | `conflicts 有≥1 活跃 CT` ∧ `storylines 有≥1 活跃线` ∧ `direction.当前拍 非空`——齐备=世界结构可演；任一缺=强制结构轮 |
| 强制结构轮 | ①②③全跑·不可豁免（基线缺失） |
| 结构轮 | ③回判信号命中·全量批 |
| 日常轮 | ③回判=继续当前拍·无结构信号——不重排/不发指令，但 **guidance+调度单逐轮照写**（取消复用） |
| 调度指令 | ③写 direction 的待办字段——下游消费（字段语义见 keys.md「direction.yaml」节） |
| Runtime Context | ③向下供给④的编译产物（direction 拍级字段）——消费端=④（见 phase_actor 数据就绪） |

## 1. 调度判定三级（按序取首个命中·SKILL.md Step1）

| 级 | 信号 | 数据源 | 可判性 | 结果 |
|---|---|---|---|---|
| 1 | **结构基线缺失** | conflicts/storylines/direction 三字段 | 机械（precheck 读） | 强制结构轮（①②③全跑·不可豁免） |
| 2 | **调度指令在场** | direction.escalation_flags | 机械（precheck 读） | 对应层被唤醒（①/②） |
| 3 | **语义匹配** | 用户指令（冲突压力）+ 循环轨道偏离（§1b 对照） | Step1 快速判定 | ①被唤醒 |

**调度分工：** precheck=纯脚本机械信号（级1/2）；Step1=语义匹配（级3）；③导演=深度分析决策（拍问题/张力/意外——产出调度指令写回 direction 供下轮 precheck 消费）；①/②=被唤醒后深度处理。

## 2. 唤醒清单（谁被唤醒·判定视角·非各层细则）

| 层 | 唤醒信号 | 来源 |
|---|---|---|
| ① 戏剧家 | 基线缺失 / `停滞` / `CT待结算` / `偏离提示` / **顶点拍**（`direction.当前拍==顶点`·机械信号·①每轮核对/登记本拍爆破源载体） / **循环轨道偏离**（Step1 语义匹配·§1b 判「该在/实际在」）/ 用户指令含冲突压力（Step1 语义匹配） | precheck + Step1 |
| ② 编剧 | 基线缺失 / `不承接` / 空表+指针非空 / 未引用CT且无活跃线可接 / 拍答后收束（advance 触发） | precheck + 回判 |
| ③ 导演 | 恒跑（检波器）；结构轮=回判信号命中·初始化轮=基线缺失·日常轮=无信号 | — |
| ⑤ 场记 | 恒跑；转场/cast基线/重置 仍为触发式（原规则不变） | precheck |
| ④⑥ | 恒跑（快路径·无调度概念） | — |

**兜底：** 窗口耗尽的验收点本身即兜底——③回判进入行6 且窗口已耗尽（拍烧穿整轮预算仍未推进）→ 批内重设窗口 **且** 写 `escalation_flags.停滞` → ①次轮加压；意图不能明显逼近时按行5 直接落 `停滞`。二者共用同一旗标·不另设计数器。

## 3. 调度指令协议（跨层规则·③写·下游消费）

- **指令生命周期**：③写 → 消费方批次含必含项（gate 放行）→ ③本轮回判清除（direction 唯一写者·与停滞/不承接「前置簿记」协议一致）——防残留重复触发。
- **多指令并集=一次结构轮**：停滞+CT待结算同场→①一次批=加压+结算；不承接+advance 同场→②一次批=三问+收束。
- **指令禁写剧情安排**：调度指令=机械待办（谁/盯什么/谁消化·场级）；剧情指挥（哪角色做什么）= guidance/调度单（见 phase_director 职责4/7）。
- **指令语义限定**：仅 `escalation_flags` 枚举值（停滞/不承接/CT待结算/偏离提示）——**不新增 direction 顶层键**（白名单见 keys.md；防镜像拦截）。

## 4. 与 precheck / gate / 回判的分工

- **precheck = 调度信号导出器**：结构基线+指令在场+原机械义务（停滞/不承接/空表/顶点/时间窗口状态/转场/区域/跨天/cast/变质/重置+SNAPSHOT 参考数据）→ 输出「**谁被唤醒**（首行唤醒判定：①/② 唤醒或未唤醒+机械原因·③ 轮型·④⑤⑥ 恒跑）+必含项」；只读·exit 0 恒过·不拦截。
- **gate = 最终拦截**：调度指令在场但消费方批次缺必含项 → exit 1（机械硬拦）；角色层/场记层/作家层每轮检查一口不漏。
- **回判 = 语义层**：precheck 信号=回判的机械输入；回判产出=下轮 precheck 的信号来源（指令写回 direction）。两者循环接力·各司其职。
