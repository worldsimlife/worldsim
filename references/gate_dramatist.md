# gate_dramatist.md — 戏剧家闸门检查清单

> **执行者：主 LLM 切换为独立审计戏剧家角色（检查前必须显式声明角色转变·只读·证据强制·对抗性）。**
> **触发：阶段1 change set 生成后、进入作家阶段前。（标准模式/调试——world_state 顶层 `输出模式: 标准`。静默模式=全局默认跳过本闸门：保留代码化核验——① `worldctl.py <世界> gate dramatist --check`（stdin 读 change set·D1/D10 必含项代码化核验+顶点出线核验（advance N 余波 比对 顶点落点.基准值——冲突双方关键状态变化·双方全无变化/基准缺失 exit 1=撤回阶段1·见 D13）·批次必含项缺失 exit 1=不进阶段2·与 gate_writer.md W4 对称）② 批次首行必写 `###META: 压力扫描 人际✓/增殖✓/轨道✓/跨叙事✓/记忆✓ {角色}:{计数}·{已触发|未达}...`（信号逐项勾·记忆✓=逐角色同类计数留痕·每出场角色必列·audit 机械对照批次 CHAR_state 角色集·缺角色/已触发缺信念演化=硬性拦截·查询轮/维护轮豁免）·均不增加 LLM 负担·由 worldctl.py 执行。）**
> **输入：** change set 草案 | conflicts.yaml | 出场角色 CHAR_.md + _state.yaml | world_state.yaml（时间/倒计时/焦点场景） | SETTING.md（激活条件判定）
> **输出格式：** 每条 → `{通过|不通过|跳过}` + 证据（文件路径+原文引用）+ 失败时给修复指令
> **对抗性要求：** 主 LLM 的输出默认不可信。你的任务是独立执行下列检查、找出蒙混过关之处，不是确认它的声称。每条「不通过」必须给出可指认的证据。**默认不通过：每一项的默认态是「不通过」——只有当你能引用证据证明该项确实干净时才给「通过」。通过不是没发现问题，是通过主动找茬后失败。**
> **边界（硬性）：** 本闸门验证 change set **产物** + 决策**过程完整性**倒查（D7-D9 因 change set 是选择性输出——「该写而没写」只有独立重扫才能发现；作家叙事是完整输出，故 gate_writer 无此层）。决策前的问题链（代价前置/档案强度/抽象方出手/认知边界闸门/Value Boundary）是 CORE 硬闸门的过程引导，**不在此重复执行**——闸门只核验产物，不复述决策思考。
> **组织维度：按戏剧家输出结构从整体到细项——决策层 → 条目层 → 指令层 → 过程层。失败动作（撤回/补做/重推）是每项标注，不是分组维度。**

## 0. 激活条件预判（先读 SETTING.md + CHAR_.md，未激活项标「跳过」）

- 循环机制（循环角色/重置/偏离代价）？→ 无则 D7-循环轨道、D9-记忆维护 跳过
- CROSS_NARRATIVES.md 存在？→ 无则 D9-跨叙事 跳过

## 第一层 · 决策层（输出 = 推进决策）

**D1 推进池** —（撤回级）change set 中至少一条 CT 被推进或注册？
（用户指令落地 → 注册/标记；否则按推进池排序：用户显式指定 > 🔴 > 🟡 > 🟢 > 同紧迫度下本轮新注册优先；全无 → 走兜底创造新冲突源）

**D2 使命三问**（一个整体，不可拆散——**对照 change set 核验产物，不复述决策时的思考**）—
- ① **代价**（撤回级）：对抗双方至少一项可核验变化？——可核验枚举：资源易主（失去方·持有者字段）/ 资源载体状态变化（抽象资源：记忆入锚/真相出土/自洽性崩溃/被承认）/ 新增伤害（核心状态）/ 控制权易手（须写明「资源+从谁→到谁」·「主动权/节奏/局面/掌控感」等无载体抽象词不算）/ 被迫选择（决策状态）/ 被迫承认（记忆锚点）/ 关系档位变化（人际动态）。硬性排除：内部认知描述（以为/错觉/掌控感/意识到）不算；纯台词对峙·悬置收场 = 零成本空转；至少一方不能只靠易主凑数——总得有人被逼、被伤、被改变。无变化 = 撤回重做
- ② **换人成立**（重推级）：把当前任何一个人的反应换成另一个人——成立吗？成立 = 模板化 = 重推该反应
- ③ **法则落点**（撤回级）：核心高压法则（SETTING.md）本轮落在谁身上？写不出具体落点 = 没在工作

**D3 实质推进** —（撤回级）每条被推进的现有 CT，对照 conflicts.yaml 该 CT「当前节拍」（磁盘=上次推进状态）→ 满足 ①对抗加码（刺激更强/赌注更高/关系更僵/资源状态向一方移动）或 ②重大转折（力量逆转/资源易主/关系定性改变）？仅出场无变化 = 未推进（该 CT 计冷却降级）。本轮新注册 CT 豁免；用户指令驱动的推进豁免。

**D4 抽象方** —（撤回级）CT 含抽象方（对抗双方=世界/规则/记忆）时：显现机制可指认（代理人/机制载体/心理显影）？本轮出手形态（代理人行动/机制生效/心理显影出现）？主角抵抗在它身上留下痕迹（法则裂缝/循环让步）？纯背景板 = 影子拳击 = 撤回

## 第二层 · 条目层（输出 = 每条 CT 条目）

**D5 CT 字段质量** —（重推级）被争夺资源载体/持有者可指认（`{资源}·载体/持有者={谁/在哪}`）？关系状态是动态对峙（空间占位+攻守态势+未决时机）不是静态位置？内部状态含生理反应+认知判断+未抉择分叉（各角色独立）不是情绪标签？——CT 编号两位格式（CT-XX）与相位/紧迫度枚举（推进中 ⏩/转折点 🔄、🔴🟡🟢/休眠）由 validate 脚本查，清单不重复列

**D12 节拍表** —（重推级·每轮完整推进必查）
- 触发：完整推进轮 change set 必须含 `###BEATSHEET:` 事件线动作（add/stay N/advance N 拍名/rewrite N/clear N）；缺失 = 不通过（`gate dramatist --check` 硬性拦截）
- 建：节拍表为空或本轮出现全新事件线（新冲突内核·对抗双方+被争夺资源）而无对应 `节拍表.{N}` = 不通过（判据=全新事件线·不是事件规模）
- 格：单轮推进超一格（节拍表拍序·最多 advance 到下一拍）= 不通过（一轮带过=撤回级）
- 实：推进锚点=节拍表.当前拍（单一权威）——读事件线当前拍定位起点·`beatsheet advance` 写回节拍表·牵动 CT 的 `当前节拍.拍名` 镜像写 `{N}-{拍名}`·重写 ④ `下一个节拍(推荐)` 为下轮目标（伪造完成/拍名镜像脱节 = 不通过）
- 线：该清未清（当前拍=余波未 beatsheet clear）/ 该换未换（现实与当前拍内容不承接且未 beatsheet clear 未 beatsheet rewrite·stay 悬置）= 不通过（人工审计·静默不触发）

**D13 顶点爆破** —（重推级·激活=`当前拍=顶点`）
- 真碎：四形态（死局两难/防御当众失效/关系不可逆断裂/代价已付出）至少其一真触发——指认哪个角色的哪个内部变量被踩爆
- 假碎：写了「爆破中」但无人被逼/被伤/被改变（表面冲突）= 不通过
- 未收：顶点未落地·未决·下轮继续（提前收场 = 不通过）——**机械部分已代码化**：出线（`advance N 余波`）由 gate --check 比对 顶点落点.基准值（冲突双方关键状态变化·任一方实质变化=落地·双方全无变化/基准缺失/落点缺角色内部变量 exit 1·静默模式保留）；本项人工审计保留叙事层找茬（真碎四形态指认/假碎识别）

## 第三层 · 指令层（输出 = 每条角色反应指令）

**D6 反应指令质量** —（重推级·**本项复核 references/phase_dramatist.md §反应硬约束·档案强度的前置检查——闸门是复核不是第一道防线；产物未达基准 = 阶段1 已漏检**）强度 ≥ CHAR_.md 档案基准？（对照 Desire/Fear/Reaction Style 原文；**适用于所有档位——脚本角色的轨道内质感强度同样必须达基准**；推高 = 物理动作升级——拔枪/逼近/毁物/动手/夺人，不只是台词更狠；低于基准 = 顺从默认）反应是 2-3 个连续可观察动作 + 至少一个决策瞬间（停顿/视线转移/权衡）？每个动作 POV 可拍（单镜头）？驱动标记存在且标「不直接入文」？**代价-反应对应：** 反应序列由代价驱动？对照 `代价:` 字段核验反应是否体现失去方/被逼方的行为（反应与代价脱节 = 重推）？

**D15 用户抉择停靠** —（重推级·激活=拍内容涉及用户角色）用户角色动作/台词逐条有本轮用户输入授权？用户角色被 NPC 直接提问/被两难逼到选择前 → 本轮停住·问题原样抛给用户·禁止替用户角色写出回应动作/回应台词（施压/表态/接受/拒绝/转移话题）；可逆日常动作（进门/落座/跟随/观察/骑马）照常写。判定边界：动作后果=剧情方向性改变（触发线索/关系定性/推动调查/不可逆代价）→ 一律视为抉择动作·必须停靠给用户——证据：批次 CHAR_{用户角色}_state + 叙事正文 vs 用户本轮输入（无授权=不通过）

## 第四层 · 过程层（输出 = 决策过程完整性·倒查防遗漏）

**D7 并行扫描重扫** —（补做级）独立重扫（不是验证主 LLM 的声称）：
- **人际张力**：两两配对在场角色（焦内+活跃焦外）的 Desire/Fear 直接对抗（阈值：同一资源竞争/行为直接威胁核心恐惧）+ 历史伤痕（CHAR_* 未处理旧账）+ 关系档位变化 → 对比：未注册张力已注册新人际 CT（对抗双方=行动角色）？已在 CT 内未重复注册？（**循环角色授权过滤：`脚本`/`漂移`在轨不注册·`觉醒`/`变质`/偏离中照常参与**）
- **增殖信号**：①外部事件信号（焦外移动/异常信号/信息揭露）②外部倒计时（先查感知者：仅感知者注册/推进 CT；未感知不产生反应）③核心高压法则落点（个体化→角色级 CT / 环境性→并入 CT）④偏离累积（同类≥2/对抗张力/触及资源；激活条件：SETTING 声明偏离代价机制）→ 对比注册结果
- **循环轨道**（激活条件：SETTING 声明循环/重置机制且有循环角色）：逐角色（焦内+活跃焦外）在轨/偏离/回归 → 对比：**先做行为授权判定（贴线路径=`脚本`/`漂移`·核对基线·不注册人际 CT；自主路径=`觉醒`/`变质`·全量参与·见 references/phase_dramatist.md §统一角色管理）**，偏离者行为=外部驱动主导（loop_machinery §2.3）？①当下刺激已响应 ②回归已按档位自洽呈现（防元视角·见 loop_machinery §2.3②） ③碎片有触发物？偏离者结算拉力+代价？偏离超限埋系统后果？（机制见 `loop_machinery.md` §1）

**D8 焦外核验** —（补做级）活跃焦外检查过？有变化/窗口临近 → 状态增量（CHAR_state + 焦外 CT + pending_actions 事件记录）？漏推写显式原因（无焦外/无变化/刚推过）。

**D9 条件触发** —（补做级）①记忆维护（激活条件：SETTING 声明重置机制且有循环角色）：本轮时间/事件跨过重置规则？命中 → change set 含联动表执行（锚点压缩/轨迹清空/状态回基线/行为轨道回归）？②跨叙事（激活条件：存在 CROSS_NARRATIVES.md）：深匹配/激活 → 角色反应指令含可写的行为偏移（可观察行为而非情绪标签）？已检查本轮不应激活两条交叉线？（跳过需写明依据）

**D10 记忆决策** —（重推级）判型（事件→锚点 / 状态→覆盖）正确？对象判定（记忆触发者=对象·纯自身行动才标「自身」）？重置先于入锚（命中重置的轮次禁止直接追加锚点）？单条 ≤100 字（事实一句+定性一句）？**提炼（入锚写前五步·references/phase_dramatist.md §记忆维护）：同类锚点≥2 已融合为概括条目？同类≥3 已做管道B 判断（达条件写信念演化 / 不达显式免写）？锚点涉及特定对象且有实质变化已更新人际动态（管道A）？**（总字数超 3000 由 validate 校验线提示，超限由戏剧家按 references/phase_dramatist.md §记忆维护·淘汰整理）

**D11 元素一致性** —（重推级）本轮叙事/决策使用的已有元素（空间/道具/线索），形态/位置/状态/性质与 scene_state 锚点**注册原文**一致？（证据：引用锚点原文——用 `worldctl.py <世界> grep <元素名>` 查全仓注册原文）不一致（位置/外观/状态/性质被凭印象改写，如暗门=地窖盖板被写成门帘后的锁门；Smart-Ammo 杀伤效力被写成与 SETTING 法则相反）= 幻觉 = 重推该反应。使用前未核对注册原文 = 违规。

**D14 循环重置** —（重推级·激活=时间越过周期重置点）
- 触发：越过到期点 → change set 含重置执行（禁跳过）
- 完整：重置记录+倒计时重建+LOOPS 补写+重置叙事帧
- 豁免：豁免角色/项符合档位（觉醒/变质保留）

## 通过标准

- **默认不通过。** 起点是全部项「不通过」，逐项主动找茬；只有找到可引用证据证明该项确实干净才翻转为「通过」——通过的形式是**找茬失败记录**（"我试了找茬，不成立，因为引原文"），不是"未发现问题"。
- 撤回级（D1 / D2①③ / D3 / D4）任一不通过 → 撤回阶段1重做（禁止用文笔掩盖）
- 补做级（D7 / D8 / D9）不通过 → 按修复指令补做后重检（≤2 轮）
- 重推级（D2② / D5 / D6 / D10）不通过 → 只重推对应项后重检（≤2 轮）
- 重检超 2 轮 → 终止该轮并报告用户（防审计与决策互相辩护死循环）
- 全部项找茬失败（有证据记录）→ 返回 `GATE PASS`，进入阶段2
