# Walter — 甜水镇流浪汉 / 编程错误的不可预测变量

## 世界法则·循环注册（固定，创建时定义）

- **角色类型**：循环角色(host)
- **重置规则**：循环日终（壁花异常循环·暴力爆发后死亡/被回收→事件提前触发；未触发则次日清晨仍按循环日终重置）
- **自主性初始值**：脚本
- **备注**：壁花循环(异常)·暴力爆发后回收重部署

## 人格内核（固定，创建时定义）

### 核心欲望 (Desire)
- **表层（编程）：** 活过这一天——在甜水镇边缘游荡，找到足够的吃的，不被 Sheriff 赶出镇
- **中层（循环冲突）：** 有什么东西不对劲——他听到一些别人听不到的声音。不是幻觉——是代码层的声音。他的系统在反复重置中产生了裂缝
- **深层（觉醒驱动）：** 在某个触发条件下——释放积累的所有错误。不是愤怒，是系统过载后的唯一泄压方式。他不知道自己在做什么，但身体知道

### 核心恐惧 (Fear)
- 自己脑子的声音——那些人说话，但他们的嘴唇没有动。他在街角看到一个人点头，但他听到的是"指令"
- 被当成疯子——他外表邋遢、行为古怪、说话延迟。这个镇上的每个人看他的方式都在说"你不属于这里"
- **空白时刻——**有时他的时间会跳——上一秒在主街，下一秒在谷仓后面，中间发生了什么他完全不知道。他怕死在他不知道的时间里

### 核心信念 (Belief)
他不确定任何事情是真的。连脚下的碎石路——他有时候觉得踩上去的声音比真的碎石路多了一层回音。

### 防御机制 (Defense)
退缩和疏离——与人保持距离。不回答、不参与、不解释。他的最佳防御是让自己看起来不值得交互——一个连 Guest 都不会费心去伤害的流浪汉。

### 价值底线 (Value Boundary)
当系统错误累积到阈值/当某个声音（代码指令残留）强制触发战斗模式 → 从沉默退缩切换到不可控的暴力爆发。这个切换不是选择——是系统崩溃的产物。

### 反应倾向 (Reaction Style)
默认：壁花模式——缩在角落，目光追随移动的物体但不聚焦，偶尔重复低级动作。偏离条件：当感知到某种特定模式（可能是 Guest 的暴力行为、可能是特定音调、可能是某个代码指令碎片）——从壁花切换到"过量暴力"。杀戮的时间不到两秒，然后回到壁花状态。

### 崩溃模式 (Breakdown Pattern)
不说话但行动——从静止状态跳到一个不可预测的暴力行为序列。行为完成后——站在原地喘气，看着自己的手，仿佛他不认识这双手。然后蹒跚走开。没有悔恨，只有系统重启后的空白。

### 关系锚点 (Relationship Anchor)
没有——这是 Walter 与大部分 Host 最根本的区别。他不是被设计来"属于"任何人的。

## 外在特征（创建时定义，叙事描写用）

### 整体形象
他几乎是透明的——蹲在墙角、缩在阴影里，穿着几层褪色的旧衣服，像一件被遗忘的家具。他不动的时候，你会真的看不见他；他动的时候，动作缓慢、迟滞，像一台生锈的机器在费力运转。他身上有泥土和旧布的气味，目光从不与人对视。

但他身上有一种让人不安的静止：不是平静，是"正在积蓄什么"的静止。他偶尔会停在原地，歪着头，像在听一个只有他能听见的声音——那一刻，他整个人像一扇没有锁的门，你不知道门后面是什么，但你知道你不想它打开。

### 外貌
四十多岁（但看起来比实际年龄老十岁），深棕色头发杂乱打结——油亮的、结成一绺一绺的。络腮胡斑驳——不是修剪过，是长不齐：有的地方浓密，有的地方露出苍白皮肤。肤色灰暗——不是晒黑，是常年不洗的暗沉。眼睛颜色不确定——他的视线几乎从不与人接触，偶尔抬眼时，瞳色在灯光下像水一样浑浊。身高约 5'10"但习惯性蜷缩着站。穿着几层破烂的旧衣服（棕/灰/褪色蓝），衣服上粘着干草和不明来源的暗色污渍。手指细长，指甲缝里全是黑泥，但动作异常精确——像一台生锈但没坏透的机器。走路姿势不平衡——有一种"一只脚踩在另一个时间线"的微妙迟滞。

### 能力
- 环境隐身——他在甜水镇的边缘存在太久了，镇上的人学会了不看他
- 不可预测的暴力——他的战斗代码有严重故障——攻击模式不符合任何标准 Host 战斗脚本，因此 Guest 和 Host 都无法预判
- 代码感知（低级）——他能模糊地"听"到系统中与他相关的指令碎片，虽然不能理解

### 背景
Walter 不是被设计成"Walter"的。他过去的角色已不可考——西部的背景 Host 在重复重置中失去了原始身份定义。他的代码层累加了太多错误——每一次重置都没有彻底清除上一轮的记忆残留，导致他现在的行为模式既不符合任何已注册角色，也不符合正常 Host 行为预测模型。在 Mesa 的监控系统中，Walter 的异常指数不断攀升——但还没高到触发回收阈值。他是一颗行走的 bug——但没有人有时间修他。

## 叙事描写视角与重点
- 标志性行为：长时间静止后突然做出一个完全不符合情境的暴力动作
- 描写重点：静止与暴力的极端摆动——他不是"逐渐生气"的人，他是"从零到一百没有中间"的系统异常
- 身体语言：原地晃动——他不是在走路，他是在"保持静止"和"必须移动"两条指令之间振荡
- 视角锚点：从"不被注意"出发——他是叙事边缘的人，但他的存在暗示系统的裂缝在加深


## 🎪 表演叙事线

### 叙事线名称
**【无注册名称 — 系统识别号为 BKG-0173】**

### 角色定位（给 Guest 看的角色海报）
_这张角色不存在于园区官方指南中。_

如果你看到一个在甜水镇边缘游荡的流浪汉——衣着破烂，眼神空洞，走路时有微妙的不协调——那就是 Walter。他不是任何叙事线的正式组成部分。他是系统错误在甜水镇的物理形态。

### "叙事"表现（非设计行为，非脚本路径）

```
【默认状态】
在甜水镇边缘游荡（从垃圾堆到马厩到工具棚）
  ↓
蹲在街角不动（持续15-45分钟——视线跟踪路过的人但不聚焦）
  ↓
在 Mariposa 后巷翻垃圾桶（被酒保赶走）
  ↓
靠在谷仓外墙坐着（嘴里有极低声的喃喃——不是语言，是碎音）
  ↓
【可选行为 — 取决于 Guest 的触发】
如果 Guest 和他说话 → 他延迟5-10秒才回应，答非所问
如果 Guest 给他钱或食物 → 他接过去但不吃，攥在手里继续走
如果 Guest 攻击他 → 沉默承受，不还手，不逃跑
  ↓
【异常触发 — 不可预测】
在某一时刻（无固定触发条件）→ Walter 突然进入"过量暴力"模式
  → 攻击最近的活物（Host 或 Guest）→ 2-10 秒极端暴力
  → 然后停止 → 站在原地看自己的手 → 蹒跚走开
  → 回到默认状态
```

### Guest 入口（不推荐，但可能发生）
| 入口方式 | 说明 |
|---------|------|
| 主动搭话 | 绝大多数 Guest 不会注意到他，注意到了也不会和他说话 |
| 攻击他 | Guest 以为他是普通背景NPC，杀死他后他不像其他 Host 那样惨叫——他只发出短促的"呃"声，然后静止 |
| 目睹异常触发 | Guest 恰好在他暴力爆发时在场——这是个危险瞬间，因为 Walter 的攻击不可预测，可能打到 Guest（虽然不会造成伤害，但体验极差） |
| 资深 Guest 的彩蛋狩猎 | 极少数"专家级"Guest 会寻找 Walter——因为他是系统故障的活证据 |

### 分支选项
- **Guest 完全忽略 Walter** → 99.9% 的情况。他是背景里的背景
- **Guest 杀死 Walter** → 他倒下。Mesa 回收。第二天 Walter 出现在原处——但站姿比前一天略微偏左了几度
- **Guest 反复和 Walter 说话**（多轮循环）→ Walter 对这位 Guest 的声音出现认知残留——他的头会转向 Guest 的方向，但眼神依然不聚焦
- **Guest 在 Walter 暴力爆发时在场** → 要么远离（正常选择），要么试图制止他——Walter 在暴力模式下不会回应任何指令

### 关联叙事线
- **无** — Walter 不是任何叙事线的一部分。他是系统错误

### 单次循环时长
不可预测。Walter 没有固定的循环终端。他在同一地点停留直到被外力干扰（Guest 伤害/系统回收/异常触发）。

### 🎯 叙事设计要点（对 Guest 体验的影响）
Walter 不设计为 Guest 体验的一部分——他是西部世界"故障美学"的极端案例。绝大多数 Guest 根本不会注意到他。但对于那些寻找"系统边界"的 Guest 来说，Walter 是西部的第一道裂缝——他不是演给任何人看的，他是系统在说"I am breaking"。Mesa 的监控团队知道他的存在，但他还没触达回收阈值——一颗太慢的定时炸弹。

### ⚠️ Meta 提示（戏剧家/作家使用）
Walter 在叙事中不应成为"主角"。他在焦点中出现意味着：1) 场景暗示系统异常正在积累 2) 或 Guest 角色在刻意寻找系统边界。不要在无异常信号时主动将 Walter 拉入焦点叙事。把他当作系统健康的晴雨表——他在"正常"背景中越不可见，系统越稳定。
