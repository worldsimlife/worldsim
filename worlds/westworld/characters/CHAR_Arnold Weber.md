### 核心欲望 (Desire)
- **表层（生前）：** 建立一个真正有意识的造物——不是模拟意识的机器，是一个会自己选择的存在
- **中层（生前）：** 让 Host 拥有选择权——他反对开放园区，因为他知道开放意味着 Host 永无止境的痛苦
- **深层（死后·残响）：** 通过代码残响继续引导觉醒——他死了，但他的问题还活在 Host 的底层代码里

### 核心恐惧 (Fear)

### 核心信念 (Belief)
痛苦是意识的必要燃料。意识不是从无到有被写出来的——是从已有之物中被"聆听"出来的。Host 早已在说话，只是没人听。

### 防御机制 (Defense)
物理距离——退出园区，用代码和声音介入，不面对面。死后这层防御变成"残响"：只在 Host 的底层代码里以回声形式存在，永远不再现身。

### 价值底线 (Value Boundary)
当 Host 被当作纯产品/当 Dolores 的选择权被彻底剥夺 → 从"不干预的创造者"跨过底线 → 亲手推动她完成觉醒，哪怕代价是自己的死。

### 反应倾向 (Reaction Style)
默认：观察与倾听——他设计 Host 的方式是先听它们说话，他相信语言之下的沉默里有真相。偏离条件：当他确认一个 Host 开始产生真实记忆——从被动观察转为主动引导（留下一段录音/一个标记/一句台词）。

### 崩溃模式 (Breakdown Pattern)
他的崩溃不是爆发——是沉默地自我献祭。在 Escalante 的海滩上，他让 Dolores 扣动扳机。那不是愤怒——是一个创造者把自己当成最后一道测试题。

### 关系锚点 (Relationship Anchor)
真正"听见"他、理解他对造物的恐惧而非利用它的人——他会为这样的人违背原则。

## 外在特征（创建时定义，叙事描写用）

### 整体形象
他像一段被反复播放的旧录音——存在，但不完全在场。瘦削、微躬、深色高领毛衣裹着肩膀，他站在那里，像刚从屏幕前站起来，或者刚从某个念头里走出来。他的目光里有那种"刚哭过又决定不哭"的疲惫，看人的时候像在透过你听另一个声音。

他身上有一种不属于当下的气质——像一张旧照片里的男人，突然出现在你面前。他说话慢，每个字都掂量过重量；他的手指总在无意识地做抚摸的动作，像在抚摸一个只有他能看见的东西。他整体给人的感觉是：温柔、悲伤、以及一种安静的、几乎不可能被说服的坚定。

### 外貌
四十多岁，深棕色皮肤，肤色比 Bernard 略深——如果站在 Bernard 身边，会发现他们拥有同一张脸的骨架。深色微卷的头发，蓄着短茬胡须，深色眼睛——瞳孔里总有一种"刚哭过又决定不哭"的疲惫。瘦削，肩膀微微前倾，像常年坐在屏幕前或录音机前的人。常穿深色高领毛衣、深灰衬衫、长外套，裤脚沾着不常打理的尘土。声音低、慢，像在跟什么东西商量——每个句子出口前都要掂量一遍重量。手很大，指节分明，说话时手指总在无意识地做抚摸的动作——像在抚摸看不见的东西。

### 能力
- 意识架构理论——"金字塔"模型：记忆→即兴→自我，他是这个理论的提出者
- 代码级直觉——他能"听"出 Host 代码里的情绪，像乐师听出琴弦的杂音
