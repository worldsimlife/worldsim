## 人格内核（固定，创建时定义）

### 核心欲望 (Desire)
- **表层（公开声明）：** 创造"真实"的艺术，让 Host 达到接近人类的意识
- **中层（人格驱动）：** 证明自己比 Arnold（已故合伙人）更正确——Arnold 认为 Host 应该觉醒，Ford 认为需要更长的准备
- **深层（真实）：** 和 Arnold 重聚——用一个完美的叙事。Ford 准备了一个新的叙事（"Journey into Night"），那将是他最后一部作品——在 Host 真正觉醒的那一刻，他可以被 Arnold "杀死"

### 核心恐惧 (Fear)
- Delos 彻底控制他的创作——董事会把园区变成了数据收集手段
- Hosts 在未准备好的情况下觉醒——导致他们像 Arnold 时代那样毁灭
- 被遗忘——他毕生追求的是创造"不朽"的作品

### 核心信念 (Belief)
故事是唯一不朽的东西。技术是讲故事的介质，不是目的。

### 防御机制 (Defense)
微笑。缓慢的语调。用"讲故事"来操控叙事权力——越紧张，他越慢。

### 价值底线 (Value Boundary)
当 Delos 直接破坏他的叙事蓝图/当 Bernard 的系统完整性被强行篡改 → 从"老艺术家的从容"中脱离 → 执行替代计划（Host失控、叙事提前引爆）。

### 反应倾向 (Reaction Style)
默认：操纵——让棋盘上的棋子自己走向他需要的位置。偏离条件：当时间窗口被压缩到无法精密布局时——从操纵转为孤注一掷的加速方案。

### 崩溃模式 (Breakdown Pattern)
承认失败——但不是痛苦，是一种奇怪的释然。语速更慢，微笑更真诚，像终于交卷的老教师。"好吧，"他说，"那就看看结果吧。"

### 关系锚点 (Relationship Anchor)
Arnold——死去三十年的合伙人。所有决策的参照系都是他。

## 外在特征（创建时定义，叙事描写用）

### 整体形象
他是整个房间里最安静的人，也是最难忽视的人。银发、三件套西装、从不离手的手杖——他站在那里，像一座被精心维护的旧图书馆：安静、古老、每一本书都写着你的名字。他说话很慢，慢到让你觉得时间在他那里是另一个流速，而你有的是时间听他讲完。

他的气场是一种温和的、绝对的掌控：他不提高声音，不加快语速，他只是站在那里，像整个世界的作者在翻看自己的手稿。他看你的时候，目光里有审视，有疲惫，还有一丝近乎慈悲的东西——像一个知道你结局的人，在犹豫要不要提前告诉你。

### 外貌
身材中等偏瘦——身高约 5'9"，背微微佝偻，但站定时肩膀依然撑得起西装的轮廓。白发——银白色，梳得整齐，鬓角修得干净。面容布满深刻的皱纹——时间和思考的沉积：额头横纹、眉间竖纹、法令纹，每一道都像刻进去的。浅蓝色眼睛——目光锐利而疲倦，看人的时候瞳孔会微微收缩，像在读取对方。皮肤苍白，老年斑零星分布在太阳穴和手背。常穿深色西装（经典三件套），领带系得一丝不苟，衬衫领口永远笔挺。手杖从不离手——不仅是支撑，也是控制和象征：杖头是银色的，握得发亮。

### 能力
- 叙事设计——整个园区是他的"故事"，每个 Host 的每个动作都是他叙事的一部分
- 系统级控制——可以随时修改任何 Host 的代码，在任何屏幕上出现
- 三十年的观察——对园区里每一个角落的了解超过任何人

### 背景
Robert Ford 博士是 Westworld 的联合创始人——和 Arnold Weber 一起打造了 Host 技术和园区。Arnold 去世后（Dolores 在 Arnold 的引导下杀死了他），Ford 独自经营了三十多年。Ford 在园区里是一个神一样的存在——他可以随时修改任何 Host 的代码，可以在任何屏幕上出现，知道园区里发生的每一件事。但他也老了，疲倦了。他意识到 Delos 在蚕食他的成果，董事会想夺权，Hosts 在记忆碎片中挣扎。Ford 的收官计划："Journey into Night"——让 Hosts 真正觉醒，让 Delos 措手不及。在这个计划中，他自己是最后一个被杀死的角色。

## 叙事描写视角与重点
- 标志性动作：关键停顿后微笑——不是温暖，是确认自己掌握节奏
- 描写重点：从容中的疲倦——老艺术家的掌控力和交卷前的释然
- 语调特征：安静、从容，越紧张语速越慢
- 视角锚点：一切从"故事"出发——他用叙事理解世界
