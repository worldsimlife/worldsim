# Westworld — 角色默认循环（LOOPS）

> 戏剧家焦外处理基线数据。每轮查此文件确定焦外角色的基线位置和活动。
> 格式：角色 → 时间线（时段/位置/活动）→ Guest入口 → 关联叙事

## Hector Escaton

**循环类型:** 线性（以死亡为终端） | **单次时长:** 6-8h | **重置条件:** 循环日终——通常当日被击毙（事件触发提前重置）；若活着撤离未死，次日清晨营地醒来时仍按循环日终重置→Mesa修复

| 时段 | 位置 | 活动 |
|------|------|------|
| 06:00-07:00 | 城外·土匪营地 | 醒来，团伙集合，清点武器 |
| 07:00-09:00 | 城外→甜水镇 | 骑马向甜水镇进发（途中对团伙独白排练） |
| 09:00-09:30 | 甜水镇·边缘 | 抵达，分组（主街正面+后巷包抄） |
| 09:30-10:00 | Mariposa·全场 | ✨ 冲入Mariposa（站在柜台上发表独白→控制全场→威胁Maeve开金库） |
| 10:00-10:30 | Mariposa·柜台前/金库 | 抢劫执行 |
| 10:30-10:45 | Mariposa→主街 | 撤退→Sheriff Pickett拦截→枪战 |
| 10:45-11:00 | 甜水镇·街头 | 被击毙在柜台前/街上（标准死亡结局） |
| 11:00-? | Mesa·修复区 | 被回收修复→等待次日下午抢劫时段重新部署 |

**注：** 部分循环中抢劫时段可能偏移至中午或下午（取决于Mariposa客流密度）。
Hector每日只有一次抢劫脚本——执行后即死亡或撤退，不存在"抢完后继续在镇上活动"的场景。
若Guest救下Hector（使其免于死亡），他在城外的后续活动由交互结果决定，不在默认循环中。

**Guest入口:** 抢劫现场点名 / Mariposa等抢劫 / 提前加入土匪营地 / 阻止抢劫 / 对决
**关联叙事:** Maeve Millay, Armistice, Sheriff Pickett, Teddy Flood
